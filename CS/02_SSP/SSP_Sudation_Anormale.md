# SSP - Sudation Anormale (Hyperhidrose - Sueurs nocturnes)

## 🎯 ANAMNÈSE (25%)

### Caractérisation de la sudation
- **Localisation** :
  - Généralisée vs localisée
  - Axillaire, palmaire, plantaire, faciale
  - Zones spécifiques : front, nuque, thorax
- **Qualité** :
  - Abondance : légère, modérée, profuse
  - Aspect : claire, colorée, malodorante
  - Sensation : froide vs chaude
- **Temporalité** :
  - Durée épisodes, fréquence
  - Moment : diurne, nocturne, mixte
  - Évolution : récente, chronique, progressive

### Circonstances de survenue
- **Facteurs déclenchants** :
  - **Physiologiques** : effort, chaleur, stress, émotions
  - **Alimentaires** : aliments épicés, alcool, caféine
  - **Positionnels** : décubitus, orthostatisme
  - **Horaires** : nocturne (réveils en sueur), matinale
- **Facteurs apaisants** :
  - Repos, fraîcheur, retrait vêtements
  - Médications symptomatiques utilisées

### Sueurs nocturnes spécifiquement
- **Caractéristiques** :
  - Réveillent-elles le patient ?
  - Nécessité changer vêtements/draps ?
  - Localisation : généralisée vs régionale
- **Fréquence** : occasionnelles vs quotidiennes
- **Retentissement** : sommeil, fatigue diurne

### Symptômes associés
- **Généraux** :
  - Fièvre, frissons
  - Variation pondérale (perte/prise)
  - Fatigue, asthénie, malaise
  - Pâleur, flush cutané
- **Cardiovasculaires** :
  - Palpitations, tachycardie
  - Douleur thoracique
  - Hypertension, hypotension
- **Neurologiques** :
  - Céphalées, vertiges
  - Tremblements, anxiété
  - Troubles concentration
- **Digestifs** :
  - Nausées, vomissements
  - Diarrhée, constipation
  - Douleurs abdominales
- **Endocriniens** :
  - Intolérance chaleur/froid
  - Bouffées chaleur, flush
  - Troubles menstruels (femmes)

### Anamnèse spécialisée selon orientation

#### Hyperthyroïdie
- Perte de poids malgré appétit conservé/augmenté
- Intolérance à la chaleur
- Nervosité, irritabilité, insomnie
- Palpitations, tachycardie
- Tremblements fins des extrémités
- Troubles du transit (diarrhée)
- Aménorrhée, troubles libido

#### Ménopause/périménopause
- **Âge** : 45-55 ans typiquement
- **Troubles menstruels** : irrégularité, aménorrhée
- **Bouffées de chaleur** : montée brutale chaleur
- **Symptômes associés** : sécheresse vaginale, troubles sommeil
- **Durée** : depuis combien de temps ?

#### Phéochromocytome
- **Triade classique** : céphalées, palpitations, sueurs profuses
- **Crises paroxystiques** : début/fin brutaux
- **Facteurs déclenchants** : effort, stress, médicaments
- **Hypertension** : permanente ou paroxystique
- **Pâleur** pendant les crises

#### Causes infectieuses
- **Fièvre** : pic nocturne, rémissions diurnes
- **Symptômes infectieux** : toux, dyspnée, douleurs
- **Terrain** : immunodépression, voyage récent
- **Perte de poids** : progressive, importante

#### Causes néoplasiques
- **Symptômes B** : fièvre, sueurs nocturnes, perte de poids >10%
- **Adénopathies** : palpables, localisation
- **Masse palpable** : localisation, caractéristiques
- **Altération état général** : fatigue, anorexie

### Médicaments et toxiques
- **Médicaments actuels** :
  - Antidépresseurs (ISRS, tricycliques)
  - Hormones (œstrogènes, progestérone)
  - Médicaments cardiovasculaires
  - Antipyrétiques récents
- **Sevrage** : alcool, opiacés, benzodiazépines
- **Toxiques** : alcool chronique, drogues

### Antécédents et terrain
- **Endocriniens** : diabète, hyperthyroïdie, troubles surrénaliens
- **Psychiatriques** : anxiété, dépression, attaques panique
- **Néoplasiques** : cancers personnels/familiaux
- **Infectieux** : tuberculose, VIH, hépatites

## 👁️ EXAMEN PHYSIQUE (25%)

### Examen général
- **Signes vitaux** :
  - Température (fièvre ? hypothermie ?)
  - Tension artérielle (HTA ? hypotension ?)
  - Fréquence cardiaque (tachycardie ?)
  - Fréquence respiratoire
- **État nutritionnel** : poids (variation ?), BMI
- **État hydratation** : déshydratation, œdèmes

### Observation cutanée
- **Zones hypersudation** : palmes, plantes, axillaires, faciale
- **Aspect peau** :
  - Moiteur, sécheresse
  - Coloration : pâleur, flush, cyanose
  - Texture : fine (hyperthyroïdie), épaisse
- **Signes associés** :
  - Télangiectasies
  - Érythème palmaire
  - Acrocyanose

### Examen endocrinien
- **Thyroïde** :
  - Palpation : goitre, nodules
  - Signes hyperthyroïdie : exophtalmie, rétraction paupières
- **Signes hyperthyroïdie** :
  - Tremblements fins doigts étendus
  - Réflexes vifs, tachycardie
  - Peau chaude et moite
- **Signes ménopause** :
  - Atrophie muqueuses génitales
  - Signes hypœstrogénie

### Examen cardiovasculaire
- **Auscultation cardiaque** : rythme, souffles
- **Pouls** : fréquence, régularité, amplitude
- **Tension artérielle** :
  - Repos et effort
  - Différence couché/debout
  - MAPA si suspicion phéochromocytome

### Examen neurologique
- **État mental** : anxiété, agitation, confusion
- **Tremblements** : repos vs action, localisation
- **Réflexes ostéotendineux** : vifs (hyperthyroïdie)
- **Signes focaux** : déficit moteur/sensitif

### Recherche de causes secondaires
- **Adénopathies** : aires ganglionnaires
- **Hépato-splénomégalie**
- **Masses palpables** : abdominales, thyroïdiennes
- **Signes infectieux** : foyer pulmonaire, cutané

## 🔬 EXAMENS COMPLÉMENTAIRES (25%)

### Bilan de première intention
- **Biologie de base** :
  - FSC complète avec plaquettes
  - VS, CRP (syndrome inflammatoire)
  - Ionogramme, créatinine
  - Glycémie à jeun
  - Bilan hépatique complet
- **Fonction thyroïdienne** :
  - TSH, T4 libre (T3 libre si hyperthyroïdie)
  - Anticorps anti-TPO si goitre

### Explorations spécialisées selon orientation

#### Suspicion phéochromocytome
- **Métanéphrines** :
  - Urinaires sur 24h (plus spécifique)
  - Plasmatiques (plus sensible)
- **Catécholamines urinaires** (noradrénaline, adrénaline)
- **Test à la clonidine** si doute diagnostique
- **Imagerie** : IRM surrénaliennes si biologie positive

#### Suspicion ménopause
- **Hormones sexuelles** :
  - FSH, LH (élevées en ménopause)
  - Œstradiol (diminué)
  - AMH (hormone antimüllérienne)
- **Âge** et **contexte clinique** souvent suffisants

#### Recherche néoplasique
- **Marqueurs tumoraux** selon orientation :
  - LDH, β2-microglobuline (lymphomes)
  - PSA (homme >50 ans)
  - Marqueurs digestifs si indiqué
- **Imagerie** :
  - Radiographie thorax
  - Scanner thoraco-abdomino-pelvien si indications

#### Recherche infectieuse
- **Hémocultures** (si fièvre)
- **Sérologies spécifiques** : VIH, hépatites, CMV, EBV
- **Tuberculose** :
  - IDR/IGRA
  - Crachats BAAR, GeneXpert
  - Radiographie thorax

### Examens complémentaires avancés
- **Test sueur quantitatif** : cystic fibrosis (enfant)
- **Bilan auto-immun** si contexte évocateur
- **Échocardiographie** si cardiopathie suspectée

## 💊 PRISE EN CHARGE (25%)

### Diagnostic différentiel

#### Causes physiologiques
- **Effort physique**, chaleur ambiante
- **Stress émotionnel**, anxiété situationnelle
- **Alimentation** : épices, alcool, boissons chaudes
- **Vêtements** inadaptés, literie excessive

#### Causes endocriniennes
- **Hyperthyroïdie** (Basedow, nodule toxique)
- **Ménopause/périménopause**
- **Phéochromocytome** (rare mais grave)
- **Diabète** (hypoglycémies)
- **Acromégalie** (rare)

#### Causes médicamenteuses
- **Antidépresseurs** (ISRS, tricycliques, IMAO)
- **Hormones** : œstrogènes, testostérone
- **Sevrage** : alcool, opiacés, benzodiazépines
- **Autres** : aspirine, nitrés, calcium bloqueurs

#### Causes infectieuses
- **Tuberculose** (classique : sueurs nocturnes)
- **Endocardite**, sepsis
- **Infections virales** : CMV, EBV, VIH
- **Abcès profonds**

#### Causes néoplasiques
- **Lymphomes** (Hodgkin++, NH)
- **Leucémies**
- **Tumeurs solides** avancées
- **Syndrome carcinoïde**

#### Autres causes
- **Hyperhidrose primaire** (génétique)
- **Troubles psychiatriques** : anxiété, attaques panique
- **Reflux gastro-œsophagien** sévère
- **Sleep apnea syndrome**

### Traitement étiologique

#### Hyperthyroïdie
- **Antithyroïdiens de synthèse** (carbimazole, PTU)
- **Bêta-bloquants** (symptomatique)
- **Iode radioactif** ou chirurgie selon contexte

#### Ménopause
- **Traitement hormonal substitutif** si indiqué
- **Alternatives** : phytoestrogènes, ISRS
- **Mesures générales** : éviter facteurs déclenchants

#### Phéochromocytome
- **Préparation préopératoire** : α-bloquants puis β-bloquants
- **Chirurgie** : surrénalectomie
- **Urgence hypertensive** : phentolamine IV

#### Causes infectieuses
- **Antibiothérapie** adaptée selon pathogène
- **Antituberculeux** si tuberculose
- **Traitement symptomatique** infections virales

### Traitement symptomatique

#### Mesures générales
- **Environnementales** :
  - Température fraîche, ventilation
  - Vêtements légers, fibres naturelles
  - Literie adaptée, drap fin
- **Hygiène de vie** :
  - Éviter déclenchants : alcool, épices, stress
  - Douche tiède (pas chaude)
  - Hydratation suffisante

#### Hyperhidrose localisée
- **Antiperspirants** : sels d'aluminium topiques
- **Ionophorèse** : courant électrique faible
- **Botox** : injections locales (axillaire, palmaire)
- **Chirurgie** : sympathectomie (cas sévères)

#### Traitement médicamenteux symptomatique
- **Anticholinergiques** : oxybutynine (effets secondaires++)
- **Bêta-bloquants** : si composante anxieuse
- **Phytothérapie** : sauge, houblon (ménopause)

### Suivi et surveillance
- **Évaluation efficacité** traitement étiologique
- **Surveillance biologique** selon pathologie
- **Qualité de vie** : retentissement social, professionnel
- **Adaptation thérapeutique** selon évolution

## 🚨 RED FLAGS

### Signes d'urgence
- **Hypertension maligne** (suspicion phéochromocytome)
- **Crise thyréotoxique** : hyperthermie, tachycardie, délirium
- **Choc** : septique, hémorragique
- **Déshydratation sévère**

### Signes de gravité
- **Syndrome B complet** : fièvre + sueurs nocturnes + perte poids >10%
- **Altération rapide état général**
- **Sueurs profuses avec troubles hémodynamiques**
- **Contexte néoplasique connu** avec aggravation

### Orientations urgentes
- **Endocrinologie** : suspicion phéochromocytome, crise thyréotoxique
- **Hématologie** : syndrome B, adénopathies
- **Infectiologie** : fièvre inexpliquée, immunodépression
- **Urgences** : instabilité hémodynamique

---

*💡 Distinguer sudation physiologique (effort, chaleur, stress) de pathologique (nocturne, profuse, chronique). L'interrogatoire est crucial pour orienter le diagnostic différentiel.*
