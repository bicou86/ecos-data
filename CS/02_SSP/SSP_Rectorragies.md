# Fiche de Révision ECOS - SANG DANS LES SELLES (RECTORRAGIES/MÉLÉNA)

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient signalant la présence de sang dans les selles
**Objectifs d'évaluation:** Différencier hémorragie haute/basse, évaluer la gravité, identifier la cause, adapter la prise en charge

---

## 📋 ANAMNÈSE

### 1. Caractérisation du saignement ⚠️ ESSENTIEL

#### 1.1 Aspect du sang
- [ ] **Sang rouge vif (rectorragies):**
  - Origine basse (côlon, rectum, anus)
  - Mélangé aux selles
  - En surface des selles
  - Isolé (sans selles)
  - Sur papier toilette uniquement
- [ ] **Sang noir (méléna):**
  - Selles noires, goudronneuses
  - Odeur fétide caractéristique
  - Origine haute (>angle de Treitz)
  - Sang digéré

#### 1.2 Quantification
- [ ] **Volume estimé:**
  - Traces (papier uniquement)
  - Quelques gouttes
  - Filet de sang
  - Cuvette rouge
  - Caillots
- [ ] **Fréquence:** Chaque selle, intermittent
- [ ] **Durée:** Depuis quand

#### 1.3 Modalités d'émission
- [ ] **Timing par rapport aux selles:**
  - Avant les selles
  - Pendant la défécation
  - Après les selles (goutte à goutte)
- [ ] **Effort de défécation:** Important ou non
- [ ] **Douleur associée** à l'émission

### 2. Symptômes associés

#### 2.1 Signes digestifs
- [ ] **Douleurs abdominales:**
  - Localisation
  - Type (coliques, continues)
- [ ] **Modification du transit:**
  - Diarrhée
  - Constipation
  - Alternance
- [ ] **Syndrome rectal:**
  - Ténesme (faux besoins)
  - Épreintes (contractions douloureuses)
  - Sensation corps étranger
- [ ] **Glaires** dans les selles

#### 2.2 Signes ano-rectaux
- [ ] **Douleur anale:**
  - À la défécation (fissure)
  - Permanente (thrombose)
  - Pulsatile (abcès)
- [ ] **Prurit anal**
- [ ] **Procidence** (prolapsus)
- [ ] **Masse** palpable

#### 2.3 Signes généraux
- [ ] **Amaigrissement** ⚠️ ALARME
- [ ] **Asthénie**
- [ ] **Anorexie**
- [ ] **Fièvre** (infection, MICI)

### 3. Signes de gravité ⚠️ URGENCE

#### 3.1 Retentissement hémodynamique
- [ ] **Malaise, syncope**
- [ ] **Vertiges orthostatiques**
- [ ] **Palpitations**
- [ ] **Dyspnée d'effort**
- [ ] **Soif intense**

#### 3.2 Signes d'anémie chronique
- [ ] **Pâleur** progressive
- [ ] **Fatigue** croissante
- [ ] **Essoufflement** à l'effort
- [ ] **Céphalées**

### 4. Orientation étiologique selon l'âge

#### 4.1 Sujet jeune (<50 ans)

**Causes ano-rectales bénignes (90%):**
- [ ] **Hémorroïdes:**
  - Sang rouge fin défécation
  - Procidence
  - Prurit
- [ ] **Fissure anale:**
  - Douleur vive défécation
  - Sang sur papier
  - Constipation

**MICI:**
- [ ] **RCH:**
  - Glaires sanglantes
  - Ténesme, épreintes
  - Diarrhée
- [ ] **Maladie de Crohn:**
  - Douleurs abdominales
  - Fistules anales
  - Manifestations extra-digestives

#### 4.2 Sujet âgé (>50 ans) ⚠️ CANCER

**Cancer colorectal:**
- [ ] **Modification récente transit**
- [ ] **Syndrome rectal**
- [ ] **Rectorragies + glaires**
- [ ] **Amaigrissement**
- [ ] **ATCD familiaux**

**Causes vasculaires:**
- [ ] **Angiodysplasies:**
  - Saignement intermittent
  - Indolore
- [ ] **Colite ischémique:**
  - Douleur brutale
  - Diarrhée sanglante

**Diverticulose:**
- [ ] **Hémorragie abondante**
- [ ] **Indolore**
- [ ] **Autolimitée**

### 5. Autres causes

#### 5.1 Infectieuses
- [ ] **Gastro-entérite:**
  - Contexte épidémique
  - Diarrhée fébrile
- [ ] **Colite à C. difficile:**
  - Post-antibiotiques
- [ ] **Amibiase, shigellose:**
  - Voyage zone endémique

#### 5.2 Médicamenteuses
- [ ] **AINS** (ulcérations)
- [ ] **Anticoagulants** (révélateur)
- [ ] **Antibiotiques** (C. difficile)

#### 5.3 Post-radiothérapie
- [ ] **Rectite radique:**
  - ATCD radiothérapie pelvienne
  - Délai variable (mois-années)

### 6. Facteurs de risque

#### 6.1 Cancer colorectal
- [ ] **Âge >50 ans**
- [ ] **ATCD familiaux** (1er degré)
- [ ] **Polypose familiale**
- [ ] **MICI ancienne** (>10 ans)
- [ ] **Syndrome de Lynch**

#### 6.2 Pathologie hémorroïdaire
- [ ] **Constipation chronique**
- [ ] **Grossesse**
- [ ] **Efforts de poussée**
- [ ] **Station assise prolongée**

### 7. Antécédents

#### 7.1 Digestifs
- [ ] **Coloscopies antérieures:** Résultats
- [ ] **Polypes:** Nombre, type
- [ ] **Hémorroïdes** traitées
- [ ] **Chirurgie colorectale**
- [ ] **MICI connue**

#### 7.2 Médicaux
- [ ] **Troubles hémostase**
- [ ] **Pathologie cardiovasculaire**
- [ ] **Radiothérapie pelvienne**

### 8. Question de clôture
"Avez-vous perdu du poids ou ressenti une grande fatigue récemment?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Évaluation hémodynamique
- [ ] **Signes vitaux:**
  - TA, hypotension orthostatique
  - FC (tachycardie)
  - FR
- [ ] **Signes d'anémie:**
  - Pâleur cutanéo-muqueuse
  - Tachycardie
- [ ] **Signes de choc** (si hémorragie massive)

### Examen abdominal

#### Palpation
- [ ] **Masse abdominale** (tumeur)
- [ ] **Douleur provoquée:** Localisation
- [ ] **Défense** (complication)
- [ ] **Organomégalie**

#### Auscultation
- [ ] **Bruits hydroaériques**
- [ ] **Souffle abdominal** (anévrisme)

### Examen proctologique ⚠️ INDISPENSABLE

#### Inspection périnéale
- [ ] **Au repos:**
  - Hémorroïdes externes
  - Fissure anale
  - Fistules
  - Suppurations
  - Condylomes
  - Dermatose

#### Inspection à la poussée
- [ ] **Prolapsus hémorroïdaire**
- [ ] **Prolapsus rectal**
- [ ] **Rectocèle**

#### Toucher rectal
- [ ] **Tonus sphinctérien**
- [ ] **Tumeur rectale:**
  - Distance marge anale
  - Circonférence atteinte
  - Mobilité
  - Consistance
- [ ] **Hémorroïdes internes** (non palpables)
- [ ] **Fécalome**
- [ ] **Sang sur doigtier:** Aspect

### Anuscopie (si disponible)
- [ ] **Hémorroïdes internes:** Grade I-IV
- [ ] **Fissure anale** postérieure
- [ ] **Papilles hypertrophiées**
- [ ] **Cryptite**

### Recherche signes extra-digestifs
- [ ] **MICI:**
  - Aphtes buccaux
  - Uvéite
  - Érythème noueux
  - Arthrites
- [ ] **Syndrome paranéoplasique**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Biologie de base
- [ ] **NFS:** Anémie microcytaire (fer)
- [ ] **Ferritine:** Carence martiale
- [ ] **TP, TCA:** Troubles coagulation
- [ ] **Ionogramme, créatinine**
- [ ] **CRP:** Inflammation (MICI)

#### 1.2 Si hémorragie importante
- [ ] **Groupe sanguin, RAI**
- [ ] **Bilan pré-transfusionnel**
- [ ] **Lactates**

### 2. Explorations morphologiques

#### 2.1 Coloscopie totale ⚠️ EXAMEN DE RÉFÉRENCE

**Indications urgentes (<24h):**
- [ ] **Hémorragie active** importante
- [ ] **Instabilité hémodynamique**

**Indications différées:**
- [ ] **Âge >50 ans** ⚠️ SYSTÉMATIQUE
- [ ] **Âge <50 ans avec:**
  - Signes d'alarme
  - Symptômes persistants
  - ATCD familiaux cancer
  - Anémie ferriprive

**Recherche:**
- [ ] **Cancer colorectal**
- [ ] **Polypes** (biopsies-exérèse)
- [ ] **MICI** (biopsies étagées)
- [ ] **Angiodysplasies**
- [ ] **Diverticules**

#### 2.2 Autres examens

**Rectosigmoïdoscopie:**
- [ ] **Si sujet jeune** sans signes d'alarme
- [ ] **Exploration limitée** au rectosigmoïde

**Angioscanner:**
- [ ] **Si hémorragie active** >0,5ml/min
- [ ] **Localisation** avant chirurgie

**Vidéocapsule:**
- [ ] **Si coloscopie normale**
- [ ] **Recherche** saignement grêle

**Entéroscanner/IRM:**
- [ ] **Bilan Crohn** (atteinte grêle)

### 3. Traitement étiologique

#### 3.1 Pathologie hémorroïdaire

**Traitement médical:**
- [ ] **Régularisation transit:** Laxatifs osmotiques
- [ ] **Topiques:** Crèmes, suppositoires
- [ ] **Veinotoniques:** Diosmine (efficacité limitée)
- [ ] **Antalgiques** si douleur
- [ ] **Mesures hygiéno-diététiques:**
  - Éviter efforts de poussée
  - Hygiène locale
  - Éviter épices, alcool

**Traitement instrumental:**
- [ ] **Ligature élastique** (grade II-III)
- [ ] **Photocoagulation infrarouge**
- [ ] **Sclérothérapie**

**Chirurgie:**
- [ ] **Hémorroïdectomie** (Milligan-Morgan)
- [ ] **Hémorroïdopexie** (Longo)
- [ ] **Si échec médical** ou grade IV

#### 3.2 Fissure anale

**Traitement médical (80% guérison):**
- [ ] **Laxatifs:** Transit régulier
- [ ] **Topiques cicatrisants**
- [ ] **Décontractants:** Trinitrine 0,4%
- [ ] **Toxine botulique** si échec
- [ ] **Bains de siège** tièdes

**Chirurgie:**
- [ ] **Sphinctérotomie latérale** interne
- [ ] **Si fissure chronique** (>6 semaines)

#### 3.3 Cancer colorectal

**Stratégie thérapeutique:**
- [ ] **RCP oncologique**
- [ ] **Bilan d'extension:** TDM TAP
- [ ] **Chirurgie:** Résection carcinologique
- [ ] **Chimiothérapie** adjuvante selon stade
- [ ] **Radiothérapie** si cancer rectal

#### 3.4 MICI

**RCH:**
- [ ] **5-ASA:** Mésalazine topique + orale
- [ ] **Corticoïdes** si poussée sévère
- [ ] **Immunosuppresseurs** (azathioprine)
- [ ] **Biothérapies** (anti-TNF)

**Crohn:**
- [ ] **Corticoïdes** poussée
- [ ] **Immunosuppresseurs**
- [ ] **Anti-TNF** (infliximab)
- [ ] **Chirurgie** si complications

#### 3.5 Diverticulose hémorragique

- [ ] **Hospitalisation surveillance**
- [ ] **Arrêt spontané** (80%)
- [ ] **Endoscopie:** Clips, coagulation
- [ ] **Embolisation** artérielle si échec
- [ ] **Colectomie** si récidives

#### 3.6 Angiodysplasies

- [ ] **Coagulation plasma argon**
- [ ] **Supplémentation fer**
- [ ] **Octréotide** si récidivant

### 4. Traitement symptomatique

#### 4.1 Anémie ferriprive
- [ ] **Fer oral:** 200mg/j × 3 mois
- [ ] **Fer IV** si mal toléré/malabsorption
- [ ] **Transfusion** si Hb <7g/dl symptomatique

#### 4.2 Hémorragie active
- [ ] **Hospitalisation**
- [ ] **Réanimation** si instable
- [ ] **Endoscopie urgente**

### 5. Surveillance

#### Post-traitement
- [ ] **Efficacité:** Arrêt saignement
- [ ] **NFS** à 1 mois
- [ ] **Ferritine** à 3 mois

#### Dépistage cancer colorectal
- [ ] **Population générale >50 ans:**
  - Test immunologique (FIT) /2 ans
  - Coloscopie si positif
- [ ] **Risque élevé:**
  - ATCD familiaux: Coloscopie à 45 ans ou 10 ans avant cas index
  - MICI: Coloscopie annuelle après 10 ans

### 6. Prévention

#### Pathologie hémorroïdaire
- [ ] **Transit régulier**
- [ ] **Hydratation**
- [ ] **Activité physique**
- [ ] **Éviter station assise** prolongée

#### Cancer colorectal
- [ ] **Dépistage organisé**
- [ ] **Alimentation:** Fibres, moins viande rouge
- [ ] **Activité physique**
- [ ] **Arrêt tabac**
- [ ] **Polypectomie** si polypes

### 7. Critères d'hospitalisation
- [ ] **Hémorragie active** importante
- [ ] **Instabilité hémodynamique**
- [ ] **Anémie sévère** symptomatique
- [ ] **Nécessité exploration** urgente
- [ ] **Terrain fragile**

### 8. Orientation spécialisée
- [ ] **Gastro-entérologue:**
  - Coloscopie indiquée
  - MICI suspectée
- [ ] **Proctologue:**
  - Pathologie ano-rectale complexe
  - Échec traitement médical
- [ ] **Oncologue:** Si cancer confirmé

---

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Différencier rectorragies/méléna**
2. **TR systématique** avec inspection
3. **Coloscopie si >50 ans** ou signes d'alarme
4. **NFS ferritine** (anémie ferriprive)
5. **Rechercher signes** de gravité
6. **Éliminer cancer** chez sujet âgé

### ❌ Pièges à éviter
1. **Banaliser saignement** chez >50 ans
2. **Attribuer aux hémorroïdes** sans exploration
3. **Oublier MICI** chez jeune
4. **Négliger anémie** chronique
5. **Retarder coloscopie** si indiquée

### 💡 Astuces mnémotechniques
- **Causes rectorragies jeune:** **H**émorroïdes, **F**issure, **M**ICI (HFM)
- **Causes rectorragies âgé:** **C**ancer, **D**iverticules, **A**ngiodysplasies (CDA)
- **Signes d'alarme:** **A**maigrissement, **A**némie, **Â**ge >50, **A**TCD familiaux (AAÂA)
- **Grades hémorroïdes:** I = **I**nternes, IV = **I**rréductibles **V**isibles
