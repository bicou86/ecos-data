# Fiche de Révision ECOS - Douleur de l'Épaule

## 🎯 Situation à Starting Point (SSP)
**Description:** Évaluation et prise en charge d'un patient consultant pour douleur d'épaule  
**Objectifs d'évaluation:** Anamnèse différentielle, examen spécialisé de l'épaule, tests cliniques, diagnostic et prise en charge

---

## 📋 ANAMNÈSE (Pondération ECOS: 25%)

### 1. Caractérisation de la douleur (OPQRST)
**Questions essentielles:**
- [ ] **Localisation précise anatomique**
  - Antérieure (biceps, conflit)
  - Postérieure (instabilité, capsule)
  - Latérale (coiffe des rotateurs)
  - Acromio-claviculaire
  - Diffuse (capsulite, arthrose)

- [ ] **Début et chronologie**
  - Traumatisme aigu vs progressif
  - Mécanisme lésionnel précis
  - Évolution dans le temps
  - Épisodes récurrents

- [ ] **Qualité et intensité**
  - Sourde, lancinante, coup de poignard
  - Échelle 0-10, variations horaires
  - Constante vs intermittente

### 2. Évaluation fonctionnelle spécifique
- [ ] **Douleur nocturne** (signe cardinal pathologie coiffe)
  - Réveils nocturnes
  - Position de sommeil impossible (côté atteint)
  - Nécessité de changer de position

- [ ] **Limitation fonctionnelle**
  - Gestes quotidiens : se coiffer, attacher soutien-gorge
  - Main-nuque, main-dos impossible
  - Port d'objets lourds
  - Mouvements au-dessus de la tête

- [ ] **Facteurs modulants**
  - **Aggravation** : mouvements overhead, port charges
  - **Amélioration** : repos, position antalgique
  - Réponse aux antalgiques/AINS

### 3. Recherche de signes d'instabilité
- [ ] **Sensations subjectives**
  - "Épaule qui se déboîte"
  - Appréhension certains mouvements
  - Sensation de faiblesse/lâchage

- [ ] **Antécédents de luxation**
  - Luxations antérieures documentées
  - Réduction spontanée vs médicale
  - Récidives, fréquence

### 4. Contexte étiologique et facteurs de risque
**Traumatique:**
- [ ] Chute sur bras tendu, épaule
- [ ] Mouvement forcé en abduction-rotation externe
- [ ] Sports de contact, à risque

**Surutilisation:**
- [ ] **Activités professionnelles** : peintres, coiffeurs
- [ ] **Sports overhead** : tennis, natation, handball
- [ ] Mouvements répétitifs quotidiens

**Âge et terrain:**
- [ ] > 40 ans : pathologie coiffe des rotateurs fréquente
- [ ] < 40 ans : instabilité, surmenage plus probable
- [ ] Diabète : capsulite adhésive

### 5. Recherche de douleurs projetées
- [ ] **Cervicales** : cervicalgies, névralgie cervico-brachiale
- [ ] **Cardiaques** : angor (épaule gauche), péricardite
- [ ] **Diaphragmatiques** : cholécystite, pneumopathie basale
- [ ] **Tumorales** : Pancoast-Tobias (apex pulmonaire)

### 6. Retentissement et contexte psycho-social
- [ ] Impact professionnel (arrêt travail)
- [ ] Qualité du sommeil altérée
- [ ] Limitation activités sportives/loisirs
- [ ] Anxiété, dépression réactionnelle

## 🩺 EXAMEN CLINIQUE - ÉPAULE (Pondération ECOS: 25%)

### Inspection (patient debout, torse nu)
- [ ] **Inspection comparative bilatérale**
- [ ] **Morphologie générale** : asymétrie, déformations
- [ ] **Amyotrophie** : fosses sus/sous-épineuses creusées
- [ ] **Tuméfactions** : kyste, hématome
- [ ] **Position antalgique** : bras pendant, soutenu

### Palpation systématique
- [ ] **Structures osseuses**
  - Clavicule sur toute sa longueur
  - Acromion, articulation acromio-claviculaire
  - Processus coracoïde
  - Tubercule majeur (trochiter) de l'humérus

- [ ] **Structures tendino-musculaires**
  - Tendon du biceps (gouttière bicipitale)
  - Coiffe des rotateurs (tubercule majeur)
  - Muscles péri-scapulaires

### Mobilités articulaires (méthode comparative)
- [ ] **Mobilité passive** (élimine cause musculaire)
  - Élévation antérieure (flexion) : 0-180°
  - Élévation latérale (abduction) : 0-180°
  - Rotation externe bras au corps : 0-60°
  - Rotation interne (main-dos) : vertèbre atteinte

- [ ] **Mobilité active** (force musculaire)
  - Comparaison avec mobilité passive
  - Déficit = atteinte musculo-tendineuse

### Tests cliniques spécialisés

#### Tests de la coiffe des rotateurs
- [ ] **Test de Jobe (Empty can test)** - Supra-épineux
  - Position : abduction 90°, antépulsion 30°, rotation interne (pouce vers sol)
  - Positif : douleur + faiblesse à la résistance
  - Sensibilité 86%, spécificité 50%

- [ ] **Test de Patte** - Infra-épineux/petit rond
  - Position : coude fléchi 90°, rotation externe contrariée
  - Positif : faiblesse en rotation externe

- [ ] **Test de Gerber (Lift-off test)** - Sous-scapulaire
  - Position : main dans le dos, décollement main-dos
  - Positif : impossibilité ou faiblesse

#### Tests de conflit sous-acromial
- [ ] **Test de Neer**
  - Manœuvre : élévation passive forcée bras tendu
  - Positif : douleur reproduite
  - Sensibilité 75%, spécificité 48%

- [ ] **Test de Hawkins-Kennedy**
  - Position : coude et épaule fléchis 90°, rotation interne forcée
  - Positif : douleur dans espace sous-acromial

- [ ] **Arc douloureux**
  - Abduction active 0-180°
  - Positif : douleur maximale 70-120° (conflit)

#### Tests d'instabilité
- [ ] **Test d'appréhension antérieur**
  - Position : décubitus, abduction 90°, rotation externe progressive
  - Positif : appréhension, contraction défensive

- [ ] **Test de recentrage (relocation)**
  - Pression postérieure sur tête humérale
  - Positif : disparition de l'appréhension

#### Tests spécifiques du biceps
- [ ] **Test de Speed**
  - Position : bras tendu, élévation antérieure contrariée
  - Positif : douleur gouttière bicipitale

- [ ] **Test de Yergason**
  - Position : coude fléchi 90°, supination contrariée
  - Positif : douleur gouttière bicipitale

### 2. Examens complémentaires selon l'orientation

**Imagerie de première intention :**
- [ ] **Radiographies standard** (face vraie, profil, axillaire)
  - Fractures, luxations, calcifications
  - Arthrose, ostéonécrose
  - Type d'acromion (Bigliani I-III)
  - Espace sous-acromial

**Imagerie spécialisée selon indication :**
- [ ] **Échographie** (opérateur-dépendant)
  - Pathologies coiffe : sensibilité 87%, spécificité 96%
  - Examen dynamique (conflit)
  - Infiltrations écho-guidées

- [ ] **IRM** (gold standard)
  - Ruptures coiffe : sensibilité 89%, spécificité 93%
  - Œdème osseux, tendinopathies
  - Labrum, instabilité

- [ ] **Arthro-IRM/scanner** (invasif)
  - Ruptures partielles coiffe articulaires
  - Lésions SLAP : sensibilité 82-100%

### 3. Prise en charge thérapeutique selon l'étiologie

#### Syndrome de conflit sous-acromial / Tendinopathie
**Phase aiguë (0-6 semaines) :**
- [ ] **Repos relatif** : éviter mouvements overhead
- [ ] **AINS réguliers** : ibuprofène 600mg × 3/j × 2-3 semaines
- [ ] **Glace** : 15-20 min × 3-4/j phase douloureuse
- [ ] **Exercices pendulaires** (Codman) précoces

**Phase de récupération (6 semaines-3 mois) :**
- [ ] **Kinésithérapie** : étirements capsule + renforcement
- [ ] **Infiltration sous-acromiale** si échec (max 3/an)
- [ ] **Acromioplastie** si échec > 6 mois

#### Rupture de la coiffe des rotateurs
**Rupture partielle :**
- [ ] **Traitement conservateur** : kinésithérapie intensive
- [ ] **Infiltrations** : corticoïdes + acide hyaluronique
- [ ] **Chirurgie** si échec 3-6 mois, patient actif

**Rupture complète :**
- [ ] **Chirurgie précoce** si :
  - Patient < 65 ans, actif
  - Rupture aiguë traumatique
  - Rupture > 3 cm ou rétractée
- [ ] **Réparation arthroscopique** : gold standard
- [ ] **Prothèse inversée** si rupture massive irréparable

#### Instabilité gléno-humérale
- [ ] **Traitement conservateur initial** : renforcement, proprioception
- [ ] **Chirurgie** si récidives fréquentes :
  - Arthroscopie : réparation Bankart, capsuloplastie
  - Butée osseuse si perte substance glénoïde

#### Capsulite adhésive (épaule gelée)
**Phase inflammatoire (0-6 mois) :**
- [ ] **Antalgiques** + AINS
- [ ] **Infiltrations intra-articulaires** précoces
- [ ] **Mobilisation douce** précoce

**Phase de raideur (6-12 mois) :**
- [ ] **Kinésithérapie intensive** : étirements
- [ ] **Hydrodilatation** sous contrôle
- [ ] **Arthrolyse** si échec conservateur

### 4. Protocoles de rééducation
**Phase 1 (Protection) 0-6 semaines :**
- [ ] Mobilisation passive, pendulaires
- [ ] Immobilisation si chirurgie (attelle 30° abduction)

**Phase 2 (Mobilité) 6-12 semaines :**
- [ ] Mobilité active-assistée
- [ ] Étirements capsulaires progressifs

**Phase 3 (Force) 3-6 mois :**
- [ ] Renforcement coiffe, stabilisateurs scapula
- [ ] Exercices en chaîne cinétique fermée

**Phase 4 (Fonctionnel) 6-12 mois :**
- [ ] Gestes spécifiques sport/profession
- [ ] Travail pliométrique, proprioception

### 5. Critères de référence spécialisée
- [ ] **Orthopédie** : rupture coiffe, instabilité, échec conservateur
- [ ] **Rhumatologie** : arthropathies inflammatoires, diagnostics complexes
- [ ] **Radiologie interventionnelle** : infiltrations complexes
- [ ] **Urgence** : luxation, fracture-luxation

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Examiner les 2 épaules comparativement** (inspection, mobilité, force)
2. **Rechercher douleur nocturne** (signe cardinal coiffe des rotateurs)
3. **Tester arc douloureux** 70-120° (conflit sous-acromial)
4. **Tests spécifiques** : Jobe (supra-épineux), Neer (conflit)
5. **Éliminer douleurs projetées** (cervicales, cardiaques)

### ❌ Pièges à éviter
1. **Oublier l'examen cervical** (névralgie cervico-brachiale)
2. **Ne pas tester la force** comparativement (rupture coiffe)
3. **Confondre limitation active vs passive** (muscle vs articulation)
4. **Mobilisation forcée** si capsulite (aggravation)
5. **IRM trop précoce** sans essai conservateur

### 💡 Astuces mnémotechniques
- **4 muscles coiffe** : "**SITS**" = **S**upra-épineux, **I**nfra-épineux, **T**eres minor, **S**ubscapulaire
- **Tests conflit** : "**Neer** + **Hawkins** = conflit **N**iet **H**aut"
- **Arc douloureux** : "**70-120°** = zone de conflit"
- **Instabilité** : "**Appréhension** + **Relocation** = instabilité antérieure"
- **Douleur nocturne** : "**Nuit** = **C**oiffe des **R**otateurs"

### 🚨 Red Flags - Signaux d'alarme
- **Épaule pseudo-paralytique** → rupture massive = chirurgie urgente
- **Douleur + fièvre** → arthrite septique = ponction d'urgence
- **Fracture-luxation** → complications neuro-vasculaires = urgence
- **Syndrome de Pancoast** → apex pulmonaire = bilan oncologique
- **Atteinte neurologique** → compression nerveuse = IRM/EMG

## 📚 SCÉNARIOS PATIENTS STANDARDISÉS

### Scénario 1 : Rupture de la coiffe des rotateurs (Inspire AMBOSS-39)
- **Patient :** Homme 52 ans, peintre, ATCD tendinopathie épaule
- **Présentation :** Douleur progressive 2 semaines, aggravation musculation
- **Examen :** Tests Neer +, Jobe +, force diminuée 4/5, arc douloureux
- **Facteurs :** Profession overhead, âge > 50 ans, douleur nocturne
- **Prise en charge :** IRM, repos, AINS réguliers, kinésithérapie
- **Chirurgie :** Possible vu profession active et âge

### Scénario 2 : Syndrome de conflit débutant (Inspire German-27)
- **Patiente :** Femme 60 ans, enseignante, douleur progressive 1 mois
- **Présentation :** Douleur mouvements overhead, paresthésies bras
- **Examen :** Tests conflit +, Jobe limite mais force préservée
- **Facteurs :** Âge, activités répétitives, pas traumatisme
- **Prise en charge :** Traitement conservateur, AINS, kinésithérapie
- **Évolution :** Bon pronostic si traitement précoce

### Scénario 3 : Tendinopathie sportive (Inspire USMLE Triage 25)
- **Patient :** Homme 34 ans, policier sportif, softball (lanceur)
- **Présentation :** Douleur antérieure 2 mois, douleur nocturne
- **Examen :** Tests Neer +, boîte vide +, force normale
- **Facteurs :** Sport overhead, mouvements répétitifs, échec AINS PRN
- **Prise en charge :** AINS réguliers, repos sportif, kinésithérapie
- **Prévention :** Technique lancer, renforcement préventif

## 🔬 TECHNIQUES D'EXAMEN SPÉCIFIQUES

### Test de Jobe (Empty can) - Technique précise
1. **Position patient** : debout, bras en abduction 90°
2. **Positionnement** : antépulsion 30°, rotation interne (pouce vers sol)
3. **Manœuvre** : résistance appliquée vers le bas
4. **Positif** : douleur + faiblesse = atteinte supra-épineux

### Test de Neer - Technique
1. **Position** : patient assis ou debout
2. **Immobilisation scapula** : main sur épaule controlatérale
3. **Manœuvre** : élévation passive forcée en rotation interne
4. **Positif** : douleur reproduite = conflit sous-acromial

### Amplitude articulaire - Mesures normales
- **Élévation antérieure** : 0-180°
- **Élévation latérale** : 0-180°
- **Rotation externe bras au corps** : 0-60°
- **Rotation interne** : main L1-L5 normale
