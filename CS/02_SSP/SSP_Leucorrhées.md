# Fiche de Révision ECOS - SÉCRÉTIONS VAGINALES ANORMALES (LEUCORRHÉES)

## 🎯 Situation à Starting Point (SSP)
**Description:** Femme consultant pour pertes vaginales anormales (leucorrhées)
**Objectifs d'évaluation:** Caractériser les leucorrhées, différencier infection et physiologique, identifier l'agent pathogène, adapter le traitement

---

## 📋 ANAMNÈSE

### 1. Caractérisation des leucorrhées ⚠️ ESSENTIEL

#### 1.1 Description des pertes
- [ ] **Couleur:**
  - Blanches (physiologiques, candidose)
  - Jaunes-verdâtres (trichomonase, gonorrhée)
  - Grises (vaginose bactérienne)
  - Brunâtres (sang ancien)
- [ ] **Aspect:**
  - Liquides, fluides
  - Épaisses, crémeuses
  - Grumeleuses "lait caillé" (candidose)
  - Mousseuses, bulleuses (trichomonase)
- [ ] **Abondance:** Légère, modérée, importante
- [ ] **Odeur:**
  - Absente (normal, candidose)
  - "Poisson pourri" (vaginose bactérienne)
  - Nauséabonde (trichomonase, corps étranger)

#### 1.2 Évolution
- [ ] **Début:** Brutal ou progressif
- [ ] **Durée:** Jours, semaines
- [ ] **Caractère:** Constant, intermittent
- [ ] **Relation avec cycle:** Ovulation, prémenstruel
- [ ] **Récidives:** Fréquence, traitement

### 2. Symptômes associés ⚠️ ORIENTATION DIAGNOSTIQUE

#### 2.1 Signes vulvo-vaginaux
- [ ] **Prurit vulvaire:**
  - Intense (candidose++)
  - Modéré (trichomonase)
  - Absent (vaginose)
- [ ] **Brûlures vaginales**
- [ ] **Dyspareunie:** Superficielle/profonde
- [ ] **Vulvodynie**
- [ ] **Érythème, œdème vulvaire**

#### 2.2 Signes urinaires
- [ ] **Dysurie:** Brûlures mictionnelles
- [ ] **Pollakiurie**
- [ ] **Urgenturie**

#### 2.3 Signes pelviens
- [ ] **Douleurs pelviennes** (MIP)
- [ ] **Métrorragies**
- [ ] **Fièvre** (infection haute)

### 3. Principales causes de leucorrhées

#### 3.1 Leucorrhées physiologiques
- [ ] **Caractéristiques:**
  - Blanches, inodores
  - Non irritantes
  - Variables selon cycle
- [ ] **Augmentation normale:**
  - Ovulation (glaire cervicale)
  - Grossesse
  - Excitation sexuelle

#### 3.2 Candidose vulvo-vaginale (30%) ⚠️ FRÉQUENT
- [ ] **Leucorrhées blanches épaisses** "lait caillé"
- [ ] **Prurit intense** +++
- [ ] **Érythème, œdème vulvaire**
- [ ] **Dyspareunie, dysurie**
- [ ] **Pas d'odeur** caractéristique

#### 3.3 Vaginose bactérienne (40%)
- [ ] **Leucorrhées grises** fluides homogènes
- [ ] **Odeur de "poisson"** +++
- [ ] **Aggravation après rapports**
- [ ] **Peu ou pas de prurit**
- [ ] **Pas d'inflammation**

#### 3.4 Trichomonase (5-10%)
- [ ] **Leucorrhées jaune-verdâtres** mousseuses
- [ ] **Abondantes, malodorantes**
- [ ] **Prurit, brûlures**
- [ ] **"Fraise" cervicale** (col rouge ponctué)
- [ ] **IST** (dépistage partenaire)

#### 3.5 Infections cervicales (cervicites)
- [ ] **Gonorrhée (Neisseria gonorrhoeae):**
  - Leucorrhées purulentes
  - Souvent asymptomatique
  - IST++
- [ ] **Chlamydia trachomatis:**
  - Leucorrhées mucopurulentes
  - 70% asymptomatique
  - Risque MIP, stérilité

#### 3.6 Autres causes
- [ ] **Corps étranger** (tampon oublié)
- [ ] **Vaginite atrophique** (ménopause)
- [ ] **Allergie/irritation** (produits d'hygiène)
- [ ] **Cancer** (col, vagin) - rare

### 4. Facteurs favorisants

#### 4.1 Candidose
- [ ] **Antibiotiques** récents
- [ ] **Grossesse**
- [ ] **Diabète** mal équilibré
- [ ] **Immunodépression**
- [ ] **Contraception œstroprogestative**
- [ ] **Vêtements serrés** synthétiques

#### 4.2 Vaginose bactérienne
- [ ] **Partenaires multiples**
- [ ] **Douches vaginales**
- [ ] **Tabagisme**
- [ ] **DIU**
- [ ] **Rapports non protégés**

#### 4.3 IST
- [ ] **Partenaires multiples**
- [ ] **Nouveau partenaire** (<3 mois)
- [ ] **Rapports non protégés**
- [ ] **ATCD IST**
- [ ] **Partenaire symptomatique**

### 5. Antécédents

#### 5.1 Gynécologiques
- [ ] **Épisodes similaires:** Fréquence, traitements
- [ ] **IST antérieures**
- [ ] **Derniers rapports sexuels**
- [ ] **Contraception** actuelle
- [ ] **DDR, grossesse** possible

#### 5.2 Médicaux
- [ ] **Diabète**
- [ ] **VIH, immunodépression**
- [ ] **Antibiotiques** récents
- [ ] **Allergies** connues

### 6. Habitudes d'hygiène
- [ ] **Toilette intime:**
  - Fréquence (excessive?)
  - Produits utilisés
  - Douches vaginales
- [ ] **Protections:**
  - Protège-slips quotidiens
  - Type de sous-vêtements
- [ ] **Pratiques sexuelles:**
  - Préservatifs
  - Lubrifiants

### 7. Impact sur qualité de vie
- [ ] **Gêne quotidienne**
- [ ] **Impact sexualité**
- [ ] **Anxiété** liée aux symptômes
- [ ] **Automédication** tentée

### 8. Question de clôture
"Votre partenaire a-t-il des symptômes?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### État général
- [ ] **Température** (fièvre = infection haute)
- [ ] **Douleur pelvienne** (MIP)

### Examen vulvaire ⚠️ INSPECTION ATTENTIVE

#### Inspection
- [ ] **Érythème vulvaire:**
  - Intense (candidose)
  - Modéré (trichomonase)
  - Absent (vaginose)
- [ ] **Œdème**
- [ ] **Excoriations** (grattage)
- [ ] **Fissures**
- [ ] **Leucorrhées** à l'orifice vulvaire

### Examen au spéculum ⚠️ ESSENTIEL

#### Aspect des leucorrhées
- [ ] **Localisation:** Vagin, col
- [ ] **Quantité**
- [ ] **Caractéristiques:** Couleur, consistance

#### Muqueuse vaginale
- [ ] **Érythème:**
  - Diffus (candidose)
  - En plaques (trichomonase)
  - Normal (vaginose)
- [ ] **Pétéchies** (trichomonase)

#### Col utérin
- [ ] **Aspect normal**
- [ ] **Col "fraise"** (trichomonase)
- [ ] **Cervicite:** Érythème, fragilité
- [ ] **Ectropion** (facteur favorisant)

### Prélèvements ⚠️ AVANT TOILETTE

#### Prélèvement vaginal
- [ ] **Examen direct**
- [ ] **Culture**
- [ ] **pH vaginal** (bandelette):
  - Normal: 3,8-4,5
  - >4,5: Vaginose, trichomonase

#### Prélèvement cervical (si cervicite)
- [ ] **PCR Chlamydia/Gonocoque**
- [ ] **Culture gonocoque**

### Tests diagnostiques au lit du patient

#### Test à la potasse (Sniff test/Whiff test)
- [ ] **KOH 10% sur lame**
- [ ] **Odeur "poisson"** = vaginose bactérienne

#### Examen direct au microscope (si disponible)
- [ ] **État frais:** Trichomonas mobiles
- [ ] **Gram:** Clue cells (vaginose)
- [ ] **KOH:** Filaments mycéliens (candidose)

### Toucher vaginal
- [ ] **Douleur mobilisation utérine** (MIP)
- [ ] **Masses annexielles**
- [ ] **Empâtement paramètres**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Prélèvement vaginal ⚠️ SYSTÉMATIQUE SI RÉCIDIVANT
- [ ] **Examen direct**
- [ ] **Culture aéro-anaérobie**
- [ ] **Antibiogramme/antifongogramme**
- [ ] **pH vaginal**

#### 1.2 Dépistage IST (si facteurs risque)
- [ ] **PCR Chlamydia trachomatis**
- [ ] **PCR Neisseria gonorrhoeae**
- [ ] **Sérologies:** VIH, syphilis, VHB, VHC
- [ ] **Prélèvement partenaire**

#### 1.3 Autres examens
- [ ] **β-HCG** si retard règles
- [ ] **Glycémie** si candidoses récidivantes
- [ ] **NFS, CRP** si suspicion MIP

### 2. Traitement selon l'étiologie

#### 2.1 Candidose vulvo-vaginale

**Traitement local (1ère ligne):**
- [ ] **Ovules antifongiques:**
  - Éconazole 150mg × 3j
  - Ou dose unique 600mg
  - Clotrimazole 200mg × 3j
- [ ] **Crème antifongique vulvaire:**
  - 2 applications/j × 7-14j

**Traitement oral (alternative):**
- [ ] **Fluconazole** 150mg dose unique
- [ ] **CI:** Grossesse 1er trimestre

**Candidose récidivante (≥4/an):**
- [ ] **Traitement d'attaque:** 14 jours
- [ ] **Traitement d'entretien:**
  - Fluconazole 150mg/semaine × 6 mois
- [ ] **Recherche facteurs** favorisants

#### 2.2 Vaginose bactérienne

**Traitement oral (préféré):**
- [ ] **Métronidazole** 500mg × 2/j × 7j
- [ ] **Ou dose unique** 2g (moins efficace)

**Traitement local:**
- [ ] **Métronidazole gel** 0,75% × 5j
- [ ] **Clindamycine crème** 2% × 7j

**Cas particuliers:**
- [ ] **Grossesse:** Traitement recommandé
- [ ] **Asymptomatique:** Pas de traitement sauf grossesse
- [ ] **Partenaire:** Pas de traitement systématique

#### 2.3 Trichomonase ⚠️ IST

**Traitement:**
- [ ] **Métronidazole** 2g dose unique
- [ ] **Ou 500mg × 2/j × 7j**
- [ ] **Traitement partenaire** OBLIGATOIRE
- [ ] **Abstinence/préservatifs** 7j
- [ ] **Dépistage autres IST**

#### 2.4 Cervicite à Chlamydia

**Traitement:**
- [ ] **Azithromycine** 1g dose unique
- [ ] **Ou Doxycycline** 100mg × 2/j × 7j
- [ ] **Traitement partenaire(s)** systématique
- [ ] **Contrôle PCR** à 3-6 mois

#### 2.5 Cervicite à gonocoque

**Traitement:**
- [ ] **Ceftriaxone** 500mg IM dose unique
- [ ] **+ Azithromycine** 1g PO (résistances)
- [ ] **Traitement partenaire(s)**
- [ ] **Déclaration obligatoire**
- [ ] **Contrôle** à J7

### 3. Mesures associées

#### 3.1 Conseils hygiéno-diététiques
- [ ] **Toilette intime:**
  - 1-2 fois/jour maximum
  - Savon pH neutre/acide
  - Pas de douche vaginale
- [ ] **Vêtements:**
  - Sous-vêtements coton
  - Éviter vêtements serrés
- [ ] **Hygiène menstruelle:**
  - Changer protections régulièrement
  - Éviter protège-slips quotidiens

#### 3.2 Mesures préventives
- [ ] **Préservatifs** (IST)
- [ ] **Limiter antibiotiques**
- [ ] **Équilibre glycémique** (diabète)
- [ ] **Probiotiques vaginaux** (prévention récidives)

### 4. Cas particuliers

#### 4.1 Grossesse
- [ ] **Traitement local** privilégié
- [ ] **Éviter métronidazole** 1er trimestre
- [ ] **Traiter vaginose** (risque accouchement prématuré)

#### 4.2 Récidives fréquentes
- [ ] **Prélèvement avec antifongigramme**
- [ ] **Recherche Candida non-albicans**
- [ ] **Traitement prolongé**
- [ ] **Traitement partenaire** (candidose)
- [ ] **Recherche diabète, VIH**

#### 4.3 Ménopause
- [ ] **Œstrogènes locaux** si atrophie
- [ ] **Hydratants vaginaux**
- [ ] **pH vaginal** augmenté (normal)

### 5. Surveillance

#### Candidose/Vaginose
- [ ] **Pas de contrôle** si asymptomatique
- [ ] **Reconsulter** si persistance/récidive

#### IST
- [ ] **Contrôle** après traitement
- [ ] **Dépistage** à 3-6 mois
- [ ] **Notification partenaires**

### 6. Complications à prévenir

#### MIP (Maladie Inflammatoire Pelvienne)
- [ ] **Si cervicite** non traitée
- [ ] **Salpingite, endométrite**
- [ ] **Risque:** Stérilité, GEU, douleurs chroniques

#### Grossesse
- [ ] **Vaginose:** Accouchement prématuré
- [ ] **IST:** Transmission nouveau-né

### 7. Information patiente

#### Éducation
- [ ] **Caractère bénin** (si non-IST)
- [ ] **Importance observance** traitement
- [ ] **Mesures préventives**
- [ ] **Consultation si récidive**

#### IST
- [ ] **Information partenaire(s)**
- [ ] **Prévention** (préservatifs)
- [ ] **Dépistage régulier**

### 8. Critères d'orientation
- [ ] **Gynécologue:**
  - Récidives fréquentes
  - Échec traitements
  - Suspicion cancer
- [ ] **Centre IST:** Bilan complet IST

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Caractériser leucorrhées** (couleur, odeur, prurit)
2. **Examen spéculum** avec prélèvements
3. **pH vaginal** (orientation diagnostique)
4. **Traiter partenaire** si IST
5. **Dépistage IST** si facteurs risque
6. **Conseils hygiène** intime

### ❌ Pièges à éviter
1. **Traiter sans prélèvement** si récidivant
2. **Oublier partenaire** (trichomonase, IST)
3. **Douches vaginales** (déséquilibre flore)
4. **Négliger diabète** si candidoses récidivantes
5. **Banaliser cervicite** (risque MIP)

### 💡 Astuces mnémotechniques
- **Candidose:** **B**lanches, **P**rurit++, **S**ans odeur (BPS)
- **Vaginose:** **G**rises, **O**deur poisson, **P**as prurit (GOP)
- **Trichomonase:** **V**ertes, **M**ousseuses, **I**ST (VMI)
- **pH vaginal:** Normal **4**, Pathologique **>5**
