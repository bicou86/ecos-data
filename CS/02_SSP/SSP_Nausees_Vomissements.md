# Fiche de Révision ECOS - NAUSÉES ET VOMISSEMENTS

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient consultant pour nausées et/ou vomissements
**Objectifs d'évaluation:** Identifier la cause, évaluer le retentissement, éliminer les urgences, adapter le traitement

---

## 📋 ANAMNÈSE

### 1. Caractérisation des symptômes ⚠️ ESSENTIEL

#### 1.1 Nausées
- [ ] **Intensité:** Légères, modérées, intenses
- [ ] **Fréquence:**
  - Permanentes
  - Intermittentes
  - Par crises
- [ ] **Durée:** Heures, jours, semaines
- [ ] **Évolution:** Stable, aggravation

#### 1.2 Vomissements
- [ ] **Fréquence:** Nombre par jour
- [ ] **Volume:** Faible, moyen, abondant
- [ ] **Aspect:**
  - Alimentaires (récents/anciens)
  - Bilieux (jaune-vert)
  - Fécaloïdes (occlusion)
  - Hémorragiques (hématémèse)
- [ ] **Effort de vomissement:**
  - Vomissements faciles
  - Efforts importants
  - Vomissements en jet (HTIC)

#### 1.3 Temporalité ⚠️ ORIENTATION DIAGNOSTIQUE
- [ ] **Horaire:**
  - Matinaux (grossesse, HTIC)
  - Post-prandiaux immédiats (sténose)
  - Post-prandiaux tardifs (gastroparésie)
  - Nocturnes
- [ ] **Début:** Brutal ou progressif
- [ ] **Ancienneté:** Aigus (<1 sem) ou chroniques

#### 1.4 Facteurs déclenchants
- [ ] **Alimentaires:**
  - Repas (volume, type)
  - Odeurs alimentaires
  - Aliments spécifiques
- [ ] **Positionnels:**
  - Changements de position
  - Décubitus
- [ ] **Autres:**
  - Mouvements (transport)
  - Stress, émotions
  - Médicaments

### 2. Symptômes associés

#### 2.1 Signes digestifs
- [ ] **Douleurs abdominales:**
  - Localisation
  - Intensité
  - Caractère (colique, continue)
- [ ] **Troubles du transit:**
  - Diarrhée
  - Constipation
  - Arrêt matières et gaz (occlusion)
- [ ] **Ballonnements, distension**
- [ ] **Pyrosis, régurgitations**

#### 2.2 Signes neurologiques ⚠️ HTIC
- [ ] **Céphalées:**
  - Matinales
  - Progressives
  - Avec photophobie
- [ ] **Troubles visuels:**
  - Diplopie
  - Flou visuel
- [ ] **Vertiges** (périphériques/centraux)
- [ ] **Troubles de conscience**
- [ ] **Déficit neurologique focal**

#### 2.3 Signes généraux
- [ ] **Fièvre** (infection)
- [ ] **Amaigrissement**
- [ ] **Asthénie**
- [ ] **Déshydratation:**
  - Soif
  - Sécheresse muqueuses
  - Pli cutané

### 3. Principales causes ⚠️ DIAGNOSTIC DIFFÉRENTIEL

#### 3.1 Causes digestives
- [ ] **Gastro-entérite aiguë:**
  - Contexte épidémique
  - Diarrhée associée
  - Fièvre
- [ ] **Intoxication alimentaire:**
  - Repas suspect
  - Cas groupés
  - Délai court
- [ ] **Occlusion intestinale:**
  - Arrêt matières/gaz
  - Douleurs coliques
  - Distension
- [ ] **Appendicite:**
  - Douleur FID
  - Défense
- [ ] **Cholécystite:**
  - Douleur hypochondre droit
  - Murphy positif
- [ ] **Pancréatite:**
  - Douleur transfixiante
  - Lipase élevée
- [ ] **Ulcère compliqué:**
  - ATCD ulcère
  - Sténose pylorique

#### 3.2 Causes neurologiques
- [ ] **HTIC:**
  - Tumeur cérébrale
  - Hydrocéphalie
  - Méningite
- [ ] **Migraine:**
  - Céphalées pulsatiles
  - Photophobie
  - ATCD migraineux
- [ ] **Vertiges:**
  - Labyrinthite
  - Maladie de Ménière
  - Névrite vestibulaire

#### 3.3 Causes métaboliques
- [ ] **Grossesse:** ⚠️ TOUJOURS ÉLIMINER
  - Retard de règles
  - Nausées matinales
  - 1er trimestre++
- [ ] **Diabète:**
  - Acidocétose
  - Gastroparésie
- [ ] **Insuffisance rénale:** Urémie
- [ ] **Hypercalcémie**
- [ ] **Insuffisance surrénalienne**
- [ ] **Hyperthyroïdie**

#### 3.4 Causes médicamenteuses ⚠️ FRÉQUENT
- [ ] **Chimiothérapie**
- [ ] **Opioïdes**
- [ ] **Antibiotiques**
- [ ] **AINS**
- [ ] **Digitaliques** (intoxication)
- [ ] **Métformine**
- [ ] **L-Dopa**
- [ ] **Contraceptifs oraux**

#### 3.5 Causes toxiques
- [ ] **Alcool:** Intoxication aiguë
- [ ] **Cannabis** (syndrome d'hyperémèse)
- [ ] **Autres toxiques**

#### 3.6 Causes psychogènes
- [ ] **Anxiété, stress**
- [ ] **Troubles du comportement alimentaire**
- [ ] **Vomissements psychogènes**

### 4. Terrain et antécédents

#### 4.1 Terrain
- [ ] **Âge:** Enfant, adulte, personne âgée
- [ ] **Sexe:** Femme en âge de procréer
- [ ] **Grossesse en cours**
- [ ] **Immunodépression**

#### 4.2 Antécédents
- [ ] **Chirurgicaux:**
  - Abdominaux (adhérences)
  - Gastriques (sténose)
- [ ] **Médicaux:**
  - Diabète
  - Insuffisance rénale
  - Pathologies neurologiques
  - Migraines
- [ ] **Épisodes similaires** antérieurs

### 5. Retentissement ⚠️ ÉVALUER GRAVITÉ

#### 5.1 Tolérance
- [ ] **Alimentation:** Possible ou impossible
- [ ] **Hydratation:** Liquides tolérés?
- [ ] **Perte de poids:** Quantifiée

#### 5.2 Complications
- [ ] **Déshydratation:**
  - Signes cliniques
  - Oligurie
- [ ] **Troubles ioniques:**
  - Hypokaliémie (faiblesse)
  - Hyponatrémie (confusion)
- [ ] **Dénutrition** si chronique
- [ ] **Syndrome de Mallory-Weiss** (déchirure)
- [ ] **Rupture œsophagienne** (Boerhaave)

### 6. Médicaments en cours
- [ ] **Liste complète** des traitements
- [ ] **Modifications récentes**
- [ ] **Automédication**
- [ ] **Phytothérapie**

### 7. Mode de vie
- [ ] **Alimentation:** Habitudes, régimes
- [ ] **Alcool:** Consommation
- [ ] **Tabac**
- [ ] **Cannabis**
- [ ] **Voyages récents** (turista)

### 8. Question de clôture
"Avez-vous de la fièvre ou des douleurs abdominales intenses?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Évaluation de la gravité ⚠️ PRIORITÉ
- [ ] **Signes vitaux:**
  - TA (hypotension)
  - FC (tachycardie)
  - Température
  - FR
- [ ] **État de conscience**
- [ ] **Signes de déshydratation:**
  - Pli cutané
  - Sécheresse muqueuses
  - Hypotension orthostatique
  - Yeux cernés

### Examen abdominal ⚠️ SYSTÉMATIQUE

#### Inspection
- [ ] **Cicatrices** (chirurgie)
- [ ] **Distension** (occlusion)
- [ ] **Péristaltisme visible**

#### Auscultation (avant palpation)
- [ ] **Bruits hydroaériques:**
  - Absents (iléus)
  - Augmentés (gastro-entérite)
  - Métalliques (occlusion)

#### Palpation
- [ ] **Douleur provoquée:** Localisation
- [ ] **Défense** (péritonite)
- [ ] **Masse palpable**
- [ ] **Murphy** (vésicule)
- [ ] **Organomégalie**

#### Percussion
- [ ] **Tympanisme** (distension gazeuse)
- [ ] **Matité** (globe vésical, ascite)

### Touchers pelviens
- [ ] **TR:** Fécalome, sang
- [ ] **TV:** Si femme (grossesse, annexes)

### Examen neurologique
- [ ] **Fond d'œil** si céphalées (œdème papillaire)
- [ ] **Signes méningés:** Raideur nuque, Kernig, Brudzinski
- [ ] **Paires crâniennes**
- [ ] **Déficit focal**
- [ ] **Syndrome cérébelleux**
- [ ] **Syndrome vestibulaire**

### Examen ORL
- [ ] **Otoscopie** (otite)
- [ ] **Examen vestibulaire:** Nystagmus
- [ ] **Pharynx**

### Recherche de complications
- [ ] **Troubles ioniques:**
  - Signes d'hypokaliémie (faiblesse, ECG)
  - Signes d'hyponatrémie (confusion)
- [ ] **Alcalose métabolique** (vomissements répétés)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Biologie de base
- [ ] **Ionogramme sanguin:** Na, K, Cl
- [ ] **Fonction rénale:** Urée, créatinine
- [ ] **Glycémie**
- [ ] **NFS, CRP** si fièvre
- [ ] **Bilan hépatique** si ictère
- [ ] **Lipase** si douleur abdominale

#### 1.2 Selon orientation
- [ ] **β-HCG:** ⚠️ SYSTÉMATIQUE femme en âge de procréer
- [ ] **Calcémie** si suspicion hypercalcémie
- [ ] **TSH** si signes thyroïdiens
- [ ] **Cortisol** si insuffisance surrénalienne
- [ ] **Toxiques urinaires** si suspicion

#### 1.3 ECG
- [ ] **Si troubles ioniques** (hypokaliémie)
- [ ] **Si digitaliques** (intoxication)

#### 1.4 Imagerie

**ASP (Abdomen Sans Préparation):**
- [ ] **Si suspicion occlusion:**
  - Niveaux hydroaériques
  - Pneumopéritoine

**Échographie abdominale:**
- [ ] **Lithiase biliaire**
- [ ] **Appendicite**
- [ ] **Grossesse extra-utérine**

**Scanner abdominal:**
- [ ] **Si urgence chirurgicale suspectée**
- [ ] **Occlusion sur bride**
- [ ] **Pancréatite**

**Scanner/IRM cérébral:**
- [ ] **Si signes neurologiques**
- [ ] **Suspicion HTIC**

### 2. Traitement symptomatique

#### 2.1 Réhydratation ⚠️ PRIORITÉ
- [ ] **Voie orale si possible:**
  - Petites quantités fréquentes
  - Boissons froides
  - SRO (soluté de réhydratation)
- [ ] **Voie IV si nécessaire:**
  - Sérum physiologique
  - Correction troubles ioniques
  - Supplémentation K+ si besoin

#### 2.2 Antiémétiques

**1ère ligne:**
- [ ] **Métoclopramide** (Primpéran):
  - 10 mg × 3/j PO ou IV
  - CI: Occlusion, Parkinson
- [ ] **Dompéridone** (Motilium):
  - 10 mg × 3/j PO
  - Moins d'effets centraux

**2ème ligne:**
- [ ] **Ondansétron** (Zophren):
  - 4-8 mg × 2-3/j
  - Efficace chimiothérapie
- [ ] **Métopimazine** (Vogalène):
  - 15 mg × 3/j

**Cas particuliers:**
- [ ] **Scopolamine** patch (mal des transports)
- [ ] **Corticoïdes** (HTIC, chimiothérapie)
- [ ] **Benzodiazépines** (composante anxieuse)

#### 2.3 Mesures diététiques
- [ ] **Mise au repos digestif** initial si sévère
- [ ] **Réalimentation progressive:**
  - Liquides clairs
  - Aliments faciles à digérer
  - Petites quantités fréquentes
- [ ] **Éviter:**
  - Aliments gras
  - Épices
  - Produits laitiers initialement

### 3. Traitement étiologique

#### 3.1 Gastro-entérite
- [ ] **Réhydratation** +++
- [ ] **Antiémétiques** symptomatiques
- [ ] **Pas d'antibiotiques** sauf cas particuliers

#### 3.2 Occlusion intestinale
- [ ] **Hospitalisation**
- [ ] **Mise à jeun strict**
- [ ] **Aspiration gastrique** (SNG)
- [ ] **Réhydratation IV**
- [ ] **Chirurgie** si strangulation

#### 3.3 Grossesse (1er trimestre)
- [ ] **Rassurance** (bénin)
- [ ] **Fractionnement repas**
- [ ] **Gingembre** (efficace)
- [ ] **Doxylamine + pyridoxine**
- [ ] **Hospitalisation** si hyperémèse gravidique

#### 3.4 Chimiothérapie
- [ ] **Prévention systématique:**
  - Ondansétron
  - Corticoïdes
  - Aprépitant si hautement émétisant
- [ ] **Traitement anticipé** avant séance

#### 3.5 Migraine
- [ ] **Traitement de crise** précoce
- [ ] **Antiémétiques** avant triptan
- [ ] **Repos** au calme et obscurité

#### 3.6 Vertiges
- [ ] **Antivertigineux:** Bétahistine
- [ ] **Repos**
- [ ] **Rééducation vestibulaire**

### 4. Cas particuliers

#### 4.1 Sujet âgé
- [ ] **Rechercher** iatrogénie
- [ ] **Surveillance** hydratation étroite
- [ ] **Prévention** syndrome confusionnel

#### 4.2 Diabétique
- [ ] **Surveillance** glycémique rapprochée
- [ ] **Adaptation** insuline
- [ ] **Recherche** acidocétose

#### 4.3 Insuffisant rénal
- [ ] **Adaptation** posologies
- [ ] **Éviter** métoclopramide si IRC sévère

### 5. Mesures associées

#### 5.1 Mesures non médicamenteuses
- [ ] **Position:** Tête surélevée
- [ ] **Environnement:** Calme, aéré
- [ ] **Relaxation** si composante anxieuse
- [ ] **Acupression** point P6 (poignet)

#### 5.2 Prévention complications
- [ ] **Bains de bouche** (hygiène)
- [ ] **Protection œsophagienne** si vomissements répétés
- [ ] **Surveillance** ionogramme si prolongé

### 6. Surveillance

#### Efficacité traitement
- [ ] **Fréquence** vomissements
- [ ] **Tolérance** alimentaire
- [ ] **État d'hydratation**
- [ ] **Poids**

#### Complications
- [ ] **Troubles ioniques**
- [ ] **Déshydratation**
- [ ] **Dénutrition** si chronique

### 7. Critères d'hospitalisation
- [ ] **Signes de gravité:**
  - Déshydratation sévère
  - Troubles ioniques importants
  - Impossibilité réhydratation orale
- [ ] **Urgences chirurgicales:**
  - Occlusion
  - Appendicite
  - Péritonite
- [ ] **HTIC suspectée**
- [ ] **Hyperémèse gravidique**
- [ ] **Terrain fragile** (âges extrêmes, comorbidités)

### 8. Orientation spécialisée
- [ ] **Gastro-entérologue:** Si chronique inexpliqué
- [ ] **Neurologue:** Si céphalées, vertiges
- [ ] **Gynécologue:** Hyperémèse gravidique
- [ ] **Psychiatre:** Vomissements psychogènes

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **β-HCG systématique** femme en âge de procréer
2. **Évaluer déshydratation** (clinique + bio)
3. **Éliminer urgences** chirurgicales
4. **Rechercher iatrogénie** (médicaments)
5. **Ionogramme** si vomissements répétés
6. **ASP si occlusion** suspectée

### ❌ Pièges à éviter
1. **Oublier grossesse** chez femme jeune
2. **Méconnaître HTIC** (vomissements en jet)
3. **Négliger hypokaliémie** (risque cardiaque)
4. **Traiter sans diagnostic** si urgence
5. **Métoclopramide si occlusion**

### 💡 Astuces mnémotechniques
- **Causes urgentes:** **O**cclusion, **A**ppendicite, **G**rossesse, **H**TIC (OAGH)
- **Complications vomissements:** **D**éshydratation, **H**ypokaliémie, **A**lcalose (DHA)
- **Antiémétiques:** **M**étoclopramide, **D**ompéridone, **O**ndansétron (MDO)
- **Déshydratation:** **P**li cutané, **S**écheresse, **H**ypotension (PSH)
