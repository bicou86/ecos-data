# Fiche de Révision ECOS - ENTRETIEN MOTIVATIONNEL

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient nécessitant un changement de comportement (arrêt tabac, perte de poids, observance thérapeutique, réduction alcool)
**Objectifs d'évaluation:** Maîtriser les techniques de l'entretien motivationnel, explorer l'ambivalence, renforcer la motivation au changement, établir un plan d'action

---

## 📋 PRINCIPES FONDAMENTAUX

### 1. Les 4 processus de l'entretien motivationnel ⚠️ SÉQUENTIELS

#### 1.1 Engager (Establishing rapport)
- [ ] **Créer l'alliance thérapeutique**
- [ ] **Attitude empathique**
- [ ] **Absence de jugement**
- [ ] **Respect de l'autonomie**
- [ ] **Curiosité bienveillante**

#### 1.2 Focaliser (Focusing)
- [ ] **Identifier le comportement cible**
- [ ] **Clarifier les objectifs**
- [ ] **Établir l'agenda**
- [ ] **Obtenir la permission**

#### 1.3 Évoquer (Evoking)
- [ ] **Explorer les motivations**
- [ ] **Faire émerger le discours-changement**
- [ ] **Identifier les valeurs**
- [ ] **Renforcer l'auto-efficacité**

#### 1.4 Planifier (Planning)
- [ ] **Négocier un plan**
- [ ] **Fixer des objectifs réalistes**
- [ ] **Anticiper les obstacles**
- [ ] **Engager vers l'action**

### 2. L'esprit de l'entretien motivationnel ⚠️ ATTITUDE

#### 2.1 Partenariat
- [ ] **Collaboration** vs confrontation
- [ ] **Expertise partagée**
- [ ] **Patient = expert de sa vie**
- [ ] **Médecin = guide**

#### 2.2 Acceptation
- [ ] **Valeur absolue** de la personne
- [ ] **Empathie authentique**
- [ ] **Support de l'autonomie**
- [ ] **Affirmation des forces**

#### 2.3 Compassion
- [ ] **Promouvoir le bien-être**
- [ ] **Priorité aux besoins du patient**
- [ ] **Altruisme**

#### 2.4 Évocation
- [ ] **Faire émerger** vs imposer
- [ ] **Motivations intrinsèques**
- [ ] **Ressources du patient**

---

## 📋 TECHNIQUES DE COMMUNICATION (OUVER)

### 1. Questions Ouvertes ⚠️ EXPLORATION

#### 1.1 Questions d'exploration
- [ ] "**Qu'est-ce qui** vous préoccupe concernant...?"
- [ ] "**Comment** voyez-vous la situation?"
- [ ] "**En quoi** est-ce important pour vous?"
- [ ] "**Que** savez-vous sur...?"
- [ ] "**Qu'est-ce qui** vous fait penser à changer?"

#### 1.2 Questions sur les valeurs
- [ ] "**Qu'est-ce qui compte** le plus pour vous?"
- [ ] "**Comment** aimeriez-vous que les choses soient?"
- [ ] "**Qu'est-ce qui** est important dans votre vie?"

#### 1.3 Questions sur le changement
- [ ] "**Si** vous décidiez de changer, **comment** feriez-vous?"
- [ ] "**Qu'est-ce qui** pourrait vous aider?"
- [ ] "**Quels seraient** les bénéfices pour vous?"

### 2. Valorisation ⚠️ RENFORCEMENT

#### 2.1 Affirmations des forces
- [ ] "**Je remarque** votre courage de parler de cela"
- [ ] "**Vous avez déjà** réussi à..."
- [ ] "**C'est important** que vous ayez identifié..."
- [ ] "**Votre détermination** est visible"

#### 2.2 Reconnaissance des efforts
- [ ] "**Vous avez fait** des efforts considérables"
- [ ] "**Malgré les difficultés**, vous continuez"
- [ ] "**C'est un pas** important"

### 3. Reflet (Écoute réflective) ⚠️ TECHNIQUE CLÉ

#### 3.1 Reflet simple
- [ ] **Répétition:** "Vous fumez 20 cigarettes par jour"
- [ ] **Paraphrase:** "Si je comprends bien, vous..."
- [ ] **Résumé:** "Vous m'avez dit que..."

#### 3.2 Reflet complexe
- [ ] **Reflet empathique:** "Cela doit être difficile..."
- [ ] **Reflet des émotions:** "Vous semblez inquiet..."
- [ ] **Reflet des valeurs:** "C'est important pour vous de..."
- [ ] **Reflet amplifié:** Exagération légère pour provoquer nuance

#### 3.3 Reflet à double face
- [ ] "**D'un côté** vous aimez fumer, **et d'un autre** vous êtes inquiet pour votre santé"
- [ ] Explore l'ambivalence

### 4. Résumés ⚠️ STRUCTURATION

#### 4.1 Résumés de collecte
- [ ] **Rassembler** les informations
- [ ] **Organiser** les idées
- [ ] **Vérifier** la compréhension

#### 4.2 Résumés de liaison
- [ ] **Transition** entre sujets
- [ ] **Connexion** des éléments

#### 4.3 Résumés de transition
- [ ] **Passage** à la planification
- [ ] **Synthèse** avant décision

---

## 📋 EXPLORATION DE L'AMBIVALENCE

### 1. Balance décisionnelle ⚠️ OUTIL CENTRAL

#### 1.1 Explorer les deux côtés
- [ ] **Avantages du statu quo:**
  - "Qu'est-ce que vous appréciez dans...?"
  - "Qu'est-ce que cela vous apporte?"
- [ ] **Inconvénients du statu quo:**
  - "Qu'est-ce qui vous dérange dans...?"
  - "Quels sont les aspects négatifs?"
- [ ] **Avantages du changement:**
  - "Que gagneriezvous à changer?"
  - "Comment serait votre vie si...?"
- [ ] **Inconvénients du changement:**
  - "Qu'est-ce qui vous inquiète dans le changement?"
  - "Quelles difficultés anticipez-vous?"

#### 1.2 Tableau de balance
```
Comportement actuel | Changement
-------------------|------------
Avantages    | Inconvénients | Avantages | Inconvénients
```

### 2. Échelles d'évaluation ⚠️ QUANTIFICATION

#### 2.1 Échelle d'importance
- [ ] "**Sur une échelle de 0 à 10**, quelle importance accordez-vous au changement?"
- [ ] "**Pourquoi** pas moins?" (explore motivations)
- [ ] "**Qu'est-ce qui** ferait monter ce chiffre?"

#### 2.2 Échelle de confiance
- [ ] "**Sur 0 à 10**, à quel point êtes-vous confiant de réussir?"
- [ ] "**Pourquoi** pas 0?" (renforce auto-efficacité)
- [ ] "**Que faudrait-il** pour augmenter votre confiance?"

#### 2.3 Échelle de préparation
- [ ] "**Où vous situez-vous** dans votre préparation au changement?"
- [ ] Explorer les raisons du score

## 📋 STADES DE CHANGEMENT (PROCHASKA)

### 1. Pré-contemplation ⚠️ "Je n'ai pas de problème"

#### Caractéristiques
- [ ] **Déni** du problème
- [ ] **Résistance** au changement
- [ ] **Minimisation** des risques

#### Stratégies adaptées
- [ ] **Information** non menaçante
- [ ] **Exploration** douce des préoccupations
- [ ] **Pas de pression** au changement
- [ ] **Semer le doute:** "Que se passerait-il si...?"

### 2. Contemplation ⚠️ "Je devrais peut-être"

#### Caractéristiques
- [ ] **Ambivalence** marquée
- [ ] **Reconnaissance** du problème
- [ ] **Mais** pas prêt à agir

#### Stratégies adaptées
- [ ] **Explorer l'ambivalence**
- [ ] **Balance décisionnelle**
- [ ] **Renforcer** les raisons de changer
- [ ] **Normaliser** l'ambivalence

### 3. Préparation/Détermination ⚠️ "Je vais le faire"

#### Caractéristiques
- [ ] **Décision** de changer
- [ ] **Planification** active
- [ ] **Recherche** de solutions

#### Stratégies adaptées
- [ ] **Élaborer un plan** concret
- [ ] **Identifier** les ressources
- [ ] **Anticiper** les obstacles
- [ ] **Renforcer** la confiance

### 4. Action ⚠️ "Je le fais"

#### Caractéristiques
- [ ] **Changement** actif
- [ ] **Efforts** visibles
- [ ] **Besoin** de soutien

#### Stratégies adaptées
- [ ] **Soutenir** les efforts
- [ ] **Résoudre** les problèmes
- [ ] **Ajuster** le plan
- [ ] **Célébrer** les succès

### 5. Maintien ⚠️ "Je continue"

#### Caractéristiques
- [ ] **Changement** établi (>6 mois)
- [ ] **Vigilance** aux rechutes
- [ ] **Intégration** dans la vie

#### Stratégies adaptées
- [ ] **Prévenir** les rechutes
- [ ] **Renforcer** les acquis
- [ ] **Identifier** situations à risque
- [ ] **Plan** de gestion des crises

### 6. Rechute (si applicable)

#### Approche
- [ ] **Normaliser:** "C'est fréquent"
- [ ] **Apprendre:** "Qu'est-ce qui s'est passé?"
- [ ] **Remotiver:** "Vous avez déjà réussi"
- [ ] **Replanifier:** Ajuster la stratégie

## 📋 DISCOURS-CHANGEMENT (DARN-CAT)

### 1. Phase préparatoire (DARN)

#### D - Désir
- [ ] **Repérer:** "J'aimerais...", "Je voudrais..."
- [ ] **Renforcer:** "Vous aimeriez donc..."

#### A - Aptitude (capacité)
- [ ] **Repérer:** "Je peux...", "Je suis capable..."
- [ ] **Renforcer:** "Vous pensez pouvoir..."

#### R - Raisons
- [ ] **Repérer:** "Parce que...", "Pour..."
- [ ] **Renforcer:** "Les raisons importantes sont..."

#### N - Nécessité (besoin)
- [ ] **Repérer:** "Je dois...", "Il faut que..."
- [ ] **Renforcer:** "C'est nécessaire pour vous..."

### 2. Phase de mobilisation (CAT)

#### C - Commitment (engagement)
- [ ] **Repérer:** "Je vais...", "Je m'engage..."
- [ ] **Renforcer:** "Vous êtes déterminé à..."

#### A - Activation
- [ ] **Repérer:** "Je suis prêt...", "Je commence..."
- [ ] **Renforcer:** "Vous êtes prêt à agir..."

#### T - Taking steps (premiers pas)
- [ ] **Repérer:** "J'ai déjà...", "J'ai commencé..."
- [ ] **Renforcer:** "Vous avez déjà fait..."

## 📋 GESTION DES RÉSISTANCES

### 1. Comprendre la résistance ⚠️ SIGNAL

#### Sources de résistance
- [ ] **Réactance:** Perte d'autonomie perçue
- [ ] **Peur** du changement
- [ ] **Manque** de confiance
- [ ] **Désaccord** sur le problème/solution

#### Manifestations
- [ ] **Argumentation**
- [ ] **Interruption**
- [ ] **Négation**
- [ ] **Inattention**

### 2. Réponses adaptées ⚠️ ROULER AVEC

#### 2.1 Reflet simple
- [ ] **Reconnaître** sans confronter
- [ ] "Vous n'êtes pas convaincu..."

#### 2.2 Reflet amplifié
- [ ] **Exagérer légèrement**
- [ ] Provoque souvent nuance du patient

#### 2.3 Reflet à double face
- [ ] **Présenter l'ambivalence**
- [ ] "D'un côté... et de l'autre..."

#### 2.4 Recadrage
- [ ] **Nouvelle perspective**
- [ ] "Une autre façon de voir..."

#### 2.5 Accord avec divergence
- [ ] **Valider partiellement**
- [ ] "Vous avez raison, et aussi..."

#### 2.6 Changement de focus
- [ ] **Rediriger** la conversation
- [ ] "Parlons plutôt de..."

## 💊 APPLICATION PRATIQUE PAR THÈME

### 1. Arrêt du tabac

#### Questions spécifiques
- [ ] "Qu'est-ce qui vous **fait penser** à arrêter?"
- [ ] "Comment le tabac **affecte** votre vie?"
- [ ] "Qu'est-ce qui **changerait** sans cigarette?"
- [ ] "Quelles **tentatives** avez-vous faites?"

#### Discours-changement à repérer
- [ ] "Ma santé m'inquiète"
- [ ] "Mes enfants me le demandent"
- [ ] "C'est cher"
- [ ] "J'en ai assez de cette dépendance"

### 2. Perte de poids

#### Questions spécifiques
- [ ] "Qu'est-ce qui vous **motive** à perdre du poids?"
- [ ] "Comment votre poids **impacte** votre quotidien?"
- [ ] "Qu'est-ce qui a **fonctionné** par le passé?"
- [ ] "Quels **changements** êtes-vous prêt à faire?"

#### Obstacles fréquents
- [ ] Plaisir de manger
- [ ] Stress/émotions
- [ ] Manque de temps
- [ ] Contexte social

### 3. Observance médicamenteuse

#### Questions spécifiques
- [ ] "Qu'est-ce qui **rend difficile** la prise?"
- [ ] "Comment **percevez-vous** ce traitement?"
- [ ] "Quels **bénéfices** en attendez-vous?"
- [ ] "Qu'est-ce qui **faciliterait** la prise?"

#### Solutions à explorer
- [ ] Pilulier
- [ ] Rappels
- [ ] Simplification
- [ ] Gestion effets secondaires

### 4. Réduction d'alcool

#### Questions spécifiques
- [ ] "Qu'est-ce que l'alcool vous **apporte**?"
- [ ] "Qu'est-ce qui vous **préoccupe** dans votre consommation?"
- [ ] "Comment serait votre vie avec **moins** d'alcool?"
- [ ] "Qu'est-ce qui vous **aiderait** à réduire?"

#### Approche sensible
- [ ] Non-jugement crucial
- [ ] Explorer fonction de l'alcool
- [ ] Identifier triggers
- [ ] Alternatives possibles

## 📌 STRUCTURE D'UNE CONSULTATION

### 1. Ouverture (5 min)

#### Établir le rapport
- [ ] **Accueil** chaleureux
- [ ] **Agenda** partagé
- [ ] **Permission:** "Pouvons-nous parler de...?"

#### Explorer la situation
- [ ] **Question ouverte** initiale
- [ ] **Écoute active**
- [ ] **Résumé** de compréhension

### 2. Exploration (10-15 min)

#### Comprendre la perspective
- [ ] **Expérience** du patient
- [ ] **Préoccupations**
- [ ] **Valeurs** et objectifs
- [ ] **Tentatives** antérieures

#### Explorer l'ambivalence
- [ ] **Balance décisionnelle**
- [ ] **Échelles** d'évaluation
- [ ] **Discours-changement**

### 3. Information et conseil (5-10 min) ⚠️ AVEC PERMISSION

#### Demander la permission
- [ ] "**Souhaitez-vous** que je vous donne des informations?"
- [ ] "**Puis-je** partager ce que nous savons?"

#### Méthode Demander-Fournir-Demander
- [ ] **Demander:** Ce que le patient sait
- [ ] **Fournir:** Information neutre
- [ ] **Demander:** Ce qu'il en pense

### 4. Planification (5-10 min)

#### Si prêt au changement
- [ ] **Plan SMART:**
  - Spécifique
  - Mesurable
  - Atteignable
  - Réaliste
  - Temporel
- [ ] **Anticiper obstacles**
- [ ] **Identifier supports**
- [ ] **Premier petit pas**

#### Si ambivalent
- [ ] **Résumer** ambivalence
- [ ] **Laisser porte ouverte**
- [ ] **Proposer** réflexion
- [ ] **Prochain RDV**

### 5. Clôture (2-3 min)

#### Synthèse
- [ ] **Résumer** la séance
- [ ] **Valoriser** efforts/réflexion
- [ ] **Confirmer** prochaines étapes
- [ ] **Rendez-vous** de suivi

## 📌 ERREURS À ÉVITER

### ❌ Pièges courants

#### Réflexe correcteur
- [ ] **Argumenter** pour le changement
- [ ] **Convaincre** par la logique
- [ ] **Minimiser** les obstacles
- [ ] **Donner** des solutions non sollicitées

#### Piège de l'expert
- [ ] **Imposer** son agenda
- [ ] **Prescrire** le changement
- [ ] **Juger** les choix
- [ ] **Prendre** la responsabilité

#### Question-réponse
- [ ] **Questions fermées** en série
- [ ] **Interrogatoire** médical
- [ ] **Pas d'exploration** approfondie

### ✅ Attitudes favorables

#### Patience
- [ ] **Respecter** le rythme
- [ ] **Accepter** l'ambivalence
- [ ] **Tolérer** les silences

#### Curiosité
- [ ] **Explorer** sans juger
- [ ] **Comprendre** la perspective
- [ ] **S'intéresser** authentiquement

#### Optimisme
- [ ] **Croire** au potentiel
- [ ] **Chercher** les forces
- [ ] **Célébrer** les petits pas

---

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Utiliser OUVER** (Questions Ouvertes, Valorisation, Écoute Réflective, Résumés)
2. **Explorer l'ambivalence** sans juger
3. **Demander permission** avant conseils
4. **Identifier stade** de changement
5. **Repérer discours-changement** (DARN-CAT)
6. **Rouler avec** la résistance

### ❌ Pièges à éviter
1. **Réflexe correcteur** (argumenter)
2. **Confrontation** directe
3. **Conseils non sollicités**
4. **Prendre responsabilité** du changement
5. **Minimiser difficultés**

### 💡 Astuces mnémotechniques
- **OUVER:** Questions **O**uvertes, Valori**U**ation, **V**alorisation, **É**coute **R**éflective
- **Esprit EM:** **PACE** (Partenariat, Acceptation, Compassion, Évocation)
- **Discours-changement:** **DARN-CAT** (Désir, Aptitude, Raisons, Nécessité - Commitment, Activation, Taking steps)
- **Stades:** **PCPAM** (Pré-contemplation, Contemplation, Préparation, Action, Maintien)
