# Fiche de Révision ECOS - MÉNOPAUSE

## 🎯 Situation à Starting Point (SSP)
**Description:** Femme consultant pour symptômes de ménopause ou bilan de ménopause
**Objectifs d'évaluation:** Confirmer le diagnostic, évaluer les symptômes et leur retentissement, discuter les options thérapeutiques, organiser le suivi

---

## 📋 ANAMNÈSE

### 1. Statut ménopausique ⚠️ DÉFINITIONS

#### 1.1 Définition et diagnostic
- [ ] **Ménopause:** Aménorrhée ≥12 mois consécutifs
- [ ] **Âge moyen:** 51 ans (45-55 ans)
- [ ] **DDR** (date dernières règles)
- [ ] **Durée aménorrhée** actuelle

#### 1.2 Phases de transition
- [ ] **Périménopause:**
  - Cycles irréguliers
  - Symptômes climatériques débutants
  - Durée: 2-8 ans avant ménopause
- [ ] **Post-ménopause:**
  - Confirmée après 12 mois aménorrhée
  - Précoce (<5 ans)
  - Tardive (>5 ans)

#### 1.3 Types de ménopause
- [ ] **Naturelle** (physiologique)
- [ ] **Chirurgicale** (ovariectomie bilatérale)
- [ ] **Iatrogène** (chimiothérapie, radiothérapie)
- [ ] **Précoce** (<40 ans = IOP)

### 2. Symptômes du syndrome climatérique ⚠️ ÉVALUATION COMPLÈTE

#### 2.1 Symptômes vasomoteurs (75%)
- [ ] **Bouffées de chaleur:**
  - Fréquence/jour
  - Intensité (légère/modérée/sévère)
  - Durée (minutes)
  - Facteurs déclenchants
- [ ] **Sueurs nocturnes:**
  - Réveil nocturne
  - Changement draps/vêtements
  - Retentissement sommeil
- [ ] **Durée symptômes:** Mois, années

#### 2.2 Symptômes génito-urinaires (50%)
- [ ] **Syndrome génito-urinaire ménopause (SGUM):**
  - Sécheresse vaginale
  - Dyspareunie
  - Prurit vulvaire
  - Brûlures vaginales
- [ ] **Symptômes urinaires:**
  - Urgenturies
  - Pollakiurie
  - Infections urinaires récidivantes
  - Incontinence urinaire

#### 2.3 Troubles du sommeil et de l'humeur
- [ ] **Insomnie:**
  - Endormissement difficile
  - Réveils nocturnes
  - Réveil précoce
- [ ] **Troubles humeur:**
  - Irritabilité
  - Anxiété
  - Humeur dépressive
  - Labilité émotionnelle
- [ ] **Fatigue chronique**

#### 2.4 Troubles cognitifs
- [ ] **Troubles mémoire**
- [ ] **Difficultés concentration**
- [ ] **"Brouillard mental"**

#### 2.5 Modifications corporelles
- [ ] **Prise de poids** (redistribution androïde)
- [ ] **Modifications peau:** Sécheresse, rides
- [ ] **Modifications cheveux:** Affinement, chute
- [ ] **Douleurs articulaires**

### 3. Retentissement sur qualité de vie ⚠️ IMPORTANT

#### 3.1 Impact fonctionnel
- [ ] **Activités quotidiennes** perturbées
- [ ] **Performance professionnelle**
- [ ] **Activités sociales** limitées
- [ ] **Score MRS** (Menopause Rating Scale)

#### 3.2 Sexualité
- [ ] **Baisse libido**
- [ ] **Dyspareunie** (sécheresse)
- [ ] **Évitement rapports**
- [ ] **Impact relationnel**

### 4. Antécédents ⚠️ ÉVALUATION RISQUES

#### 4.1 Gynéco-obstétricaux
- [ ] **Âge ménarche**
- [ ] **Parité, allaitement**
- [ ] **Contraception** antérieure
- [ ] **Pathologies gynécologiques**
- [ ] **Chirurgies pelviennes**

#### 4.2 Facteurs de risque cardiovasculaire
- [ ] **HTA**
- [ ] **Diabète**
- [ ] **Dyslipidémie**
- [ ] **Tabagisme**
- [ ] **Obésité**
- [ ] **Sédentarité**

#### 4.3 Facteurs de risque ostéoporose
- [ ] **ATCD fractures** (personnels/familiaux)
- [ ] **IMC <19**
- [ ] **Corticothérapie prolongée**
- [ ] **Ménopause précoce**
- [ ] **Alcool, tabac**
- [ ] **Carence calcium/vitamine D**

#### 4.4 Facteurs de risque cancer
- [ ] **ATCD familiaux:**
  - Cancer sein (1er degré)
  - Cancer ovaire
  - Mutations BRCA
- [ ] **ATCD personnels:**
  - Pathologie mammaire
  - Hyperplasie endométriale

#### 4.5 Contre-indications THM
- [ ] **Cancer hormono-dépendant**
- [ ] **Thrombose veineuse**
- [ ] **AVC, IDM**
- [ ] **Pathologie hépatique sévère**
- [ ] **Saignements génitaux** non explorés

### 5. Traitements essayés
- [ ] **THM antérieur:** Tolérance, efficacité
- [ ] **Phytoestrogènes**
- [ ] **Médecines alternatives**
- [ ] **Modifications hygiéno-diététiques**

### 6. Attentes et préférences
- [ ] **Demande de traitement**
- [ ] **Craintes THM**
- [ ] **Préférence naturel/hormonal**
- [ ] **Objectifs prioritaires**

### 7. Question de clôture
"Y a-t-il d'autres symptômes qui vous gênent depuis l'arrêt de vos règles?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Examen général
- [ ] **Poids, taille, IMC**
- [ ] **Tour de taille** (>88cm = risque)
- [ ] **TA**

### Examen mammaire ⚠️ SYSTÉMATIQUE
- [ ] **Inspection:** Asymétrie, rétraction
- [ ] **Palpation:** Nodules, écoulement
- [ ] **Aires ganglionnaires**
- [ ] **Mammographie** à jour?

### Examen gynécologique

#### Examen vulvaire
- [ ] **Atrophie vulvaire:**
  - Perte pilosité
  - Amincissement grandes lèvres
  - Pâleur muqueuse
- [ ] **Fissures, érythème**
- [ ] **Prolapsus** (effort de poussée)

#### Examen au spéculum
- [ ] **Muqueuse vaginale:**
  - Pâle, sèche
  - Perte élasticité
  - Pétéchies
- [ ] **Col:** Atrophique
- [ ] **Leucorrhées** (infections)
- [ ] **Frottis cervical** si indiqué

#### Toucher vaginal
- [ ] **Sténose vaginale**
- [ ] **Utérus:** Taille (involution)
- [ ] **Annexes:** Normalement non palpables
- [ ] **Douleur** (atrophie)

### Examen cardiovasculaire
- [ ] **Auscultation cardiaque**
- [ ] **Pouls périphériques**
- [ ] **Recherche varices**

### Examen ostéo-articulaire
- [ ] **Taille:** Perte cm (tassements)
- [ ] **Cyphose dorsale**
- [ ] **Distance côtes-bassin** (<2 travers doigt)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Confirmation ménopause (si doute)
- [ ] **FSH >25 UI/L** (2 dosages à 6 sem)
- [ ] **Œstradiol <50 pg/ml**
- [ ] **AMH** (réserve ovarienne)
- [ ] ⚠️ Inutiles si clinique évidente

#### 1.2 Bilan pré-thérapeutique (si THM envisagé)
- [ ] **Mammographie** (<2 ans)
- [ ] **Frottis cervical** (<3 ans)
- [ ] **Échographie pelvienne** si métrorragies
- [ ] **Bilan lipidique**
- [ ] **Glycémie**
- [ ] **TSH** si symptômes

#### 1.3 Évaluation risque fracturaire
- [ ] **Ostéodensitométrie** si:
  - Ménopause précoce
  - ATCD fracture
  - IMC <19
  - Corticothérapie
- [ ] **Score FRAX** (risque à 10 ans)

### 2. Traitement hormonal de la ménopause (THM)

#### 2.1 Indications ⚠️ BALANCE BÉNÉFICE/RISQUE
- [ ] **Syndrome climatérique** invalidant
- [ ] **Efficace sur:**
  - Bouffées chaleur (90%)
  - SGUM
  - Prévention ostéoporose
- [ ] **Fenêtre d'opportunité:** <60 ans ou <10 ans post-ménopause

#### 2.2 Schémas thérapeutiques

**Femme avec utérus:**
- [ ] **Œstrogène + Progestatif:**
  - Schéma combiné continu
  - Schéma séquentiel (si périménopause)
- [ ] **Voies:**
  - Transdermique (patch, gel) préférée
  - Orale

**Femme hystérectomisée:**
- [ ] **Œstrogène seul**

**Doses:**
- [ ] **Dose minimale efficace**
- [ ] **Ajustement selon symptômes**

#### 2.3 Molécules

**Œstrogènes:**
- [ ] **17β-œstradiol** transdermique:
  - Patch: 25-50 μg/j
  - Gel: 0,5-1,5 mg/j
- [ ] **Œstradiol oral:** 1-2 mg/j

**Progestatifs:**
- [ ] **Progestérone naturelle** 100-200 mg/j
- [ ] **Dydrogestérone** 10 mg/j
- [ ] **DIU lévonorgestrel** (alternative)

### 3. Traitement local du SGUM

#### 3.1 Œstrogènes locaux ⚠️ 1ÈRE LIGNE
- [ ] **Estriol crème/ovules** 0,5 mg
- [ ] **Promestriène** (Colpotrophine)
- [ ] **Schéma:**
  - Attaque: Quotidien × 2-3 sem
  - Entretien: 2-3 fois/sem
- [ ] **Sécurité:** Pas d'augmentation risque cancer

#### 3.2 Alternatives non hormonales
- [ ] **Hydratants vaginaux**
- [ ] **Lubrifiants** (rapports)
- [ ] **Acide hyaluronique** vaginal
- [ ] **Laser vaginal** (CO2, Er:YAG)

### 4. Alternatives au THM

#### 4.1 Médicaments non hormonaux

**Bouffées de chaleur:**
- [ ] **ISRS/IRSN:**
  - Paroxétine 10-20 mg/j
  - Venlafaxine 37,5-75 mg/j
- [ ] **Gabapentine** 300-900 mg/j
- [ ] **Clonidine** 0,075-0,15 mg/j

#### 4.2 Phytoestrogènes
- [ ] **Isoflavones soja** 40-80 mg/j
- [ ] **Efficacité modeste** et variable
- [ ] **CI:** Cancer sein

#### 4.3 Thérapies complémentaires
- [ ] **Acupuncture**
- [ ] **Hypnose**
- [ ] **Yoga, méditation**
- [ ] **Thérapies cognitivo-comportementales**

### 5. Mesures hygiéno-diététiques ⚠️ FONDAMENTALES

#### 5.1 Mode de vie
- [ ] **Activité physique:** 150 min/sem
- [ ] **Arrêt tabac**
- [ ] **Limitation alcool**
- [ ] **Gestion stress**
- [ ] **Maintien poids** normal

#### 5.2 Nutrition
- [ ] **Calcium:** 1200 mg/j (alimentation + suppléments)
- [ ] **Vitamine D:** 800-1000 UI/j
- [ ] **Protéines:** 1g/kg/j
- [ ] **Phytoestrogènes** alimentaires

#### 5.3 Prévention bouffées chaleur
- [ ] **Éviter déclencheurs:**
  - Aliments épicés
  - Café, alcool
  - Stress
  - Chaleur
- [ ] **Vêtements:** Couches, fibres naturelles
- [ ] **Ventilateur** nocturne

### 6. Prévention des complications

#### 6.1 Ostéoporose
- [ ] **Ostéodensitométrie** selon risque
- [ ] **Supplémentation** Ca/Vit D
- [ ] **Exercices** en charge
- [ ] **Prévention chutes**
- [ ] **Bisphosphonates** si ostéoporose

#### 6.2 Risque cardiovasculaire
- [ ] **Contrôle FRCV**
- [ ] **Bilan lipidique** annuel
- [ ] **Activité physique**
- [ ] **Alimentation** méditerranéenne

### 7. Surveillance

#### 7.1 Sous THM
- [ ] **Consultation:** 3 mois puis annuelle
- [ ] **Efficacité/tolérance**
- [ ] **Mammographie** annuelle
- [ ] **Frottis** selon recommandations
- [ ] **Réévaluation annuelle** bénéfice/risque
- [ ] **Tentative arrêt** après 5 ans

#### 7.2 Sans THM
- [ ] **Suivi gynécologique** annuel
- [ ] **Dépistages** organisés
- [ ] **Prévention** ostéoporose

### 8. Information et éducation

#### 8.1 Sur la ménopause
- [ ] **Processus naturel**
- [ ] **Évolution symptômes**
- [ ] **Options thérapeutiques**

#### 8.2 Sur le THM
- [ ] **Bénéfices:** Symptômes, os
- [ ] **Risques:**
  - Cancer sein: +8/10000 après 5 ans
  - Thrombose: Moindre si transdermique
- [ ] **Durée:** Minimale nécessaire
- [ ] **Surveillance** requise

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Confirmer statut** ménopausique (12 mois aménorrhée)
2. **Évaluer retentissement** symptômes (score MRS)
3. **Rechercher CI** au THM
4. **Examen gynéco-mammaire** complet
5. **Proposer THM** si syndrome climatérique sévère
6. **Traitement local** SGUM en 1ère ligne

### ❌ Pièges à éviter
1. **THM systématique** (individualiser)
2. **Oublier dépistages** (sein, col)
3. **Négliger SGUM** (qualité vie++)
4. **THM après 60 ans** (fenêtre fermée)
5. **Arrêt brutal THM** (sevrage progressif)

### 💡 Astuces mnémotechniques
- **Symptômes ménopause:** **BIS** (Bouffées, Insomnie, Sécheresse)
- **CI THM:** **CAST** (Cancer, AVC, Saignements, Thrombose)
- **Prévention ostéoporose:** **CAVE** (Calcium, Activité, Vitamine D, Éviter tabac)
- **Fenêtre THM:** **60** ans ou **10** ans post-ménopause
