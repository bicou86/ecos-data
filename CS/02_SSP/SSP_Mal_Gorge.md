# Fiche de Révision ECOS - MAL DE GORGE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient se présentant avec douleur de gorge (odynophagie)
**Objectifs d'évaluation:** Différencier angine virale/bactérienne, identifier les complications, adapter l'antibiothérapie, reconnaître les urgences

---

## 📋 ANAMNÈSE

### 1. Caractérisation de la douleur ⚠️ ESSENTIEL

#### 1.1 Caractéristiques de la douleur
- [ ] **Localisation:**
  - Pharynx (central)
  - Unilatérale (phlegmon?)
  - Irradiation aux oreilles (otalgie réflexe)
- [ ] **Intensité:** EVA 0-10
- [ ] **Type:**
  - Brûlure
  - Serrement
  - Piqûre
  - Gêne simple
- [ ] **Évolution:**
  - Début brutal ou progressif
  - Durée (jours)
  - Aggravation/amélioration

#### 1.2 Facteurs modulateurs
- [ ] **Aggravation:**
  - Déglutition (odynophagie)
  - Alimentation (solides > liquides)
  - Parole
- [ ] **Soulagement:**
  - Boissons chaudes/froides
  - Antalgiques (efficacité)

### 2. Symptômes associés ORL

#### 2.1 Signes locaux
- [ ] **Dysphagie:** Difficulté à avaler
- [ ] **Hypersialorrhée:** Salivation excessive
- [ ] **Trismus:** Limitation ouverture buccale (phlegmon)
- [ ] **Voix:**
  - Enrouement (laryngite)
  - Voix "chaude" (phlegmon)
  - Aphonie
- [ ] **Halitose:** Mauvaise haleine

#### 2.2 Signes régionaux
- [ ] **Adénopathies cervicales:**
  - Localisation
  - Sensibilité
  - Taille
- [ ] **Otalgie réflexe** (sans otite)
- [ ] **Rhinorrhée:** Claire ou purulente

### 3. Symptômes généraux ⚠️ ORIENTATION ÉTIOLOGIQUE

#### 3.1 Syndrome infectieux
- [ ] **Fièvre:**
  - Température maximale
  - Brutale ou progressive
  - Frissons
- [ ] **Altération état général:**
  - Asthénie
  - Myalgies
  - Courbatures
- [ ] **Anorexie**

#### 3.2 Signes viraux évocateurs
- [ ] **Syndrome grippal:** Toux, rhinite, conjonctivite
- [ ] **Éruption cutanée** (viroses éruptives)
- [ ] **Symptômes digestifs:** Diarrhée (entérovirus)

### 4. Recherche étiologique

#### 4.1 Angine érythémateuse/érythémato-pultacée
- [ ] **Contexte épidémique** (hiver)
- [ ] **Contage familial/collectivité**
- [ ] **Début brutal** avec fièvre élevée
- [ ] **Absence de toux** (évoque streptocoque)

#### 4.2 Angine pseudomembraneuse
- [ ] **Fausses membranes** grisâtres
- [ ] **MNI (mononucléose):**
  - Adolescent/jeune adulte
  - Asthénie intense
  - Polyadénopathie
  - Splénomégalie
- [ ] **Diphtérie:** Non vacciné, voyage

#### 4.3 Angine ulcéro-nécrotique
- [ ] **Angine de Vincent:**
  - Halitose fétide
  - Ulcération unilatérale
  - Mauvaise hygiène bucco-dentaire
- [ ] **Hémopathie:** Signes généraux graves

#### 4.4 Angine vésiculeuse
- [ ] **Herpangine:** Vésicules postérieures
- [ ] **Herpes:** Gingivostomatite associée
- [ ] **Zona pharyngé** (rare)

### 5. Complications à rechercher ⚠️ URGENCES

#### 5.1 Complications locorégionales
- [ ] **Phlegmon péri-amygdalien:**
  - Trismus progressif
  - Bombement du voile unilatéral
  - Voix modifiée
  - Hypersialorrhée
- [ ] **Cellulite cervicale:**
  - Tuméfaction cervicale
  - Torticolis
  - Dyspnée

#### 5.2 Complications générales
- [ ] **Scarlatine:**
  - Éruption scarlatiniforme
  - Langue framboisée
  - Desquamation secondaire
- [ ] **RAA (rhumatisme articulaire aigu):**
  - Arthralgies migratrices
  - Cardite
  - Chorée
- [ ] **GNA (glomérulonéphrite aiguë):**
  - Œdèmes
  - HTA
  - Urines foncées

### 6. Critères de gravité ⚠️ HOSPITALISATION

#### 6.1 Signes locaux graves
- [ ] **Dyspnée laryngée** (épiglottite)
- [ ] **Œdème de Quincke**
- [ ] **Abcès rétropharyngé** (enfant)

#### 6.2 Signes généraux graves
- [ ] **Signes de sepsis:**
  - Hypotension
  - Confusion
  - Marbrures
- [ ] **Déshydratation** (impossibilité de boire)

### 7. Antécédents et terrain

#### 7.1 Antécédents ORL
- [ ] **Angines récidivantes:**
  - Fréquence annuelle
  - Germe identifié
  - Traitements reçus
- [ ] **Amygdalectomie**
- [ ] **Portage streptocoque**

#### 7.2 Terrain à risque
- [ ] **Immunodépression:**
  - VIH
  - Chimiothérapie
  - Corticothérapie
- [ ] **Valvulopathie** (risque endocardite)
- [ ] **Diabète**
- [ ] **Grossesse**

### 8. Traitements déjà pris
- [ ] **Automédication:**
  - Antalgiques (efficacité)
  - Anti-inflammatoires
  - Antibiotiques (lesquels, durée)
- [ ] **Phytothérapie, gargarismes**

### 9. Contexte épidémiologique
- [ ] **Saison:** Hiver (viral++), printemps (streptocoque)
- [ ] **Collectivité:** École, crèche
- [ ] **Voyage récent** (diphtérie)
- [ ] **Pratiques sexuelles** (IST pharyngées)

### 10. Question de clôture
"Avez-vous des difficultés à respirer ou à ouvrir la bouche?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Signes vitaux
- [ ] **Température** (fièvre)
- [ ] **FC, TA**
- [ ] **FR** (dyspnée?)
- [ ] **SaO2**

### Examen pharyngé ⚠️ ESSENTIEL

#### Inspection oropharynx (abaisse-langue)
- [ ] **Muqueuse pharyngée:**
  - Érythémateuse
  - Œdématiée
- [ ] **Amygdales:**
  - Taille (grades 1-4)
  - **Érythémateuses**
  - **Exsudat blanc/gris** (pultacé)
  - **Fausses membranes** adhérentes
  - **Ulcérations**
  - **Vésicules**
- [ ] **Voile du palais:**
  - Symétrie (phlegmon = asymétrie)
  - Œdème de la luette

#### Autres éléments
- [ ] **Langue:**
  - Saburrale (enduit blanchâtre)
  - Framboisée (scarlatine)
  - Dépapillée
- [ ] **Haleine:** Fétide (Vincent, phlegmon)

### Palpation cervicale ⚠️ SYSTÉMATIQUE

#### Aires ganglionnaires
- [ ] **Sous-mandibulaires** (satellites angine)
- [ ] **Jugulo-carotidiennes**
- [ ] **Sous-mentales**
- [ ] **Occipitales** (MNI)
- [ ] **Spinales** (MNI)

#### Caractéristiques adénopathies
- [ ] **Taille, nombre**
- [ ] **Sensibilité** (inflammatoires)
- [ ] **Mobilité**

### Examen ORL complet
- [ ] **Otoscopie:** Otite associée?
- [ ] **Rhinoscopie:** Rhinopharyngite?
- [ ] **Cavité buccale:**
  - Hygiène bucco-dentaire
  - Gingivite
  - Aphtes

### Examen cutané
- [ ] **Éruption:**
  - Scarlatiniforme (scarlatine)
  - Morbilliforme (viroses)
  - Purpura (méningocoque)
- [ ] **Énanthème** (taches buccales)

### Examen général
- [ ] **Splénomégalie** (MNI)
- [ ] **Hépatomégalie** (MNI, hépatite)
- [ ] **Signes de déshydratation**

### Score de Mac Isaac ⚠️ DÉCISION THÉRAPEUTIQUE
- [ ] **Fièvre >38°C:** +1
- [ ] **Absence de toux:** +1
- [ ] **Adénopathies cervicales sensibles:** +1
- [ ] **Atteinte amygdalienne** (↑ volume ou exsudat): +1
- [ ] **Âge:**
  - 3-14 ans: +1
  - 15-44 ans: 0
  - ≥45 ans: -1

**Interprétation:**
- Score ≤1: Pas de TDR ni antibiotique
- Score ≥2: TDR (Test Diagnostic Rapide)
- TDR positif: Antibiothérapie

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Test de diagnostic rapide (TDR) ⚠️ SYSTÉMATIQUE SI SCORE ≥2
- [ ] **Streptocoque groupe A**
- [ ] **Résultat en 5-10 minutes**
- [ ] **Si positif:** Antibiothérapie
- [ ] **Si négatif:** Pas d'antibiotique (viral)

#### 1.2 Autres examens (selon contexte)
- [ ] **NFS:** Si angine sévère/atypique
  - Syndrome mononucléosique (MNI)
  - Hyperleucocytose (bactérien)
  - Agranulocytose
- [ ] **MNI test, sérologie EBV** (si suspicion)
- [ ] **Prélèvement pharyngé** (si échec traitement)

### 2. Traitement de l'angine streptococcique

#### 2.1 Antibiothérapie ⚠️ SI TDR POSITIF
**1ère intention:**
- [ ] **Amoxicilline:**
  - Adulte: 1g × 2/j × 6 jours
  - Enfant: 50 mg/kg/j en 2 prises × 6 jours

**Si allergie pénicilline:**
- [ ] **Allergie sans risque anaphylaxie:**
  - Céfuroxime-axétil: 250mg × 2/j × 4 jours
  - Cefpodoxime: 100mg × 2/j × 5 jours
- [ ] **Allergie avec risque anaphylaxie:**
  - Azithromycine: 500mg/j × 3 jours
  - Clarithromycine: 250mg × 2/j × 5 jours

#### 2.2 Traitement symptomatique (toutes angines)
- [ ] **Antalgiques/antipyrétiques:**
  - Paracétamol 1g × 4/j
  - AINS (ibuprofène 400mg × 3/j)
- [ ] **Mesures locales:**
  - Gargarismes (eau salée)
  - Pastilles antiseptiques
  - Sprays anesthésiants
- [ ] **Hydratation** +++
- [ ] **Alimentation:** Texture adaptée

### 3. Cas particuliers

#### 3.1 Angine de Vincent
- [ ] **Pénicilline V** ou métronidazole
- [ ] **Soins bucco-dentaires**
- [ ] **Bains de bouche antiseptiques**

#### 3.2 Mononucléose infectieuse
- [ ] **Repos** (risque rupture rate)
- [ ] **Éviter sports contact** × 1 mois
- [ ] **Pas d'amoxicilline** (rash cutané)
- [ ] **Corticoïdes** si obstruction pharyngée

#### 3.3 Herpangine
- [ ] **Traitement symptomatique** seul
- [ ] **Éviction collectivité** (contagieux)

### 4. Traitement des complications

#### 4.1 Phlegmon péri-amygdalien ⚠️ URGENCE
- [ ] **Hospitalisation**
- [ ] **Ponction évacuatrice** ou incision drainage
- [ ] **Antibiothérapie IV:**
  - Amoxicilline-acide clavulanique
  - + métronidazole si échec
- [ ] **Antalgiques** majeurs
- [ ] **Corticoïdes** (œdème)

#### 4.2 Cellulite cervicale ⚠️ URGENCE VITALE
- [ ] **Réanimation**
- [ ] **Antibiothérapie IV large spectre**
- [ ] **Chirurgie** (drainage, nécrosectomie)

### 5. Prévention

#### 5.1 Mesures générales
- [ ] **Hygiène des mains**
- [ ] **Éviction scolaire:** 48h si scarlatine
- [ ] **Traitement de l'entourage** (si scarlatine)

#### 5.2 Amygdalectomie (indications)
- [ ] **Angines récidivantes:**
  - ≥5 épisodes/an × 2 ans
  - ≥3 épisodes/an × 3 ans
- [ ] **Complications:** Phlegmon, RAA
- [ ] **Hypertrophie obstructive** (SAOS)

### 6. Surveillance

#### Angine traitée
- [ ] **Amélioration à 48-72h**
- [ ] **Si échec:** Réévaluation, prélèvement
- [ ] **Observance antibiotique** (6 jours complets)

#### Complications post-streptococciques
- [ ] **RAA:** 2-3 semaines après
- [ ] **GNA:** 10 jours après
- [ ] **Information patient** sur signes d'alerte

### 7. Critères d'hospitalisation
- [ ] **Signes de gravité locaux:**
  - Dyspnée, dysphagie majeure
  - Suspicion phlegmon/cellulite
- [ ] **Signes généraux graves:**
  - Sepsis
  - Déshydratation
- [ ] **Terrain fragile:**
  - Immunodépression
  - Nourrisson <3 mois
- [ ] **Échec traitement ambulatoire**

### 8. Éducation du patient
- [ ] **Évolution naturelle** (3-7 jours)
- [ ] **Importance observance** antibiotique si prescrit
- [ ] **Signes d'alerte:**
  - Difficultés respiratoires
  - Impossibilité d'avaler
  - Fièvre persistante >72h
- [ ] **Prévention contagion** (hygiène)

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Score de Mac Isaac** systématique
2. **TDR streptocoque** si score ≥2
3. **Examen du voile** (asymétrie = phlegmon)
4. **Palpation ganglionnaire** bilatérale
5. **Rechercher trismus** (limitation ouverture)
6. **Antibiotique seulement si TDR+**

### ❌ Pièges à éviter
1. **Antibiotiques systématiques** (80% viral)
2. **Amoxicilline si MNI** (éruption)
3. **Négliger phlegmon** (urgence)
4. **Oublier complications** post-streptocoque
5. **Corticoïdes en 1ère intention** (masquage)

### 💡 Astuces mnémotechniques
- **Mac Isaac:** **F**ièvre, **A**bsence **T**oux, **A**dénopathies, **A**mygdales (FATAA)
- **Phlegmon:** **T**rismus, **A**symétrie voile, **V**oix chaude, **H**ypersialorrhée (TAVH)
- **RAA:** **2-3** semaines après angine
- **Durée ATB streptocoque:** **6** jours amoxicilline
