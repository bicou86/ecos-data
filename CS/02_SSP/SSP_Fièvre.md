# Fiche de Révision ECOS - FIÈVRE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient se présentant avec un syndrome fébrile (température > 38°C) nécessitant identification de l'origine et évaluation de la gravité.
**Objectifs d'évaluation:** Recherche systématique du foyer infectieux, reconnaissance des signes de gravité, orientation diagnostique et thérapeutique

## 📋 ANAMNÈSE

### 1. Caractérisation de la fièvre
- [ ] **Début:** brutal vs progressif, date précise
- [ ] **Durée:** aiguë (< 7j), prolongée (> 7j), chronique (> 3 sem)
- [ ] **Intensité:** T° maximale mesurée, méthode de mesure
- [ ] **Pattern:** continue, intermittente, ondulante
- [ ] **Réponse antipyrétiques:** efficacité paracétamol/AINS

### 2. Symptômes généraux (symptômes B) ⚠️
- [ ] **Frissons:** solennels (bactériémie), tremblements
- [ ] **Sueurs:** nocturnes profuses (lymphome, tuberculose)
- [ ] **Perte de poids:** involontaire > 10% en 6 mois
- [ ] **Asthénie:** intensité, retentissement fonctionnel

### 3. Recherche point d'appel infectieux - SYSTÉMATIQUE

#### Respiratoire
- [ ] **Toux:** sèche/productive, expectorations (couleur)
- [ ] **Dyspnée:** repos/effort, orthopnée
- [ ] **Douleur thoracique:** pleurale, augmentée inspiration

#### ORL
- [ ] **Rhinorrhée:** claire/purulente, obstruction nasale
- [ ] **Odynophagie:** mal de gorge, dysphagie
- [ ] **Otalgie:** uni/bilatérale, otorrhée
- [ ] **Anosmie/agueusie:** COVID-19

#### Neurologique ⚠️
- [ ] **Céphalées:** intensité, photophobie, phonophobie
- [ ] **Raideur nuque:** méningisme
- [ ] **Troubles conscience:** confusion, somnolence
- [ ] **Convulsions:** généralisées/focales

#### Cutané
- [ ] **Éruption:** type, localisation, évolution
- [ ] **Purpura:** ⚠️ URGENCE si fébrile
- [ ] **Plaies:** érysipèle, cellulite
- [ ] **Points injection:** toxicomanie IV

#### Digestif
- [ ] **Douleurs abdominales:** localisation, défense
- [ ] **Diarrhée:** fréquence, glairo-sanglante
- [ ] **Vomissements:** bilieux, alimentaires
- [ ] **Ictère:** urines foncées, selles décolorées

#### Urinaire
- [ ] **Brûlures mictionnelles:** dysurie
- [ ] **Pollakiurie:** urgenturies, nycturie
- [ ] **Douleurs lombaires:** uni/bilatérales
- [ ] **Hématurie:** macroscopique

#### Ostéo-articulaire
- [ ] **Arthralgies:** mono/polyarticulaire
- [ ] **Arthrite:** gonflement, rougeur, chaleur
- [ ] **Rachialgie:** douleur vertébrale localisée
- [ ] **Myalgies:** diffuses, localisées

### 4. Contexte épidémiologique ⚠️

#### Voyages
- [ ] **Destination:** zone endémique paludisme, dengue
- [ ] **Durée et conditions:** hygiène, alimentation
- [ ] **Prophylaxie:** antipaludique, vaccinations
- [ ] **Délai retour:** incubation variable selon pathogène

#### Expositions
- [ ] **Contacts malades:** tuberculose, COVID, grippe
- [ ] **Animaux:** morsures, griffures, tiques
- [ ] **Professionnelle:** soignant, éleveur
- [ ] **Sexuelle:** IST, rapports non protégés

### 5. Terrain

#### Immunosuppression ⚠️
- [ ] **VIH:** CD4, charge virale
- [ ] **Chimiothérapie:** neutropénie
- [ ] **Corticothérapie:** > 20mg/j > 3 semaines
- [ ] **Splénectomie:** vaccinations, antibioprophylaxie
- [ ] **Greffe:** immunosuppresseurs

#### Comorbidités
- [ ] **Diabète:** déséquilibre, infections récurrentes
- [ ] **Cardiopathie:** valvulopathie (endocardite)
- [ ] **BPCO:** exacerbations fréquentes
- [ ] **Cirrhose:** infections spontanées

#### Interventions récentes
- [ ] **Chirurgie:** < 30 jours, type, complications
- [ ] **Hospitalisation:** infections nosocomiales
- [ ] **Soins dentaires:** porte entrée endocardite
- [ ] **Cathéters:** voies centrales, sondes

### 6. Médicaments
- [ ] **Antibiotiques récents:** lesquels, durée
- [ ] **Nouveaux médicaments:** fièvre médicamenteuse
- [ ] **AINS:** peuvent masquer la fièvre
- [ ] **Immunosuppresseurs:** risque infectieux

## 🩺 EXAMEN CLINIQUE

### 1. Signes vitaux ⚠️
- [ ] **Température:** confirmer hyperthermie
- [ ] **PA:** hypotension (choc septique)
- [ ] **FC:** tachycardie, dissociation pouls-T°
- [ ] **FR:** polypnée > 22 (qSOFA)
- [ ] **SaO₂:** hypoxémie < 95%
- [ ] **Conscience:** GCS < 15 (qSOFA)

### 2. État général
- [ ] **Apparence:** toxique, marbrures
- [ ] **Hydratation:** pli cutané, sécheresse muqueuses
- [ ] **Perfusion:** temps recoloration capillaire > 3s

### 3. Examen cutané complet ⚠️
- [ ] **Inspection complète:** déshabiller patient
- [ ] **Purpura:** ne s'efface pas vitropression
- [ ] **Pétéchies:** endocardite, méningococcémie
- [ ] **Érythème migrant:** maladie de Lyme
- [ ] **Nodules d'Osler:** endocardite
- [ ] **Taches de Janeway:** endocardite

### 4. Examen ORL
- [ ] **Pharynx:** érythème, exsudat amygdalien
- [ ] **Tympans:** otoscopie si possible
- [ ] **Sinus:** douleur pression/percussion
- [ ] **Cavité buccale:** état dentaire, abcès

### 5. Aires ganglionnaires
- [ ] **Cervicales:** sous-mentales, jugulo-carotidiennes
- [ ] **Sus-claviculaires:** Troisier
- [ ] **Axillaires:** palpation bilatérale
- [ ] **Inguinales:** adénopathies inflammatoires
- [ ] **Caractères:** taille, consistance, mobilité, douleur

### 6. Examen cardiovasculaire
- [ ] **Auscultation 4 foyers:** souffle nouveau ⚠️
- [ ] **Frottement péricardique:** péricardite
- [ ] **Signes insuffisance cardiaque:** OMI, RHJ
- [ ] **Pouls périphériques:** tous présents

### 7. Examen pulmonaire
- [ ] **Inspection:** tirage, cyanose
- [ ] **Percussion:** matité (condensation)
- [ ] **Auscultation:** crépitants, abolition MV
- [ ] **Frottement pleural:** pleurésie

### 8. Examen neurologique
- [ ] **Raideur nuque:** ⚠️ URGENCE
- [ ] **Kernig/Brudzinski:** signes méningés
- [ ] **Déficit focal:** AVC, abcès cérébral
- [ ] **Paires crâniennes:** paralysie faciale (Lyme)

### 9. Examen abdominal
- [ ] **Inspection:** distension, circulation collatérale
- [ ] **Palpation:** défense, Murphy, masses
- [ ] **Hépatomégalie:** bord inférieur, consistance
- [ ] **Splénomégalie:** palpation, percussion
- [ ] **Fosses lombaires:** Giordano (pyélonéphrite)

### 10. Examen ostéo-articulaire
- [ ] **Articulations:** arthrite septique
- [ ] **Rachis:** douleur percussion épineuses
- [ ] **Sacro-iliaques:** spondylodiscite

## 💊 PRISE EN CHARGE

### 1. ⚠️ CRITÈRES DE GRAVITÉ - URGENCES

#### Sepsis/Choc septique (qSOFA ≥ 2)
- [ ] **Confusion:** GCS < 15
- [ ] **FR ≥ 22/min**
- [ ] **PAS ≤ 100 mmHg**
→ Urgence, réanimation

#### Signes spécifiques d'alerte
- [ ] **Purpura fébrile:** méningococcémie
- [ ] **Souffle nouveau:** endocardite
- [ ] **Syndrome méningé:** méningite
- [ ] **Neutropénie < 500:** aplasie fébrile
- [ ] **Retour zone endémique:** paludisme

### 2. Examens complémentaires

#### Bilan de première intention
- [ ] **NFS:** leucocytose, neutropénie, lymphocytes
- [ ] **CRP/PCT:** syndrome inflammatoire
- [ ] **Ionogramme:** troubles électrolytiques
- [ ] **Fonction rénale:** créatinine, urée
- [ ] **Bilan hépatique:** cytolyse, cholestase
- [ ] **Lactates:** hypoperfusion tissulaire
- [ ] **Gazométrie:** si dyspnée ou sepsis
- [ ] **BU ± ECBU:** leucocyturie, nitrites
- [ ] **Rx thorax:** foyer pulmonaire
- [ ] **ECG:** troubles rythme, ischémie

#### Hémocultures ⚠️ AVANT antibiotiques
- [ ] **2-3 paires:** sites différents
- [ ] **Espacées 30 min:** si possible
- [ ] **Aéro-anaérobies:** flacons appropriés
- [ ] **Volume suffisant:** 8-10 mL/flacon

#### Selon orientation clinique

##### Méningite suspectée
- [ ] **PL URGENTE:** après TDM si signes focaux
- [ ] **Cytologie:** polynucléaires/lymphocytes
- [ ] **Biochimie:** glucose, protéines, lactates
- [ ] **Bactériologie:** Gram, culture, antigènes
- [ ] **PCR:** méningocoque, pneumocoque, HSV

##### Endocardite suspectée
- [ ] **Hémocultures répétées:** 3 paires/24h
- [ ] **ETT:** végétations, insuffisance valvulaire
- [ ] **ETO:** si ETT négative et forte suspicion
- [ ] **Critères Duke:** majeurs et mineurs

##### Retour voyage tropical
- [ ] **Frottis/goutte épaisse:** ⚠️ paludisme
- [ ] **Test rapide paludisme:** antigène HRP2
- [ ] **Sérologies:** dengue, chikungunya
- [ ] **Coproculture:** si diarrhée

##### Tuberculose suspectée
- [ ] **IDR/QuantiFERON:** immunité cellulaire
- [ ] **Recherche BK:** crachats x3, tubage
- [ ] **Rx/TDM thorax:** infiltrats, cavernes
- [ ] **Biopsie ganglionnaire:** si adénopathies

### 3. Traitement symptomatique

#### Antipyrétiques
- [ ] **Paracétamol:** 1g x 4/j max 4g/j
- [ ] **AINS:** ibuprofène 400mg x 3/j si CI paracétamol
- [ ] **Alternance:** possible si fièvre mal tolérée

#### Mesures générales
- [ ] **Hydratation:** PO 2-3L/j ou IV si nécessaire
- [ ] **Repos:** arrêt travail
- [ ] **Surveillance:** T° x 4/j, courbe thermique
- [ ] **Nutrition:** maintien apports caloriques

### 4. Antibiothérapie empirique

#### Sepsis grave/choc septique
- [ ] **Dans l'heure:** après hémocultures
- [ ] **Large spectre:** pipéracilline-tazobactam 4g x 3/j
- [ ] **+ Aminoside:** gentamicine 5-7 mg/kg/j
- [ ] **Adaptation:** selon antibiogramme à 48-72h

#### Méningite bactérienne
- [ ] **URGENCE ABSOLUE:** ne pas retarder
- [ ] **Ceftriaxone:** 2g x 2/j IV
- [ ] **+ Amoxicilline:** 200mg/kg/j si > 50 ans (Listeria)
- [ ] **+ Dexaméthasone:** 10mg x 4/j x 4j

#### Pneumonie communautaire
- [ ] **Amoxicilline:** 1g x 3/j PO
- [ ] **+ Macrolide:** si atypique suspectée
- [ ] **Durée:** 7-10 jours

#### Pyélonéphrite aiguë
- [ ] **Fluoroquinolone:** ciprofloxacine 500mg x 2/j
- [ ] **Ou C3G:** ceftriaxone 1g/j IM/IV
- [ ] **Durée:** 10-14 jours
- [ ] **ECBU contrôle:** à 48h

#### Endocardite
- [ ] **Bithérapie IV:** pénicilline G + gentamicine
- [ ] **Durée:** 4-6 semaines minimum
- [ ] **Adaptation:** selon germe et CMI
- [ ] **Surveillance:** fonction rénale, audiogramme

### 5. Surveillance et évolution

#### Critères d'hospitalisation
- [ ] **Sepsis/choc:** réanimation/USI
- [ ] **Immunodépression:** isolement protecteur
- [ ] **Comorbidités:** décompensation
- [ ] **Échec ambulatoire:** aggravation à 48-72h

#### Surveillance hospitalière
- [ ] **Constantes:** scope continu si sepsis
- [ ] **Bilan:** NFS, CRP à J2-J3
- [ ] **Hémocultures:** contrôle si positives
- [ ] **Efficacité ATB:** apyrexie à 48-72h

#### Suivi ambulatoire
- [ ] **Consultation:** J2-J3 si pas amélioration
- [ ] **Consignes retour:** signes gravité
- [ ] **Observance:** traitement complet
- [ ] **Contrôle:** fin de traitement

## 📊 DIAGNOSTICS DIFFÉRENTIELS

### Causes infectieuses (75%)

| Localisation | Clinique | Examens | Traitement |
|--------------|----------|---------|------------|
| **Pneumonie** | Toux, dyspnée, crépitants | Rx thorax, hémocultures | Amoxicilline |
| **Pyélonéphrite** | Douleur lombaire, BU+ | ECBU, écho rénale | Fluoroquinolone |
| **Méningite** | Céphalées, raideur nuque | PL urgente | C3G + amox |
| **Endocardite** | Souffle, phénomènes emboliques | Hémocultures, ETO | Bithérapie IV |
| **Paludisme** | Retour voyage, accès fébrile | Frottis sanguin | Artémisinine |

### Causes non infectieuses (25%)

| Étiologie | Arguments pour | Examens |
|-----------|----------------|---------|
| **Néoplasie** | AEG, sueurs nocturnes, adénopathies | TDM-TAP, biopsie |
| **Connectivite** | Arthralgies, éruption, femme jeune | AAN, ANCA |
| **Médicamenteuse** | Nouveau traitement, éosinophilie | Arrêt test |
| **Thrombose** | Facteurs risque, douleur membre | D-dimères, écho-Doppler |
| **Hyperthyroïdie** | Tremblements, tachycardie, thermophobie | TSH, T4 |

## 📌 POINTS CLÉS

### À faire systématiquement
1. **Recherche foyer infectieux** complet
2. **Évaluation gravité** (qSOFA)
3. **Examen cutané** intégral
4. **Hémocultures** avant antibiotiques
5. **Paracétamolémie** si prise antipyrétiques

### Pièges à éviter
- Oublier le **paludisme** après voyage
- Méconnaître une **endocardite** (souffle tardif)
- Banaliser fièvre chez **immunodéprimé**
- Retarder ATB si **sepsis grave**
- Négliger causes **non infectieuses**

### Mnémotechnique
**VITAMINE** pour causes de fièvre:
- **V**asculaire (TVP, EP)
- **I**nfectieux
- **T**umoral
- **A**uto-immun
- **M**édicamenteux
- **I**nflammatoire
- **N**écrose
- **E**ndocrinien
