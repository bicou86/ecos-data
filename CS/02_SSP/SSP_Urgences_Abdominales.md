# Urgences abdominales

## Domaine
Urgences/Chirurgie/Gastroentérologie

## Description
Identification et prise en charge des pathologies abdominales nécessitant une intervention urgente, avec distinction entre urgences chirurgicales et médicales.

## URGENCES CHIRURGICALES ("Les 5 P")

### 1. PERFORATION
**Pathologies** :
- Ulcère gastro-duodénal perforé
- Perforation colique (diverticulite, cancer)
- Perforation grêle (Crohn, corps étranger)

**Clinique** :
- Douleur brutale "en coup de poignard"
- Contracture abdominale (ventre de bois)
- Disparition de la matité pré-hépatique
- Silence auscultatoire

**Imagerie** :
- Pneumopéritoine sur ASP/thorax debout
- Scanner : air libre, épanchement

**PEC** :
- Réanimation (voies, O2, remplissage)
- Antibiotiques large spectre
- Chirurgie en urgence

### 2. PÉRITONITE
**Types** :
- Primaire : Ascite infectée (PBS)
- Secondaire : Perforation d'organe creux
- Tertiaire : Post-opératoire

**Signes cardinaux** :
- Contracture généralisée
- Douleur intense permanente
- Arrêt du transit
- État septique

**Bilan** :
- NFS, CRP, PCT, hémocultures
- Lactates (hypoperfusion)
- Scanner abdominal

**PEC** :
- Choc septique protocol
- Antibiothérapie probabiliste
- Laparotomie exploratrice

### 3. OBSTRUCTION (Occlusion)

#### Occlusion mécanique
**Grêle** (80%) :
- Brides (60%)
- Hernie étranglée (20%)
- Tumeur, invagination

**Côlon** (20%) :
- Cancer (60%)
- Volvulus (15%)
- Fécalome

**Clinique** :
- Douleurs coliques
- Vomissements (précoces si haute)
- Arrêt matières et gaz
- Distension abdominale

**ASP - Niveaux hydro-aériques** :
- Grêle : Centraux, valvules conniventes
- Côlon : Périphériques, haustrations

#### Iléus paralytique
- Post-opératoire
- Péritonite
- Hypokaliémie
- Médicaments (opioïdes)

**PEC occlusion** :
- Aspiration naso-gastrique
- Réhydratation, correction troubles
- Chirurgie si :
  - Strangulation
  - Échec traitement médical
  - Côlon (sauf sigmoid)

### 4. INFLAMMATION/INFECTION

#### Appendicite aiguë
**Diagnostic** :
- Douleur migrant vers FID
- McBurney, Rovsing, psoas
- Fièvre modérée
- Leucocytose, CRP

**Complications** :
- Perforation
- Abcès
- Plastron

**PEC** :
- Appendicectomie < 24h
- ATB si compliquée

#### Cholécystite aiguë
**Clinique** :
- Murphy positif
- Douleur HCD + fièvre
- ± Ictère (Mirizzi)

**Imagerie** :
- Écho : Épaississement paroi > 4mm
- Murphy échographique

**PEC** :
- ATB (C3G + métronidazole)
- Cholécystectomie précoce (< 72h)

#### Diverticulite
**Hinchey** :
- I : Abcès péricolique
- II : Abcès pelvien
- III : Péritonite purulente
- IV : Péritonite stercorale

**PEC** :
- I-II : ATB ± drainage
- III-IV : Chirurgie urgente (Hartmann)

### 5. PATHOLOGIE VASCULAIRE

#### Ischémie mésentérique aiguë
**Types** :
- Embolique (50%) : FA, IDM
- Thrombotique (25%) : Athérosclérose
- Veineuse (10%) : Thrombophilie
- NOMI (15%) : Bas débit

**Clinique** :
- Douleur disproportionnée
- Transit normal initial
- Acidose lactique

**Diagnostic** :
- Angio-scanner urgent
- Lactates élevés

**PEC** :
- Anticoagulation (si embolique)
- Revascularisation
- Résection intestin nécrosé
- Second look 24-48h

#### Anévrisme aorte abdominale rompu
**Triade** :
- Douleur abdominale/dorsale
- Masse pulsatile
- Hypotension

**PEC** :
- 2 VVP gros calibre
- Hypotension permissive (PAS 80-90)
- Bloc opératoire immédiat
- Cross-match sang

## URGENCES MÉDICALES

### Pancréatite aiguë
**Étiologies** (I GET SMASHED) :
- Idiopathique
- Gallstones (lithiase)
- Ethanol
- Trauma
- Steroids
- Mumps (oreillons)
- Autoimmune
- Scorpion
- Hypercalcémie/Hyperlipidémie
- ERCP
- Drugs

**Diagnostic** : 2/3 critères
- Douleur typique transfixiante
- Lipase > 3N
- Imagerie compatible

**Scores pronostiques** :
- Ranson (admission + 48h)
- BISAP
- APACHE II

**PEC** :
- Réhydratation agressive
- Analgésie
- Nutrition entérale précoce
- ATB si nécrose infectée

### Colique hépatique
**Clinique** :
- Douleur HCD intense
- Post-prandiale (repas gras)
- Durée > 30 min

**Complications** :
- Cholécystite
- Angiocholite
- Pancréatite biliaire

**PEC** :
- Antispasmodiques
- AINS
- Cholécystectomie à froid

### Angiocholite
**Triade de Charcot** :
- Douleur HCD
- Fièvre avec frissons
- Ictère

**Pentade de Reynolds** (forme grave) :
- Triade de Charcot +
- Confusion
- Choc septique

**PEC** :
- ATB urgents (C3G + métronidazole)
- Drainage biliaire urgent (ERCP)

### Colique néphrétique
**Clinique** :
- Douleur lombaire irradiant aine
- Agitation (vs péritonite immobile)
- Hématurie microscopique

**Imagerie** :
- Écho : Dilatation pyélocalicielle
- TDM low-dose : Localisation calcul

**Critères hospitalisation** :
- Rein unique
- Anurie
- Pyélonéphrite associée
- Échec traitement ambulatoire

## APPROCHE SYSTÉMATIQUE

### ABCDE initial
- **A** : Voies aériennes
- **B** : Respiration (pneumonie basale?)
- **C** : Circulation (choc?)
- **D** : Neurologique
- **E** : Exposition complète

### Examens urgents
**Biologie** :
- NFS, CRP, PCT
- Ionogramme, urée, créat
- Bilan hépatique, lipase
- Lactates, gazométrie
- βHCG si femme

**Imagerie** :
- ASP debout + thorax : Pneumopéritoine, niveaux
- Échographie : Rapide, chevet
- Scanner abdo-pelvien : Gold standard

### Critères de gravité
- Instabilité hémodynamique
- Péritonite généralisée
- Acidose lactique
- SIRS/Sepsis
- Défaillance d'organe

## PIÈGES DIAGNOSTIQUES

### Causes extra-abdominales
- **IDM inférieur** : Épigastralgie
- **Pneumonie basale** : Douleur HCD/HCG
- **Acidocétose** : Pseudo-abdomen aigu
- **Porphyrie** : Crises douloureuses
- **Zona** : Phase pré-éruptive

### Terrains particuliers
**Grossesse** :
- Appendicite déplacée
- HELLP syndrome
- Rupture utérine

**Immunodéprimé** :
- Typhlite
- CMV colite
- Abcès mycotique

**Âgé** :
- Présentation atypique
- Ischémie plus fréquente

## Points clés pour l'ECOS
1. **Identifier urgences chirurgicales** (5P)
2. **Contracture = péritonite** jusqu'à preuve contraire
3. **Scanner** = examen clé
4. **Lactates** si suspicion ischémie
5. **βHCG** systématique chez femme
6. **Réanimation** parallèle au diagnostic
7. **Chirurgien** prévenu précocement

## Mnémotechnique
**"Les 5 P" des urgences chirurgicales**:
- **P**erforation
- **P**éritonite
- **P**athologie obstructive (occlusion)
- **P**athologie inflammatoire (appendicite)
- **P**athologie vasculaire (ischémie)
