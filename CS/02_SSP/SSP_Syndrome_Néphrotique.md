# Syndrome néphrotique

## Type
SSP Néphrologie

## Description
Syndrome glomérulaire défini par une protéinurie massive > 3g/24h (ou 50mg/kg/j chez l'enfant) et une hypoalbuminémie < 30g/L, responsable d'œdèmes.

## Présentation clinique typique
- Œdèmes blancs, mous, déclives
- Prise de poids progressive
- Urines mousseuses
- Asthénie
- +/- Complications thromboemboliques ou infectieuses

## ANAMNÈSE

### Mode de présentation

#### Symptômes initiaux
- **Œdèmes** :
  - Début : Paupières le matin
  - Extension : Membres inférieurs, puis généralisés
  - Rapidité d'installation
  - Prise de poids (quantifier)
- **Urines** :
  - Mousseuses (protéinurie)
  - Volume : Oligurie fréquente
  - Couleur : Foncées si hématurie associée
- **Signes généraux** :
  - Asthénie progressive
  - Anorexie
  - Douleurs abdominales (enfant)

#### Circonstances de découverte
- Fortuite sur bilan biologique
- Œdèmes inexpliqués
- Complication inaugurale (thrombose, infection)

### Recherche étiologique

#### Syndrome néphrotique primitif (glomérulopathies)
- **Enfant** :
  - Syndrome néphrotique idiopathique (85%)
  - Début 2-6 ans
  - Épisode infectieux précédent
- **Adulte** :
  - Hyalinose segmentaire et focale (HSF)
  - Glomérulonéphrite extramembraneuse
  - Glomérulonéphrite à IgA
  - Maladie à lésions glomérulaires minimes

#### Syndrome néphrotique secondaire

**Diabète** :
- Ancienneté > 10 ans
- Rétinopathie associée (parallélisme)
- Équilibre glycémique

**Maladies systémiques** :
- Lupus : Femme jeune, signes extra-rénaux
- Amylose : Myélome, infections chroniques
- Vascularites : ANCA

**Infections** :
- VIH, VHB, VHC
- Endocardite
- Paludisme (enfant)

**Médicaments/toxiques** :
- AINS
- Sels d'or, D-pénicillamine
- Héroïne

**Cancers** :
- Tumeurs solides (poumon, digestif)
- Hémopathies (Hodgkin)
- Syndrome paranéoplasique

### Complications à rechercher

#### Thromboemboliques
- **TVP/EP** : Douleur, dyspnée
- **Thrombose veines rénales** :
  - Douleur lombaire brutale
  - Hématurie macroscopique
  - Aggravation fonction rénale
- **Facteurs de risque** :
  - Albuminémie < 20g/L
  - Syndrome néphrotique profond

#### Infectieuses
- **Infections bactériennes** :
  - Pneumocoque ++
  - Péritonite spontanée (enfant)
  - Cellulite, érysipèle
- **Facteurs** : Hypogammaglobulinémie, perte IgG

#### Insuffisance rénale aiguë
- Fonctionnelle (hypovolémie)
- Nécrose tubulaire aiguë
- Thrombose veines rénales
- Néphropathie à IgM

### Antécédents

#### Néphrologiques
- Protéinurie antérieure
- Hématurie
- HTA
- Épisodes antérieurs syndrome néphrotique

#### Facteurs de risque cardiovasculaire
- Dyslipidémie (aggravée par SN)
- Diabète
- Tabagisme
- Antécédents familiaux

#### Médicaments
- Néphrotoxiques
- Anticoagulants (si thrombose)
- Immunosuppresseurs antérieurs

## EXAMEN CLINIQUE

### État général
- **Poids** : Gain récent (quantifier)
- **PA** : Variable (haute si néphritique)
- **Température** : Apyrexie habituelle
- **État nutritionnel** : Dénutrition possible

### Œdèmes : Caractéristiques spécifiques

#### Syndrome néphrotique pur
- **Blancs** : Pas de signe inflammatoire
- **Mous** : Prennent le godet
- **Indolores**
- **Déclives** : Migration selon position
- **Symétriques**
- **Distribution** :
  - Paupières (matin)
  - Membres inférieurs (soir)
  - Lombes (décubitus)
  - Organes génitaux
  - Anasarque si sévère

#### Épanchements séreux
- **Ascite** : Matité déclive
- **Pleurésie** : Matité, abolition MV
- **Péricarde** : Rare

### Signes de complications

#### Thrombose
- **TVP** : Mollet douloureux, signe de Homans
- **EP** : Dyspnée, douleur thoracique
- **Thrombose veines rénales** : Douleur lombaire

#### Infection
- Fièvre (toute fièvre = urgence)
- Signes de localisation
- Érysipèle : Placard inflammatoire

#### Hypovolémie efficace
- **Hypotension orthostatique**
- **Tachycardie**
- **Extrémités froides**
- **Oligurie**

### Recherche étiologie

#### Signes de maladie systémique
- **Lupus** : Éruption malaire, arthralgies
- **Amylose** : Macroglossie, purpura
- **Diabète** : Neuropathie, rétinopathie

#### Signes de cancer
- Adénopathies
- Hépatomégalie
- Altération état général

## DIAGNOSTIC

### Critères diagnostiques
1. **Protéinurie** > 3g/24h (ou rapport P/C > 300 mg/mmol)
2. **Hypoalbuminémie** < 30g/L
3. **Œdèmes** (inconstants au début)
4. **Hyperlipidémie** (habituelle mais non obligatoire)

### Syndrome néphrotique pur vs impur

#### SN pur
- Protéinurie sélective (albumine++)
- Pas d'hématurie
- Pas d'HTA
- Fonction rénale normale
- Complément normal

#### SN impur
- Hématurie microscopique
- HTA
- Insuffisance rénale
- Hypocomplémentémie
→ Oriente vers cause secondaire

## EXAMENS COMPLÉMENTAIRES

### Biologie de première intention

#### Confirmation syndrome
- **Protéinurie 24h** ou rapport P/C
- **Électrophorèse protéines** urinaires :
  - Sélective : Albumine > 80%
  - Non sélective : Globulines ++
- **Albuminémie** : < 30g/L
- **Protidémie** : < 60g/L

#### Bilan rénal
- **Créatinine, urée** : Fonction rénale
- **Ionogramme** : Na, K
- **Bandelette** : Sang, leucocytes
- **Sédiment** : Hématies, cylindres

#### Bilan lipidique
- **Cholestérol total** : Augmenté
- **LDL** : Très augmenté
- **Triglycérides** : Augmentés
- **HDL** : Variable

#### Complications
- **NFS** : Hémoconcentration
- **TP, TCA** : Si anticoagulation
- **D-dimères** : Si suspicion thrombose

### Biologie étiologique

#### Enfant
- Si SN pur entre 1-10 ans : Pas de bilan
- Traitement d'épreuve corticoïdes

#### Adulte (systématique)
- **Immunologie** :
  - AAN, anti-DNA
  - ANCA
  - C3, C4, CH50
  - Cryoglobuline
  - Anti-PLA2R (GEM)
- **Sérologies** : VIH, VHB, VHC
- **Électrophorèse protéines** sériques
- **Glycémie** à jeun
- **Recherche cancer** selon âge :
  - > 50 ans : Coloscopie, scanner TAP
  - Mammographie, PSA

### Imagerie

#### Échographie rénale
- **Systématique**
- Taille, différenciation
- Dilatation (obstacle)
- Échogénicité augmentée

#### Doppler veines rénales
- Si suspicion thrombose
- Si albuminémie < 20g/L

#### Scanner/IRM
- Recherche cancer si > 50 ans
- Thrombose veineuse profonde

### Biopsie rénale

#### Indications
- **Adulte** : Systématique (sauf diabète typique)
- **Enfant** :
  - Âge < 1 an ou > 10 ans
  - SN impur
  - Corticorésistance
  - Rechutes fréquentes

#### Résultats : Types histologiques
- **Lésions glomérulaires minimes** : MO normale
- **HSF** : Sclérose segmentaire
- **GEM** : Épaississement membrane basale
- **Proliférative** : Hypercellularité

## COMPLICATIONS

### Thromboemboliques (25-40%)

#### Facteurs de risque
- Albuminémie < 20g/L
- Fibrinogène > 6g/L
- Antithrombine III basse
- GEM ++

#### Localisations
- TVP membres inférieurs
- Embolie pulmonaire
- Thrombose veines rénales
- Thromboses artérielles (rares)

### Infectieuses

#### Mécanisme
- Perte IgG, facteur B, C3
- Hypogammaglobulinémie
- Immunosuppresseurs

#### Types
- **Bactériennes** : Pneumocoque, Haemophilus
- **Péritonite primitive** (enfant)
- **Cellulite, érysipèle**
- **Zona** sous immunosuppresseurs

### Insuffisance rénale aiguë

#### Causes
- **Fonctionnelle** : Hypovolémie, diurétiques
- **NTA** : Sepsis, néphrotoxiques
- **Thrombose veines rénales**
- **Progression maladie rénale**

### Dyslipidémie athérogène
- Augmentation risque cardiovasculaire
- Xanthomes si prolongé
- Indication statines

### Dénutrition
- Perte protéines
- Anorexie
- Régime restrictif mal conduit

## TRAITEMENT

### Traitement symptomatique

#### Restriction sodée
- **< 3g/j** NaCl (50 mmol Na)
- Fondamental
- Éducation diététique

#### Diurétiques
- **Furosémide** : 40-500mg/j
- **Association** : Thiazidique, spironolactone
- **Surveillance** : Poids, ionogramme, fonction rénale
- **Objectif** : Perte 0.5-1kg/j

#### Restriction hydrique
- Si hyponatrémie < 130
- 500-1000 mL/j

#### Repos
- Favorise diurèse
- Prévention thrombose (mobilisation)

### Traitement étiologique

#### Syndrome néphrotique idiopathique enfant

**Corticothérapie** :
- Prednisone 60mg/m²/j (max 60mg) 4 semaines
- Puis 40mg/m² 1j/2 4 semaines
- Décroissance sur 2-3 mois
- **Réponse** : 90% à J8-15

**Corticorésistance** :
- Absence rémission à 4 semaines
- Indication biopsie
- Immunosuppresseurs : Ciclosporine, tacrolimus

**Corticodépendance** :
- Rechute à décroissance
- Traitement épargneur : Lévamisole, MMF, rituximab

#### Glomérulopathies adulte

**Lésions glomérulaires minimes** :
- Corticoïdes 1mg/kg/j
- Réponse 4-8 semaines
- Décroissance lente (6 mois)

**HSF** :
- Corticoïdes + ciclosporine
- ou tacrolimus
- Objectif : Rémission partielle

**GEM** :
- Traitement conservateur si bas risque
- Rituximab ou cyclophosphamide si haut risque
- Anti-PLA2R : Marqueur réponse

**Néphropathie diabétique** :
- IEC/ARA2 systématique
- Contrôle glycémique strict
- Contrôle PA < 130/80

### Traitement des complications

#### Prévention thromboembolique
**Anticoagulation préventive** si :
- Albuminémie < 20g/L
- ATIII < 70%
- IMC > 35
- Immobilisation

**Anticoagulation curative** si :
- Thrombose documentée
- GEM avec albuminémie < 20g/L

#### Prévention infectieuse
- **Vaccination** : Pneumocoque, grippe
- **Antibioprophylaxie** : Discutée enfant
- **Pénicilline V** si hypogammaglobulinémie sévère

#### Dyslipidémie
- **Statines** : Si persistant > 6 mois
- **Objectif** : LDL < 2.6 mmol/L
- Surveillance CPK

#### Supplémentations
- **Vitamine D** : Perte protéine porteuse
- **Calcium** si corticoïdes
- **Fer** si anémie

### Néphroprotection
- **IEC/ARA2** : Réduction protéinurie
- **Contrôle PA** : < 130/80
- **Éviction néphrotoxiques**

## SURVEILLANCE

### Phase aiguë (hospitalisation)
- **Quotidien** :
  - Poids, diurèse
  - PA, œdèmes
  - Ionogramme si diurétiques
- **Hebdomadaire** :
  - Protéinurie
  - Albuminémie
  - Créatinine

### Phase d'entretien
- **Mensuel** début :
  - Protéinurie (bandelette à domicile)
  - Poids
  - PA
- **Trimestriel** :
  - Bilan rénal
  - Albuminémie
  - Lipides
- **Annuel** :
  - Échoographie rénale
  - Bilan complet

### Définitions évolutives

#### Rémission complète
- Protéinurie < 0.3g/24h
- Albuminémie > 35g/L
- Créatinine normale

#### Rémission partielle
- Protéinurie < 3.5g/24h et réduction > 50%
- Albuminémie > 30g/L

#### Rechute
- Protéinurie > 3.5g/24h
- Après rémission

#### Corticodépendance
- Rechute pendant décroissance
- Ou dans les 15j après arrêt

#### Corticorésistance
- Absence rémission après 4 semaines (enfant)
- Ou 16 semaines (adulte)

## PRONOSTIC

### Facteurs de bon pronostic
- Âge jeune
- SN pur
- Corticosensibilité
- Lésions minimes
- Absence complications

### Facteurs de mauvais pronostic
- Insuffisance rénale initiale
- Protéinurie massive persistante
- HSF, proliférative
- Complications thromboemboliques
- Infections sévères

## Points clés pour l'ECOS
1. **Protéinurie > 3g/24h** + **albumine < 30g/L** = diagnostic
2. **Œdèmes blancs mous déclives** = typiques
3. **Biopsie rénale** systématique chez l'adulte
4. **Restriction sodée** = base du traitement
5. **Anticoagulation** si albumine < 20g/L
6. **Corticoïdes** 1ère ligne enfant
7. **Complications** : Thrombose, infections

## Mnémotechniques

**"OPEN"** pour critères syndrome néphrotique:
- **O**edèmes
- **P**rotéinurie > 3g/24h
- **E**ffondrement albumine < 30g/L
- **N**éphrologie (biopsie adulte)

**"TILE"** pour complications:
- **T**hrombose
- **I**nfection
- **L**ipides augmentés
- **E**ffondrement fonction rénale
