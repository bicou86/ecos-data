# 🟡 SSP : Ictère

---

## 🗣️ 1. Anamnèse – Questions clés

| Domaine                          | Questions à explorer                                                                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Chronologie**                  | - Depuis quand ? Apparition brutale ou progressive ?<br>- Évolution : stable, fluctuante, aggravation ?                                          |
| **Symptômes associés**           | - Fièvre ? Douleur abdominale (surtout HD) ?<br>- Prurit ? Urines foncées ? Selles décolorées ?<br>- Asthénie, anorexie, perte de poids ?        |
| **Caractéristiques de l’ictère** | - Ictère uniquement cutané ou aussi oculaire ?<br>- Fluctuations dans le temps ?                                                                 |
| **Contexte hémolytique**         | - ATCD anémie ? Splénomégalie ? Pâleur ?<br>- Prise de médicaments (quinine, céphalosporines, etc.) ?<br>- Exposition à toxiques (plomb, fava) ? |
| **Contexte hépatique**           | - ATCD hépatite ? Consommation d’alcool ou drogues IV ?<br>- IST, voyages en zone endémique ?                                                    |
| **Contexte biliaire**            | - Coliques hépatiques ? ATCD lithiasiques ?<br>- Chirurgie biliaire ou digestive ?                                                               |
| **Médicaments/toxiques**         | - Paracétamol, ATB, statines, contraceptifs, produits de phytothérapie ?                                                                         |
| **ATCD familiaux**               | - Ictère néonatal, maladies héréditaires (Gilbert, Crigler-Najjar) ?                                                                             |

---

## 🧑‍⚕️ 2. Examen clinique

| Étapes                         | Objectifs                                                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Inspection**                 | - Ictère cutanéo-muqueux (sclères, palais)<br>- Érythrose palmaire, angiomes stellaires<br>- Signe de flap hépatique, encéphalopathie |
| **Palpation abdominale**       | - Hépatomégalie, douleur en HCD<br>- Masse abdominale (vésicule palpable = signe de Courvoisier)                                      |
| **Recherche de splénomégalie** | - Signe en faveur de cause hémolytique ou hépatique chronique                                                                         |
| **Recherche de prurit**        | - Grattage, lésions de griffe                                                                                                         |
| **Signes généraux**            | - Amaigrissement, fièvre, asthénie<br>- Signes d'insuffisance hépatocellulaire                                                        |

## 🧪 3. DD + Signes évocateurs, examens, résultats, traitement

| **Diagnostic**                                                 | **Signes cliniques évocateurs**                                          | **Examens**                                                     | **Résultats attendus**                                                         | **Traitement**                                                                     |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **Ictère hémolytique (pré-hépatique)**                         | Pas d’urines foncées, pas de prurit                                      | NFS, LDH, haptoglobine, frottis, bilirubine totale/différenciée | Bilirubine **indirecte↑**, haptoglobine ↓, LDH ↑, réticulocytes ↑              | Traiter la cause (ex. arrêt médicament, maladie auto-immune)                       |
| **Hépatite virale aiguë**                                      | Fièvre, asthénie, douleurs HCD, ictère progressif                        | Sérologies virales (VHA-E), ALAT, ASAT, PAL, GGT                | ALAT > ASAT, bilirubine ↑, IgM VHA ou HBsAg +                                  | Repos, hydratation, traitement antiviral selon virus                               |
| **Hépatite toxique ou médicamenteuse**                         | Prise de paracétamol, ATB, statines, herbes médicinales                  | ALAT, ASAT, dosage paracétamol, INR                             | ALAT très ↑, parfois INR ↑                                                     | Arrêt produit, N-acétylcystéine (si paracétamol)                                   |
| **Cirrhose décompensée**                                       | ATCD alcoolisme, angiomes stellaires, ascite                             | Biologie hépatique, échographie, fibroscan                      | Hépatopathie chronique, hypoalbuminémie, TP ↓                                  | Traitement cause, surveillance, transplantation si nécessaire                      |
| **Syndrome de Gilbert**                                        | Ictère intermittent, jeune adulte, déclenché par stress/jeûne            | Bilirubine indirecte ↑ seule, bilan hépatique normal            | Aucun autre trouble biologique                                                 | Rassurance, pas de traitement nécessaire                                           |
| **Crigler-Najjar type I/II**                                   | Ictère néonatal sévère, troubles neurologiques (type I)                  | Bilirubine indirecte très ↑, tests génétiques                   | Type I : pas de réponse au phénobarbital<br>Type II : réponse au phénobarbital | Type I : photothérapie, transplantation<br>Type II : phénobarbital ± photothérapie |
| **Syndrome de Dubin-Johnson / Rotor**                          | Ictère conjugué chronique sans autre anomalie                            | Bilirubine **directe↑**, reste du bilan normal                  | Test urinaire anormal, foie noirâtre (Dubin-Johnson)                           | Pas de traitement, bénin                                                           |
| **Cholestase intra-hépatique (hépatite, médicaments, sepsis)** | Prurit, ictère, urines foncées, selles pâles                             | ALAT, PAL, GGT, écho hépatique                                  | PAL, GGT ↑, bilirubine directe ↑                                               | Traitement de la cause, cholestyramine pour le prurit                              |
| **Obstacle biliaire (lithiase, tumeur)**                       | Ictère progressif, douleurs HCD (si lithiase), prurit, vésicule palpable | Échographie abdo, scanner, CPRE                                 | Dilatation des voies biliaires, calculs visibles, tumeur suspecte              | CPRE, chirurgie, traitement du cancer (si tumeur)                                  |

## 💊 4. Traitements généraux

### Selon l’étiologie :

* **Infectieuse (hépatites)** : antiviraux ou symptomatiques
* **Toxique / Médicamenteux** : arrêt du produit, antidote (paracétamol)
* **Chirurgical** : si obstacle biliaire (calcul, tumeur)
* **Héréditaire** : traitement symptomatique ou transplantation si sévère (Crigler-Najjar type I)
* **Auto-immun** : corticoïdes ± immunosuppresseurs
* **Symptomatique** : cholestyramine pour le prurit, photothérapie (chez le nouveau-né)

## 📌 À retenir pour l’ECOS

* Faire la **différenciation : pré-hépatique / hépatique / post-hépatique**
* Ne pas oublier de **demander les selles décolorées, urines foncées et prurit**
* L’**examen clinique orienté** est essentiel (grattage, foie palpable, masse, splénomégalie)
* Toujours **prescrire une échographie abdominale** en 1ʳᵉ intention si suspicion d’obstacle
* Ne jamais oublier les **causes médicamenteuses**
* En cas de cholestase, rechercher une **douleur biliaire**, un **cancer pancréatique**, ou une **cholangite**
