# 🧠 SSP : Confusion aiguë (Delirium)

---

## 🗣️ 1. Anamnèse – Questions clés

| Domaine                              | Questions importantes                                                                                                |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **Début et évolution**               | - Depuis quand ?<br>- Brutal ou progressif ?<br>- Fluctuations dans la journée ?                                     |
| **Contexte médical**                 | - Âge avancé, hospitalisation récente ?<br>- ATCD de démence ou confusion antérieure ?                               |
| **Symptômes associés**               | - Hallucinations, troubles du sommeil ?<br>- Troubles moteurs, chutes récentes ?<br>- Prise de médicaments récents ? |
| **Infections**                       | - Fièvre ? Symptômes urinaires ? Toux ? Douleur ?                                                                    |
| **Consommations**                    | - Alcool, sevrage, substances ?<br>- Médicaments : anticholinergiques, benzodiazépines, opioïdes ?                   |
| **Troubles métaboliques**            | - Diabète ? Insuffisance rénale ou hépatique ? Déséquilibre électrolytique connu ?                                   |
| **Douleur, constipation, rétention** | - Douleur non exprimée ?<br>- Derniers épisodes mictionnels et selles ?                                              |
| **État fonctionnel antérieur**       | - Niveau d’autonomie, troubles cognitifs préexistants ?                                                              |

## 🧑‍⚕️ 2. Examen clinique

| Étapes                          | Ce qu’il faut rechercher                                             |
| ------------------------------- | -------------------------------------------------------------------- |
| **État de conscience**          | Vigilance fluctuante, désorientation spatio-temporelle               |
| **Attention**                   | Test des mois à l’envers, séries de 7, 100-7                         |
| **Comportement**                | Agitation, apathie, hallucinations, troubles du cycle veille-sommeil |
| **Signes focaux neurologiques** | Déficit focal, tremblements, myoclonies, raideur méningée            |
| **Signes infectieux**           | Fièvre, syndrome inflammatoire local (pulmonaire, urinaire, etc.)    |
| **Hydratation / dénutrition**   | Pli cutané, muqueuses, perte de poids, albumine ↓                    |
| **Surcharge / déshydratation**  | Turgescence jugulaire, œdèmes, bruit hydro-aérique réduit            |
| **Examen médicamenteux**        | Revue complète du traitement en cours                                |

## 🧪 3. Diagnostiques différentiels, signes, examens, résultats, traitements

| **Diagnostic**                                             | **Signes évocateurs**                                            | **Examens utiles**                           | **Résultats attendus**                                 | **Traitement**                                          |
| ---------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| **Syndrome confusionnel (delirium)**                       | Apparition aiguë, fluctuation, trouble attention, hallucinations | Clinique + CAM (Confusion Assessment Method) | Confirme le diagnostic, pas de cause organique visible | Traitement étiologique + environnement calme            |
| **Infection (Urinaires, pulmonaires, sepsis)**             | Fièvre, frissons, toux, douleur lombaire, hypoxie                | ECBU, CRP, hémocultures, radio thorax        | Hyperleucocytose, foyer infectieux                     | Antibiothérapie adaptée, hydratation                    |
| **Trouble métabolique**                                    | Diabète, IR, troubles ioniques, IC                               | NFS, iono, créatinine, glycémie, GDS         | Hypo/hypernatrémie, urée/Cr ↑, hypoxie                 | Correction rapide des troubles métaboliques             |
| **Sevrage alcoolique / benzodiazépines**                   | ATCD alcoolisme, tremblements, agitation, sueurs                 | Clinique, bilan hépatique, dosage alcoolémie | Gamma GT ↑, CDT ↑, sevrage récent                      | Benzodiazépines (lorazépam), surveillance rapprochée    |
| **Toxiques / iatrogénie**                                  | Médicaments anticholinergiques, opioïdes, sédatifs               | Revue thérapeutique, toxicologie             | Médicament en cause, QT long, bradycardie              | Arrêt/substitution médicament, surveillance ECG         |
| **Encéphalopathie hépatique**                              | Cirrhose, astérixis, troubles du sommeil, confusion              | Ammoniémie, TP, NH3, bilan hépatique         | NH3 ↑, TP ↓, bilirubine ↑                              | Lactulose, traitement cause hépatique                   |
| **Trouble neurologique aigu (AVC, hémorragie, épilepsie)** | Signes focaux, chute, antécédent AVC                             | Scanner cérébral, EEG                        | AVC, saignement, onde lente à l’EEG                    | Prise en charge neuro, anticoagulation selon indication |
| **Hypoglycémie**                                           | Tremblements, sueurs, troubles comportementaux                   | Glycémie capillaire                          | < 70 mg/dL                                             | Glucose per os ou IV si sévère                          |
| **Démence débutante (pseudo-confusionnelle)**              | Troubles mnésiques chroniques, altération progressive            | MMS, MOCA, neuro-imagerie                    | Atrophie corticale, test cognitifs altérés             | PEC gériatrique, stimulation cognitive                  |
| **Dépression pseudo-démentielle**                          | Ralentissement, repli, perte d'intérêt                           | Examen psy, test de l’horloge, GDS           | Dépression masquée                                     | Antidépresseurs, psychothérapie, soutien social         |

## 💊 4. Traitement

### Principes généraux :

* **Traiter la cause sous-jacente** : infection, trouble métabolique, sevrage, médicament…
* **Prévention des complications** : chutes, fausse route, syndrome d’immobilisation
* **Contexte adapté** : calme, repères temporels et spatiaux visibles (horloge, calendrier)
* **Favoriser l'autonomie** : mobiliser, réalimenter, éviter contention
* **Hydratation et nutrition optimales**

### Si agitation sévère :

* **Non médicamenteux** : famille présente, réduction des stimuli
* **Antipsychotiques** :

  * *Halopéridol* (faible dose) : 0,5–1 mg PO/IM
  * *Risperidone*, *olanzapine* (formes orales en cas d'agitation modérée)
* **⚠️ Benzodiazépines :** à éviter sauf sevrage alcoolique ou BZD

---

## 📌 À retenir pour l’ECOS

* Toujours **rechercher une cause réversible** rapidement
* Utiliser un **outil de dépistage validé** : **CAM** (Confusion Assessment Method)
* Différencier **démence** (chronique) vs **delirium** (aigu, fluctuant)
* Ne pas négliger les **causes médicamenteuses**
* Attention aux **facteurs gériatriques classiques** : infection, douleur, dénutrition, rétention, constipation
* Raisonner selon la **règle des 6 I** :

  * **Infection**
  * **Insuffisance d’organe**
  * **Iatrogénie**
  * **Immobilisation**
  * **Intoxication**
  * **Infarctus/AVC**
