# ⚖️ SSP : Amaigrissement involontaire

---

## 🗣️ 1. Anamnèse – Questions clés

| Domaine                            | Questions importantes                                                                                                                    |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Perte de poids**                 | - Combien de kilos ? Sur quelle période ?<br>- Volontaire ou involontaire ?<br>- Associée à un changement d’appétit ou d’alimentation ?  |
| **Contexte général**               | - Âge, antécédents médicaux ?<br>- Alcool, tabac, drogues ?<br>- Changement de mode de vie, stress, deuil ?                              |
| **Symptômes associés**             | - Fièvre, sueurs nocturnes, douleurs ?<br>- Diarrhée chronique, vomissements, dysphagie ?<br>- Fatigue, insomnie, troubles de l’humeur ? |
| **Signes fonctionnels ciblés**     | - Respiratoire : toux, dyspnée ?<br>- Digestif : selles, douleurs abdo, transit ?<br>- Neuropsy : troubles cognitifs, isolement social ? |
| **Médicaments**                    | - Prise récente ou chronique (diurétiques, thyroxine, chimiothérapie…) ?                                                                 |
| **Bilan alimentaire et ingestion** | - Difficulté à mâcher/déglutir ? Douleurs buccales ?<br>- Régimes restrictifs, anorexie ?<br>- Troubles digestifs post-ingestion ?       |
| **ATCD familiaux**                 | - Cancers, troubles thyroïdiens, maladies psychiatriques ?                                                                               |

---

## 🧑‍⚕️ 2. Examen clinique

| Étapes                        | Ce qu’il faut rechercher                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Évaluation nutritionnelle** | - IMC < 18,5 ? Perte de masse musculaire ou graisseuse ?<br>- Signe de sarcopénie ?                                            |
| **Inspection générale**       | - Cachexie, fonte musculaire, peau sèche, cheveux cassants ?<br>- Signe de déshydratation ?                                    |
| **Examen ORL / buccal**       | - Dentition, candidose, aphtes, troubles de la déglutition                                                                     |
| **Examen abdominal**          | - Masse palpable, douleur, hépatosplénomégalie                                                                                 |
| **Examen neuropsychiatrique** | - Apathie, ralentissement, troubles cognitifs                                                                                  |
| **Signes spécifiques**        | - Goitre, exophtalmie (hyperthyroïdie)<br>- Adénopathies (cancer, lymphome)<br>- Signes d’insuffisance cardiaque ou pulmonaire |

## 🧪 3. Diagnostiques différentiels : signes, examens, résultats, traitements

| **Diagnostic**                                      | **Signes évocateurs**                                               | **Examens utiles**                                       | **Résultats attendus**                                 | **Traitement**                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------- |
| **Cancer (digestif, pulmonaire, hémato, pancréas)** | Amaigrissement + fatigue, douleur, masse, hémorragies, anémie       | Imagerie (TDM TAP), endoscopie, bilan tumoral            | Masse, adénopathie, tumeur visible, marqueurs tumoraux | Chirurgie, chimiothérapie, radiothérapie selon type               |
| **Hyperthyroïdie**                                  | Amaigrissement + appétit conservé, tachycardie, agitation, diarrhée | TSH, T3/T4                                               | TSH ↓, T3/T4 ↑                                         | Antithyroïdiens, β-bloquants, iode radioactif, chirurgie          |
| **Dépression, anorexie mentale**                    | Amaigrissement, asthénie, tristesse, insomnie, isolement            | Hétéro- et auto-questionnaire, DSM-5                     | Critères psychiatriques, exclusion causes organiques   | Psychothérapie, antidépresseurs, soutien nutritionnel             |
| **Malabsorption (Crohn, cœliaque, pancréatite)**    | Diarrhées, stéatorrhée, douleurs abdo, ballonnements                | BU, bilan nutritionnel, endoscopie, sérologies, biopsies | Carences, lésions muqueuses, inflammation              | Régime, traitement spécifique (gluten-free, enzymes, immunosupp.) |
| **Infections chroniques (tuberculose, VIH)**        | Sueurs nocturnes, toux chronique, fièvre, asthénie                  | IDR, sérologies, PCR, imagerie thoracique                | Infiltrats, cavernes, sérologies +                     | Antibiotiques, antirétroviraux, soutien nutritionnel              |
| **Insuffisance d’organe (IC, IRC, BPCO avancée)**   | Dyspnée, œdèmes, orthopnée, nycturie                                | BNP, créatinine, EFR, ECG, écho cœur/poumons             | Fonction altérée, dilatation, HTAP, baisse VEMS        | Traitement de l’organe cible, diurétiques, régime                 |
| **Maladie neurodégénérative**                       | Troubles de mémoire, apraxie, perte autonomie                       | MMSE, imagerie cérébrale, consultation mémoire           | Atrophie cérébrale, bilan neuro anormal                | PEC multidisciplinaire, nutrition, aide sociale                   |
| **Addictions (alcool, drogues, tabac)**             | Contexte social difficile, négligence, anorexie                     | GGT, CDT, toxicologie urinaire, bilan hépatique          | Anomalies hépatiques, carences multiples               | Sevrage, accompagnement social et médical                         |
| **Vieillissement / dénutrition du sujet âgé**       | Sarcopénie, fatigue, chutes, isolement                              | Bilan nutritionnel, albumine, CRP, IMC                   | Albumine ↓, poids ↓, IMC bas                           | Suppléments, repas enrichis, soutien à domicile                   |

---

## 💊 4. Traitement

### Approche globale :

1. **Traiter la cause sous-jacente**
   (néoplasie, endocrino, psy, infectieux, digestif…)

2. **Apport nutritionnel adapté**

   * Enrichissement alimentaire
   * Supplémentation orale (protéines, calories, micronutriments)
   * Assistance par diététicien

3. **Soutien global**

   * Activité physique adaptée (lutte contre sarcopénie)
   * Accompagnement psychologique
   * Prise en charge sociale si isolement

4. **Cas sévères**

   * Alimentation entérale ou parentérale si nécessaire

---

## 📌 À retenir pour l’ECOS

* Toujours **quantifier la perte de poids** (> 5% en 6–12 mois = significatif)
* Identifier si **volontaire ou involontaire**
* Raisonner selon les **3 axes principaux** :

  * Organique (cancer, digestif, endocrinien)
  * Psychiatrique (dépression, anorexie)
  * Social (isolement, pauvreté, dépendance)
* Un **examen clinique complet est crucial** : ne pas se limiter à l’IMC
* **Bilan biologique initial large** recommandé : NFS, CRP, TSH, bilan hépatique, rénal, albumine, iono
* **Soutien nutritionnel rapide** en cas de risque de dénutrition
