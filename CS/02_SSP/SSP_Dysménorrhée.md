# Fiche de Révision ECOS - DYSMÉNORRHÉE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patiente consultant pour douleurs pelviennes cycliques liées aux menstruations nécessitant différenciation primaire/secondaire et prise en charge adaptée.
**Objectifs d'évaluation:** Diagnostic différentiel dysménorrhée primaire vs secondaire, recherche pathologie sous-jacente, traitement symptomatique et étiologique

## 📋 ANAMNÈSE

### 1. Caractérisation de la dysménorrhée ⚠️ ESSENTIEL

#### 1.1 Description de la douleur
- [ ] **Type de douleur:**
  - Crampes pelviennes
  - Spasmes utérins
  - Douleur sourde continue
  - Coliques
- [ ] **Localisation:**
  - Hypogastrique médiane
  - Irradiation dos, cuisses
  - Unilatérale (endométriose?)
- [ ] **Intensité:** EVA 0-10
- [ ] **Durée:** Heures, jours

#### 1.2 Chronologie par rapport aux règles
- [ ] **Début:**
  - Avant les règles (syndrome prémenstruel)
  - Avec le début des règles
  - Durant tout le cycle
- [ ] **Pic douloureux:** J1, J2 habituellement
- [ ] **Durée totale:** 1-3 jours typiquement
- [ ] **Évolution durant le flux**

#### 1.3 Âge de début ⚠️ ORIENTATION
- [ ] **Dès les premières règles:** Primaire probable
- [ ] **Après période sans douleur:** Secondaire probable
- [ ] **Âge actuel** de la patiente

### 2. Retentissement fonctionnel ⚠️ ÉVALUER SÉVÉRITÉ

#### 2.1 Impact sur les activités
- [ ] **Absentéisme:** École, travail
- [ ] **Alitement nécessaire**
- [ ] **Limitation activités** quotidiennes
- [ ] **Arrêt sport**
- [ ] **Nombre jours** impactés/mois

#### 2.2 Impact psychosocial
- [ ] **Anxiété anticipatoire**
- [ ] **Altération qualité de vie**
- [ ] **Impact relationnel**
- [ ] **Évitement social**

### 3. Symptômes associés

#### 3.1 Symptômes menstruels
- [ ] **Ménorragies:** Règles abondantes
- [ ] **Métrorragies:** Saignements entre règles
- [ ] **Caillots** importants
- [ ] **Durée règles** (normale 3-7j)
- [ ] **Cycle:** Régularité, durée

#### 3.2 Symptômes généraux
- [ ] **Nausées, vomissements**
- [ ] **Diarrhée** (prostaglandines)
- [ ] **Céphalées**
- [ ] **Fatigue intense**
- [ ] **Malaise, lipothymies**
- [ ] **Lombalgies**

#### 3.3 Symptômes évocateurs endométriose ⚠️ RECHERCHER
- [ ] **Dyspareunie profonde**
- [ ] **Douleurs pelviennes chroniques**
- [ ] **Dyschésie:** Douleur défécation pendant règles
- [ ] **Dysurie:** Douleur miction pendant règles
- [ ] **Infertilité**
- [ ] **Spotting** prémenstruel

### 4. Dysménorrhée primaire vs secondaire

#### 4.1 Dysménorrhée primaire (90%)
- [ ] **Début:** 6-24 mois après ménarche
- [ ] **Âge:** Adolescentes, jeunes femmes
- [ ] **Douleur:** Crampes rythmiques
- [ ] **Durée:** 48-72h max
- [ ] **Examen:** Normal
- [ ] **Amélioration:** Avec âge, grossesse

#### 4.2 Dysménorrhée secondaire ⚠️ CAUSE ORGANIQUE
- [ ] **Début:** Après 25 ans ou aggravation
- [ ] **Douleur:** Continue, progressive
- [ ] **Durée:** Peut persister après règles
- [ ] **Symptômes associés** spécifiques
- [ ] **Examen:** Anomalies possibles

### 5. Causes de dysménorrhée secondaire

#### 5.1 Endométriose (30-50%)
- [ ] **Douleurs progressives**
- [ ] **Dyspareunie profonde**
- [ ] **Infertilité associée**
- [ ] **ATCD familiaux**

#### 5.2 Adénomyose
- [ ] **Femmes >35 ans**
- [ ] **Ménorragies importantes**
- [ ] **Utérus augmenté volume**

#### 5.3 Fibromes utérins
- [ ] **Ménorragies**
- [ ] **Pesanteur pelvienne**
- [ ] **Masse palpable**

#### 5.4 Malformations utérines
- [ ] **Douleurs dès ménarche**
- [ ] **Hématométrie** (sang retenu)

#### 5.5 DIU (stérilet)
- [ ] **Surtout DIU cuivre**
- [ ] **Augmentation douleurs et flux**

#### 5.6 Sténose cervicale
- [ ] **Post-conisation, curetage**
- [ ] **Flux diminué**

#### 5.7 MIP (Maladie Inflammatoire Pelvienne)
- [ ] **ATCD IST**
- [ ] **Leucorrhées**
- [ ] **Fièvre**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Dysménorrhée primaire
- [ ] **Aucun examen** si:
  - Adolescente
  - Tableau typique
  - Examen normal
  - Réponse au traitement

#### 1.2 Dysménorrhée secondaire suspectée

**Échographie pelvienne:** ⚠️ 1ÈRE LIGNE
- [ ] **Voie endovaginale** (si possible)
- [ ] **Recherche:**
  - Endométriomes ovariens
  - Adénomyose (utérus hétérogène)
  - Fibromes
  - Malformations
  - Hydrosalpinx

**IRM pelvienne:**
- [ ] **Si suspicion endométriose**
- [ ] **Cartographie lésions**
- [ ] **Bilan préopératoire**

**Hystéroscopie:**
- [ ] **Si suspicion:**
  - Polypes
  - Synéchies
  - Malformation

**Cœlioscopie diagnostique:**
- [ ] **Gold standard endométriose**
- [ ] **Biopsies** pour confirmation
- [ ] **Traitement** simultané possible

#### 1.3 Biologie
- [ ] **β-HCG:** Éliminer grossesse
- [ ] **NFS:** Si ménorragies (anémie)
- [ ] **Ferritine**
- [ ] **CA-125:** Peu spécifique

### 2. Traitement de la dysménorrhée primaire

#### 2.1 AINS ⚠️ PREMIÈRE LIGNE
- [ ] **Début:** Dès début douleurs ou règles
- [ ] **Molécules:**
  - Ibuprofène 400-600mg × 3/j
  - Naproxène 550mg × 2/j
  - Acide méfénamique 500mg × 3/j
- [ ] **Durée:** 2-3 jours
- [ ] **Efficacité:** 70-80%
- [ ] **CI:** Ulcère, allergie, grossesse

#### 2.2 Contraception hormonale ⚠️ TRÈS EFFICACE
**Œstroprogestatifs:**
- [ ] **Pilule continue** ou cyclique
- [ ] **Patch, anneau vaginal**
- [ ] **Réduction prostaglandines**
- [ ] **Efficacité:** 90%

**Progestatifs seuls:**
- [ ] **DIU lévonorgestrel** (Mirena)
- [ ] **Implant** (Nexplanon)
- [ ] **Pilule microprogestative**
- [ ] **Aménorrhée** fréquente (bénéfique)

#### 2.3 Autres traitements médicamenteux
- [ ] **Antispasmodiques:** Phloroglucinol
- [ ] **Paracétamol:** Moins efficace seul
- [ ] **Association** AINS + antispasmodique

### 3. Traitement non médicamenteux

#### 3.1 Mesures générales
- [ ] **Chaleur locale:** Bouillotte, bain chaud
- [ ] **Repos** pendant pic douloureux
- [ ] **Position antalgique**

#### 3.2 Hygiène de vie
- [ ] **Exercice physique** régulier
- [ ] **Alimentation équilibrée:**
  - Oméga-3
  - Magnésium
  - Vitamine B1
- [ ] **Réduction stress**
- [ ] **Arrêt tabac**

#### 3.3 Thérapies complémentaires
- [ ] **TENS** (neurostimulation)
- [ ] **Acupuncture**
- [ ] **Yoga, relaxation**
- [ ] **Ostéopathie**
- [ ] **Psychothérapie** si composante anxieuse

### 4. Traitement de la dysménorrhée secondaire

#### 4.1 Endométriose

**Médical:**
- [ ] **AINS + contraception** continue
- [ ] **Analogues GnRH** (ménopause artificielle)
- [ ] **Diénogest** 2mg/j
- [ ] **Add-back therapy** (œstrogènes faible dose)

**Chirurgical:**
- [ ] **Cœlioscopie:** Exérèse lésions
- [ ] **Préservation fertilité** si désir grossesse
- [ ] **Hystérectomie** si échec (dernier recours)

#### 4.2 Adénomyose
- [ ] **DIU lévonorgestrel** +++
- [ ] **Analogues GnRH**
- [ ] **Embolisation artères utérines**
- [ ] **Hystérectomie** si sévère

#### 4.3 Fibromes
- [ ] **Surveillance** si peu symptomatiques
- [ ] **Traitement médical:** Analogues GnRH
- [ ] **Myomectomie** si désir grossesse
- [ ] **Embolisation**
- [ ] **Hystérectomie** si nombreux/volumineux

#### 4.4 DIU
- [ ] **Retrait** si douleurs invalidantes
- [ ] **Remplacement** par DIU hormonal

### 5. Prise en charge spécifique

#### 5.1 Adolescente
- [ ] **Rassurance** +++
- [ ] **Éducation** sur menstruations
- [ ] **AINS** première ligne
- [ ] **Contraception** si échec AINS

#### 5.2 Désir de grossesse
- [ ] **AINS** jusqu'ovulation seulement

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Différencier primaire/secondaire** (âge début)
2. **Évaluer retentissement** fonctionnel
3. **Rechercher endométriose** (dyspareunie++)
4. **AINS première ligne** si primaire
5. **Contraception hormonale** si échec AINS
6. **Échographie si secondaire** suspectée

### ❌ Pièges à éviter
1. **Banaliser douleurs** intenses
2. **Examens inutiles** si primaire typique
3. **Oublier contraception** = traitement
4. **Négliger endométriose** chez jeune
5. **Retarder cœlioscopie** si échec médical

### 💡 Astuces mnémotechniques
- **Endométriose - 4D:** **D**ysménorrhée, **D**yspareunie, **D**ysurie, **D**yschésie
- **AINS efficaces:** **I**buprofène, **N**aproxène, **A**cide méfénamique (INA)
- **Dysménorrhée primaire:** **A**do, **C**rampes, **A**INS efficaces (ACA)
- **Causes secondaires:** **E**ndométriose, **A**dénomyose, **F**ibromes, **M**IP (EAFM)
