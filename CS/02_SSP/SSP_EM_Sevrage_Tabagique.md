# SSP - Sevrage Tabagique et Entretien Motivationnel

## 1. ÉVALUATION INITIALE - MODÈLE DES 5A

### 1.1 ASK - Identifier la consommation ⚠️ SYSTÉMATIQUE
**Questions d'ouverture** :
- "Êtes-vous fumeur/fumeuse ?"
- "Avez-vous déjà fumé ?"
- "Fumez-vous occasionnellement ?"

**Si fumeur actuel** :
- Nombre de cigarettes/jour
- Durée du tabagisme (paquets-années)
- Type de tabac (cigarettes, roulées, pipe, cigare)
- Usage d'e-cigarette ou tabac chauffé

### 1.2 ASSESS - Évaluer motivation et dépendance

#### Test de Fagerström (dépendance nicotinique) ⚠️ ESSENTIEL
| Question | Points |
|----------|--------|
| **Délai 1ère cigarette après réveil** | |
| < 5 min | 3 |
| 6-30 min | 2 |
| 31-60 min | 1 |
| > 60 min | 0 |
| **Difficulté à ne pas fumer dans lieux interdits** | |
| Oui | 1 |
| Non | 0 |
| **Cigarette la plus importante** | |
| La première | 1 |
| Une autre | 0 |
| **Nombre cigarettes/jour** | |
| ≤ 10 | 0 |
| 11-20 | 1 |
| 21-30 | 2 |
| ≥ 31 | 3 |
| **Fume plus le matin** | |
| Oui | 1 |
| Non | 0 |
| **Fume même si malade** | |
| Oui | 1 |
| Non | 0 |

**Interprétation** :
- 0-2 : Pas de dépendance
- 3-4 : Dépendance faible
- 5-6 : Dépendance modérée
- 7-8 : Dépendance forte
- 9-10 : Dépendance très forte

#### Évaluation de la motivation
**Stade de changement** :
- **Pré-contemplation** : "Je n'ai pas l'intention d'arrêter"
- **Contemplation** : "J'envisage d'arrêter dans les 6 mois"
- **Préparation** : "Je veux arrêter dans le mois"
- **Action** : Arrêt < 6 mois
- **Maintien** : Arrêt > 6 mois

**Questions d'exploration** :
- "Avez-vous l'intention d'arrêter de fumer ?"
- "Quand envisagez-vous d'arrêter ?"
- "Avez-vous déjà essayé d'arrêter ?"
- "Qu'est-ce qui vous a aidé/gêné lors des tentatives précédentes ?"

### 1.3 ADVISE - Conseiller clairement
**Message clair et personnalisé** :
- "En tant que médecin, je vous recommande d'arrêter de fumer"
- Personnaliser selon contexte (grossesse, maladie CV, etc.)
- Éviter le jugement et la culpabilisation

### 1.4 ASSIST - Aider selon le stade

#### Non motivé (pré-contemplation)
**Intervention brève (3-5 min)** :
- Explorer ambivalence sans insister
- "Qu'est-ce que le tabac vous apporte ?"
- "Y a-t-il des aspects qui vous préoccupent ?"
- Laisser documentation adaptée

#### Ambivalent (contemplation)
**Entretien motivationnel (10-15 min)** :
- Balance décisionnelle
- Explorer avantages/inconvénients
- Renforcer le discours-changement
- Proposer nouveau RDV

#### Motivé (préparation/action)
**Intervention soutenue (20-30 min)** :
- Fixer date d'arrêt (dans 2-4 semaines)
- Prescrire substitution nicotinique
- Plan de gestion des situations à risque
- Prévoir suivi rapproché

### 1.5 ARRANGE - Organiser le suivi
**Calendrier de suivi** :
- Semaine 1 : Contact téléphonique ou consultation
- Semaine 2 : Consultation
- Semaine 4 : Consultation
- Semaine 8 : Consultation
- Mois 3 et 6 : Suivi

## 2. SUBSTITUTION NICOTINIQUE

### 2.1 Principes généraux ⚠️ ADAPTEZ LA DOSE
- **Pas de risque de surdosage** nicotinique
- **Auto-titration** : Patient ajuste selon besoins
- **Combinaison** patch + forme courte durée plus efficace
- **Durée** : 2-3 mois minimum, jusqu'à 6-12 mois si nécessaire

### 2.2 Formes galéniques

#### Patch (timbre transdermique)
**Dosages disponibles** :
- Nicorette® 16h : 25mg → 15mg → 10mg
- Nicotinell® 24h : 21mg → 14mg → 7mg

**Schéma selon dépendance** :
- **Forte** (> 20 cig/j) : Dose forte 4-6 sem → moyenne 4 sem → faible 4 sem
- **Modérée** (10-20 cig/j) : Dose moyenne 8 sem → faible 4 sem
- **Faible** (< 10 cig/j) : Dose faible 8-12 sem

#### Formes orales courte durée
**Gommes à mâcher** :
- 2mg ou 4mg selon dépendance
- Technique "chew and park" : Mâcher → parker contre joue → répéter
- Maximum 24 gommes/jour

**Comprimés sublinguaux** :
- 1-2mg
- Laisser fondre sous la langue
- Maximum 30 comprimés/jour

**Inhalateur** :
- Cartouches 10mg
- Inhaler 20 min
- Maximum 12 cartouches/jour

**Spray buccal** :
- 1mg/pulvérisation
- 1-2 pulvérisations selon besoin
- Maximum 64 pulvérisations/jour

### 2.3 Stratégies de combinaison
**Dépendance forte/très forte** :
- Patch dose maximale + forme orale à la demande
- Ajuster patch si symptômes de sevrage persistants
- Liberté d'utilisation formes orales selon envies

## 3. MÉDICAMENTS NON NICOTINIQUES

### 3.1 Bupropion (Zyban®)
**Posologie** :
- J1-J6 : 150mg × 1/jour
- J7+ : 150mg × 2/jour
- Arrêt tabac J8-J14
- Durée totale : 7-9 semaines

**Contre-indications** :
- Épilepsie, troubles convulsifs
- Troubles alimentaires
- Sevrage alcool/benzodiazépines
- IMAO < 14 jours

**Effets secondaires** :
- Insomnie (éviter prise vespérale)
- Sécheresse buccale
- Céphalées

### 3.2 Varénicline (Champix®) - Non disponible depuis 2021
**Information historique** :
- Agoniste partiel récepteurs nicotiniques
- Efficacité supérieure (33% abstinence à 6 mois)
- Retiré du marché pour impuretés

## 4. GESTION DES SITUATIONS SPÉCIFIQUES

### 4.1 Syndrome de sevrage
**Symptômes et durée** :
- **Envie impérieuse** (craving) : Pic 24-72h, diminue en 3-4 sem
- **Irritabilité, anxiété** : 2-4 semaines
- **Troubles concentration** : 2-3 semaines
- **Troubles sommeil** : 1-2 semaines
- **Augmentation appétit** : Plusieurs mois
- **Constipation** : Variable

**Prise en charge** :
- Augmenter substitution si insuffisante
- Techniques de gestion du stress
- Activité physique régulière
- Hydratation suffisante

### 4.2 Prise de poids ⚠️ PRÉOCCUPATION FRÉQUENTE
**Informations à transmettre** :
- Moyenne : 3-4 kg (extrêmes 0-30 kg)
- Due au sevrage (~300 kcal/j) + compensation orale
- Bénéfices arrêt >> risques prise de poids
- Retour progressif au poids normal

**Conseils pratiques** :
- Ne pas faire régime pendant sevrage
- Privilégier fruits/légumes pour grignotage
- Augmenter activité physique
- Boire eau régulièrement
- Un problème à la fois

### 4.3 Rechute et faux-pas
**Distinguer** :
- **Faux-pas** : 1-2 cigarettes isolées
- **Rechute** : Retour consommation régulière

**Approche motivationnelle** :
- Normaliser : "C'est fréquent, moyenne 5 tentatives"
- Explorer circonstances sans juger
- Renforcer apprentissages
- Ajuster plan si nécessaire
- Maintenir espoir et soutien

## 5. TECHNIQUES D'ENTRETIEN MOTIVATIONNEL SPÉCIFIQUES

### 5.1 Explorer l'ambivalence
**Balance décisionnelle** :
```
Continuer à fumer          |  Arrêter de fumer
---------------------------|---------------------------
Avantages :                |  Avantages :
- Gestion stress           |  - Santé améliorée
- Plaisir, habitude        |  - Économies
- Moments sociaux          |  - Liberté retrouvée
                          |  - Exemple enfants
Inconvénients :           |  Inconvénients :
- Coût                    |  - Sevrage difficile
- Santé détériorée        |  - Prise de poids
- Dépendance              |  - Perte "béquille"
```

### 5.2 Questions ouvertes adaptées
**Explorer motivation** :
- "Qu'est-ce qui vous ferait envisager d'arrêter ?"
- "Comment voyez-vous votre vie sans tabac ?"
- "Qu'est-ce qui serait différent pour vous ?"

**Renforcer confiance** :
- "Qu'est-ce qui vous a aidé lors de vos précédentes tentatives ?"
- "Sur une échelle de 0 à 10, quelle est votre confiance en votre capacité d'arrêter ?"
- "Pourquoi [X] et pas [X-2] ?"

### 5.3 Reflets et résumés
**Reflet simple** :
Patient : "J'aimerais arrêter mais c'est trop dur"
Soignant : "L'arrêt vous semble vraiment difficile"

**Reflet double face** :
"D'un côté vous aimeriez arrêter pour votre santé, et de l'autre vous craignez de ne pas y arriver"

**Résumé structuré** :
"Si je comprends bien, vous fumez depuis 20 ans, vous avez déjà essayé d'arrêter 3 fois, la dernière fois vous avez tenu 2 mois avec des patchs, et maintenant vous voulez réessayer car votre fille est enceinte"

## 6. POPULATIONS PARTICULIÈRES

### 6.1 Grossesse ⚠️ URGENCE
- **Arrêt immédiat** idéal, réduction si impossible
- **Substitution nicotinique** possible (rapport bénéfice/risque favorable)
- **Éviter** bupropion (données insuffisantes)
- **Suivi rapproché** et soutien psychologique
- **Post-partum** : Risque rechute élevé

### 6.2 Adolescents
- **Approche non-jugeante** essentielle
- **Explorer** : Image, pairs, rebellion
- **Formes orales** privilégiées (gommes, comprimés)
- **Impliquer** parents selon contexte
- **Prévention** vapotage concomitant

### 6.3 Pathologies psychiatriques
- **Dépression** : Bupropion peut être bénéfique
- **Schizophrénie** : Doses substitution plus élevées
- **Troubles anxieux** : Gestion anxiété concomitante
- **Adaptation** posologie psychotropes après arrêt

### 6.4 Maladies cardiovasculaires
- **Bénéfice majeur** de l'arrêt
- **Substitution nicotinique** sûre (même post-IDM)
- **Surveillance** : TA, FC
- **Message positif** : Réduction risque 50% à 1 an

## 8. EFFICACITÉ ET PRONOSTIC

### 8.1 Taux d'abstinence à 6 mois
- **Arrêt spontané** : 3-5%
- **Conseil médical seul** : 7-10%
- **Substitution nicotinique** : 19-25%
- **Bupropion** : 24%
- **Varénicline** (historique) : 33%
- **Combinaison + suivi** : 30-36%

### 8.2 Facteurs de bon pronostic
- Motivation intrinsèque forte
- Soutien social présent
- Absence de co-addictions
- Tentatives antérieures > 24h
- Substitution adéquate
- Suivi régulier

## 9. MESSAGES CLÉS POUR L'EXAMEN ECOS

### 9.1 Structure de consultation ⚠️ SÉQUENCE TYPE
1. **Demander permission** d'aborder le sujet
2. **Évaluer** consommation et dépendance (Fagerström)
3. **Explorer** motivation sans juger
4. **Informer** avec permission (explore-informe-explore)
5. **Négocier** objectif réaliste
6. **Prescrire** si approprié
7. **Planifier** suivi

### 9.2 Erreurs à éviter
- Confrontation ou jugement
- Conseils non sollicités
- Minimiser la difficulté
- Oublier d'évaluer la dépendance
- Sous-doser la substitution
- Négliger le suivi

### 9.3 Points bonus ECOS
- Utiliser les 5A systématiquement
- Calculer le score de Fagerström
- Adapter intervention au stade
- Proposer combinaison substituts
- Planifier suivi structuré
- Valoriser efforts antérieurs
