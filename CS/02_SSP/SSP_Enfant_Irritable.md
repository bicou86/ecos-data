# Fiche de Révision ECOS - Enfant Irritable/Qui Pleure

## 🎯 Situation à Starting Point (SSP)
**Description:** Parent consulte pour un enfant irritable, pleurs excessifs ou changement comportemental
**Objectifs d'évaluation:** Identifier red flags (méningite, invagination), diagnostics bénins, conseils d'apaisement

---

## 📋 ANAMNÈSE

### 1. Anamnèse actuelle et caractérisation des pleurs
**Questions essentielles:**
- [ ] **Âge exact de l'enfant** (nouveau-né, nourrisson, enfant)
- [ ] Début et évolution des pleurs/irritabilité
- [ ] **Caractère des pleurs:** inconsolables vs calmables
- [ ] **Moment de survenue:** jour vs nuit, rapport aux repas
- [ ] **Durée des épisodes** et fréquence
- [ ] **Facteurs déclenchants** identifiables
- [ ] **Moyens d'apaisement** efficaces ou non
- [ ] Changement par rapport au comportement habituel

### 2. Recherche de RED FLAGS (URGENCES)

**Signes méningés/neurologiques:**
- [ ] **Fièvre** (température rectale exacte)
- [ ] **Raideur nucale** (si >12-18 mois)
- [ ] **Fontanelle antérieure** (bombée, tendue si <18 mois)
- [ ] **Cris aigus** stridents
- [ ] **Troubles de conscience:** léthargie, hypotonie
- [ ] **Photophobie** (si âge approprié)
- [ ] **Purpura** cutané ne s'effaçant pas à la vitropression

**Signes digestifs (invagination intestinale):**
- [ ] **Pleurs paroxystiques** intenses toutes les 10-15 min
- [ ] **Vomissements** bilieux ou fécaloïdes
- [ ] **Rectorragies** ("gelée de groseille")
- [ ] **Masse palpable** abdominale (boudin d'invagination)
- [ ] **Arrêt des selles** et gaz

**Autres urgences:**
- [ ] **Trauma:** chute, maltraitance (hématomes suspects)
- [ ] **Intoxication** accidentelle
- [ ] **Corps étranger** (oreilles, nez, œsophage)

### 3. Symptômes par âge

**Nouveau-né (0-28 jours):**
- [ ] Prise pondérale (pesées régulières)
- [ ] **Allaitement:** efficacité, durée, fréquence
- [ ] **Selles:** fréquence, aspect (méconium, selles de lait)
- [ ] **Ictère** (intensité, évolution)
- [ ] **Régurgitations,** vomissements
- [ ] Température (hypothermie aussi dangereuse)

**Nourrisson (1-24 mois):**
- [ ] **Sommeil:** durée, qualité, réveils
- [ ] **Alimentation:** appétit, diversification
- [ ] **Développement psychomoteur:** sourire, tenue de tête, position assise
- [ ] **Dentition:** poussée dentaire (hypersalivation, joues rouges)
- [ ] **Vaccinations** récentes (réaction possible)

**Enfant (>2 ans):**
- [ ] **Capacité de communication:** peut exprimer douleur/gêne
- [ ] **Troubles du sommeil,** cauchemars
- [ ] **Scolarité,** adaptation sociale
- [ ] **Énurésie,** encoprésie
- [ ] **Troubles comportementaux** associés

### 4. Antécédents et contexte

**Antécédents périnataux:**
- [ ] **Grossesse:** complications, prématurité
- [ ] **Accouchement:** voie basse, césarienne, complications
- [ ] **Période néonatale:** réanimation, hospitalisation
- [ ] **Poids de naissance** et croissance

**Développement et santé:**
- [ ] **Courbes de croissance:** poids, taille, PC
- [ ] **Développement psychomoteur:** normal vs retard
- [ ] **Vaccinations:** à jour selon calendrier
- [ ] **Pathologies chroniques**
- [ ] **Hospitalisations** antérieures

### 5. Environnement familial et social
- [ ] **Situation familiale:** parents, fratrie
- [ ] **Stress parental:** fatigue, épuisement, dépression post-partum
- [ ] **Support social:** famille élargie, amis
- [ ] **Conditions de vie:** logement, moyens financiers
- [ ] **Violence domestique** (évaluation discrète)

### 6. Prise médicamenteuse
- [ ] **Médicaments:** dose, fréquence
- [ ] **Compléments:** vitamine D, fer
- [ ] **Intoxication accidentelle** possible

## 🩺 EXAMEN CLINIQUE (STATUS)

### Observation générale (PRIORITÉ)
- [ ] **État général:** alerte vs léthargique
- [ ] **Comportement:** interactif vs apathique
- [ ] **Pleurs pendant examen:** consolables vs inconsolables
- [ ] **Coloration:** normale vs marbrée vs cyanotique
- [ ] **Niveau de conscience** (échelle adaptée à l'âge)

### Signes vitaux (âge-ajustés)
- [ ] **Température** rectale (gold standard <5 ans)
- [ ] **Fréquence cardiaque** (tachycardie si fièvre/déshydratation)
- [ ] **Fréquence respiratoire,** signes de détresse
- [ ] **Tension artérielle** si accessible
- [ ] **Saturométrie** si signes respiratoires

### Examen neurologique (si fièvre/troubles conscience)
- [ ] **Fontanelles** (bombement, tension si <18 mois)
- [ ] **Périmètre crânien** vs courbes
- [ ] **Tonus** musculaire global
- [ ] **Réflexes archaïques** (si nouveau-né/nourrisson)
- [ ] **Purpura** cutané (vitropression)

### Examen digestif (si vomissements/douleurs)
- [ ] **Inspection:** distension, circulation collatérale
- [ ] **Auscultation:** bruits intestinaux (silence = iléus)
- [ ] **Palpation douce:** masse, défense, douleur
- [ ] **Palpation bimanuelle** (recherche boudin d'invagination)
- [ ] **Toucher rectal** si indication (rectorragies)

### Examen ORL et dentition
- [ ] **Tympans:** otite, corps étranger
- [ ] **Gorge:** angine, herpangine
- [ ] **Gencives:** inflammation, poussée dentaire
- [ ] **Nez:** obstruction, corps étranger

### Examen cutané
- [ ] **Éruption:** localisation, type de lésions
- [ ] **Hématomes:** localisation suspecte (maltraitance)
- [ ] **Pâleur,** ictère
- [ ] **État d'hydratation:** pli cutané, muqueuses

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Conduite diagnostique selon l'âge

**Nouveau-né fiévreux (<28 jours):**
- [ ] **HOSPITALISATION SYSTÉMATIQUE**
- [ ] **Bilan septique complet:** FSC, CRP, hémocultures, ECBU, PL
- [ ] **Antibiothérapie empirique** après prélèvements

**Nourrisson 1-3 mois fiévreux:**
- [ ] **Évaluation risque élevé** (critères de Rochester/Philadelphia)
- [ ] **Si bas risque:** surveillance rapprochée possible
- [ ] **Si haut risque:** bilan + hospitalisation

### 2. Diagnostics différentiels par âge

| Âge | Diagnostics fréquents | Red flags à éliminer | Examens |
|-----|----------------------|---------------------|---------|
| **0-3 mois** | • Coliques du nourrisson<br>• RGO<br>• Faim/soif<br>• Inconfort (couche, chaleur) | • Méningite<br>• Sepsis<br>• Malformation (sténose pylore) | FSC, CRP si fièvre |
| **3-12 mois** | • Poussée dentaire<br>• Otite<br>• Constipation<br>• Angoisses séparation | • Invagination<br>• Méningite<br>• Maltraitance | Clinique +++<br>Écho abdominale si signes |
| **1-3 ans** | • Terreurs nocturnes<br>• Caprices<br>• Maladies virales<br>• Troubles adaptation | • Méningite<br>• Trauma<br>• Intoxication | Selon contexte clinique |

### 3. Prise en charge spécifique

#### Coliques du nourrisson (règle des 3)
**Critères:** pleurs >3h/jour, >3j/semaine, >3 semaines
- [ ] **Rassurer les parents** (bénin, transitoire)
- [ ] **Conseils:** position ventrale, massage, bercement
- [ ] **Probiotiques** (Lactobacillus reuteri)
- [ ] **Éviter changements** alimentaires fréquents

#### Poussée dentaire
- [ ] **Signes:** hypersalivation, joues rouges, mâchouillements
- [ ] **Traitement:** anneau dentition réfrigéré
- [ ] **Antalgiques:** paracétamol (15mg/kg/6h) si douleur
- [ ] **Éviter:** gels sucrés, miel, colliers ambre (risque étouffement)

#### Otite moyenne aiguë
- [ ] **Diagnostic:** tympan rouge, bombé, douleur
- [ ] **Traitement:** antalgiques ± antibiotiques selon âge/sévérité
- [ ] **Surveillance:** amélioration sous 48-72h

#### Fièvre isolée bien tolérée
- [ ] **Mesures physiques:** déshabiller, hydratation
- [ ] **Paracétamol:** 15mg/kg toutes les 6h (max 60mg/kg/j)
- [ ] **Surveillance:** signes d'aggravation
- [ ] **Reconsultation:** si persistance >72h ou dégradation

### 4. Conseils d'apaisement (tous âges)

**Techniques de réconfort:**
- [ ] **Emmaillotage** (nouveau-nés)
- [ ] **Bercement,** balancement
- [ ] **Bruit blanc:** aspirateur, sèche-cheveux
- [ ] **Position:** ventre contre l'épaule
- [ ] **Succion:** tétine, doigt propre
- [ ] **Contact peau-à-peau**

**Gestion parentale:**
- [ ] **Relais entre parents** (éviter épuisement)
- [ ] **Accepter l'impuissance** temporaire
- [ ] **Réseau de soutien:** famille, amis, professionnels
- [ ] **Consulter si épuisement** parental extrême

### 5. Signes d'alarme - Quand reconsulter IMMÉDIATEMENT
- [ ] **Fièvre >38°C** chez <3 mois
- [ ] **Convulsions**
- [ ] **Troubles de conscience:** léthargie, hypotonie sévère
- [ ] **Vomissements** persistants, bilieux
- [ ] **Refus alimentaire** complet >12h
- [ ] **Purpura** cutané
- [ ] **Pleurs inconsolables** >2h continues
- [ ] **Détresse respiratoire**

### 6. Prévention et éducation
- [ ] **Sécurisation environnement:** prévention accidents
- [ ] **Vaccinations:** respecter calendrier
- [ ] **Développement normal:** étapes clés
- [ ] **Soutien parental:** groupes de parents, PMI
- [ ] **Dépistage dépression** post-partum maternelle

---

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Éliminer RED FLAGS** (méningite, invagination) AVANT tout
2. **Examen fontanelles** si <18 mois + fièvre
3. **Rassurer ET éduquer** les parents systématiquement

### ❌ Pièges à éviter
1. Minimiser pleurs chez nouveau-né fiévreux (<28j = hospitalisation)
2. Prescrire antibiotiques sans indication (surthérapie)
3. Négliger épuisement parental (risque maltraitance/dépression)

### 💡 Astuces mnémotechniques
- **"3-3-3"** = Coliques du nourrisson (>3h/j, >3j/sem, >3sem)
- **"Fièvre + fontanelle bombée"** = méningite jusqu'à preuve du contraire
- **"Pleurs paroxystiques + vomissements + rectorragies"** = invagination
