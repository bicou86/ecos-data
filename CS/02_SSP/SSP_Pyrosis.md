# Fiche de Révision ECOS - PYROSIS (BRÛLURES RÉTROSTERNALES)

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient se plaignant de brûlures rétrosternales (pyrosis)
**Objectifs d'évaluation:** Confirmer le reflux gastro-œsophagien (RGO), rechercher les complications, identifier les signes d'alarme, adapter le traitement

---

## 📋 ANAMNÈSE

### 1. Caractérisation du pyrosis ⚠️ ESSENTIEL

#### 1.1 Description de la douleur
- [ ] **Localisation:**
  - Rétrosternale ascendante
  - Épigastrique
  - Irradiation gorge, mâchoire
- [ ] **Type de sensation:**
  - Brûlure
  - Chaleur remontante
  - Acidité
- [ ] **Intensité:** EVA 0-10
- [ ] **Fréquence:**
  - Quotidienne
  - Hebdomadaire
  - Occasionnelle

#### 1.2 Temporalité
- [ ] **Horaire:**
  - Post-prandial (30-60 min après repas)
  - Nocturne (réveil)
  - À jeun
- [ ] **Durée des épisodes:** Minutes à heures
- [ ] **Ancienneté:** Semaines, mois, années
- [ ] **Évolution:** Stable, aggravation

#### 1.3 Facteurs déclenchants
- [ ] **Alimentaires:**
  - Repas copieux, gras
  - Aliments acides (tomates, agrumes)
  - Épices
  - Chocolat, café
  - Alcool
  - Boissons gazeuses
- [ ] **Positionnels:**
  - Décubitus (couché)
  - Antéflexion (se pencher)
  - Effort physique post-prandial

#### 1.4 Facteurs de soulagement
- [ ] **Antiacides** (efficacité immédiate)
- [ ] **Position assise/debout**
- [ ] **Eau, lait**
- [ ] **IPP** (si déjà essayés)

### 2. Symptômes associés du RGO

#### 2.1 Manifestations digestives
- [ ] **Régurgitations acides:**
  - Sans effort de vomissement
  - Goût acide/amer
  - Nocturnes (oreiller taché)
- [ ] **Éructations** fréquentes
- [ ] **Hoquet** persistant
- [ ] **Nausées**
- [ ] **Sensation de plénitude** gastrique

#### 2.2 Manifestations extra-digestives ⚠️ SOUVENT MÉCONNUES
- [ ] **ORL:**
  - Sensation de boule dans la gorge
  - Enrouement matinal
  - Pharyngite chronique
  - Otalgies
- [ ] **Respiratoires:**
  - Toux chronique sèche
  - Asthme nocturne
  - Dyspnée
  - Pneumopathies récidivantes
- [ ] **Dentaires:**
  - Érosions dentaires
  - Halitose
  - Goût métallique

### 3. Signes d'alarme ⚠️ ENDOSCOPIE URGENTE

- [ ] **Dysphagie** (difficulté à avaler)
- [ ] **Odynophagie** (douleur à la déglutition)
- [ ] **Amaigrissement** involontaire
- [ ] **Anémie** (pâleur, asthénie)
- [ ] **Hémorragie digestive:**
  - Hématémèse
  - Méléna
- [ ] **Vomissements répétés**
- [ ] **Âge >50 ans** avec symptômes récents
- [ ] **ATCD familiaux** cancer œsophage/estomac

### 4. Complications du RGO

#### 4.1 Œsophagite
- [ ] **Douleur intense** persistante
- [ ] **Dysphagie progressive**
- [ ] **Saignements** occultes

#### 4.2 Sténose peptique
- [ ] **Dysphagie** aux solides puis liquides
- [ ] **Blocages alimentaires**
- [ ] **Régurgitations** non acides

#### 4.3 Endobrachyœsophage (Barrett)
- [ ] **Facteurs de risque:**
  - RGO ancien (>10 ans)
  - Homme >50 ans
  - Obésité
  - Tabagisme
  - Caucasien

### 5. Facteurs de risque et aggravants

#### 5.1 Mode de vie
- [ ] **Surpoids/obésité** (IMC)
- [ ] **Tabagisme** actif
- [ ] **Consommation alcool**
- [ ] **Stress** chronique
- [ ] **Repas tardifs** (<3h avant coucher)
- [ ] **Vêtements serrés** (ceinture)

#### 5.2 Facteurs anatomiques
- [ ] **Hernie hiatale** connue
- [ ] **Grossesse** actuelle
- [ ] **Chirurgie gastrique** antérieure

#### 5.3 Médicaments favorisants
- [ ] **Relaxants du SIO:**
  - Inhibiteurs calciques
  - Dérivés nitrés
  - Théophylline
  - Benzodiazépines
- [ ] **Irritants muqueux:**
  - AINS
  - Aspirine
  - Biphosphonates
  - Fer, potassium
- [ ] **Anticholinergiques**
- [ ] **Progestérone**

### 6. Diagnostic différentiel ⚠️ ÉLIMINER URGENCES

#### 6.1 Douleur thoracique cardiaque
- [ ] **Angor:**
  - Douleur constrictive
  - Effort déclenchant
  - Irradiation bras gauche, mâchoire
  - Facteurs de risque cardiovasculaire
- [ ] **Infarctus:** Douleur prolongée, sueurs, malaise

#### 6.2 Autres causes digestives
- [ ] **Ulcère gastroduodénal:**
  - Douleur épigastrique
  - Rythmée par repas
  - Périodes de rémission
- [ ] **Lithiase biliaire:**
  - Colique hépatique
  - Post-prandiale (gras)
- [ ] **Pancréatite:**
  - Douleur transfixiante
  - Position antalgique

### 7. Antécédents médicaux
- [ ] **Pathologies digestives:**
  - Ulcère
  - H. pylori
  - Chirurgie digestive
- [ ] **Pathologies associées:**
  - Sclérodermie
  - Diabète (gastroparésie)
  - Pathologies neurologiques

### 8. Traitements essayés
- [ ] **Antiacides:** Efficacité, fréquence
- [ ] **Anti-H2** (ranitidine)
- [ ] **IPP:**
  - Molécule, dose
  - Durée, efficacité
  - Arrêt (rebond?)
- [ ] **Mesures hygiéno-diététiques**

### 9. Impact sur la qualité de vie
- [ ] **Sommeil perturbé**
- [ ] **Alimentation limitée**
- [ ] **Activités restreintes**
- [ ] **Anxiété** liée aux symptômes
- [ ] **Arrêts de travail**

### 10. Question de clôture
"Avez-vous des difficultés à avaler ou avez-vous perdu du poids récemment?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Examen général
- [ ] **Poids, taille, IMC** (surpoids?)
- [ ] **État nutritionnel**
- [ ] **Signes d'anémie** (pâleur)

### Examen abdominal
- [ ] **Inspection:** Distension
- [ ] **Palpation:**
  - Épigastralgie provoquée
  - Défense (complication)
  - Hépatomégalie
- [ ] **Percussion:** Tympanisme
- [ ] **Auscultation:** Bruits hydroaériques

### Examen thoracique
- [ ] **Auscultation cardiaque** (diagnostic différentiel)
- [ ] **Auscultation pulmonaire** (complications)

### Examen ORL
- [ ] **Pharynx:** Érythème postérieur
- [ ] **Larynx:** Signes d'irritation (si laryngoscopie)
- [ ] **Dentition:** Érosions

### Recherche de complications
- [ ] **Signes de saignement:**
  - Pâleur conjonctivale
  - Tachycardie
- [ ] **Signes de déshydratation** (vomissements)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Endoscopie œso-gastro-duodénale (EOGD) ⚠️ INDICATIONS
- [ ] **Signes d'alarme** présents
- [ ] **Âge >50 ans** avec symptômes nouveaux
- [ ] **Symptômes atypiques**
- [ ] **Résistance au traitement** IPP
- [ ] **Symptômes persistants** après arrêt IPP

**Recherche:**
- [ ] **Œsophagite:** Classification de Los Angeles (A-D)
- [ ] **Hernie hiatale**
- [ ] **Endobrachyœsophage** (biopsies)
- [ ] **Sténose, ulcère**
- [ ] **Lésions malignes**

#### 1.2 pH-métrie œsophagienne (si EOGD normale)
- [ ] **Sur 24h** ambulatoire
- [ ] **Sans IPP** (arrêt 7 jours avant)
- [ ] **Confirme RGO** pathologique
- [ ] **Corrélation** symptômes-reflux

#### 1.3 pH-impédancemétrie
- [ ] **Si suspicion reflux non acide**
- [ ] **Sous IPP** possible
- [ ] **Détecte tous types** de reflux

#### 1.4 Manométrie œsophagienne
- [ ] **Avant chirurgie** anti-reflux
- [ ] **Si dysphagie** sans obstacle
- [ ] **Évalue motricité** œsophagienne

#### 1.5 Autres examens
- [ ] **NFS:** Si suspicion anémie
- [ ] **ECG:** Si douleur thoracique atypique
- [ ] **Test thérapeutique IPP** (2-4 semaines)

### 2. Traitement médicamenteux

#### 2.1 IPP (Inhibiteurs de la Pompe à Protons) ⚠️ 1ÈRE LIGNE
**Traitement d'attaque (4-8 semaines):**
- [ ] **Oméprazole** 20 mg/j
- [ ] **Ésoméprazole** 20-40 mg/j
- [ ] **Lansoprazole** 15-30 mg/j
- [ ] **Pantoprazole** 20-40 mg/j
- [ ] **Rabéprazole** 10-20 mg/j

**Modalités:**
- [ ] **30 min avant repas** (matin)
- [ ] **Double dose** si œsophagite sévère
- [ ] **Efficacité** en 2-4 jours

**Traitement d'entretien:**
- [ ] **Dose minimale efficace**
- [ ] **À la demande** si RGO non compliqué
- [ ] **Continu** si œsophagite sévère

#### 2.2 Anti-H2 (alternative)
- [ ] **Ranitidine** 150 mg × 2/j
- [ ] **Famotidine** 20 mg × 2/j
- [ ] **Moins efficaces** que IPP

#### 2.3 Antiacides et alginates
- [ ] **Soulagement rapide** symptomatique
- [ ] **Gaviscon** après repas et coucher
- [ ] **Complément** aux IPP si besoin

#### 2.4 Prokinétiques
- [ ] **Dompéridone** 10 mg × 3/j
- [ ] **Si composante** motrice (gastroparésie)
- [ ] **Durée limitée** (risques cardiaques)

### 3. Mesures hygiéno-diététiques ⚠️ FONDAMENTALES

#### 3.1 Modifications alimentaires
- [ ] **Éviter aliments déclenchants:**
  - Graisses, fritures
  - Chocolat, menthe
  - Tomates, agrumes
  - Épices
  - Café, thé
  - Alcool
- [ ] **Fractionner repas** (petites portions)
- [ ] **Éviter repas tardifs** (>3h avant coucher)
- [ ] **Mastiquer lentement**
- [ ] **Boire entre** les repas

#### 3.2 Modifications du mode de vie
- [ ] **Perte de poids** si surcharge
- [ ] **Arrêt tabac**
- [ ] **Surélévation** tête de lit (15-20 cm)
- [ ] **Position latérale gauche** pour dormir
- [ ] **Éviter vêtements serrés**
- [ ] **Éviter efforts** post-prandiaux
- [ ] **Gestion du stress**

### 4. Traitement des complications

#### 4.1 Œsophagite
- [ ] **Grade A-B:** IPP dose standard 4-8 sem
- [ ] **Grade C-D:** IPP double dose 8 sem
- [ ] **Entretien au long cours**
- [ ] **Contrôle endoscopique** si sévère

#### 4.2 Sténose peptique
- [ ] **Dilatation endoscopique** progressive
- [ ] **IPP forte dose** au long cours
- [ ] **Surveillance endoscopique**

#### 4.3 Endobrachyœsophage
- [ ] **IPP au long cours**
- [ ] **Surveillance endoscopique:**
  - Sans dysplasie: 3-5 ans
  - Dysplasie bas grade: 6-12 mois
  - Dysplasie haut grade: traitement
- [ ] **Résection/ablation** si dysplasie

### 5. Traitement chirurgical

#### 5.1 Indications
- [ ] **Échec traitement médical** optimal
- [ ] **Dépendance IPP** chez sujet jeune
- [ ] **Complications récidivantes**
- [ ] **Volumineuse hernie hiatale**
- [ ] **Manifestations respiratoires** sévères

#### 5.2 Fundoplicature de Nissen
- [ ] **Technique de référence**
- [ ] **Par laparoscopie**
- [ ] **Valve anti-reflux** 360°
- [ ] **Efficacité** 85-90%

#### 5.3 Complications chirurgicales
- [ ] **Dysphagie** post-opératoire (10-15%)
- [ ] **Gas-bloat syndrome** (impossibilité éructer)
- [ ] **Récidive** (10-15%)

### 6. Cas particuliers

#### 6.1 Grossesse
- [ ] **Mesures posturales** +++
- [ ] **Antiacides** autorisés
- [ ] **IPP** si nécessaire (oméprazole)

#### 6.2 H. pylori
- [ ] **Recherche non systématique**
- [ ] **Éradication** si présent
- [ ] **Peut aggraver** RGO après éradication

### 7. Surveillance

#### RGO non compliqué
- [ ] **Réévaluation** à 4-8 semaines
- [ ] **Ajustement** traitement selon réponse
- [ ] **Tentative sevrage** IPP annuelle

#### RGO compliqué
- [ ] **Suivi spécialisé**
- [ ] **Endoscopie** selon protocole
- [ ] **IPP au long cours**

### 8. Éducation du patient
- [ ] **Caractère bénin** si non compliqué
- [ ] **Importance observance**
- [ ] **Modifications mode de vie** essentielles
- [ ] **Signes d'alarme** à connaître
- [ ] **Effets secondaires IPP** long terme:
  - Risque fractures
  - Carences (B12, fer, magnésium)
  - Infections digestives

### 9. Critères d'orientation spécialisée
- [ ] **Gastro-entérologue:**
  - Signes d'alarme
  - Résistance traitement
  - Complications
- [ ] **Chirurgien:** Si indication opératoire

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Rechercher signes d'alarme** systématiquement
2. **Différencier douleur cardiaque** (ECG si doute)
3. **Test thérapeutique IPP** si typique
4. **Mesures hygiéno-diététiques** toujours associées
5. **EOGD si >50 ans** ou signes d'alarme
6. **Éducation posturale** (surélévation tête lit)

### ❌ Pièges à éviter
1. **Banaliser RGO** (complications possibles)
2. **IPP d'emblée** sans mesures associées
3. **Oublier manifestations** extra-digestives
4. **Négliger perte de poids** (cancer)
5. **Arrêt brutal IPP** (rebond acide)

### 💡 Astuces mnémotechniques
- **Signes d'alarme:** **D**ysphagie, **A**maigrissement, **A**némie, **S**aignement (DAAS)
- **Aliments à éviter:** **C**afé, **C**hocolat, **A**lcool, **T**omates, **É**pices (CCATÉ)
- **Classification œsophagite:** Los **A**ngeles: **A** (minime) à **D** (circonférentielle)
- **IPP timing:** **30** min avant repas
