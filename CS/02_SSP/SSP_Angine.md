# Fiche de Révision ECOS - ANGINE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient (enfant ou adulte) consultant pour mal de gorge fébrile nécessitant distinction entre angine virale et bactérienne pour décision thérapeutique.
**Objectifs d'évaluation:** Diagnostic différentiel viral/bactérien, indication antibiothérapie, reconnaissance des complications

---

## 📋 ANAMNÈSE

### 1. Douleur pharyngée
- [ ] **Début:** brutal (streptocoque) vs progressif (viral)
- [ ] **Intensité:** odynophagie sévère, dysphagie
- [ ] **Irradiation:** oreilles (otalgie réflexe)
- [ ] **Latéralité:** unilatérale (phlegmon)

### 2. Symptômes associés
- [ ] **Fièvre:** intensité, frissons
- [ ] **Symptômes ORL:** rhinorrhée, toux, enrouement (viral)
- [ ] **Symptômes généraux:** asthénie, céphalées, myalgies
- [ ] **Symptômes digestifs:** nausées, vomissements, douleurs abdominales (enfant)
- [ ] **Éruption cutanée:** scarlatine

### 3. Terrain
- [ ] **Âge:** < 3 ans (rarement streptocoque), 5-15 ans (pic streptocoque)
- [ ] **Antécédents angines:** récidives, complications
- [ ] **Immunodépression:** VIH, corticothérapie
- [ ] **Allergie pénicilline:** importante pour traitement

### 4. Contexte épidémiologique
- [ ] **Contacts:** angine dans entourage, collectivité
- [ ] **Saison:** hiver-printemps (streptocoque)
- [ ] **Antibiotiques récents:** < 3 mois

---

## 🩺 EXAMEN CLINIQUE

### 1. État général
- [ ] **Constantes:** T°, FC, PA, FR
- [ ] **Hydratation:** muqueuses, pli cutané
- [ ] **État général:** altéré (complications)

### 2. Examen pharyngé ⚠️

#### Angine érythémateuse
- [ ] **Pharynx rouge:** diffus, bilatéral
- [ ] **Amygdales:** hypertrophiées, congestives
- [ ] **Absence exsudat:** aspect vernissé

#### Angine érythémato-pultacée
- [ ] **Exsudat blanc-grisâtre:** punctiforme ou confluent
- [ ] **Facilement détachable:** à l'abaisse-langue
- [ ] **Amygdales hypertrophiées:** bilatérales

#### Angine pseudo-membraneuse
- [ ] **Fausses membranes:** adhérentes, grisâtres
- [ ] **Saignement:** si tentative de décollement
- [ ] **Suspicion diphtérie:** ⚠️ URGENCE

#### Angine vésiculeuse
- [ ] **Vésicules:** pharynx postérieur
- [ ] **Herpangine:** entérovirus
- [ ] **Gingivostomatite:** HSV

#### Angine ulcéro-nécrotique
- [ ] **Ulcération unilatérale:** profonde
- [ ] **Haleine fétide:** angine de Vincent
- [ ] **Fausses membranes:** nécrotiques

### 3. Examen ORL complet
- [ ] **Cavité buccale:** énanthème, pétéchies palais
- [ ] **Langue:** framboisée (scarlatine)
- [ ] **Tympans:** otite associée
- [ ] **Rhinoscopie antérieure:** rhinorrhée

### 4. Aires ganglionnaires
- [ ] **Sous-angulo-maxillaires:** sensibles, mobiles
- [ ] **Jugulo-carotidiennes:** chaîne antérieure
- [ ] **Cervicales postérieures:** EBV
- [ ] **Généralisées:** mononucléose

### 5. Examen cutané
- [ ] **Scarlatine:** érythème granité diffus
- [ ] **Pétéchies:** palais mou (streptocoque)
- [ ] **Érythème:** joues soufflées (érythème infectieux)

### 6. Examen général
- [ ] **Auscultation cardiaque:** souffle (RAA)
- [ ] **Abdomen:** splénomégalie (MNI)
- [ ] **Articulations:** arthrite (RAA)

## 💊 PRISE EN CHARGE

### 1. Score de McIsaac (diagnostic streptocoque)

| Critère | Points |
|---------|--------|
| **Fièvre > 38°C** | +1 |
| **Absence de toux** | +1 |
| **Adénopathies cervicales sensibles** | +1 |
| **Exsudat amygdalien** | +1 |
| **Âge 3-14 ans** | +1 |
| **Âge ≥ 45 ans** | -1 |

**Interprétation:**
- Score ≤ 1: Pas de TDR ni ATB (risque < 10%)
- Score 2-3: TDR recommandé
- Score ≥ 4: ATB d'emblée ou après TDR

### 2. Examens complémentaires

#### Test de diagnostic rapide (TDR)
- [ ] **Indication:** score McIsaac 2-3
- [ ] **Technique:** écouvillonnage amygdales
- [ ] **Résultat:** 5-10 minutes
- [ ] **Spécificité:** 95%, sensibilité 85-90%

#### Autres examens (si doute)
- [ ] **Culture pharyngée:** gold standard, résultat 24-48h
- [ ] **NFS:** hyperlymphocytose (viral), syndrome mononucléosique
- [ ] **MNI test:** mononucléose infectieuse
- [ ] **ASLO:** à distance (RAA)

### 3. Traitement

#### Angine streptococcique confirmée

##### Première intention
- [ ] **Amoxicilline:** 50mg/kg/j en 2 prises x 6 jours (enfant)
- [ ] **Amoxicilline:** 1g x 2/j x 6 jours (adulte)
- [ ] **Durée courte:** 6 jours suffit (vs 10j historique)

##### Si allergie pénicilline
- [ ] **Azithromycine:** 20mg/kg/j x 3j (enfant)
- [ ] **Azithromycine:** 500mg/j x 3j (adulte)
- [ ] **Alternative:** céfuroxime si allergie non grave

#### Traitement symptomatique (toutes angines)
- [ ] **Paracétamol:** 15mg/kg/6h (enfant), 1g/6h (adulte)
- [ ] **AINS:** ibuprofène si douleur intense
- [ ] **Gargarismes:** eau salée tiède
- [ ] **Pastilles:** anesthésiques locaux
- [ ] **Hydratation:** importante

#### Corticothérapie
- [ ] **Indications limitées:** dysphagie sévère, phlegmon
- [ ] **Prednisolone:** 1mg/kg/j x 3-5j
- [ ] **Toujours avec ATB** si bactérien

### 4. Surveillance
- [ ] **Amélioration:** 48-72h sous ATB
- [ ] **Apyrexie:** attendue à 48h
- [ ] **Persistance symptômes:** réévaluation

---

## ⚠️ COMPLICATIONS

### 1. Complications suppuratives locorégionales

#### Phlegmon péri-amygdalien ⚠️
- [ ] **Clinique:** trismus, voussure du pilier, voix nasonnée
- [ ] **Douleur unilatérale:** intense
- [ ] **Traitement:** hospitalisation, ATB IV, drainage

#### Abcès rétro-pharyngé
- [ ] **Dysphagie:** importante
- [ ] **Torticolis:** refus mobilisation
- [ ] **Imagerie:** TDM cervical

#### Cellulite cervicale
- [ ] **Tuméfaction cervicale:** douloureuse
- [ ] **Fièvre élevée:** sepsis
- [ ] **Urgence chirurgicale**

### 2. Complications post-streptococciques

#### Rhumatisme articulaire aigu (RAA)
- [ ] **Délai:** 2-3 semaines post-angine
- [ ] **Critères Jones:** cardite, polyarthrite, chorée
- [ ] **Prévention:** ATB bien conduite

#### Glomérulonéphrite aiguë (GNA)
- [ ] **Délai:** 1-3 semaines
- [ ] **Clinique:** œdèmes, HTA, hématurie
- [ ] **Évolution:** généralement favorable

#### Syndrome PANDAS
- [ ] **TOC/tics:** apparition brutale
- [ ] **Post-streptococcique:** controversé
- [ ] **Enfants:** 3-12 ans

### 3. Complications toxiniques

#### Scarlatine
- [ ] **Érythème:** granité, respect péribuccal
- [ ] **Langue framboisée:** pathognomonique
- [ ] **Desquamation:** J7-J10

#### Syndrome de choc toxique
- [ ] **Hypotension:** brutale
- [ ] **Érythrodermie:** diffuse
- [ ] **Défaillance multiviscérale:** réanimation

---

## 🔍 DIAGNOSTICS DIFFÉRENTIELS

| Pathologie | Caractéristiques | Traitement |
|------------|------------------|------------|
| **Mononucléose (EBV)** | Angine + ADP généralisées + splénomégalie | Symptomatique, éviter amoxicilline |
| **Herpangine** | Vésicules pharynx postérieur, entérovirus | Symptomatique |
| **Angine de Vincent** | Ulcéro-nécrotique unilatérale, haleine fétide | Pénicilline + métronidazole |
| **Diphtérie** | Fausses membranes adhérentes, AEG | URGENCE, sérothérapie + ATB |
| **Primo-infection VIH** | Syndrome pseudo-grippal + pharyngite | Sérologie VIH |
| **Agranulocytose** | Angine ulcéro-nécrotique + neutropénie | Hospitalisation urgente |

## 👶 PARTICULARITÉS PÉDIATRIQUES

### Épidémiologie selon l'âge
- [ ] **< 3 ans:** rarement streptocoque (viral ++)
- [ ] **3-15 ans:** pic incidence streptocoque
- [ ] **> 15 ans:** diminution progressive

### Présentation clinique enfant
- [ ] **Symptômes atypiques:** douleurs abdominales, vomissements
- [ ] **Scarlatine:** plus fréquente
- [ ] **Convulsions fébriles:** nourrisson

### Conseils aux parents
- [ ] **Éviction scolaire:** 48h après début ATB si streptocoque
- [ ] **Contagiosité:** gouttelettes, lavage mains
- [ ] **Surveillance:** température, hydratation, alimentation
- [ ] **Reconsulter si:** aggravation, torticolis, éruption

---

## 📌 POINTS CLÉS

### À faire systématiquement
1. **Score de McIsaac** pour décision TDR/ATB
2. **Examen pharyngé** complet bilatéral
3. **Palpation ganglions** cervicaux
4. **TDR** si score 2-3
5. **Traitement symptomatique** systématique

### Pièges à éviter
- Traiter toute angine par ATB (80% virales)
- Oublier allergie pénicilline
- Méconnaître phlegmon (trismus++)
- Prescrire amoxicilline si MNI suspectée
- Négliger complications post-streptococciques

### Red flags ⚠️
- **Trismus:** phlegmon péri-amygdalien
- **Torticolis fébrile:** abcès rétro-pharyngé
- **Fausses membranes:** diphtérie
- **AEG marquée:** complications
- **Stridor:** obstruction voies aériennes
