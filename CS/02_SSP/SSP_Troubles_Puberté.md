# SSP - Troubles de la Puberté (Puberté précoce et tardive)

## 🎯 ANAMNÈSE (25%)

### Définition et critères d'âge
- **Puberté précoce** :
  - **Filles** : <8 ans (sein/pilosité) ou <7 ans (origine afro-américaine)
  - **Garçons** : <9 ans (augmentation volume testiculaire >4 mL)
- **Puberté tardive** :
  - **Filles** : aucun signe à 13 ans ou >5 ans entre thélarche et ménarche
  - **Garçons** : aucun signe à 14 ans ou >5 ans évolution complète

### Anamnèse du développement pubertaire

#### Évaluation stade pubertaire actuel (classification Tanner)
- **Développement mammaire** (filles - stades M1 à M5) :
  - M1 : prépubère, pas de développement
  - M2 : bourgeon mammaire, aréole surélevée (débu tpuberté)
  - M3 : augmentation sein et aréole sans contour séparé
  - M4 : projection aréole et mamelon formant mont secondaire
  - M5 : développement adulte, aréole dans contour sein
- **Développement génital garçons** (stades G1 à G5) :
  - G1 : prépubère, testicules <4 mL (orchidometer Prader)
  - G2 : testicules 4-6 mL, scrotum commence s'agrandir (début puberté)
  - G3 : testicules 6-12 mL, pénis s'allonge
  - G4 : testicules 12-20 mL, pénis s'allonge et s'élargit
  - G5 : testicules >20 mL, développement génital adulte
- **Pilosité pubienne** (filles et garçons - stades P1 à P5) :
  - P1 : absence poils pubiens
  - P2 : quelques poils longs, pigmentés, raides
  - P3 : poils plus foncés, bouclés, étendus sur pubis
  - P4 : pilosité de type adulte mais surface réduite
  - P5 : pilosité adulte, extension cuisses (garçons)

#### Chronologie développement pubertaire
- **Séquence normale filles** :
  - Poussée staturale → thélarche (8-13 ans) → pubarche → ménarche (10-16 ans)
  - Durée totale : 2-6 ans (moyenne 4 ans)
- **Séquence normale garçons** :
  - Augmentation testiculaire (9-14 ans) → pubarche → poussée staturale → mue voix
  - Durée totale : 3-5 ans

### Signes associés puberté précoce
- **Développement physique accéléré** :
  - Poussée croissance prématurée
  - Maturation osseuse avancée
  - Changements corporels (odeur corporelle, acné)
- **Symptômes neurologiques** (si cause centrale) :
  - Céphalées, troubles visuels
  - Nausées, vomissements matinaux
  - Troubles comportement, irritabilité
- **Manifestations endocriniennes** :
  - Cycles menstruels précoces (filles)
  - Érections fréquentes, masturbation (garçons)
  - Sécrétions vaginales, leucorrhées

### Signes associés puberté tardive
- **Retard développement** :
  - Absence poussée croissance
  - Maintien caractéristiques prépubères
  - Retard maturation osseuse
- **Impact psychologique** :
  - Complexes, retrait social
  - Comparaison avec pairs
  - Difficultés scolaires, baisse estime soi
- **Symptômes associés** :
  - Troubles olfaction (syndrome Kallmann)
  - Fatigue chronique, faible libido
  - Troubles nutritionnels, amaigrissement

### Anamnèse des antécédents

#### Antécédents personnels
- **Développement prénatal** :
  - Terme naissance, poids, taille
  - Complications grossesse, accouchement
  - Exposition hormones in utero
- **Croissance antérieure** :
  - Courbes croissance depuis naissance
  - Cassures courbe récentes
  - Consultation antérieures endocrinologie
- **Pathologies** :
  - Traumatismes crâniens, méningites
  - Tumeurs cérébrales, irradiations
  - Pathologies chroniques sévères
  - Troubles nutritionnels, anorexie

#### Antécédents familiaux détaillés
- **Puberté parentale** :
  - Âge ménarche mère (<12 ans ? >16 ans ?)
  - Âge développement pubertaire père
  - Puberté précoce/tardive dans famille
- **Tailles parentales** : calculer taille cible
- **Pathologies familiales** :
  - Hypogonadisme, syndrome Kallmann
  - Tumeurs hypophysaires
  - Pathologies auto-immunes
  - Anomalies génétiques

### Anamnèse médicamenteuse et toxiques
- **Médicaments** :
  - Corticoïdes prolongés
  - Hormones sexuelles (crèmes, pilule mère)
  - Antiépileptiques, psychotropes
- **Exposition accidentelle** :
  - Produits cosmétiques hormonaux
  - Phytoestrogènes, compléments alimentaires
- **Toxiques** :
  - Alcool, tabac (puberté précoce)
  - Cannabis (retard pubertaire)

## 👁️ EXAMEN PHYSIQUE (25%)

### Évaluation anthropométrique complète
- **Mensurations** :
  - Poids, taille, BMI (courbes percentilées)
  - Vitesse croissance annuelle
  - Prédiction taille finale vs taille cible
- **Proportions corporelles** :
  - Envergure/taille (N ~1)
  - Segment supérieur/inférieur (hypogonadisme si >1)
  - Recherche eunuchoïdisme (bras longs, petits testicules)

### Examen spécialisé développement pubertaire
- **Classification Tanner précise** :
  - **Seins** (filles) : stades M1-M5, symétrie, galactorrhée ?
  - **Testicules** (garçons) : volume orchidometer (N >4 mL = début puberté)
  - **Pilosité pubienne** : stades P1-P5, distribution
  - **Autres** : pilosité axillaire, faciale (garçons)
- **Signes maturité sexuelle** :
  - Mue voix (garçons)
  - Acné, odeur corporelle
  - Gynécomastie (physiologique garçons)

### Recherche pathologie sous-jacente

#### Signes neurologiques centraux
- **Examen neurologique** :
  - Conscience, troubles comportement
  - Déficit moteur/sensitif, troubles coordination
  - Réflexes ostéotendineux
- **Signes d'HTIC** :
  - Céphalées, vomissements, œdème papillaire
  - Troubles visuels : champ visuel, acuité
  - Paralysies oculomotrices
- **Troubles hypothalamiques** :
  - Troubles thermorégulation, soif, appétit
  - Troubles sommeil, rythme circadien

#### Recherche syndrome dysgénésique
- **Syndrome Turner** (filles) :
  - Petite taille, pterygium colli
  - Thorax en bouclier, cubitus valgus
  - Lymphœdème, naevi multiples
- **Syndrome Klinefelter** (garçons) :
  - Grande taille, eunuchoïdisme
  - Testicules petits, durs
  - Gynécomastie, troubles apprentissage

#### Signes d'hypogonadisme hypogonadotrope
- **Syndrome Kallmann** :
  - Anosmie, troubles olfaction
  - Agénésie rénale unilatérale
  - Fente labio-palatine, daltonisme
- **Autres signes** :
  - Micropénis (garçons)
  - Cryptorchidie, testicules petits

### Examen général orienté
- **Signes malnutrition** : cachexie, fonte musculaire
- **Pathologies chroniques** : cardiaques, respiratoires, digestives
- **Signes endocriniens** :
  - Hypothyroïdie : retard croissance + puberté
  - Hypercorticisme : obésité facio-tronculaire, vergetures

## 🔬 EXAMENS COMPLÉMENTAIRES (25%)

### Bilan de première intention
- **Maturation osseuse** :
  - Âge osseux : radiographie poignet-main gauche
  - Méthode Greulich-Pyle ou Tanner-Whitehouse
  - Comparaison âge osseux/âge chronologique
  - Prédiction taille finale (tables Bayley-Pinneau)

### Bilan hormonal selon contexte

#### Puberté précoce - Filles
- **Bilan initial** :
  - LH, FSH basales (souvent peu informatives)
  - Œstradiol
  - TSH, T4 libre (éliminer hypothyroïdie)
- **Test stimulation GnRH** :
  - Pic LH >5-7 UI/L → pubertaire
  - LH/FSH >0.6 → évocateur puberté centrale
- **Si pseudo-puberté précoce** :
  - 17-hydroxyprogestérone (hyperplasie surrénale)
  - Androgènes : testostérone, androstènedione
  - Tumeurs ovariennes : échographie pelvienne

#### Puberté précoce - Garçons
- **Bilan systématique** (étiologie organique fréquente) :
  - LH, FSH, testostérone
  - Test GnRH : pic LH >25 UI/L → pubertaire
- **Recherche étiologique** :
  - β-HCG (tumeurs germinales)
  - α-fœtoprotéine
  - IRM cérébrale plus souvent nécessaire

#### Puberté tardive
- **Bilan hormonal** :
  - LH, FSH basales
  - Testostérone (garçons), œstradiol (filles)
  - TSH, T4 libre, prolactine
- **Test stimulation GnRH** :
  - Différencier retard constitutionnel de hypogonadisme
  - Réponse LH/FSH normale → retard constitutionnel
- **Autres selon orientation** :
  - Caryotype si suspicion Turner/Klinefelter
  - Ferritine, transferrine (hémo-chromatose)

### Imagerie selon contexte
- **IRM hypothalamo-hypophysaire** :
  - **Indications** : puberté précoce centrale (surtout garçons)
  - Tumeurs : craniopharyngiome, adénome hypophysaire
  - Lésions acquises : traumatisme, infection
- **Échographie pelvienne** (filles) :
  - Volume utérin, ovaires
  - Kystes ovariens, tumeurs
  - Épaisseur endomètre
- **Échographie testicules** : si asymétrie, masse palpable

### Examens spécialisés
- **Dosages spécifiques** selon orientation étiologique :
  - Inhibine B (fonction gonadique)
  - AMH (hormone antimüllérienne)
  - DHEA-S (surrénales)
- **Tests dynamiques** :
  - Test LH-RH (GnRH) : différentiel central/périphérique
  - Test stimulation HCG (fonction leydigienne)

## 💊 PRISE EN CHARGE (25%)

### Puberté précoce

#### Étiologies principales
- **Puberté précoce centrale (90% filles, 60% garçons)** :
  - **Idiopathique** (80% filles, 20% garçons)
  - **Tumorales** : craniopharyngiome, adénome hypophysaire
  - **Infectieuses** : méningite, encéphalite séquelles
  - **Traumatiques** : traumatisme crânien, irradiation
  - **Autres** : neurofibromatose, McCune Albright
- **Pseudo-puberté précoce (périphérique)** :
  - **Filles** : kystes ovariens, tumeurs ovariennes
  - **Garçons** : tumeurs testicules, hyperplasie surrénale
  - **Mixte** : tumeurs surrénales, exposition hormones

#### Traitement puberté précoce centrale
- **Analogues GnRH** (traitement de référence) :
  - **Indications** : <6 ans (filles), <8 ans (garçons)
  - Âge osseux très avancé, impact psychologique
  - **Molécules** : leuproréline, triptoreline (mensuel/trimestriel)
  - **Mécanisme** : désensibilisation récepteurs GnRH
  - **Efficacité** : arrêt progression pubertaire, amélioration taille finale
- **Surveillance traitement** :
  - Tous les 3-6 mois : taille, poids, stade Tanner
  - Âge osseux annuel
  - Dosages hormonaux : suppression LH, FSH, stéroïdes
  - Arrêt : âge physiologique puberté (10-11 ans filles, 11-12 ans garçons)

#### Traitement pseudo-puberté précoce
- **Étiologique selon cause** :
  - Chirurgie : tumeurs ovariennes, testiculaires
  - Médical : hyperplasie surrénale (hydrocortisone)
  - Suppression exposition : crèmes, médicaments

### Puberté tardive

#### Étiologies principales
- **Retard pubertaire simple** (85% cas) :
  - Constitutionnel, familial
  - Rattrapage spontané vers 13-14 ans (filles), 14-15 ans (garçons)
- **Hypogonadisme hypogonadotrope** :
  - **Congénital** : syndrome Kallmann, mutations génétiques
  - **Acquis** : tumeurs, radiothérapie, traumatismes
  - **Fonctionnel** : anorexie, sport intensif, stress
- **Hypogonadisme hypergonadotrope** :
  - **Génétique** : Turner, Klinefelter, mutations
  - **Acquis** : chimiothérapie, radiothérapie, trauma

#### Traitement retard pubertaire
- **Retard constitutionnel** :
  - **Surveillance** : croissance, développement psychologique
  - **Traitement inducteur** si impact psychologique :
    - **Filles** : œstrogènes faibles doses (6 mois)
    - **Garçons** : testostérone retard IM (3-6 mois)
  - Objectif : déclencher puberté, pas traitement substitutif complet

- **Hypogonadisme confirmé** :
  - **Traitement substitutif définitif** :
    - **Filles** : œstrogènes puis œstroprogestatifs
    - **Garçons** : testostérone (gel, injections)
  - **Induction pubertaire progressive** : doses croissantes
  - **Préservation fertilité** : conseil génétique, conservation gamètes

### Prise en charge psychologique
- **Soutien psychologique** : impact développement, image corporelle
- **Information famille** : évolution naturelle, pronostic
- **Suivi multidisciplinaire** : endocrinologue, psychologue
- **Adaptation scolaire** : aménagements si nécessaire

### Suivi long terme
- **Surveillance croissance** : vitesse, prédiction taille finale
- **Évaluation développement pubertaire** : progression stages Tanner
- **Bilan biologique régulier** : hormones, âge osseux
- **Dépistage complications** : densité osseuse, fertilité future
- **Transition médecine adulte** : vers 16-18 ans

## 🚨 RED FLAGS

### Puberté précoce - Urgences
- **Signes neurologiques** : céphalées, troubles visuels, vomissements
- **Puberté précoce rapide** : évolution <6 mois
- **Garçon <6 ans** avec puberté : étiologie organique fréquente
- **Troubles comportement sévères** : agressivité, hypersexualité

### Puberté tardive - Signaux alarme
- **Anosmie associée** : syndrome Kallmann
- **Signes Turner/Klinefelter** : caryotype urgent
- **Retard croissance sévère** : bilan endocrinien complet
- **Anorexie mentale** : prise en charge spécialisée urgente

### Orientations spécialisées urgentes
- **Endocrinologie pédiatrique** : diagnostic/traitement troubles pubertaires
- **Neurochirurgie** : masses intracrâniennes
- **Gynécologie** : masses ovariennes, troubles menstruels
- **Psychiatrie** : troubles comportement, anorexie

### Critères hospitalisation
- **Tumeurs cérébrales** : bilan/traitement urgents
- **Anorexie sévère** : dénutrition, troubles électrolytiques
- **Troubles psychologiques majeurs** : risque suicidaire
- **Complications endocriniennes** : crise surrénalienne

---

*💡 Les troubles pubertaires nécessitent une évaluation soigneuse pour distinguer les variants normaux des pathologies. L'impact psychologique est majeur et doit être pris en compte dans la décision thérapeutique. La prise en charge multidisciplinaire est essentielle.*
