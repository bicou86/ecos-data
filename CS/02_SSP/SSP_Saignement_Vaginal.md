# Fiche de Révision ECOS - SAIGNEMENT VAGINAL ANORMAL

## 🎯 Situation à Starting Point (SSP)
**Description:** Femme consultant pour saignements vaginaux anormaux (métrorragies, ménorragies)
**Objectifs d'évaluation:** Caractériser le saignement, éliminer une urgence, identifier la cause selon l'âge, adapter la prise en charge

---

## 📋 ANAMNÈSE

### 1. Caractérisation du saignement ⚠️ ESSENTIEL

#### 1.1 Type de saignement
- [ ] **Ménorragies:** Règles abondantes (>80ml) ou prolongées (>7j)
- [ ] **Métrorragies:** Saignements entre les règles
- [ ] **Ménométrorragies:** Association des deux
- [ ] **Spotting:** Pertes minimes brunâtres
- [ ] **Saignement post-coïtal**
- [ ] **Saignement post-ménopausique** ⚠️ CANCER

#### 1.2 Quantification
- [ ] **Abondance:**
  - Nombre de protections/jour
  - Protections saturées en <2h
  - Débordements nocturnes
  - Caillots (taille)
- [ ] **Score de Higham** (>100 = ménorragies)
- [ ] **Durée:** Jours de saignement

#### 1.3 Chronologie
- [ ] **Début:** Date, circonstances
- [ ] **Évolution:** Stable, aggravation
- [ ] **Cyclicité:** Régulier, anarchique
- [ ] **DDR** (date dernières règles)

### 2. Retentissement ⚠️ ÉVALUER GRAVITÉ

#### 2.1 Signes d'anémie
- [ ] **Asthénie** progressive
- [ ] **Dyspnée d'effort**
- [ ] **Palpitations**
- [ ] **Vertiges, malaises**
- [ ] **Céphalées**
- [ ] **Pâleur** remarquée

#### 2.2 Impact fonctionnel
- [ ] **Limitation activités**
- [ ] **Absentéisme** (école, travail)
- [ ] **Vie sociale** altérée
- [ ] **Anxiété** liée aux saignements

### 3. Orientation selon l'âge ⚠️ CRUCIAL

#### 3.1 Adolescente (ménarche - 19 ans)
- [ ] **Causes fonctionnelles (80%):**
  - Cycles anovulatoires (immaturité axe)
  - Normale 1-2 ans post-ménarche
- [ ] **Troubles coagulation:**
  - Maladie de Willebrand
  - Thrombopénie
  - Médicaments (aspirine)
- [ ] **Grossesse** compliquée

#### 3.2 Femme en période d'activité génitale (20-45 ans)
- [ ] **Grossesse et complications:** ⚠️ TOUJOURS ÉLIMINER
  - Fausse couche
  - GEU
  - Môle hydatiforme
  - Grossesse normale (1er trimestre)
- [ ] **Causes hormonales:**
  - Anovulation (SOPK)
  - Insuffisance lutéale
  - Contraception inadaptée
- [ ] **Causes organiques:**
  - Fibromes utérins
  - Polypes endométriaux
  - Adénomyose
  - Endométriose

#### 3.3 Périménopause (45-55 ans)
- [ ] **Fluctuations hormonales**
- [ ] **Hyperplasie endométriale**
- [ ] **Polypes, fibromes**
- [ ] **Cancer endomètre** (risque augmente)

#### 3.4 Post-ménopause (>1 an aménorrhée) ⚠️ CANCER JUSQU'À PREUVE DU CONTRAIRE
- [ ] **Cancer endomètre (10-15%)**
- [ ] **Atrophie endométriale (60%)**
- [ ] **Polypes (20%)**
- [ ] **THS mal équilibré**
- [ ] **Cancer col, vagin, vulve**

### 4. Symptômes associés

#### 4.1 Signes gynécologiques
- [ ] **Douleurs pelviennes**
- [ ] **Dyspareunie**
- [ ] **Leucorrhées** anormales
- [ ] **Prurit vulvaire**
- [ ] **Masse pelvienne** palpée

#### 4.2 Signes endocriniens
- [ ] **Bouffées chaleur** (ménopause)
- [ ] **Galactorrhée** (hyperprolactinémie)
- [ ] **Hirsutisme** (hyperandrogénie)
- [ ] **Prise/perte poids**

#### 4.3 Signes généraux
- [ ] **Fièvre** (infection, cancer)
- [ ] **Amaigrissement** ⚠️ ALARME
- [ ] **Sueurs nocturnes**

### 5. Facteurs de risque

#### 5.1 Cancer endomètre
- [ ] **Âge >50 ans**
- [ ] **Obésité** (IMC >30)
- [ ] **Nulliparité**
- [ ] **Ménopause tardive** (>55 ans)
- [ ] **SOPK**
- [ ] **Tamoxifène**
- [ ] **Syndrome de Lynch**
- [ ] **Diabète, HTA**

#### 5.2 Troubles hémorragiques
- [ ] **ATCD familiaux** saignements
- [ ] **Saignements** autres sites
- [ ] **Ecchymoses** faciles
- [ ] **Ménorragies** depuis ménarche

### 6. Antécédents

#### 6.1 Gynéco-obstétricaux
- [ ] **Histoire menstruelle:**
  - Âge ménarche
  - Cycles habituels
  - Contraception
- [ ] **Grossesses:** Issues
- [ ] **Frottis cervical:** Date, résultats
- [ ] **Chirurgies gynécologiques**
- [ ] **IST**

#### 6.2 Médicaux
- [ ] **Pathologies endocriniennes:**
  - Thyroïde
  - Hyperprolactinémie
- [ ] **Troubles coagulation**
- [ ] **Pathologies hépatiques** (coagulopathie)
- [ ] **Pathologies rénales**

### 7. Médicaments et contraception

#### 7.1 Contraception hormonale
- [ ] **Type:** Pilule, DIU, implant
- [ ] **Observance**
- [ ] **Oublis récents**
- [ ] **Changement récent**

#### 7.2 Autres médicaments
- [ ] **Anticoagulants, antiagrégants**
- [ ] **Corticoïdes**
- [ ] **Tamoxifène**
- [ ] **Psychotropes** (hyperprolactinémie)
- [ ] **THS**

### 8. Question de clôture
"Pourriez-vous être enceinte? Avez-vous perdu du poids récemment?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### État général
- [ ] **Constantes vitales:** TA, FC (tachycardie?)
- [ ] **Signes d'anémie:**
  - Pâleur cutanéo-muqueuse
  - Tachycardie
- [ ] **IMC** (obésité = facteur risque)

### Examen abdominal
- [ ] **Masses pelviennes** palpables
- [ ] **Utérus gravide** (grossesse)
- [ ] **Sensibilité, défense**

### Examen gynécologique ⚠️ SYSTÉMATIQUE

#### Examen au spéculum
- [ ] **Origine du saignement:**
  - Col (polype, cancer, ectropion)
  - Vagin (déchirure, atrophie)
  - Vulve (lésions)
  - Endo-utérin confirmé
- [ ] **Col:**
  - Aspect (lésion visible)
  - Saignement au contact
- [ ] **Frottis cervical** si indiqué

#### Toucher vaginal bimanuel
- [ ] **Utérus:**
  - Taille (augmentée = fibromes, adénomyose)
  - Consistance
  - Mobilité
  - Sensibilité
- [ ] **Annexes:**
  - Masses
  - Sensibilité
- [ ] **Paramètres:** Souplesse

### Recherche signes endocriniens
- [ ] **Thyroïde:** Goitre, nodules
- [ ] **Galactorrhée** (expression seins)
- [ ] **Hirsutisme** (score Ferriman-Gallwey)
- [ ] **Acanthosis nigricans** (insulinorésistance)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires urgents

#### 1.1 Si suspicion grossesse
- [ ] **β-HCG** ⚠️ SYSTÉMATIQUE si âge procréer
- [ ] **Échographie pelvienne** si β-HCG positif:
  - Localisation grossesse
  - Vitalité
  - Complications

#### 1.2 Bilan retentissement
- [ ] **NFS:** Anémie (Hb, VGM)
- [ ] **Ferritine:** Carence martiale
- [ ] **TP, TCA:** Si suspicion coagulopathie
- [ ] **Groupe sanguin, RAI** si anémie sévère

### 2. Explorations selon l'âge

#### 2.1 Femme jeune (<40 ans)

**Échographie pelvienne:** ⚠️ 1ÈRE LIGNE
- [ ] **Voie endovaginale** + sus-pubienne
- [ ] **Mesure endomètre**
- [ ] **Recherche:**
  - Fibromes (nombre, taille, localisation)
  - Polypes
  - Kystes ovariens
  - Adénomyose

**Bilan hormonal (si cycles irréguliers):**
- [ ] **FSH, LH, œstradiol** (J3)
- [ ] **Prolactine**
- [ ] **TSH**
- [ ] **Testostérone** si hirsutisme

#### 2.2 Femme >40 ans ou facteurs risque

**Hystéroscopie + biopsie:** ⚠️ GOLD STANDARD
- [ ] **Visualisation cavité**
- [ ] **Biopsies dirigées**
- [ ] **Polypectomie** si polype

**Alternative: Échographie + biopsie Pipelle**
- [ ] **Si endomètre >4mm** post-ménopause
- [ ] **Si endomètre >12mm** pré-ménopause

#### 2.3 Adolescente

**Bilan coagulation si:**
- [ ] **Ménorragies depuis ménarche**
- [ ] **ATCD familiaux**
- [ ] **Autres saignements**

**Tests:**
- [ ] **NFS, plaquettes**
- [ ] **TP, TCA**
- [ ] **Facteur Willebrand**
- [ ] **Facteur VIII**

### 3. Traitement des saignements aigus

#### 3.1 Hémorragie active ⚠️ URGENCE
- [ ] **Hospitalisation**
- [ ] **VVP, remplissage**
- [ ] **Transfusion** si Hb <7g/dl

**Traitement hormonal haute dose:**
- [ ] **Œstrogènes conjugués** IV 25mg/4-6h
- [ ] **Ou pilule œstroprogestative** 3cp/j × 7j
- [ ] **Puis décroissance progressive**

#### 3.2 Antifibrinolytiques
- [ ] **Acide tranexamique** 1g × 3-4/j
- [ ] **Pendant règles** (5 jours max)
- [ ] **Réduction 40-50%** flux

### 4. Traitement étiologique

#### 4.1 Saignements fonctionnels/dysfonctionnels

**Contraception hormonale:** ⚠️ 1ÈRE LIGNE
- [ ] **Pilule œstroprogestative**
- [ ] **DIU au lévonorgestrel** (Mirena)
- [ ] **Implant progestatif**

**Progestatifs cycliques:**
- [ ] **Dydrogestérone** 10mg J16-25
- [ ] **Progestérone micronisée** 200mg J16-25

#### 4.2 Fibromes utérins

**Traitement médical:**
- [ ] **DIU lévonorgestrel**
- [ ] **Analogues GnRH** (3-6 mois max)
- [ ] **Acide tranexamique**
- [ ] **AINS** pendant règles

**Traitement chirurgical:**
- [ ] **Myomectomie** (désir grossesse)
- [ ] **Embolisation** artères utérines
- [ ] **Hystérectomie** (pas désir grossesse)

#### 4.3 Polypes endométriaux
- [ ] **Polypectomie hystéroscopique**
- [ ] **Analyse anatomopathologique**

#### 4.4 Adénomyose
- [ ] **DIU lévonorgestrel** +++
- [ ] **Analogues GnRH**
- [ ] **Hystérectomie** si échec

#### 4.5 Hyperplasie endométriale

**Sans atypies:**
- [ ] **Progestatifs** 3-6 mois
- [ ] **DIU lévonorgestrel**
- [ ] **Contrôle histologique** 3-6 mois

**Avec atypies:**
- [ ] **Hystérectomie** (risque cancer 30%)

#### 4.6 Cancer endomètre
- [ ] **Hystérectomie totale** + annexectomie
- [ ] **Curage ganglionnaire**
- [ ] **Radiothérapie** adjuvante selon stade
- [ ] **Chimiothérapie** si avancé

### 5. Traitement symptomatique

#### 5.1 Correction anémie
- [ ] **Fer oral:** 200mg/j
- [ ] **Fer IV** si mal toléré
- [ ] **Transfusion** si sévère

#### 5.2 Antalgiques
- [ ] **AINS** pendant règles
- [ ] **Paracétamol**

### 6. Techniques chirurgicales conservatrices

#### 6.1 Endomètrectomie
- [ ] **Résection** endométriale
- [ ] **Thermoablation**
- [ ] **Si échec médical**
- [ ] **Pas désir grossesse**

### 7. Surveillance

#### Traitement médical
- [ ] **Efficacité** à 3 mois
- [ ] **Tolérance**
- [ ] **Hémoglobine**

#### Post-ménopause
- [ ] **Tout saignement** = exploration
- [ ] **Échographie annuelle** si THS

### 8. Prévention
- [ ] **Contraception adaptée**
- [ ] **Poids normal** (prévention cancer)
- [ ] **Surveillance** si facteurs risque

### 9. Critères d'hospitalisation
- [ ] **Hémorragie active** importante
- [ ] **Instabilité hémodynamique**
- [ ] **Anémie sévère** mal tolérée
- [ ] **Grossesse compliquée**

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **β-HCG systématique** si âge procréer
2. **Spéculum obligatoire** (origine saignement)
3. **Échographie pelvienne** première ligne
4. **Biopsie endomètre** si >40 ans
5. **Tout saignement post-ménopausique** = cancer jusqu'à preuve contraire
6. **NFS ferritine** (retentissement)

### ❌ Pièges à éviter
1. **Oublier grossesse** chez jeune femme
2. **Banaliser saignement** post-ménopause
3. **Traiter sans diagnostic** histologique >40 ans
4. **Négliger coagulopathie** chez adolescente
5. **Hystérectomie trop rapide** chez jeune

### 💡 Astuces mnémotechniques
- **Causes organiques:** **PALM** (Polype, Adénomyose, Leiomyome, Malignité)
- **Causes fonctionnelles:** **COEIN** (Coagulopathie, Ovulatoire, Endomètre, Iatrogène, Non classé)
- **Cancer endomètre - facteurs:** **O**bésité, **N**ulliparité, **T**amoxifène, **Â**ge (ONTÂ)
- **Urgence:** **H**émorragie, **G**rossesse, **A**némie sévère (HGA)
