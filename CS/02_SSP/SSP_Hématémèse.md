# Fiche de Révision ECOS - HÉMATÉMÈSE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient présentant des vomissements de sang (hématémèse)
**Objectifs d'évaluation:** Évaluer la gravité, identifier la cause, stabiliser le patient, organiser la prise en charge urgente

---

## 📋 ANAMNÈSE

### 1. Caractérisation de l'hématémèse ⚠️ URGENCE VITALE

#### 1.1 Description du saignement
- [ ] **Aspect du sang vomi:**
  - Rouge vif (saignement actif récent)
  - Noir "marc de café" (sang digéré)
  - Caillots
  - Mélange alimentaire
- [ ] **Volume estimé:**
  - Quelques filets
  - Demi-verre
  - Plusieurs verres
  - Cuvette entière
- [ ] **Nombre d'épisodes**
- [ ] **Délai depuis le premier épisode**

#### 1.2 Différencier hématémèse vraie
- [ ] **Éliminer hémoptysie:**
  - Effort de toux vs vomissement
  - Sang spumeux aéré
  - Contexte respiratoire
- [ ] **Éliminer épistaxis déglutie**
- [ ] **Éliminer saignement buccal/pharyngé**

#### 1.3 Évolution
- [ ] **Premier épisode** ou récidive
- [ ] **Saignement actif** ou arrêté
- [ ] **Aggravation** ou stabilisation

### 2. Signes de gravité ⚠️ ÉVALUATION IMMÉDIATE

#### 2.1 Signes de choc hémorragique
- [ ] **Malaise, lipothymie**
- [ ] **Syncope**
- [ ] **Soif intense**
- [ ] **Sueurs froides**
- [ ] **Agitation, confusion**
- [ ] **Dyspnée**

#### 2.2 Terrain à risque
- [ ] **Âge >65 ans**
- [ ] **Comorbidités:**
  - Cardiopathie
  - Insuffisance rénale
  - Cirrhose
  - Cancer
- [ ] **Anticoagulants/antiagrégants**

### 3. Symptômes associés

#### 3.1 Signes digestifs
- [ ] **Méléna:** Selles noires goudronneuses
- [ ] **Douleur épigastrique:**
  - Antécédents ulcère
  - Rythmée par repas
- [ ] **Pyrosis** (RGO)
- [ ] **Dysphagie** (varices, tumeur)
- [ ] **Vomissements** précédant l'hématémèse

#### 3.2 Signes d'hypertension portale
- [ ] **Ascite**
- [ ] **Ictère**
- [ ] **Confusion** (encéphalopathie)
- [ ] **Antécédents varices** œsophagiennes

### 4. Orientation étiologique ⚠️ CAUSES PRINCIPALES

#### 4.1 Ulcère gastroduodénal (45%)
- [ ] **ATCD ulcère** documenté
- [ ] **Douleur épigastrique** chronique
- [ ] **Prise AINS/aspirine**
- [ ] **Tabagisme**
- [ ] **H. pylori** connu

#### 4.2 Rupture varices œsophagiennes (20%)
- [ ] **Cirrhose connue:**
  - Alcoolique
  - Virale (VHB, VHC)
  - NASH
  - Autres
- [ ] **Signes d'HTP:**
  - Splénomégalie
  - Circulation collatérale
  - Ascite
- [ ] **Hémorragie massive** brutale

#### 4.3 Syndrome de Mallory-Weiss (15%)
- [ ] **Vomissements répétés** avant saignement
- [ ] **Contexte alcoolisation** aiguë
- [ ] **Efforts de vomissement** importants
- [ ] **Saignement modéré** autolimité

#### 4.4 Œsophagite peptique
- [ ] **RGO chronique**
- [ ] **Pyrosis** ancien
- [ ] **Hernie hiatale**

#### 4.5 Tumeurs (5%)
- [ ] **Cancer œsophage/estomac:**
  - Dysphagie progressive
  - Amaigrissement
  - Âge >50 ans
- [ ] **GIST** (tumeur stromale)

#### 4.6 Causes rares
- [ ] **Syndrome de Boerhaave** (perforation)
- [ ] **Angiodysplasies**
- [ ] **Fistule aorto-digestive**
- [ ] **Hémobilie**

### 5. Facteurs de risque et antécédents

#### 5.1 Médicaments à risque
- [ ] **AINS:** Dose, durée
- [ ] **Aspirine:** Même faible dose
- [ ] **Corticoïdes**
- [ ] **Anticoagulants:** AVK, AOD
- [ ] **Antiagrégants:** Clopidogrel, ticagrelor
- [ ] **Biphosphonates**

#### 5.2 Habitudes de vie
- [ ] **Alcool:**
  - Consommation chronique (cirrhose)
  - Consommation aiguë récente
- [ ] **Tabac**

#### 5.3 Antécédents digestifs
- [ ] **Hémorragies digestives** antérieures
- [ ] **Endoscopies:** Résultats
- [ ] **Chirurgie gastrique**
- [ ] **Radiothérapie thoracique**

### 6. Évaluation du retentissement

#### 6.1 Quantification pertes
- [ ] **Nombre d'épisodes**
- [ ] **Volume total** estimé
- [ ] **Durée** du saignement

#### 6.2 Tolérance
- [ ] **État conscience**
- [ ] **Capacité** à se tenir debout
- [ ] **Sensation** de malaise

### 7. Question de clôture
"Avez-vous des douleurs thoraciques ou des difficultés à respirer?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Évaluation hémodynamique ⚠️ PRIORITÉ ABSOLUE

#### Signes vitaux
- [ ] **TA:** Hypotension (<90/60)
- [ ] **Hypotension orthostatique:** Chute >20 mmHg
- [ ] **FC:** Tachycardie (>100/min)
- [ ] **FR:** Polypnée
- [ ] **Température**
- [ ] **SaO2**
- [ ] **Score de Glasgow**

#### Signes de choc
- [ ] **Cutanés:**
  - Pâleur
  - Sueurs
  - Marbrures
  - Extrémités froides
  - TRC >3 sec
- [ ] **Neurologiques:**
  - Agitation
  - Confusion
  - Somnolence

### Classification de la sévérité hémorragique

| Classe | Perte sanguine | FC | TA | Signes cliniques |
|--------|---------------|----|----|-----------------|
| I | <15% (<750ml) | <100 | Normale | Asymptomatique |
| II | 15-30% (750-1500ml) | 100-120 | Normale | Anxiété, soif |
| III | 30-40% (1500-2000ml) | 120-140 | Diminuée | Confusion, oligurie |
| IV | >40% (>2000ml) | >140 | Effondrée | Léthargie, anurie |

### Examen abdominal
- [ ] **Inspection:** Distension, circulation collatérale
- [ ] **Palpation:**
  - Douleur épigastrique
  - Hépatomégalie
  - Splénomégalie
  - Ascite
- [ ] **TR:** Méléna, sang rouge

### Signes d'hépatopathie chronique
- [ ] **Ictère**
- [ ] **Angiomes stellaires**
- [ ] **Érythrose palmaire**
- [ ] **Hippocratisme digital**
- [ ] **Gynécomastie**
- [ ] **Astérixis** (encéphalopathie)

### Recherche complications
- [ ] **Pneumopathie inhalation**
- [ ] **Insuffisance rénale** aiguë (oligurie)
- [ ] **Encéphalopathie** hépatique

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Mesures d'urgence immédiates ⚠️ RÉANIMATION

#### 1.1 Monitorage
- [ ] **Scope:** FC, TA, SaO2
- [ ] **TA:** Toutes les 15 min initialement
- [ ] **Diurèse horaire:** Sonde urinaire
- [ ] **État conscience**

#### 1.2 Voies d'abord
- [ ] **2 VVP de gros calibre** (16-18G)
- [ ] **VVC** si état de choc

#### 1.3 Prélèvements urgents
- [ ] **Groupe sanguin, RAI** ⚠️ 2 déterminations
- [ ] **NFS, plaquettes**
- [ ] **TP, TCA, fibrinogène**
- [ ] **Ionogramme, urée, créatinine**
- [ ] **Bilan hépatique**
- [ ] **Lactates**
- [ ] **Gazométrie artérielle**

### 2. Réanimation volémique

#### 2.1 Remplissage vasculaire
- [ ] **Cristalloïdes:** 
  - Sérum physiologique 0,9%
  - Ringer lactate
  - 500ml en 15-30 min
  - Objectif: TAs >90 mmHg

#### 2.2 Transfusion ⚠️ STRATÉGIE RESTRICTIVE
- [ ] **Seuil transfusionnel:**
  - Hb <7 g/dl (patient stable)
  - Hb <9 g/dl (cardiopathie)
- [ ] **CGR:** 1 CGR augmente Hb de 1g/dl
- [ ] **Objectif:** Hb 7-9 g/dl

#### 2.3 Hémostase
- [ ] **PFC** si TP <50% ou anticoagulants
- [ ] **Plaquettes** si <50 000/mm³
- [ ] **Fibrinogène** si <1g/L

### 3. Traitement médical spécifique

#### 3.1 IPP intraveineux ⚠️ SYSTÉMATIQUE
- [ ] **Bolus:** Oméprazole 80mg IV
- [ ] **Puis:** 8mg/h IVSE ou 40mg × 2/j IV
- [ ] **Avant endoscopie** (ne pas retarder)

#### 3.2 Si suspicion varices œsophagiennes
- [ ] **Analogues somatostatine:**
  - Octréotide: 50μg bolus puis 50μg/h
  - Ou Terlipressine: 2mg/4h
- [ ] **Antibioprophylaxie:**
  - Ceftriaxone 1g/j × 7j
  - Ou Norfloxacine 400mg × 2/j PO
- [ ] **Lactulose** prévention encéphalopathie

#### 3.3 Prokinétiques
- [ ] **Érythromycine** 250mg IV
- [ ] **30 min avant endoscopie**
- [ ] **Améliore visualisation**

### 4. Endoscopie digestive haute ⚠️ URGENCE

#### 4.1 Timing
- [ ] **<12h** si hémodynamique stable
- [ ] **<2h** si:
  - Instabilité persistante
  - Suspicion varices
  - Hémorragie active

#### 4.2 Préparation
- [ ] **Jeûne** (si possible)
- [ ] **Érythromycine** préalable
- [ ] **Intubation** si trouble conscience

#### 4.3 Gestes thérapeutiques

**Ulcère:**
- [ ] **Injection adrénaline** 1/10000
- [ ] **Clips hémostatiques**
- [ ] **Thermocoagulation**
- [ ] **Classification Forrest:**
  - Ia: Jet artériel actif
  - Ib: Suintement actif
  - IIa: Vaisseau visible
  - IIb: Caillot adhérent
  - IIc: Base pigmentée
  - III: Fond propre

**Varices œsophagiennes:**
- [ ] **Ligature élastique** (préférée)
- [ ] **Sclérothérapie** si échec
- [ ] **Sonde de Blakemore** si échec (pont)

**Mallory-Weiss:**
- [ ] **Clips** si saignement actif
- [ ] **Souvent spontanément résolutif**

### 5. Échec endoscopie

#### 5.1 Radiologie interventionnelle
- [ ] **Artériographie** avec embolisation
- [ ] **Si hémorragie active** >0,5ml/min

#### 5.2 Chirurgie
- [ ] **Indications:**
  - Échec endoscopie × 2
  - Instabilité malgré réanimation
  - Transfusion >6 CGR/24h
- [ ] **Gestes:** Selon étiologie

#### 5.3 TIPS (varices)
- [ ] **Shunt porto-systémique** intrahépatique
- [ ] **Si échec** traitement endoscopique

### 6. Surveillance post-thérapeutique

#### 6.1 Monitorage continu
- [ ] **Hémodynamique**
- [ ] **Hb** toutes les 6h initialement
- [ ] **Signes de resaignement**

#### 6.2 Critères de resaignement
- [ ] **Hématémèse** récidivante
- [ ] **Instabilité** hémodynamique
- [ ] **Chute Hb** >2g/dl
- [ ] **Besoins transfusionnels** persistants

### 7. Prévention récidive

#### 7.1 Ulcère
- [ ] **IPP au long cours**
- [ ] **Éradication H. pylori**
- [ ] **Arrêt AINS/aspirine** si possible
- [ ] **Contrôle endoscopique** si ulcère gastrique

#### 7.2 Varices œsophagiennes
- [ ] **Bêtabloquants:** Propranolol, carvédilol
- [ ] **Ligatures itératives** jusqu'à éradication
- [ ] **Suivi endoscopique** régulier

### 8. Scores pronostiques

#### 8.1 Score de Rockall
**Pré-endoscopique:**
- Âge, comorbidités, TA, FC

**Post-endoscopique:**
- Diagnostic, stigmates hémorragie

**Interprétation:**
- <3: Faible risque
- ≥8: Haut risque mortalité

#### 8.2 Score de Glasgow-Blatchford
- Urée, Hb, TA, FC, méléna, syncope, hépatopathie, cardiopathie
- Score 0: Sortie possible
- Score >0: Hospitalisation

### 9. Critères d'hospitalisation
- [ ] **Réanimation/USI:**
  - État de choc
  - Hémorragie active
  - Comorbidités sévères
- [ ] **Hospitalisation conventionnelle:**
  - Tous les autres cas
  - Surveillance 48-72h minimum

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Évaluer hémodynamique** en priorité
2. **2 VVP gros calibre** immédiatement
3. **Groupe sanguin × 2** + RAI
4. **IPP IV** sans attendre endoscopie
5. **Endoscopie <12h** (urgente si instable)
6. **Transfusion restrictive** (Hb 7-9 g/dl)

### ❌ Pièges à éviter
1. **Retarder réanimation** pour examens
2. **Surtransfuser** (aggrave HTP)
3. **Oublier antibioprophylaxie** si cirrhose
4. **NG tube** systématique (inutile)
5. **Négliger resaignement** précoce

### 💡 Astuces mnémotechniques
- **Causes principales:** **U**lcère, **V**arices, **M**allory-Weiss, **T**umeur (UVMT)
- **Réanimation:** **V**oies veineuses, **O**2, **L**iquides, **S**ang (VOLS)
- **Forrest:** **I** = Actif, **II** = Récent, **III** = Ancien
- **Choc:** Classe **III** = **30**% pertes = TA↓
