# Fiche de Révision ECOS - BAISSE D'ACUITÉ VISUELLE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient consultant pour diminution de la vision nécessitant diagnostic étiologique urgent vs chronique et orientation adaptée.
**Objectifs d'évaluation:** Diagnostic différentiel causes aiguës/chroniques, recherche urgences ophtalmologiques, orientation spécialisée

---

## 📋 ANAMNÈSE

### 1. Caractérisation de la baisse visuelle
- [ ] **Début:** brutal (< 24h) vs progressif (semaines/mois)
- [ ] **Uni/bilatérale:** simultané vs successif
- [ ] **Degré:** vision floue vs amputation champ visuel
- [ ] **Évolution:** stable, fluctuante, aggravation
- [ ] **Facteurs déclenchants:** trauma, effort, médicaments

### 2. Symptômes associés ⚠️ Urgences
- [ ] **Douleur oculaire:** glaucome aigu, uvéite
- [ ] **Céphalées:** maladie de Horton, hypertension intracrânienne
- [ ] **Éclairs lumineux:** décollement rétine
- [ ] **Voile noir:** occlusion vasculaire
- [ ] **Vision double:** atteinte neurologique
- [ ] **Nausées/vomissements:** glaucome aigu, HTIC

### 3. Antécédents et facteurs de risque
- [ ] **Ophtalmologiques:** myopie, glaucome, DMLA
- [ ] **Cardiovasculaires:** HTA, diabète, arythmie
- [ ] **Neurologiques:** AVC, migraine
- [ ] **Médicaments:** hydroxychloroquine, corticoïdes
- [ ] **Familiaux:** DMLA, glaucome

---

## 🩺 EXAMEN CLINIQUE

### Acuité visuelle
- [ ] **Échelle Monoyer:** loin (avec/sans correction)
- [ ] **Échelle Parinaud:** près
- [ ] **Test trou sténopéique:** amélioration = réfraction
- [ ] **Quantification:** 10/10 normal, < 1/10 malvoyance

### Examen ophtalmologique
- [ ] **Inspection:** rougeur, larmoiement, ptosis
- [ ] **Pupilles:** réflexe photomoteur, déficit afférent
- [ ] **Motilité oculaire:** paralysie, diplopie
- [ ] **Champ visuel:** amputation, scotomes
- [ ] **Fond d'œil:** papille, vaisseaux, macula

---

## 💊 URGENCES OPHTALMOLOGIQUES ⚠️

### 1. Glaucome aigu par fermeture
- [ ] **Clinique:** douleur intense + vomissements + BAV
- [ ] **Examen:** œil rouge, pupille fixe semi-dilatée
- [ ] **Traitement:** collyres hypotonisants + laser

### 2. Occlusion artère centrale rétine
- [ ] **Clinique:** BAV brutale unilatérale indolore
- [ ] **Fond d'œil:** pâleur rétine, tache rouge cerise
- [ ] **Traitement:** urgence < 6h, massage oculaire

### 3. Décollement de rétine
- [ ] **Clinique:** éclairs + voile noir progressif
- [ ] **Fond d'œil:** soulèvement rétinien
- [ ] **Traitement:** chirurgie urgente

### 4. Neuropathie optique ischémique
- [ ] **Maladie de Horton:** > 50 ans + céphalées + VS élevée
- [ ] **Traitement:** corticoïdes 1mg/kg/j immédiat

---

## 🔍 CAUSES CHRONIQUES

### 1. Cataracte
- [ ] **Symptômes:** baisse progressive + éblouissement
- [ ] **Examen:** opacités cristalliniennes
- [ ] **Traitement:** chirurgie si gêne fonctionnelle

### 2. DMLA (dégénérescence maculaire)
- [ ] **Symptômes:** baisse vision centrale + métamorphopsies
- [ ] **Facteurs risque:** âge, tabac, hérédité
- [ ] **Traitement:** anti-VEGF si forme humide

### 3. Glaucome chronique
- [ ] **Asymptomatique:** jusqu'à stade avancé
- [ ] **Champ visuel:** altérations périphériques
- [ ] **Traitement:** collyres hypotonisants

### 4. Rétinopathie diabétique
- [ ] **Diabète > 10 ans:** microanévrismes, hémorragies
- [ ] **Surveillance:** fond d'œil annuel
- [ ] **Traitement:** équilibre glycémique + laser

---

## 📌 CONDUITE À TENIR

### 1. Baisse brutale → URGENCE
- [ ] **Orientation ophtalmologique immédiate**
- [ ] **Bilan étiologique:** cardiovasculaire, inflammatoire
- [ ] **Traitement:** selon cause

### 2. Baisse progressive
- [ ] **Bilan ophtalmologique programmé**
- [ ] **Correction optique:** lunettes, lentilles
- [ ] **Surveillance évolution**

### 3. Examens complémentaires
- [ ] **Angiographie rétinienne:** DMLA, diabète
- [ ] **OCT macula:** œdème, atrophie
- [ ] **Champ visuel:** glaucome, neuropathie
- [ ] **IRM orbito-cérébrale:** si atteinte neurologique

---

## 📌 POINTS CLÉS
- **Urgence si début brutal** (< 24h)
- **Réflexe photomoteur** systématique
- **Fond d'œil** après dilatation
- **Orientation ophtalmologique** rapide si anomalie
