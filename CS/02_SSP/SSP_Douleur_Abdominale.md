# Douleurs Abdominales - Fiche de révision ECOS

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient se présentant avec des douleurs abdominales aiguës ou chroniques
**Objectifs d'évaluation:** Recherche signes de gravité, anamnèse digestive complète, examen abdominal systématique, élimination des urgences chirurgicales

---

## 📋 ANAMNÈSE SYSTÉMATIQUE

### 1. Caractérisation de la douleur ⚠️ PRIORITÉ DIAGNOSTIQUE

#### Localisation précise
- [ ] **Épigastre** : estomac, pancréas, voies biliaires
- [ ] **Hypochondre droit** : foie, vésicule, angle colique
- [ ] **Hypochondre gauche** : rate, queue pancréas, angle colique
- [ ] **Flancs** : reins, uretères
- [ ] **Fosse iliaque droite** : appendice, iléon, ovaire
- [ ] **Fosse iliaque gauche** : sigmoïde, ovaire
- [ ] **Péri-ombilical** : intestin grêle
- [ ] **Sus-pubien** : vessie, utérus

#### Temporalité et évolution
- [ ] **Début** : brutal (perforation, embolie) vs progressif
- [ ] **Durée** : < 3 mois (aiguë) vs > 3 mois (chronique)
- [ ] **Évolution** : constante, coliques, par crises

#### Qualité et intensité
- [ ] **Type** : crampe, brûlure, torsion, coup de poignard
- [ ] **Intensité** : échelle 0-10
- [ ] **Irradiation** : dos, épaules, organes génitaux

#### Facteurs modulants
- [ ] **Relation avec repas** :
  - Post-prandiale immédiate (gastrite)
  - Post-prandiale tardive 2-3h (ulcère duodénal)
  - Calmée par repas (ulcère duodénal)
  - Déclenchée par repas gras (vésicule)
- [ ] **Soulagement** : antiacides, vomissements, position
- [ ] **Aggravation** : mouvement, inspiration, décubitus

### 2. Signes d'alarme (Red Flags) ⚠️

#### Signes généraux
- [ ] **Âge ≥ 50 ans** avec symptômes nouveaux
- [ ] **Amaigrissement** involontaire (>5% en 3 mois)
- [ ] **Anorexie** persistante
- [ ] **Fièvre** > 38.5°C
- [ ] **Ictère** cutané ou scléral

#### Signes digestifs
- [ ] **Hémorragie digestive** : hématémèse, méléna, rectorragies
- [ ] **Vomissements** incoercibles, fécaloïdes
- [ ] **Dysphagie** progressive
- [ ] **Changement récent transit** : constipation/diarrhée

#### Signes systémiques
- [ ] **État de choc** : hypotension, tachycardie, marbrures
- [ ] **Masse abdominale** palpable
- [ ] **Défense généralisée**

### 3. Symptômes associés

#### Digestifs
- [ ] **Nausées/vomissements** :
  - Timing par rapport aux repas
  - Aspect : alimentaire, bilieux, fécaloïde
- [ ] **Transit intestinal** :
  - Dernières selles/gaz (iléus ?)
  - Consistance, couleur, sang
- [ ] **Troubles dyspeptiques** : pyrosis, régurgitations

#### Urogénitaux
- [ ] **Signes urinaires** : brûlures, pollakiurie, hématurie
- [ ] **Chez la femme** : DDR, possibilité grossesse ⚠️

#### Généraux
- [ ] **Fièvre** : intensité, frissons
- [ ] **Altération état général** : fatigue, perte poids

### 4. Antécédents et terrain

#### Antécédents médicaux
- [ ] **Digestifs** : ulcère, RGO, MICI, lithiases
- [ ] **Chirurgicaux** : chirurgie abdominale (brides)
- [ ] **Cardiovasculaires** : IDM (douleur épigastrique)

#### Médicaments
- [ ] **AINS, aspirine** (ulcère)
- [ ] **Anticoagulants** (hémorragie)
- [ ] **Corticoïdes** (perforation)

#### Habitudes
- [ ] **Alcool** : quantité (pancréatite)
- [ ] **Tabac** : facteur ulcère, cancer
- [ ] **Alimentation** : repas gras, épices

## 🩺 EXAMEN CLINIQUE

### 1. État général et signes vitaux
- [ ] **Constantes** : TA, FC, FR, T°, SaO₂
- [ ] **Faciès** : douloureux, anxieux, ictérique
- [ ] **Position** : antalgique (chien de fusil = pancréatite)
- [ ] **Signes de choc** : pâleur, marbrures, extrémités froides

### 2. Inspection abdominale
- [ ] **Cicatrices** chirurgicales
- [ ] **Forme abdomen** : plat, distendu, asymétrique
- [ ] **Circulation collatérale** (HTP)
- [ ] **Mouvements respiratoires** (absents si péritonite)
- [ ] **Ecchymoses** : Cullen, Grey-Turner (pancréatite)

### 3. Auscultation (AVANT palpation!)
- [ ] **Bruits hydroaériques** :
  - Normaux : 5-34/min
  - Silence : iléus, péritonite
  - Métalliques : occlusion
  - Hyperactifs : gastro-entérite
- [ ] **Souffles vasculaires** : aorte, artères rénales

### 4. Percussion
- [ ] **4 quadrants** : tympanisme (gaz), matité (liquide)
- [ ] **Foie** : délimitation, hépatomégalie
- [ ] **Matité des flancs** (ascite)

### 5. Palpation systématique

#### Technique
- Observer le visage du patient
- Commencer loin de la zone douloureuse
- Palpation superficielle puis profonde

#### Palpation superficielle
- [ ] **4 quadrants** systématiquement
- [ ] **Défense** : contracture réflexe des muscles
- [ ] **Hyperesthésie cutanée**

#### Palpation profonde
- [ ] **Recherche de masses** : taille, consistance, mobilité
- [ ] **Douleur maximale**
- [ ] **Contracture** (péritonite)

#### Palpation d'organes
- [ ] **Foie** : bord inférieur, surface, consistance
- [ ] **Rate** : normalement non palpable
- [ ] **Reins** : ballottement rénal
- [ ] **Aorte** : diamètre (anévrisme si >3cm)
- [ ] **Orifices herniaires** : inguinaux, cruraux

### 6. Tests spécifiques ⚠️

#### Signe de Murphy (cholécystite)
- Patient en décubitus dorsal
- Main sous rebord costal droit
- Inspiration profonde
- **Positif** : arrêt inspiration par douleur

#### Point de McBurney (appendicite)
- 1/3 externe ligne ombilic-EIAS droite
- Douleur à la pression/décompression

#### Autres signes
- [ ] **Giordano** : percussion fosses lombaires (pyélonéphrite)
- [ ] **Psoas** : extension hanche (appendicite rétrocæcale)

### 7. Examens complémentaires au lit du patient
- [ ] **Toucher rectal** : fécalome, sang, douleur Douglas
- [ ] **Examen gynécologique** si indiqué

---

## 🔬 EXAMENS COMPLÉMENTAIRES

### 1. Biologie d'urgence
- [ ] **NFS** : anémie (saignement), hyperleucocytose
- [ ] **CRP** : syndrome inflammatoire
- [ ] **Ionogramme, urée, créatinine** : déshydratation
- [ ] **Bilan hépatique** : ASAT, ALAT, bilirubine, PAL
- [ ] **Lipase** : pancréatite si >3N
- [ ] **βHCG** : obligatoire chez femme en âge de procréer ⚠️
- [ ] **Bandelette urinaire** + ECBU si infection

### 2. Imagerie
- [ ] **ECG** : si douleur épigastrique (éliminer IDM)
- [ ] **Échographie abdominale** : liquide libre, lithiases, appendicite
- [ ] **Scanner abdomino-pelvien** : péritonite, occlusion, pancréatite
- [ ] **ASP debout** : pneumopéritoine, niveaux hydro-aériques

## 🎯 DIAGNOSTIC DIFFÉRENTIEL PAR LOCALISATION

### Hypochondre droit
| Diagnostic | Arguments POUR | Examens |
|------------|----------------|----------|
| **Cholécystite aiguë** | Murphy +, fièvre, douleur >6h | Écho: épaississement vésiculaire |
| **Colique hépatique** | Douleur <6h, pas fièvre, repas gras | Écho: lithiase vésiculaire |
| **Angiocholite** | Triade Charcot (fièvre+douleur+ictère) | Écho: dilatation VBP |
| **Pyélonéphrite** | Fièvre, Giordano +, signes urinaires | BU +, ECBU |

### Épigastre
| Diagnostic | Arguments POUR | Examens |
|------------|----------------|----------|
| **Ulcère gastroduodénal** | Rythmé par repas, AINS, H.pylori | Endoscopie |
| **Pancréatite aiguë** | Douleur transfixiante, alcool | Lipase >3N, scanner |
| **IDM inférieur** | Terrain CV, malaise, sueurs | ECG, troponines |
| **RGO** | Pyrosis, décubitus aggrave | Amélioration IPP |

### Fosse iliaque droite
| Diagnostic | Arguments POUR | Examens |
|------------|----------------|----------|
| **Appendicite** | Migration péri-ombilical→FID, McBurney + | Scanner, échographie |
| **Iléite terminale** | Diarrhée chronique, AEG | Scanner : épaississement iléal |

### Fosse iliaque gauche
| Diagnostic | Arguments POUR | Examens |
|------------|----------------|----------|
| **Diverticulite** | >50 ans, fièvre, défense FIG | Scanner : épaississement colique |
| **Colite (MICI)** | Diarrhée glairo-sanglante chronique | Coloscopie |

### Douleur diffuse
| Diagnostic | Arguments POUR | Examens |
|------------|----------------|----------|
| **Péritonite** | Contracture, silence auscultatoire | Scanner : pneumopéritoine |
| **Occlusion** | Arrêt matières/gaz, vomissements | ASP : niveaux hydro-aériques |
| **Ischémie mésentérique** | Terrain vasculaire, douleur+++/examen pauvre | Angio-scanner |

## 💊 PRISE EN CHARGE

### 1. Mesures générales
- [ ] **Voie veineuse** périphérique
- [ ] **Réhydratation** si déshydratation
- [ ] **Mise à jeun** si chirurgie probable
- [ ] **Antalgie adaptée** : paracétamol, éviter AINS si ulcère
- [ ] **Antiémétiques** si vomissements

### 2. Urgences chirurgicales

#### Péritonite
- **Chirurgie EN URGENCE**
- Antibiothérapie IV large spectre
- Réanimation hydroélectrolytique

#### Appendicite
- **Appendicectomie** (cœlioscopie)
- Antibiothérapie péri-opératoire

#### Cholécystite
- Antibiothérapie (augmentin)
- **Cholécystectomie** précoce

#### Angiocholite
- **Antibiothérapie IV** urgente (C3G + métronidazole)
- **Drainage biliaire** urgent (CPRE)

### 3. Urgences médicales

#### Pancréatite aiguë
- Hospitalisation, réhydratation intensive
- Antalgie (morphine), mise à jeun
- Traitement étiologique (sevrage alcool, cholécystectomie)

#### Occlusion intestinale
- Aspiration nasogastrique
- Réhydratation IV
- Chirurgie si strangulation

#### Colique néphrétique
- AINS (kétorolac), antispasmodiques
- Hyperhydratation après levée obstacle

### 4. Traitements ambulatoires

#### Ulcère gastroduodénal
- **IPP** forte dose 4-8 semaines
- **Éradication H.pylori** si positif
- Arrêt AINS/aspirine

#### RGO
- IPP 20-40mg/j
- Mesures hygiéno-diététiques

## ⚠️ RED FLAGS - SIGNES D'ALARME

- **Défense généralisée** → Péritonite
- **Masse pulsatile** → Anévrisme aorte
- **Ictère + fièvre** → Angiocholite
- **Amaigrissement + âge >50 ans** → Cancer
- **Arrêt matières et gaz** → Occlusion
- **Hématémèse/méléna** → Hémorragie digestive
- **Douleur épigastrique + terrain CV** → IDM

## 🎯 POINTS CLÉS POUR L'ECOS

### ✅ À faire absolument
1. **Test de grossesse** chez toute femme en âge de procréer
2. **ECG** si douleur épigastrique
3. **Ausculter AVANT de palper**
4. **Signe de Murphy** si suspicion cholécystite
5. **Toucher rectal** systématique
6. **Lipase** si suspicion pancréatite

### ❌ Pièges à éviter
1. Oublier grossesse extra-utérine
2. Méconnaître IDM épigastrique
3. Banaliser douleur chez sujet âgé
4. Donner morphine avant diagnostic
5. Ne pas rechercher hernie étranglée
6. Oublier anévrisme aorte chez >70 ans
