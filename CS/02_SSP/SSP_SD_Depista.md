# Fiche de Révision ECOS - DÉPISTAGES ET PRÉVENTION

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient consultant pour check-up, bilan de santé ou demandant des dépistages adaptés
**Objectifs d'évaluation:** Identifier les dépistages appropriés selon l'âge et les facteurs de risque, expliquer les bénéfices/risques, organiser le suivi préventif

---

## 📋 ANAMNÈSE

### 1. Motif de consultation et attentes
- [ ] **Raison de la demande:**
  - Check-up de routine
  - Inquiétude spécifique
  - Demande employeur/assurance
  - Antécédent familial récent
- [ ] **Derniers bilans:**
  - Date du dernier check-up
  - Examens déjà réalisés
  - Résultats anormaux antérieurs

### 2. Identification des facteurs de risque ⚠️ ESSENTIEL

#### 2.1 Données démographiques
- [ ] **Âge** (détermine les dépistages)
- [ ] **Sexe** (dépistages spécifiques)
- [ ] **Origine ethnique** (certains risques augmentés)

#### 2.2 Antécédents familiaux ⚠️ ORIENTATION DÉPISTAGE
- [ ] **Cancers familiaux:**
  - Cancer du sein (âge diagnostic, BRCA?)
  - Cancer colorectal (syndrome Lynch?)
  - Cancer prostate
  - Cancer ovaire
  - Mélanome
- [ ] **Maladies cardiovasculaires:**
  - IDM précoce (<55 ans homme, <65 ans femme)
  - AVC précoce
  - Mort subite
- [ ] **Diabète type 2**
- [ ] **Hypercholestérolémie familiale**
- [ ] **Maladies génétiques** (hémochromatose, etc.)

#### 2.3 Facteurs de risque modifiables
- [ ] **Tabagisme:**
  - Statut actuel/sevré
  - Nombre paquets-années
  - Âge début/arrêt
- [ ] **Alcool:**
  - Consommation hebdomadaire
  - AUDIT-C si nécessaire
- [ ] **Activité physique:**
  - Fréquence/durée/intensité
  - Sédentarité professionnelle
- [ ] **Alimentation:**
  - Équilibre alimentaire
  - Consommation fruits/légumes
  - Sel, graisses saturées

### 3. Dépistages déjà réalisés ⚠️ MISE À JOUR

#### 3.1 Dépistages oncologiques
- [ ] **Cancer du sein:**
  - Dernière mammographie
  - Auto-palpation régulière
  - Suivi gynécologique
- [ ] **Cancer colorectal:**
  - Test FIT/Hemoccult
  - Coloscopie (date, résultats)
- [ ] **Cancer du col utérin:**
  - Dernier frottis cervical
  - Test HPV
  - Vaccination HPV
- [ ] **Cancer de la prostate:**
  - Discussion PSA
  - Toucher rectal

#### 3.2 Dépistages cardiovasculaires
- [ ] **Tension artérielle:**
  - Dernière mesure
  - Suivi si HTA connue
- [ ] **Bilan lipidique:**
  - Date dernier bilan
  - Valeurs LDL/HDL
- [ ] **Glycémie:**
  - Dépistage diabète
  - HbA1c si à risque

#### 3.3 Autres dépistages
- [ ] **Ostéoporose:**
  - DEXA scan (femmes >65 ans)
  - Facteurs de risque fracture
- [ ] **Anévrisme aorte abdominale:**
  - Échographie (hommes 65-75 ans fumeurs)
- [ ] **Dépistage visuel:**
  - Glaucome (>40 ans)
  - DMLA (>50 ans)
- [ ] **Dépistage auditif** (>65 ans)

### 4. Vaccinations ⚠️ PRÉVENTION

#### 4.1 Vaccinations de base
- [ ] **DTP:** Dernier rappel
- [ ] **ROR:** Statut complet
- [ ] **Hépatite B:** Statut sérologique
- [ ] **BCG:** Si indiqué

#### 4.2 Vaccinations selon l'âge
- [ ] **HPV:** 11-26 ans
- [ ] **Zona:** >65 ans
- [ ] **Pneumocoque:** >65 ans ou à risque
- [ ] **Grippe:** Annuelle si >65 ans ou à risque

#### 4.3 Vaccinations spécifiques
- [ ] **Voyage:** Selon destination
- [ ] **Professionnelles:** Selon exposition
- [ ] **Grossesse:** Coqueluche, grippe

### 5. Santé mentale et addictions
- [ ] **Dépistage dépression** (PHQ-2/PHQ-9)
- [ ] **Anxiété** (GAD-7 si indiqué)
- [ ] **Consommation substances**
- [ ] **Violence domestique** (si signes d'appel)

### 6. Santé sexuelle et reproductive
- [ ] **Contraception** adaptée
- [ ] **Dépistage IST** si à risque
- [ ] **Désir de grossesse** (acide folique)
- [ ] **Ménopause** (symptômes, THS)

---

## 🩺 EXAMEN CLINIQUE (STATUS)

### Mesures anthropométriques
- [ ] **Poids, taille, IMC**
- [ ] **Tour de taille** (risque métabolique)
- [ ] **Tension artérielle** (2 mesures)

### Examen général de dépistage
- [ ] **Peau:** Inspection lésions suspectes
- [ ] **Ganglions:** Palpation aires ganglionnaires
- [ ] **Thyroïde:** Palpation, nodules
- [ ] **Seins:** Palpation si indiquée
- [ ] **Abdomen:** Masse, organomégalie
- [ ] **Pouls périphériques** (dépistage AOMI)

### Examens spécifiques selon l'âge
- [ ] **Toucher rectal** (homme >50 ans)
- [ ] **Examen gynécologique** si indiqué
- [ ] **Acuité visuelle/auditive** (>65 ans)
- [ ] **Test cognitif** (MMS si >75 ans)

---

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Recommandations de dépistage par âge ⚠️ GUIDELINES

#### 18-39 ans
- [ ] **TA:** Tous les 3-5 ans (annuel si facteurs risque)
- [ ] **Lipides:** À partir de 35 ans homme, 45 ans femme
- [ ] **Glycémie:** Si surpoids + facteur risque
- [ ] **Frottis cervical:** 25-65 ans, tous les 3 ans
- [ ] **IST:** Si sexuellement actif à risque

#### 40-49 ans
- [ ] **Mammographie:** Discussion 45-49 ans (risque moyen)
- [ ] **TA:** Tous les 2 ans
- [ ] **Lipides:** Tous les 5 ans
- [ ] **Glycémie:** Tous les 3 ans si facteurs risque

#### 50-74 ans ⚠️ ÂGE CLÉ DÉPISTAGES
- [ ] **Cancer colorectal:** FIT tous les 2 ans (50-74 ans)
- [ ] **Mammographie:** Tous les 2 ans (50-74 ans)
- [ ] **TA:** Annuelle
- [ ] **Lipides:** Selon risque CV
- [ ] **Glycémie:** Tous les 3 ans
- [ ] **AAA:** Échographie unique (hommes 65-75 ans fumeurs)
- [ ] **Ostéoporose:** DEXA femmes >65 ans

#### >75 ans
- [ ] **Dépistages individualisés** selon:
  - Espérance de vie
  - Comorbidités
  - Préférences patient
- [ ] **Dépistage troubles cognitifs**
- [ ] **Évaluation gériatrique** si fragilité

### 2. Examens de dépistage à prescrire

#### Bilan biologique de base
- [ ] **NFS** (anémie)
- [ ] **Glycémie à jeun**
- [ ] **Bilan lipidique:** CT, LDL, HDL, TG
- [ ] **Créatinine, DFG**
- [ ] **ALAT** (si facteurs risque hépatiques)
- [ ] **TSH** (si symptômes)
- [ ] **Vitamine D** (si facteurs risque)

#### Dépistages oncologiques
- [ ] **FIT test** (50-74 ans)
- [ ] **Mammographie** (50-74 ans)
- [ ] **Frottis cervical/Test HPV** (25-65 ans)
- [ ] **PSA:** Discussion bénéfices/risques (50-70 ans)

#### Imagerie si indiquée
- [ ] **Radio thorax:** Non recommandée en routine
- [ ] **Échographie AAA:** Hommes 65-75 ans fumeurs
- [ ] **DEXA scan:** Femmes >65 ans, hommes >70 ans

### 3. Conseils de prévention ⚠️ ÉDUCATION

#### Mode de vie
- [ ] **Tabac:** Sevrage (proposer aide)
- [ ] **Alcool:** Maximum 10 verres/semaine
- [ ] **Activité physique:** 150 min/semaine modérée
- [ ] **Alimentation:** Méditerranéenne, 5 fruits/légumes
- [ ] **Poids:** Objectif IMC 18.5-25

#### Prévention spécifique
- [ ] **Soleil:** Protection UV, auto-examen peau
- [ ] **Chutes:** Exercices équilibre (>65 ans)
- [ ] **Vaccinations:** Mise à jour calendrier
- [ ] **Santé bucco-dentaire:** Contrôle annuel

### 4. Organisation du suivi

#### Planification des dépistages
- [ ] **Calendrier personnalisé** selon âge/risques
- [ ] **Rappels** pour examens périodiques
- [ ] **Carnet de santé/dossier** partagé

#### Orientation si nécessaire
- [ ] **Consultation spécialisée** si anomalie
- [ ] **Programme dépistage organisé** (sein, côlon)
- [ ] **Conseil génétique** si histoire familiale

### 5. Communication et décision partagée

#### Information du patient
- [ ] **Bénéfices** du dépistage
- [ ] **Limites et risques:**
  - Faux positifs/négatifs
  - Surdiagnostic
  - Examens complémentaires
- [ ] **Choix éclairé** du patient

#### Documentation
- [ ] **Résumé des recommandations** remis
- [ ] **Prochains rendez-vous** planifiés
- [ ] **Coordonnées** pour questions

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Adapter dépistages** à l'âge et facteurs de risque
2. **Mammographie** 50-74 ans tous les 2 ans
3. **FIT test** 50-74 ans tous les 2 ans
4. **Frottis cervical** 25-65 ans tous les 3 ans
5. **Conseils hygiène de vie** systématiques
6. **Mise à jour vaccinations**

### ❌ Pièges à éviter
1. **Dépistage systématique** sans tenir compte de l'âge
2. **PSA systématique** sans discussion bénéfices/risques
3. **Radio thorax** de routine (non recommandée)
4. **Oublier dépistages** IST chez jeunes à risque
5. **Négliger santé mentale** dans bilan global

### 💡 Astuces mnémotechniques
- **Dépistages 50 ans:** **MFC** (Mammographie, FIT, Cervical)
- **Facteurs risque CV:** **THADIS** (Tabac, HTA, Âge, Diabète, IMC, Sédentarité)
- **Vaccins >65 ans:** **GPZ** (Grippe, Pneumocoque, Zona)
