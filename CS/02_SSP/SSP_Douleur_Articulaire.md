# Fiche de Révision ECOS - SSP Douleur Articulaire Générale

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient consultant pour douleurs articulaires, polyarthrite ou oligoarthrite, nécessitant une approche systémique
**Objectifs d'évaluation:** Différencier inflammatoire vs mécanique, localisation, évaluation systémique, diagnostic différentiel

## 📋 ANAMNÈSE (25%)

### 1. Anamnèse actuelle et caractérisation de la douleur
**Questions essentielles:**
- [ ] **Début et évolution:** aigu (<6 sem) vs chronique (>6 sem)
- [ ] **Localisation précise:** quelles articulations touchées
- [ ] **Distribution:** monoarthrite, oligoarthrite (<5), polyarthrite (≥5)
- [ ] **Symétrie:** bilatérale/symétrique vs asymétrique
- [ ] **Type de douleur:** inflammatoire vs mécanique
- [ ] **Intensité:** échelle 1-10, évolution dans le temps
- [ ] **Facteurs déclenchants:** traumatisme, infection, stress

### 2. Caractères inflammatoires vs mécaniques

**Douleur INFLAMMATOIRE:**
- [ ] **Raideur matinale** >30-60 minutes (CLEF DU DIAGNOSTIC)
- [ ] **Douleur de repos et nocturne** (réveils)
- [ ] **Amélioration par le mouvement**
- [ ] **Tuméfaction articulaire** (gonflement)
- [ ] **Dérouillage matinal** prolongé

**Douleur MÉCANIQUE:**
- [ ] **Douleur à l'effort** et en fin de journée
- [ ] **Amélioration par le repos**
- [ ] **Raideur matinale** <30 minutes
- [ ] **Pas de réveils nocturnes**

### 3. Examen articulaire systématique
**Atteinte des petites articulations:**
- [ ] **MCP (métacarpo-phalangiennes)** - typique PR
- [ ] **IPP (interphalangiennes proximales)** - typique PR
- [ ] **IPD (interphalangiennes distales)** - arthrose/psoriasis
- [ ] **Poignets** - fréquent dans PR
- [ ] **MTP (métatarso-phalangiennes)** - PR débutante

**Atteinte des grosses articulations:**
- [ ] **Genoux, chevilles** - nombreuses causes
- [ ] **Hanches, épaules** - arthrose, PR évoluée
- [ ] **Coudes** - goutte, PR, arthrite septique

### 4. Symptômes généraux (orientation étiologique)
- [ ] **Fièvre** (arthrite septique, connectivite, goutte)
- [ ] **Altération état général, amaigrissement**
- [ ] **Asthénie chronique** (maladies systémiques)
- [ ] **Sudations nocturnes**
- [ ] **Lymphadénopathies** (connectivites)

### 5. Symptômes extra-articulaires
**Cutanés:**
- [ ] **Psoriasis** (arthrite psoriasique)
- [ ] **Rash malaire** (lupus)
- [ ] **Nodules cutanés** (nodules rhumatoïdes)
- [ ] **Purpura, livedo** (vascularite)
- [ ] **Érythème migrant** (Lyme)

**Oculaires:**
- [ ] **Syndrome sec** (Sjögren, PR)
- [ ] **Uvéite** (spondylarthrites)
- [ ] **Conjonctivite** (arthrite réactionnelle)

**Autres systèmes:**
- [ ] **Atteinte rénale** (lupus, vascularite)
- [ ] **Atteinte pulmonaire** (PR, sclérodermie)
- [ ] **Troubles digestifs** (Crohn, arthrite réactionnelle)
- [ ] **Urétrite** (arthrite réactionnelle)

### 6. Antécédents et facteurs déclenchants
- [ ] **Infection récente** (arthrite réactionnelle, septique)
- [ ] **Voyage, piqûre de tique** (Lyme)
- [ ] **Antécédents familiaux** (PR, spondylarthrites)
- [ ] **Traumatisme articulaire** ancien
- [ ] **Prise médicamenteuse** (quinolones, diurétiques)

## 🩺 EXAMEN CLINIQUE (25%)

### Signes vitaux et inspection générale
- [ ] **TA, FC, T°** (fièvre = infection/inflammation)
- [ ] **Poids/IMC** (surcharge = arthrose)
- [ ] **État général** (altéré si maladie systémique)
- [ ] **Démarche, attitude antalgique**

### Examen articulaire systémique (INDISPENSABLE)

**Inspection:**
- [ ] **Tuméfaction, déformation** articulaire
- [ ] **Érythème, chaleur locale**
- [ ] **Attitude vicieuse** (flexion, déviation)
- [ ] **Atrophie musculaire** périarticulaire
- [ ] **Nodules rhumatoïdes** (faces d'extension)

**Palpation de CHAQUE articulation:**
- [ ] **Chaleur locale** (comparaison côté sain)
- [ ] **Douleur à la pression**
- [ ] **Épanchement articulaire** (choc rotulien au genou)
- [ ] **Synovite palpable** (épaississement synovial)

**Tests spécifiques des mains:**
- [ ] **Squeeze test** (compression latérale MCP = douleur)
- [ ] **Force de préhension** (dynamomètre)
- [ ] **Capacité fonctionnelle** (fermer le poing, pincer)

### Mobilités articulaires
- [ ] **Amplitudes actives et passives** 
- [ ] **Limitation douloureuse vs mécanique**
- [ ] **Instabilité articulaire**
- [ ] **Craquements, crépitations** (arthrose)

### Recherche atteinte rachis
- [ ] **Schöber test** (spondylarthrite)
- [ ] **Mobilité cervicale** (PR: subluxation C1-C2)
- [ ] **Douleurs sacro-iliaques**

### Examen extra-articulaire
- [ ] **Peau:** psoriasis, nodules, éruptions
- [ ] **Yeux:** conjonctivite, uvéite, syndrome sec
- [ ] **Ganglions** lymphatiques
- [ ] **Organomégalie** (rate, foie)

## 💊 PRISE EN CHARGE (25%)

### 1. Examens complémentaires

**Biologie inflammatoire:**
- [ ] **VS, CRP** (syndrome inflammatoire)
- [ ] **NFS** (anémie inflammatoire, thrombocytose)
- [ ] **Fibrinogène** (inflammation aiguë)

**Auto-anticorps (si polyarthrite):**
- [ ] **Facteur rhumatoïde (FR)** - sens. 70%, spéc. 80%
- [ ] **Anti-CCP** - sens. 60%, spéc. 95% (très spécifique PR)
- [ ] **AAN** (connectivites: lupus, Sjögren, sclérodermie)
- [ ] **Anti-DNA natif** (lupus actif)
- [ ] **Complément C3/C4** (consommation si lupus actif)

**Autres examens orientés:**
- [ ] **HLA-B27** (spondylarthrites)
- [ ] **ANCA** (vascularites)
- [ ] **Sérologie Lyme** si contexte
- [ ] **Acide urique** (goutte)

**Imagerie:**
- [ ] **Radiographies mains/poignets + pieds face** (PR)
- [ ] **Radiographies des articulations symptomatiques**
- [ ] **Échographie articulaire** (synovite, épanchement)
- [ ] **IRM** si suspicion ostéonécrose, arthrite précoce

### 2. Diagnostics différentiels

| Diagnostic | Arguments POUR | Arguments CONTRE | Examens clés |
|------------|----------------|------------------|--------------|
| **Polyarthrite rhumatoïde** | • MCP/IPP bilatérales<br>• Raideur >2h<br>• Symétrique<br>• Synovite | • IPD touchées<br>• Asymétrique<br>• Pas de raideur | FR, anti-CCP, Rx mains/pieds |
| **Lupus érythémateux** | • Femme jeune<br>• Rash malaire<br>• Atteinte rénale<br>• Cytopenies | • Arthrite non érosive<br>• Déformations rares | AAN, anti-DNA, complément |
| **Arthrite psoriasique** | • Psoriasis<br>• Asymétrique<br>• Atteinte IPD<br>• Enthésites | • Distribution symétrique | HLA-B27, Rx (ostéolyse) |
| **Spondylarthrite** | • Rachialgie inflammatoire<br>• Enthésites<br>• Atteinte axiale | • Polyarthrite symétrique<br>• Pas d'atteinte rachis | HLA-B27, IRM sacro-iliaques |
| **Goutte** | • Homme, MTP I<br>• Crises aiguës<br>• Hyperuricémie | • Polyarthrite chronique<br>• Femme jeune | Uricémie, ponction cristaux |
| **Arthrose** | • Douleur mécanique<br>• IPD, CMC<br>• Âge >50 ans | • Inflammation marquée<br>• Raideur matinale | Rx (ostéophytes, pincement) |

### 3. Critères diagnostiques PR (ACR/EULAR 2010)
**Score ≥6/10 = Polyarthrite rhumatoïde**

| Critère | Points |
|---------|--------|
| **Atteinte articulaire:**<br>• 2-10 grandes articulations<br>• 1-3 petites articulations<br>• 4-10 petites articulations<br>• >10 articulations | 1<br>2<br>3<br>5 |
| **Sérologie:**<br>• FR ou anti-CCP faible<br>• FR ou anti-CCP élevé | 2<br>3 |
| **Durée >6 semaines** | 1 |
| **Syndrome inflammatoire (VS/CRP)** | 1 |

### 4. Traitement

#### Traitement symptomatique immédiat:
- [ ] **AINS** + protection gastrique (IPP)
- [ ] **Corticothérapie** faible dose (<10mg prednisolone)
- [ ] **Antalgiques** selon EVA
- [ ] **Repos articulaire** en poussée
- [ ] **Attelles de repos** nocturnes

#### Traitement de fond (si PR confirmée):
- [ ] **Méthotrexate** 15-25mg/semaine (1ère ligne)
- [ ] **Acide folique** 5-10mg/semaine
- [ ] **Alternative:** léflunomide, sulfasalazine
- [ ] **Biothérapies** si échec DMARDs

## 📌 POINTS CLÉS POUR L'EXAMEN (25%)

### ✅ À faire absolument
1. **Caractériser la raideur matinale** (durée précise >/<60min)
2. **Examen articulaire systémique complet** (toutes articulations)
3. **Squeeze test** et tests fonctionnels des mains
4. **Rechercher atteinte extra-articulaire** (peau, yeux, ganglions)

### ❌ Pièges à éviter
1. Oublier l'examen des pieds (MTP souvent touchées en premier)
2. Ne pas différencier douleur inflammatoire vs mécanique
3. Négliger la recherche de signes cutanés (psoriasis discret)
4. Manquer une monoarthrite septique (urgence diagnostique)

### 💡 Astuces mnémotechniques
**"RAIDEUR"** pour douleur inflammatoire:
- **R**éveils nocturnes
- **A**mélioration par mouvement  
- **I**nflammation (tuméfaction)
- **D**érouillage >60min
- **E**tat général altéré
- **U**nilatéral puis bilatéral
- **R**epos ne soulage pas

### 🚨 Urgences à ne pas manquer
- [ ] **Arthrite septique** (monoarthrite fébrile)
- [ ] **Polyarthrite rhumatoïde** débutante (window of opportunity <3 mois)
- [ ] **Lupus avec atteinte rénale** 
- [ ] **Vascularite systémique**
