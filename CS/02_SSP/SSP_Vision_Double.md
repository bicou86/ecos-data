# Fiche de Révision ECOS - VISION DOUBLE (DIPLOPIE)

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient se présentant avec vision double (diplopie)
**Objectifs d'évaluation:** Différencier diplopie monoculaire et binoculaire, identifier la cause, reconnaître les urgences neurologiques

---

## 📋 ANAMNÈSE

### 1. Caractérisation de la diplopie ⚠️ ESSENTIEL

#### 1.1 Test diagnostique fondamental
- [ ] **Occlusion alternée des yeux:**
  - **Diplopie disparaît** à l'occlusion d'un œil → BINOCULAIRE (95%)
  - **Diplopie persiste** œil ouvert → MONOCULAIRE (5%)

#### 1.2 Caractéristiques de la vision double
- [ ] **Orientation des images:**
  - Horizontale (III, VI)
  - Verticale (III, IV)
  - Oblique (combinaison)
- [ ] **Distance entre les images:**
  - Fixe
  - Variable selon direction du regard
- [ ] **Position compensatrice** de la tête (torticolis)

#### 1.3 Installation et évolution
- [ ] **Mode d'apparition:**
  - **Brutal** → urgence (AVC, anévrisme)
  - **Progressif** (tumeur, myasthénie)
  - **Fluctuant** (myasthénie++)
- [ ] **Évolution dans la journée:**
  - Aggravation vespérale (myasthénie)
  - Amélioration au repos
- [ ] **Durée:** Minutes, heures, jours, permanent

### 2. Symptômes associés ⚠️ ORIENTATION ÉTIOLOGIQUE

#### 2.1 Signes neurologiques
- [ ] **Céphalées:**
  - Brutales intenses (hémorragie méningée)
  - Progressives (HTIC)
  - Rétro-orbitaires (Horton)
- [ ] **Ptosis:** Chute paupière (III, myasthénie, Horton)
- [ ] **Mydriase:** Dilatation pupillaire (III compressif)
- [ ] **Troubles sensitifs** faciaux (atteinte V)
- [ ] **Vertiges, ataxie** (tronc cérébral)
- [ ] **Déficits neurologiques** focaux

#### 2.2 Signes oculaires
- [ ] **Douleur oculaire/périorbitaire:**
  - Mobilisation douloureuse
  - Spontanée
- [ ] **Exophtalmie** (protrusion globe)
- [ ] **Œil rouge** (inflammation orbitaire)
- [ ] **Baisse acuité visuelle** associée

#### 2.3 Signes généraux
- [ ] **Fatigabilité musculaire** (myasthénie)
- [ ] **Troubles de déglutition** (myasthénie bulbaire)
- [ ] **Faiblesse membres** (myasthénie généralisée)
- [ ] **Signes thyroïdiens** (Basedow)

### 3. Causes de diplopie binoculaire ⚠️ 95% DES CAS

#### 3.1 Paralysies oculomotrices

**Nerf III (oculomoteur commun):**
- [ ] **Ptosis** (releveur paupière)
- [ ] **Œil en dehors et en bas** (divergent)
- [ ] **Mydriase** si atteinte extrinsèque
- [ ] **Causes:**
  - Anévrisme communicante postérieure (mydriase)
  - Diabète (respect pupille)
  - Compression tumorale

**Nerf IV (pathétique/trochléaire):**
- [ ] **Diplopie verticale/oblique**
- [ ] **Tête penchée côté opposé** (compensation)
- [ ] **Difficultés escaliers** (regard bas)
- [ ] **Causes:** Traumatisme, congénital

**Nerf VI (abducens):**
- [ ] **Œil en dedans** (convergent)
- [ ] **Diplopie horizontale** maximale en latéral
- [ ] **Causes:**
  - HTIC (faux signe localisant)
  - Diabète
  - SEP

#### 3.2 Myasthénie ⚠️ FLUCTUANT
- [ ] **Fatigabilité:** Aggravation fin journée/effort
- [ ] **Test au glaçon:** Amélioration par froid
- [ ] **Ptosis variable**
- [ ] **Atteinte autres muscles:**
  - Bulbaires (déglutition, phonation)
  - Membres (faiblesse proximale)
- [ ] **Amélioration repos**

#### 3.3 Orbitopathie dysthyroïdienne (Basedow)
- [ ] **Exophtalmie** uni/bilatérale
- [ ] **Rétraction paupière supérieure**
- [ ] **Œdème palpébral**
- [ ] **Signes thyrotoxicose:**
  - Tachycardie, tremblements
  - Amaigrissement, thermophobie
  - Goitre

#### 3.4 Causes vasculaires ⚠️ URGENCES
- [ ] **AVC tronc cérébral:**
  - Syndrome alterne
  - Vertiges, ataxie
  - Troubles déglutition
- [ ] **Anévrisme:**
  - Céphalée brutale
  - III avec mydriase
  - Méningisme
- [ ] **Fistule carotido-caverneuse:**
  - Exophtalmie pulsatile
  - Souffle oculaire
  - Chémosis

#### 3.5 Autres causes
- [ ] **SEP:** Adulte jeune, poussées-rémissions
- [ ] **Tumeur:** Tronc cérébral, orbite
- [ ] **Syndrome de Miller-Fisher:** Post-infectieux
- [ ] **Maladie de Horton:** >50 ans, céphalées

### 4. Causes de diplopie monoculaire (5%)

#### 4.1 Causes oculaires
- [ ] **Cataracte débutante** (noyau décentré)
- [ ] **Luxation/subluxation cristallin**
- [ ] **Astigmatisme irrégulier**
- [ ] **Kératocône**
- [ ] **Pathologie maculaire** (membrane)

#### 4.2 Causes fonctionnelles
- [ ] **Troubles de conversion**
- [ ] **Simulation**

### 5. Facteurs de risque et antécédents

#### 5.1 Pathologies à risque
- [ ] **Diabète** (mononeuropathie)
- [ ] **HTA** (AVC)
- [ ] **Dysthyroïdie** (Basedow)
- [ ] **Maladies auto-immunes** (myasthénie, SEP)
- [ ] **Cancer** (métastases, paranéoplasique)

#### 5.2 Antécédents
- [ ] **Traumatisme crânien** récent
- [ ] **Chirurgie:** Strabisme, cataracte
- [ ] **Épisodes antérieurs** (SEP, myasthénie)
- [ ] **Infections récentes** (Miller-Fisher)

#### 5.3 Médicaments
- [ ] **Antiépileptiques** (phénytoïne, carbamazépine)
- [ ] **Aminosides** (toxicité)
- [ ] **Psychotropes** (lithium)

### 6. Contexte de survenue
- [ ] **Effort physique** (myasthénie)
- [ ] **Stress, fatigue**
- [ ] **Exposition chaleur** (SEP)
- [ ] **Traumatisme** même minime

### 7. Question de clôture
"Avez-vous remarqué une faiblesse musculaire ailleurs ou d'autres symptômes neurologiques?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Test de Lancaster (ou écran de Hess) ⚠️ LOCALISATION
- [ ] **Principe:** Dissociation œil droit/gauche
- [ ] **Identifie muscle/nerf atteint**
- [ ] **Quantifie déficit**

### Examen oculomoteur ⚠️ SYSTÉMATIQUE

#### Positions du regard (9 positions)
- [ ] **Position primaire** (droit devant)
- [ ] **6 positions cardinales:**
  - Haut/droite, haut/gauche
  - Latéral droit, latéral gauche  
  - Bas/droite, bas/gauche
- [ ] **Regard vers le haut et bas**

#### Analyse des mouvements
- [ ] **Limitation** dans une direction
- [ ] **Œil hypoactif** (parésie)
- [ ] **Œil hyperactif** (controlatéral)
- [ ] **Nystagmus** associé

### Examen pupillaire
- [ ] **Taille, symétrie**
- [ ] **Réflexe photomoteur** direct/consensuel
- [ ] **Mydriase:** III extrinsèque (compression)
- [ ] **Myosis:** Claude Bernard-Horner

### Examen palpébral
- [ ] **Ptosis:** Mesure fente palpébrale
- [ ] **Test de fatigue:** Regard soutenu vers haut
- [ ] **Test au glaçon** (myasthénie)
- [ ] **Rétraction palpébrale** (Basedow)

### Examen orbitaire
- [ ] **Exophtalmie:** Mesure exophtalmomètre
- [ ] **Pulsatilité** (fistule)
- [ ] **Souffle** à l'auscultation (fistule)
- [ ] **Œdème, érythème** périorbitaire

### Examen neurologique complet

#### Autres nerfs crâniens
- [ ] **II:** Acuité, champ visuel, FO
- [ ] **V:** Sensibilité faciale, réflexe cornéen
- [ ] **VII:** Motricité faciale
- [ ] **IX, X:** Déglutition, voile
- [ ] **XI:** Hausse épaules
- [ ] **XII:** Motricité linguale

#### Recherche syndrome myasthénique
- [ ] **Test de fatigabilité:**
  - Maintien bras tendus
  - Flexions répétées
- [ ] **Amélioration au repos**
- [ ] **Force musculaire** segmentaire

#### Signes de localisation
- [ ] **Syndrome cérébelleux**
- [ ] **Syndrome pyramidal**
- [ ] **Troubles sensitifs**

### Examen général
- [ ] **TA** (HTA, hypotension orthostatique)
- [ ] **Signes thyroïdiens:** Goitre, tremblements
- [ ] **Artères temporales** (Horton)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Imagerie cérébrale ⚠️ URGENTE SI SIGNES D'ALERTE
- [ ] **IRM cérébrale + angio-IRM:**
  - Coupe fines orbites/sinus caverneux
  - Séquences T1, T2, FLAIR, diffusion
  - Recherche: AVC, anévrisme, tumeur, SEP
- [ ] **Scanner + angio-TDM:** Si IRM non disponible

#### 1.2 Tests myasthénie (si suspicion)
- [ ] **Test aux anticholinestérasiques:**
  - Edrophonium (Tensilon) IV
  - Néostigmine IM
  - Amélioration transitoire (minutes)
- [ ] **Anticorps anti-RACh** (récepteurs acétylcholine)
- [ ] **Anticorps anti-MuSK**
- [ ] **EMG:** Décrément à stimulation répétitive
- [ ] **Scanner thoracique:** Thymome

#### 1.3 Bilan thyroïdien (si Basedow)
- [ ] **TSH, T4L, T3L**
- [ ] **Anticorps anti-récepteur TSH**
- [ ] **Échographie thyroïdienne**
- [ ] **Scanner/IRM orbites:** Muscles oculomoteurs

#### 1.4 Autres examens
- [ ] **Glycémie, HbA1c** (diabète)
- [ ] **VS, CRP** (Horton si >50 ans)
- [ ] **PL:** Si méningite, hémorragie méningée
- [ ] **Bilan auto-immun** (SEP, myasthénie)

### 2. Traitement étiologique

#### 2.1 Paralysie oculomotrice diabétique
- [ ] **Équilibre glycémique** optimal
- [ ] **Récupération spontanée** 3-6 mois
- [ ] **Occlusion œil** si gêne importante
- [ ] **Prismes** si diplopie résiduelle

#### 2.2 Myasthénie
- [ ] **Anticholinestérasiques:**
  - Pyridostigmine (Mestinon) 60mg × 3-5/j
  - Adaptation selon symptômes
- [ ] **Immunosuppresseurs:**
  - Corticoïdes (prednisone)
  - Azathioprine, mycophénolate
- [ ] **Immunoglobulines IV** ou plasmaphérèse (crises)
- [ ] **Thymectomie** si thymome ou <60 ans

#### 2.3 Orbitopathie dysthyroïdienne
- [ ] **Traitement hyperthyroïdie** (ATS, iode radioactif)
- [ ] **Phase inflammatoire:**
  - Corticoïdes IV (méthylprednisolone)
  - Radiothérapie orbitaire
- [ ] **Phase séquellaire:**
  - Chirurgie décompression orbitaire
  - Chirurgie muscles oculomoteurs

#### 2.4 Causes vasculaires

**AVC:**
- [ ] **Thrombolyse IV** si <4h30
- [ ] **Thrombectomie** si occlusion proximale
- [ ] **Antiagrégants** secondaire
- [ ] **Contrôle facteurs de risque**

**Anévrisme:**
- [ ] **Neurochirurgie/neuroradiologie** urgente
- [ ] **Exclusion:** Coiling ou clipping
- [ ] **Surveillance réanimation**

**Fistule carotido-caverneuse:**
- [ ] **Embolisation** endovasculaire

#### 2.5 SEP
- [ ] **Poussée:** Corticoïdes IV (méthylprednisolone 1g/j × 3-5j)
- [ ] **Traitement de fond:** Immunomodulateurs

#### 2.6 Horton
- [ ] **Corticothérapie urgente:** Prednisone 1mg/kg/j
- [ ] **Biopsie artère temporale** (dans les 15j)

### 3. Traitement symptomatique

#### 3.1 Correction optique temporaire
- [ ] **Occlusion alternée** (éviter diplopie)
- [ ] **Cache translucide** (Scotch dépoli)
- [ ] **Prismes** sur lunettes (déviations stables <15∆)

#### 3.2 Toxine botulique
- [ ] **Injection muscle hyperactif**
- [ ] **Paralysies récentes** (<6 mois)
- [ ] **Effet temporaire** (3-6 mois)

### 4. Chirurgie du strabisme
- [ ] **Indications:**
  - Diplopie persistante >6-12 mois
  - Déviation stable
  - Échec traitement médical
- [ ] **Techniques:** Recul, résection, transposition

### 5. Rééducation orthoptique
- [ ] **Exercices fusion binoculaire**
- [ ] **Élargissement champ vision simple**
- [ ] **Adaptation prismatique**

### 6. Surveillance

#### Selon étiologie
- [ ] **Diabète:** Récupération 3-6 mois
- [ ] **Myasthénie:** Ajustement traitement
- [ ] **Post-AVC:** Rééducation, prévention secondaire
- [ ] **Basedow:** Évolution orbitopathie

### 7. Conduite automobile
- [ ] **Contre-indication temporaire** si diplopie
- [ ] **Reprise après:**
  - Résolution complète
  - Ou correction efficace (prismes, occlusion)
- [ ] **Certificat médical** aptitude

### 8. Critères d'hospitalisation
- [ ] **Urgences neurologiques:**
  - III + mydriase (anévrisme)
  - Signes AVC
  - Céphalées brutales
- [ ] **Crise myasthénique** (troubles déglutition/respiration)
- [ ] **Compression orbitaire** (Basedow)

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Test occlusion alternée** (mono vs binoculaire)
2. **Examen 9 positions** du regard
3. **Rechercher mydriase** (III compressif = urgence)
4. **Test fatigabilité** si myasthénie suspectée
5. **IRM urgente** si signes d'alerte
6. **Penser Horton** si >50 ans

### ❌ Pièges à éviter
1. **Méconnaître anévrisme** (III + mydriase)
2. **Oublier myasthénie** (fluctuant, fatigabilité)
3. **Négliger diabète** comme cause fréquente
4. **Retarder imagerie** si signes neurologiques
5. **Autoriser conduite** avec diplopie

### 💡 Astuces mnémotechniques
- **Nerfs oculomoteurs:** **3** (tous sauf 2), **4** (SO = muscle opposé), **6** (droit latéral)
- **III complet:** **P**tosis, **M**ydriase, **D**ivergence (PMD)
- **Myasthénie:** **F**atigabilité, **F**luctuation, **F**roid améliore (3F)
- **Urgences diplopie:** **A**névrisme, **A**VC, **H**orton (AAH)
