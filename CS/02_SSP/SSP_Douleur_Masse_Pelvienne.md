# Fiche de Révision ECOS - DOULEUR ET MASSE PELVIENNE

## 🎯 Situation à Starting Point (SSP)
**Description:** Femme consultant pour douleur pelvienne et/ou masse pelvienne palpable
**Objectifs d'évaluation:** Différencier douleur aiguë/chronique, identifier l'origine de la masse, éliminer les urgences, adapter la prise en charge

---

## 📋 ANAMNÈSE

### 1. Caractérisation de la douleur pelvienne ⚠️ ESSENTIEL

#### 1.1 Description de la douleur
- [ ] **Localisation:**
  - Hypogastrique médiane
  - Latéralisée (droite/gauche)
  - Fosse iliaque
  - Irradiations (dos, cuisses, périnée)
- [ ] **Type:**
  - Crampes, spasmes
  - Pesanteur
  - Brûlure
  - Coup de poignard
- [ ] **Intensité:** EVA 0-10
- [ ] **Évolution:** Constante, intermittente, cyclique

#### 1.2 Chronologie
- [ ] **Début:** Brutal ou progressif
- [ ] **Durée:**
  - Aiguë (<3 mois)
  - Chronique (>3-6 mois)
- [ ] **Relation avec cycle menstruel:**
  - Prémenstruelle
  - Menstruelle (dysménorrhée)
  - Ovulatoire (mittelschmerz)
  - Acyclique

#### 1.3 Facteurs modulateurs
- [ ] **Aggravants:**
  - Rapports sexuels
  - Défécation
  - Miction
  - Effort physique
- [ ] **Soulageants:**
  - Position antalgique
  - Antalgiques
  - Chaleur

### 2. Caractérisation de la masse pelvienne

#### 2.1 Découverte
- [ ] **Autopalpation** par patiente
- [ ] **Découverte fortuite** (examen)
- [ ] **Symptômes révélateurs**

#### 2.2 Évolution
- [ ] **Taille:** Augmentation progressive
- [ ] **Consistance perçue**
- [ ] **Mobilité**
- [ ] **Douleur à la palpation**

### 3. Symptômes associés

#### 3.1 Symptômes gynécologiques
- [ ] **Troubles des règles:**
  - Aménorrhée (grossesse?)
  - Ménorragies
  - Métrorragies
  - Spotting
- [ ] **Leucorrhées:** Aspect, odeur
- [ ] **Dyspareunie:** Superficielle/profonde
- [ ] **Infertilité**

#### 3.2 Symptômes urinaires
- [ ] **Pollakiurie** (compression)
- [ ] **Dysurie**
- [ ] **Urgenturie**
- [ ] **Incontinence**
- [ ] **Hématurie**

#### 3.3 Symptômes digestifs
- [ ] **Constipation** (compression)
- [ ] **Ténesme rectal**
- [ ] **Ballonnements**
- [ ] **Nausées, vomissements**

#### 3.4 Signes généraux
- [ ] **Fièvre** (infection, néoplasie)
- [ ] **Amaigrissement** ⚠️ ALARME
- [ ] **Asthénie**
- [ ] **Anorexie**

### 4. Causes de douleur pelvienne aiguë ⚠️ URGENCES

#### 4.1 Grossesse compliquée
- [ ] **GEU (Grossesse Extra-Utérine):**
  - Retard règles
  - Métrorragies
  - Douleur latéralisée
  - Malaise (rupture)
- [ ] **Fausse couche:**
  - Saignements abondants
  - Contractions utérines
- [ ] **Hématome décidual**

#### 4.2 Pathologie ovarienne
- [ ] **Torsion d'annexe:** ⚠️ URGENCE
  - Douleur brutale intense
  - Nausées, vomissements
  - Masse annexielle connue
- [ ] **Rupture kyste:**
  - Douleur brutale
  - Résolution progressive
- [ ] **Hémorragie intra-kystique**

#### 4.3 Infections
- [ ] **Salpingite/MIP:**
  - Fièvre
  - Leucorrhées purulentes
  - Partenaires multiples
  - ATCD IST
- [ ] **Abcès tubo-ovarien:**
  - Fièvre élevée
  - AEG
  - Masse douloureuse

#### 4.4 Autres causes aiguës
- [ ] **Appendicite** (FID)
- [ ] **Pyélonéphrite**
- [ ] **Colique néphrétique**
- [ ] **Diverticulite sigmoïdienne**

### 5. Causes de douleur pelvienne chronique

#### 5.1 Endométriose ⚠️ FRÉQUENT
- [ ] **Dysménorrhée progressive**
- [ ] **Dyspareunie profonde**
- [ ] **Douleurs cycliques**
- [ ] **Infertilité**

#### 5.2 Adénomyose
- [ ] **Ménorragies importantes**
- [ ] **Dysménorrhée**
- [ ] **Utérus augmenté**

#### 5.3 Syndrome douloureux pelvien chronique
- [ ] **Douleur >6 mois**
- [ ] **Multifactoriel**
- [ ] **Retentissement psychosocial**

#### 5.4 Adhérences pelviennes
- [ ] **ATCD chirurgie**
- [ ] **ATCD infections**
- [ ] **Douleur position-dépendante**

### 6. Causes de masse pelvienne

#### 6.1 Origine ovarienne
- [ ] **Kyste fonctionnel:** Folliculaire, lutéal
- [ ] **Kyste organique:**
  - Dermoïde (tératome)
  - Endométriome
  - Cystadénome
- [ ] **Cancer ovaire:** ⚠️ APRÈS 50 ANS
  - Ascite
  - AEG
  - Masse fixée

#### 6.2 Origine utérine
- [ ] **Fibrome utérin:**
  - Ménorragies
  - Pesanteur
  - Masse ferme mobile
- [ ] **Grossesse:** Normale ou pathologique
- [ ] **Cancer endomètre/col**

#### 6.3 Origine tubaire
- [ ] **Hydrosalpinx**
- [ ] **Pyosalpinx**
- [ ] **GEU**

#### 6.4 Autres origines
- [ ] **Vessie pleine** (rétention)
- [ ] **Tumeur digestive**
- [ ] **Abcès pelvien**

### 7. Antécédents gynécologiques

#### 7.1 Histoire menstruelle
- [ ] **DDR** (date dernières règles)
- [ ] **Régularité cycles**
- [ ] **Contraception** actuelle
- [ ] **Test grossesse** récent

#### 7.2 Antécédents obstétricaux
- [ ] **Grossesses:** Nombre, évolution
- [ ] **Accouchements:** Voie, complications
- [ ] **IVG, fausses couches**
- [ ] **GEU** antérieure

#### 7.3 Antécédents médicaux
- [ ] **Chirurgies pelviennes**
- [ ] **IST, MIP**
- [ ] **Endométriose connue**
- [ ] **Cancers gynécologiques** familiaux

### 8. Facteurs de risque

#### 8.1 GEU
- [ ] **ATCD GEU**
- [ ] **Chirurgie tubaire**
- [ ] **IST/salpingite**
- [ ] **DIU**
- [ ] **PMA**
- [ ] **Tabac**

#### 8.2 Cancer ovaire
- [ ] **Âge >50 ans**
- [ ] **ATCD familiaux** (sein, ovaire)
- [ ] **Mutation BRCA1/2**
- [ ] **Nulliparité**
- [ ] **Endométriose**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires urgents

#### 1.1 Biologie ⚠️ EN URGENCE
- [ ] **β-HCG:** ⚠️ SYSTÉMATIQUE femme en âge de procréer
- [ ] **NFS:** Anémie (hémorragie)
- [ ] **CRP:** Syndrome inflammatoire
- [ ] **Groupe, RAI** si chirurgie probable

#### 1.2 Échographie pelvienne ⚠️ EXAMEN CLÉ
**Voies abdominale et endovaginale:**
- [ ] **Utérus:** Taille, fibromes, endomètre
- [ ] **Ovaires:** Kystes, masses
- [ ] **Trompes:** Hydrosalpinx, GEU
- [ ] **Douglas:** Épanchement
- [ ] **Doppler:** Vascularisation masses

**Si grossesse (β-HCG+):**
- [ ] **Localisation sac** gestationnel
- [ ] **Vitalité embryonnaire**
- [ ] **Épanchement** (hémopéritoine)

### 2. Examens complémentaires différés

#### 2.1 IRM pelvienne
- [ ] **Caractérisation masses** complexes
- [ ] **Bilan endométriose**
- [ ] **Bilan extension** cancer

#### 2.2 Scanner abdomino-pelvien
- [ ] **Urgences abdominales**
- [ ] **Bilan extension** cancer
- [ ] **Recherche carcinose**

#### 2.3 Marqueurs tumoraux (si masse suspecte)
- [ ] **CA-125:** Cancer ovaire (peu spécifique)
- [ ] **CA 19-9**
- [ ] **ACE, CA 15-3**
- [ ] **HCG, AFP** (tumeurs germinales)

#### 2.4 Cœlioscopie diagnostique
- [ ] **Si diagnostic incertain**
- [ ] **Biopsies**
- [ ] **Traitement simultané** possible

### 3. Prise en charge des urgences

#### 3.1 GEU ⚠️ URGENCE VITALE
**GEU non rompue:**
- [ ] **Hospitalisation**
- [ ] **VVP, bilan préopératoire**
- [ ] **Options thérapeutiques:**
  - Méthotrexate IM (critères stricts)
  - Cœlioscopie (salpingectomie/salpingotomie)

**GEU rompue:**
- [ ] **Réanimation** (remplissage, transfusion)
- [ ] **Chirurgie urgente**

#### 3.2 Torsion d'annexe ⚠️ URGENCE CHIRURGICALE
- [ ] **Cœlioscopie urgente** (<6h)
- [ ] **Détorsion**
- [ ] **Kystectomie** si kyste
- [ ] **Annexectomie** si nécrose

#### 3.3 Salpingite/MIP
- [ ] **Hospitalisation** si sévère
- [ ] **Bi-antibiothérapie:**
  - Ceftriaxone 1g/j + Doxycycline 200mg/j + Métronidazole 1g/j
  - Durée: 14-21 jours
- [ ] **Traitement partenaire(s)**

#### 3.4 Rupture kyste ovarien
- [ ] **Surveillance** si stable
- [ ] **Antalgiques**
- [ ] **Chirurgie** si hémorragie active

### 4. Prise en charge des masses pelviennes

#### 4.1 Kyste ovarien fonctionnel
- [ ] **Surveillance échographique** à 3 mois
- [ ] **Contraception œstroprogestative** (prévention)
- [ ] **Résolution spontanée** habituelle

#### 4.2 Kyste organique bénin
- [ ] **Kystectomie cœlioscopique**
- [ ] **Préservation ovaire** si possible
- [ ] **Analyse anatomopathologique**

#### 4.3 Fibrome utérin
**Surveillance si:**
- [ ] **Asymptomatique**
- [ ] **Petit volume**
- [ ] **Pas de croissance**

**Traitement médical:**
- [ ] **AINS** (douleurs, ménorragies)
- [ ] **Progestatifs**
- [ ] **Analogues GnRH** (réduction volume)

**Traitement chirurgical:**
- [ ] **Myomectomie** (désir grossesse)
- [ ] **Embolisation** artères utérines
- [ ] **Hystérectomie** (pas désir grossesse)

#### 4.4 Suspicion cancer ovaire
- [ ] **RCP oncologique**
- [ ] **Bilan extension** (TDM TAP)
- [ ] **Laparotomie exploratrice**
- [ ] **Chirurgie carcinologique**
- [ ] **Chimiothérapie** adjuvante

### 5. Prise en charge douleur pelvienne chronique

#### 5.1 Endométriose
- [ ] **Contraception continue**
- [ ] **AINS**
- [ ] **Analogues GnRH** si sévère
- [ ] **Chirurgie** (exérèse lésions)

#### 5.2 Approche multidisciplinaire
- [ ] **Gynécologue**
- [ ] **Algologue**
- [ ] **Psychologue**
- [ ] **Kinésithérapeute** pelvien

#### 5.3 Traitements complémentaires
- [ ] **Antidépresseurs** (douleur neuropathique)
- [ ] **Antiépileptiques** (gabapentine)
- [ ] **Techniques relaxation**
- [ ] **Thérapies cognitivo-comportementales**

### 6. Surveillance

#### Masses bénignes
- [ ] **Échographie** à 3-6 mois
- [ ] **Marqueurs tumoraux** si indiqués
- [ ] **Évolution symptômes**

#### Post-opératoire
- [ ] **Contrôle** à 1 mois
- [ ] **Échographie** si conservateur
- [ ] **Anatomopathologie** discussion

### 7. Prévention
- [ ] **Contraception** (kystes fonctionnels)
- [ ] **Dépistage IST**
- [ ] **Suivi gynécologique** régulier
- [ ] **Conseil génétique** si ATCD familiaux

### 8. Critères d'hospitalisation
- [ ] **Urgences chirurgicales:**
  - GEU
  - Torsion annexe
  - Péritonite
- [ ] **Instabilité hémodynamique**
- [ ] **Douleur non contrôlée**
- [ ] **Fièvre + masse pelvienne**

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **β-HCG systématique** si âge procréer
2. **Éliminer urgences** (GEU, torsion)
3. **Échographie pelvienne** première ligne
4. **TV bimanuel** complet
5. **Rechercher endométriose** si chronique
6. **CA-125 si masse** suspecte >50 ans

### ❌ Pièges à éviter
1. **Oublier grossesse** (toujours β-HCG)
2. **Retarder chirurgie** si torsion
3. **Négliger cancer** après ménopause
4. **Banaliser douleur** chronique
5. **Opérer kyste** fonctionnel

### 💡 Astuces mnémotechniques
- **Urgences pelviennes:** **G**EU, **T**orsion, **A**ppendicite, **S**alpingite (GTAS)
- **Masse ovarienne - caractères malignité:** **S**olide, **A**scite, **B**ilatéral, **F**ixé (SABF)
- **Endométriose - 5D:** Dysménorrhée, Dyspareunie, Dysurie, Dyschésie, Douleur chronique
- **GEU - facteurs risque:** **S**alpingite, **T**abac, **A**TCD GEU, **D**IU (STAD)
