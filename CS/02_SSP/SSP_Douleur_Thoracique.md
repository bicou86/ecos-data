# Fiche de Révision ECOS - DOULEUR THORACIQUE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient présentant une douleur thoracique aiguë ou subaiguë nécessitant évaluation urgente pour éliminer les causes vitales.
**Objectifs d'évaluation:** Anamnèse SOCRATES, recherche des drapeaux rouges, diagnostic différentiel cardiovasculaire/pulmonaire/digestif

## 📋 ANAMNÈSE

### 1. Caractérisation de la douleur (SOCRATES)
- [ ] **Site:** Localisation précise (montrez avec un doigt)
- [ ] **Onset:** Début brutal vs progressif, circonstances
- [ ] **Character:** Oppression, brûlure, déchirement, coup de poignard
- [ ] **Radiation:** Irradiation mâchoire, bras gauche, dos, épigastre
- [ ] **Associated symptoms:** Dyspnée, sudations, nausées, palpitations
- [ ] **Time:** Durée, constante vs intermittente
- [ ] **Exacerbating/Relieving:** Effort, position, respiration, repas
- [ ] **Severity:** Intensité 0-10, pire douleur de sa vie?

### 2. Symptômes associés ⚠️
- [ ] **Cardiovasculaires:** palpitations, syncope, lipothymie
- [ ] **Respiratoires:** dyspnée, orthopnée, toux, hémoptysie
- [ ] **Digestifs:** nausées, vomissements, régurgitations
- [ ] **Généraux:** fièvre, frissons, sudations profuses

### 3. Facteurs de risque cardiovasculaire
- [ ] **Tabac:** paquets-années
- [ ] **HTA:** valeurs, traitement
- [ ] **Diabète:** type, complications
- [ ] **Dyslipidémie:** valeurs, traitement
- [ ] **ATCD familiaux:** IDM < 55 ans ♂, < 65 ans ♀
- [ ] **Obésité:** IMC
- [ ] **Sédentarité:** activité physique

### 4. Facteurs de risque thrombo-embolique
- [ ] **Immobilisation:** voyage > 6h, alitement
- [ ] **Chirurgie récente:** < 1 mois
- [ ] **Cancer actif:** type, traitement
- [ ] **Contraception orale/THM**
- [ ] **ATCD TVP/EP**
- [ ] **Grossesse/post-partum**

### 5. Antécédents
- [ ] **Cardiovasculaires:** IDM, angioplastie, pontage, IC
- [ ] **Pulmonaires:** asthme, BPCO, pneumonie, EP
- [ ] **Digestifs:** RGO, ulcère, œsophagite
- [ ] **Psychiatriques:** anxiété, attaque de panique

### 6. Médicaments et toxiques
- [ ] **Traitements actuels:** anticoagulants, antiagrégants, β-bloquants
- [ ] **Allergies médicamenteuses**
- [ ] **Toxiques:** cocaïne, amphétamines
- [ ] **Compliance thérapeutique**

## 🩺 EXAMEN CLINIQUE

### 1. Signes vitaux ⚠️ OBLIGATOIRES
- [ ] **PA:** aux 2 bras (différence > 20 mmHg = dissection?)
- [ ] **FC:** régularité, fréquence
- [ ] **FR:** polypnée, signes de lutte
- [ ] **T°:** fièvre
- [ ] **SaO₂:** hypoxémie

### 2. État général
- [ ] **Détresse:** anxiété, agitation
- [ ] **Diaphorèse:** sudations profuses
- [ ] **Cyanose:** centrale/périphérique
- [ ] **Position:** antalgique, orthopnée

### 3. Examen cardiovasculaire

#### Inspection
- [ ] **Turgescence jugulaire:** IC droite
- [ ] **Choc de pointe:** visible, dévié
- [ ] **Cicatrices:** sternotomie, thoracotomie

#### Palpation
- [ ] **Choc de pointe:** 5e EIC, LMC gauche
- [ ] **Frémissement:** thrill systolique
- [ ] **Pouls périphériques:** tous présents, symétriques
- [ ] **Œdèmes MI:** signe du godet
- [ ] **RHJ:** reflux hépato-jugulaire
- [ ] **TRC:** temps recoloration capillaire

#### Auscultation
- [ ] **B1-B2:** intensité, dédoublement
- [ ] **Bruits surajoutés:** B3 (IC), B4 (HVG)
- [ ] **Souffles:** systolique/diastolique, foyer, irradiation
- [ ] **Frottement péricardique:** superficiel, systolo-diastolique
- [ ] **Pouls carotidiens/fémoraux:** souffles

### 4. Examen pulmonaire

#### Inspection
- [ ] **FR:** tachypnée, bradypnée
- [ ] **Amplitude:** superficielle, tirage
- [ ] **Asymétrie:** hémithorax immobile

#### Palpation
- [ ] **Ampliation:** symétrique bilatérale
- [ ] **Vibrations vocales:** diminuées/augmentées
- [ ] **Emphysème sous-cutané:** crépitations neigeuses
- [ ] **Douleur costale:** reproduction palpation

#### Percussion
- [ ] **Sonorité:** normale, matité, tympanisme
- [ ] **Symétrie:** comparative

#### Auscultation
- [ ] **Murmure vésiculaire:** présent, diminué, aboli
- [ ] **Crépitants:** OAP, pneumonie
- [ ] **Sibilants:** bronchospasme
- [ ] **Frottement pleural:** râpeux, superficiel

### 5. Examen abdominal
- [ ] **Douleur épigastrique:** RGO, ulcère
- [ ] **Défense:** péritonite
- [ ] **Hépatomégalie:** IC droite
- [ ] **Battements épigastriques:** anévrisme aorte

## 💊 PRISE EN CHARGE

### 1. ⚠️ URGENCES VITALES - Les 5 à éliminer

| Urgence | Clinique | ECG | Examens | Traitement |
|---------|----------|-----|---------|------------|
| **SCA ST+** | Oppression + sudations + irradiation | Sus-ST ou BBG nouveau | Troponines | MONABASH + coronaro urgente |
| **SCA ST-** | Idem mais moins typique | Sous-ST, T négatives | Troponines élevées | MONABASH + coronaro < 24h |
| **EP** | Dyspnée + douleur pleurale + FDR | Tachycardie, S1Q3T3 | D-dimères, angio-CT | Anticoagulation |
| **Dissection aortique** | Déchirement maximal d'emblée | Normal ou ischémie | CT thorax | Chirurgie urgente |
| **Pneumothorax** | Douleur + dyspnée brutales | Normal | Rx thorax | Drainage si compressif |
| **Tamponnade** | Dyspnée + hypotension + TJ | Microvoltage, alternance | Echo cœur | Ponction péricardique |

### 2. Examens complémentaires urgents

#### Systématiques
- [ ] **ECG 12 dérivations:** < 10 minutes!
- [ ] **Troponines:** T0 et T3h (hs-TnT)
- [ ] **Rx thorax:** face ± profil
- [ ] **Gazométrie:** si dyspnée ou SaO₂ < 95%

#### Selon orientation
- [ ] **D-dimères:** si probabilité EP faible/intermédiaire
- [ ] **Angio-CT thoracique:** EP, dissection
- [ ] **ETT:** péricardite, tamponnade, IC
- [ ] **Coronarographie:** SCA ST+

#### Biologie complémentaire
- [ ] **NFS, CRP:** syndrome inflammatoire
- [ ] **Iono, créat:** fonction rénale
- [ ] **BNP/NT-proBNP:** insuffisance cardiaque
- [ ] **Bilan lipidique:** à jeun si SCA

### 3. Scores cliniques

#### Score de Wells (EP)
| Critère | Points |
|---------|--------|
| Signes cliniques TVP | 3 |
| EP plus probable qu'autre diagnostic | 3 |
| FC > 100/min | 1.5 |
| Immobilisation/chirurgie < 4 sem | 1.5 |
| ATCD TVP/EP | 1.5 |
| Hémoptysie | 1 |
| Cancer actif | 1 |

- Score ≤ 4: probabilité faible → D-dimères
- Score > 4: probabilité élevée → Angio-CT

#### Score TIMI (SCA)
- Âge ≥ 65 ans
- ≥ 3 FDR cardiovasculaires
- Sténose coronaire connue ≥ 50%
- Aspirine dans les 7 derniers jours
- ≥ 2 épisodes angineux en 24h
- Modifications ECG (ST ou T)
- Troponines élevées

### 4. Traitement selon étiologie

#### SCA (MONABASH)
- [ ] **M**orphine: si douleur intense
- [ ] **O**xygène: si SaO₂ < 90%
- [ ] **N**itrés: sublingual (CI si PAS < 90)
- [ ] **A**spirine: 300mg à croquer
- [ ] **B**êta-bloquants: bisoprolol
- [ ] **A**nticoagulation: héparine
- [ ] **S**tatines: haute dose
- [ ] **H**ospitalisation: USI/cardiologie

#### EP
- [ ] **Anticoagulation:** HBPM ou HNF
- [ ] **Oxygène:** si hypoxémie
- [ ] **Thrombolyse:** si instabilité hémodynamique
- [ ] **Surveillance:** USI si risque intermédiaire/élevé

#### Dissection aortique
- [ ] **Contrôle PA:** β-bloquants IV
- [ ] **Antalgie:** morphine
- [ ] **Chirurgie:** urgente si type A
- [ ] **Transfert:** centre spécialisé

#### Péricardite
- [ ] **AINS:** ibuprofène 600mg x 3/j
- [ ] **Colchicine:** 0.5mg x 2/j x 3 mois
- [ ] **Repos:** éviter efforts
- [ ] **Surveillance:** échocardiographie

## 🔍 DIAGNOSTICS DIFFÉRENTIELS

### Causes cardiovasculaires
| Pathologie | Pour | Contre |
|------------|------|--------|
| **SCA** | FDR CV, douleur typique, ECG modifié, troponines + | Jeune sans FDR, ECG normal, troponines - |
| **Péricardite** | Douleur positionnelle, frottement, sus-ST diffus | Pas de frottement, ECG normal |
| **Myocardite** | Contexte viral, troponines +, dysfonction VG | Coronaires pathologiques |

### Causes pulmonaires
| Pathologie | Pour | Contre |
|------------|------|--------|
| **EP** | FDR thrombose, D-dimères +, défaut perfusion | D-dimères -, angio-CT normal |
| **Pneumonie** | Fièvre, toux, foyer Rx | Apyrexie, Rx normale |
| **Pleurésie** | Douleur pleurale, épanchement | Rx normale |

### Causes digestives
| Pathologie | Pour | Contre |
|------------|------|--------|
| **RGO** | Pyrosis, post-prandial, soulagé IPP | Pas de relation repas |
| **Spasme œsophagien** | Dysphagie, soulagé nitrés | ECG anormal |
| **Pancréatite** | Douleur transfixiante, lipase élevée | Lipase normale |

### Causes pariétales
| Pathologie | Pour | Contre |
|------------|------|--------|
| **Syndrome de Tietze** | Tuméfaction 2-3e côte, jeune | Signes systémiques |
| **Costochondrite** | Douleur reproduction palpation | ECG anormal |
| **Zona** | Éruption vésiculaire, métamérique | Pas d'éruption |

### Causes psychogènes
- [ ] **Attaque de panique:** contexte anxieux, hyperventilation
- [ ] **Trouble somatoforme:** examens normaux répétés

## 📌 POINTS CLÉS

### À faire absolument
1. **ECG dans les 10 minutes**
2. **PA aux 2 bras** (dissection)
3. **Éliminer les 5 urgences vitales**
4. **Troponines** T0 et T3h
5. **Score de Wells** si suspicion EP

### Pièges à éviter
- Minimiser douleur atypique (femme, diabétique, âgé)
- Oublier EP chez le jeune
- Négliger dissection aortique
- Rassurer trop vite sur ECG normal
- Oublier causes abdominales

### Red flags ⚠️
- **Douleur + sudations profuses:** SCA
- **Déchirement maximal d'emblée:** dissection
- **Dyspnée + douleur pleurale:** EP
- **Asymétrie PA > 20 mmHg:** dissection
- **Nouveau souffle + fièvre:** endocardite

### Présentations atypiques SCA
- **Femmes:** fatigue, nausées, douleur dorsale
- **Diabétiques:** asymptomatique, dyspnée isolée
- **Âgés:** confusion, syncope
- **Jeunes:** spasme coronaire, cocaïne
