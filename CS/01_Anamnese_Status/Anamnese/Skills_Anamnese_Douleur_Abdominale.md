# Anamnèse de la douleur abdominale

## Domaine
Gastroentérologie/Urgences/Médecine interne

## Description
Approche systématique de l'anamnèse d'une douleur abdominale permettant d'orienter le diagnostic différentiel et d'identifier les urgences.

## CARACTÉRISATION DE LA DOULEUR (PQRST)

### P - Provocation/Palliation
- **Facteurs déclenchants** :
  - Alimentation (ulcère, cholécystite, pancréatite)
  - Jeûne (ulcère duodénal)
  - Effort (ischémie mésentérique)
  - Position (pancréatite)
  - Stress
- **Facteurs soulageants** :
  - Alimentation (ulcère duodénal)
  - Vomissements (occlusion haute)
  - Position antalgique (genoux fléchis)
  - Antiacides (RGO, ulcère)
  - Défécation (côlon irritable)

### Q - Qualité/Type
- **Colique** : Spasmodique, par vagues (organes creux)
- **Transfixiante** : En coup de poignard (perforation, pancréatite)
- **Sourde** : Continue, profonde (organes pleins)
- **Brûlure** : Pyrosis (RGO, ulcère)
- **Torsion** : Volvulus, torsion annexielle
- **Déchirure** : Dissection aortique

### R - Région/Radiation (Irradiation)
- **Épaule droite** : Irritation diaphragmatique (cholécystite, abcès sous-phrénique)
- **Épaule gauche** : Rate, pancréas (signe de Kehr)
- **Dos** : Pancréatite, ulcère perforé, AAA
- **Aine/testicules** : Colique néphrétique, hernie
- **Omoplates** : Voies biliaires
- **Diffuse** : Péritonite, occlusion, gastro-entérite

### S - Sévérité/Symptômes associés
- **Intensité** : EVA 0-10
- **Évolution** : Stable, croissante, décroissante
- **Retentissement** : Activités, sommeil

### T - Temps/Temporalité
- **Début** :
  - Brutal : Perforation, AAA, ischémie
  - Progressif : Inflammation, infection
- **Durée** :
  - Minutes : Colique
  - Heures : Inflammation
  - Jours/semaines : Tumeur, chronique
- **Évolution** :
  - Continue
  - Intermittente
  - Cyclique (menstruations)
- **Horaire** :
  - Post-prandial précoce (gastrique)
  - Post-prandial tardif 2-3h (biliaire)
  - Nocturne (ulcère duodénal)

## SYMPTÔMES ASSOCIÉS

### Digestifs
- **Nausées/vomissements** :
  - Précoces : Gastrique, biliaire
  - Tardifs : Occlusion basse
  - Fécaloïdes : Occlusion colique, fistule
  - Bilieux : Post-gastrique
  - Alimentaires : Gastrique
- **Transit** :
  - Diarrhée : Gastro-entérite, MICI
  - Constipation : Occlusion, côlon irritable
  - Arrêt matières et gaz : Occlusion complète
  - Alternance : Côlon irritable, cancer colique
- **Distension** : Occlusion, aérophagie
- **Ténesme** : Rectite, tumeur rectale
- **Fausses envies** : Pathologie rectale

### Urologiques
- Dysurie, pollakiurie
- Hématurie
- Rétention urinaire

### Gynécologiques
- Date dernières règles
- Métrorragies
- Leucorrhées
- Dyspareunie

### Généraux
- **Fièvre** : Infection, inflammation
- **Frissons** : Bactériémie, angiocholite
- **Perte de poids** : Cancer, MICI
- **Anorexie** : Pathologie grave
- **Asthénie** : Anémie, cancer

### Hémorragiques
- **Hématémèse** : Origine haute
- **Méléna** : Saignement digestif haut
- **Rectorragies** : Origine basse

## ANTÉCÉDENTS

### Médicaux
- **Digestifs** :
  - Ulcère, RGO
  - Lithiase biliaire
  - Pancréatite
  - MICI (Crohn, RCH)
  - Diverticulose
  - Hernie
- **Cardiovasculaires** :
  - Athérosclérose
  - Fibrillation auriculaire (ischémie)
  - Anévrisme aortique
- **Métaboliques** :
  - Diabète
  - Dyslipidémie
  - Porphyrie
  - Drépanocytose

### Chirurgicaux
- Type et date des interventions
- Complications post-opératoires
- Adhérences (risque occlusion)

### Gynéco-obstétricaux
- Contraception
- Grossesse en cours?
- Césariennes
- GEU antérieure
- Endométriose
- Kystes ovariens

### Familiaux
- Cancer digestif
- MICI
- Polyposes
- Anévrisme

## HABITUDES ET MODE DE VIE

### Toxiques
- **Alcool** : Pancréatite, cirrhose, gastrite
- **Tabac** : Ulcère, Crohn, cancer
- **Drogues** : Cocaïne (ischémie)

### Alimentaires
- Repas récents suspects
- Voyage récent (turista)
- Allergies/intolérances
- Jeûne, régime

### Médicaments
- **AINS** : Ulcère, perforation
- **Corticoïdes** : Perforation masquée
- **Antibiotiques** : Colite à C. difficile
- **Opioïdes** : Constipation, iléus
- **Anticoagulants** : Hématome

## RED FLAGS - URGENCES

### Urgences vitales
- **Choc** : Hémorragie, perforation, sepsis
- **Péritonite** : Contracture, défense généralisée
- **Ischémie mésentérique** : Douleur disproportionnée
- **AAA rompu** : Douleur + masse pulsatile + choc
- **GEU rompue** : Femme jeune + retard règles + choc

### Signes d'alarme
- Douleur brutale intense
- Vomissements incoercibles
- Hématémèse/méléna massif
- Fièvre > 39°C
- Ictère + fièvre + douleur (Charcot)
- Défense/contracture
- Silence abdominal
- Troubles conscience

## ORIENTATION DIAGNOSTIQUE

### Par âge
**Enfant** :
- Invagination, appendicite, GEA

**Adulte jeune** :
- Appendicite, GEU, MICI, colique néphrétique

**Adulte moyen** :
- Cholécystite, ulcère, diverticulite, pancréatite

**Personne âgée** :
- Ischémie, cancer, occlusion, AAA, diverticulite

### Par terrain
**Femme enceinte** :
- GEU, appendicite, cholécystite, HELLP

**Immunodéprimé** :
- Typhlite, CMV, abcès

**Cirrhotique** :
- PBS, ascite infectée, CHC

**Diabétique** :
- Acidocétose, gastroparésie

## SCORES ET CRITÈRES

### Score d'Alvarado (appendicite)
- Migration douleur FID : 1
- Anorexie : 1
- Nausées/vomissements : 1
- Défense FID : 2
- Rebond FID : 1
- Fièvre > 37.3°C : 1
- Leucocytose > 10'000 : 2
- Polynucléose > 75% : 1
**Total ≥ 7 : Probable appendicite**

### Critères de Ranson (pancréatite)
À l'admission et à 48h

### Critères de Rome IV (côlon irritable)
Douleur abdominale récurrente ≥ 1 jour/semaine depuis 3 mois avec ≥ 2 critères :
- Liée à la défécation
- Changement fréquence selles
- Changement consistance selles

## PIÈGES DIAGNOSTIQUES

### Causes extra-abdominales
- **Thoraciques** : IDM, pneumonie basale, PE
- **Métaboliques** : Acidocétose, hypercalcémie, porphyrie
- **Neurologiques** : Zona, radiculopathie
- **Psychiatriques** : Somatisation, anxiété
- **Toxiques** : Plomb, araignée

## Points clés pour l'ECOS
1. **Caractériser précisément** la douleur (PQRST)
2. **Rechercher les red flags** systématiquement
3. **Éliminer GEU** chez femme en âge de procréer
4. **Penser aux causes extra-abdominales**
5. **Adapter aux âges extrêmes**
6. **Histoire menstruelle** chez la femme
7. **Antécédents chirurgicaux** (adhérences)
