# SSP - Ophtalmologie : Anamnèse et Status

## 1. ANAMNÈSE OPHTALMOLOGIQUE

### 1.1 Questions fondamentales (TRIADES ESSENTIELLES)

#### Triade symptomatique principale ⚠️ TOUJOURS DEMANDER
1. **"Avez-vous l'œil rouge ?"**
2. **"Avez-vous mal à l'œil ?"**
3. **"Votre vision a-t-elle baissé ?"**

#### Questions de précision immédiate
- **"Depuis quand ?"** (début brutal vs progressif)
- **"Un œil ou les deux ?"**
- **"C'est constant ou intermittent ?"**

### 1.2 Symptômes visuels détaillés

#### Baisse d'acuité visuelle (BAV)
- **Chronologie** :
  - Brutale (< 24h) : Urgence potentielle
  - Progressive (semaines/mois)
  - Fluctuante
- **Caractéristiques** :
  - Vision de loin et/ou de près
  - Vision centrale ou périphérique
  - Amélioration avec trou sténopéïque (réfraction)
- **Associations** :
  - Douleur (uvéite, glaucome aigu)
  - Sans douleur (OACR, NOIAA, décollement rétine)

#### Troubles du champ visuel
- **Scotome** : "Avez-vous des taches dans votre vision ?"
  - Central : DMLA, maculopathie
  - Paracentral
  - Périphérique : glaucome, rétinite pigmentaire
- **Hémianopsie** : "Voyez-vous la moitié du champ visuel ?"
  - Homonyme : lésion rétrochiasmatique
  - Bitemporale : compression chiasmatique
- **Quadranopsie** : Perte d'un quadrant

#### Phénomènes visuels
- **Myodésopsies** (mouches volantes) :
  - "Voyez-vous des points noirs qui bougent ?"
  - Brutales et nombreuses : décollement vitré/rétine
  - Anciennes et stables : bénignes
- **Phosphènes** (éclairs lumineux) :
  - "Voyez-vous des éclairs ?"
  - Traction vitréo-rétinienne
  - Associés aux myodésopsies : urgence
- **Métamorphopsies** :
  - "Les lignes droites paraissent-elles ondulées ?"
  - Test d'Amsler
  - DMLA, membrane épirétinienne
- **Halos colorés** :
  - Autour des lumières
  - Glaucome, œdème cornéen

#### Diplopie
- **Monoculaire** :
  - Persiste œil fermé
  - Causes : cataracte, astigmatisme, subluxation cristallin
- **Binoculaire** :
  - Disparaît œil fermé
  - Paralysie oculomotrice
  - Direction variable selon le muscle atteint

### 1.3 Symptômes oculaires associés

#### Douleur oculaire
- **Superficielle** :
  - Sensation de corps étranger
  - Brûlure, picotement
  - Kératite, conjonctivite
- **Profonde** :
  - Sourde, lancinante
  - Uvéite, glaucome
  - Sclérite
- **Rétrobulbaire** :
  - Névrite optique
  - Augmentée aux mouvements

#### Œil rouge
- **Type** :
  - Cercle périkératique : uvéite, kératite
  - Diffus : conjonctivite
  - Secteur : épisclérite, hémorragie sous-conjonctivale
- **Associations** :
  - Sécrétions : conjonctivite
  - Photophobie : uvéite, kératite

#### Photophobie
- **Vraie** : Douleur à la lumière (uvéite, kératite)
- **Fausse** : Éblouissement (cataracte, albinisme)

#### Larmoiement (épiphora)
- **Réflexe** : Kératite, corps étranger
- **Par obstruction** : Dacryocystite
- **Paradoxal** : Sécheresse oculaire

#### Sécrétions
- **Purulentes** : Conjonctivite bactérienne
- **Muqueuses** : Conjonctivite virale
- **Croûtes** : Blépharite

### 1.4 Antécédents ophtalmologiques

#### Corrections optiques
- Port de lunettes/lentilles
- Dernière consultation ophtalmo
- Dernière correction
- Type de lentilles (souples, rigides)
- Hygiène des lentilles

#### Pathologies oculaires
- Glaucome (type, traitement)
- Cataracte
- DMLA
- Diabète oculaire
- Décollement de rétine
- Uvéites récidivantes

#### Chirurgies oculaires
- Cataracte
- Glaucome
- Réfractive (LASIK)
- Vitréo-rétinienne
- Strabisme

#### Traumatismes
- Corps étranger
- Contusion
- Plaie
- Brûlure (chimique, thermique, UV)

### 1.5 Facteurs de risque et terrain

#### Maladies systémiques
- **Diabète** ⚠️ SYSTÉMATIQUE
  - Type, durée
  - Équilibre (HbA1c)
  - Autres complications
- **HTA** : Rétinopathie hypertensive
- **Maladies auto-immunes** :
  - Polyarthrite rhumatoïde : sclérite
  - Spondylarthrite : uvéite antérieure
  - Behçet : uvéite postérieure
- **Migraine** : Aura visuelle

#### Médicaments
- **Corticoïdes** : Cataracte, glaucome
- **Antipaludéens** : Maculopathie
- **Ethambutol** : Névrite optique
- **Amiodarone** : Dépôts cornéens

#### Antécédents familiaux
- Glaucome
- DMLA
- Myopie forte
- Maladies génétiques oculaires

### 1.6 Mode de vie et expositions
- **Profession** : Exposition UV, produits chimiques, écrans
- **Loisirs** : Sports à risque, bricolage
- **Tabac** : DMLA, occlusions vasculaires
- **Alcool** : Neuropathie optique

## 2. EXAMEN OPHTALMOLOGIQUE (STATUS)

### 2.1 Installation et matériel

#### Installation optimale
- Patient assis confortablement
- Menton et front appuyés (si lampe à fente)
- Éclairage tamisé pour pupilles
- Distance adaptée selon l'examen

#### Matériel de base
- Échelle d'acuité visuelle (Snellen/Monoyer)
- Lampe de poche
- Ophtalmoscope direct
- Cache-œil
- Fluorescéine
- Coton-tige
- Loupe

#### Matériel spécialisé
- Lampe à fente
- Tonomètre
- Lentilles d'examen (Volk)
- Périmètre

### 2.2 Acuité visuelle ⚠️ TOUJOURS EN PREMIER

#### Technique standard
1. **Distance** : 5-6 mètres (ou 3m avec échelle adaptée)
2. **Un œil à la fois** : Commencer par le meilleur
3. **Sans puis avec correction** si porteur
4. **Progression** : Grosses lettres → petites
5. **Notation** : 
   - Décimale : 10/10 = normal
   - Snellen : 20/20 = normal
   - LogMAR

#### Acuité de près
- Distance : 33 cm
- Échelle de Parinaud
- Avec correction de près si presbyte

#### Si acuité < 1/10
- Compte les doigts (distance)
- Mouvements de la main
- Perception lumineuse orientée
- Cécité

#### Trou sténopéïque
- Amélioration = trouble réfractif
- Pas d'amélioration = pathologie organique

### 2.3 Inspection externe

#### Paupières
- **Position** : Ptosis, rétraction
- **Bord libre** : Blépharite, orgelet, chalazion
- **Cils** : Trichiasis, madarose
- **Peau** : Eczéma, herpès

#### Appareil lacrymal
- **Points lacrymaux** : Perméables
- **Sac lacrymal** : Pression → reflux
- **Glande lacrymale** : Hypertrophie

#### Globe oculaire
- **Position** : Exophtalmie, énophtalmie
- **Taille** : Microphtalmie, buphtalmie
- **Mobilité** : Limitations, nystagmus

### 2.4 Examen du segment antérieur

#### Conjonctive
- **Hyperhémie** :
  - Diffuse : conjonctivite
  - Cercle périkératique : uvéite/kératite
  - Sectorielle : épisclérite
- **Sécrétions** : Type, quantité
- **Follicules/Papilles** : Éversion paupière
- **Hémorragie sous-conjonctivale**

#### Cornée
**Inspection simple**
- Transparence
- Reflet cornéen
- Diamètre (normal : 11-12 mm)

**Test à la fluorescéine** ⚠️ IMPORTANT
1. Instiller une goutte
2. Éclairer en lumière bleue
3. Rechercher :
   - Ulcère dendritique (herpès)
   - Érosion/ulcère
   - Kératite ponctuée

#### Chambre antérieure
- **Profondeur** :
  - Éclairage latéral
  - Étroite : risque glaucome aigu
- **Clarté** :
  - Tyndall : uvéite
  - Hypopion : pus
  - Hyphéma : sang

#### Iris
- **Couleur** : Hétérochromie
- **Relief** : Nodules, atrophie
- **Synéchies** : Adhérences pupillaires

#### Pupilles ⚠️ EXAMEN SYSTÉMATIQUE

**Inspection**
- **Taille** : 
  - Myosis < 2 mm
  - Normal 2-5 mm
  - Mydriase > 5 mm
- **Forme** : Ronde, régulière
- **Isocorie** : Symétrie
- **Position** : Centrée

**Réflexes photomoteurs**
1. **Direct** : Éclairer → constriction
2. **Consensuel** : Éclairer → constriction controlatérale
3. **RAPD** (Marcus Gunn) :
   - Alternance lumineuse rapide
   - Dilatation paradoxale = atteinte nerf optique

**Réflexe d'accommodation**
- Convergence + myosis
- Vision de loin → près

#### Cristallin
- **Transparence** : Cataracte
- **Position** : Subluxation
- **Reflet rouge** : Test du reflet rétinien

### 2.5 Oculomotricité

#### Mouvements oculaires
**9 positions du regard**
- Primaire (droit devant)
- 8 positions cardinales

**Test en H**
- Suivre le doigt
- Sans bouger la tête
- Noter limitations, douleur

#### Poursuite et saccades
- **Poursuite** : Mouvement lent continu
- **Saccades** : Mouvements rapides
- Ralentissement = atteinte neurologique

#### Cover test (strabisme)
1. **Cover** : Cacher un œil
2. **Uncover** : Découvrir
3. **Alternate cover** : Alternance rapide
- Mouvement de refixation = strabisme

#### Test de Hirschberg
- Reflet cornéen centré = orthophorie
- Décentré = strabisme (1 mm = 7°)

### 2.6 Examen du fond d'œil

#### Ophtalmoscopie directe

**Préparation**
- Dilatation si possible (tropicamide)
- Pièce sombre
- Patient fixe un point

**Technique**
1. **Approche** : 
   - OD examinateur → OD patient
   - OG examinateur → OG patient
2. **Distance** : Commencer à 30 cm
3. **Réglage dioptries** : 0 puis ajuster
4. **Approche progressive** : Jusqu'à 2-3 cm

**Examen systématique**
1. **Papille** :
   - Couleur : rosée
   - Contours : nets
   - Excavation : C/D ratio < 0.3
   - Émergence vaisseaux
2. **Vaisseaux** :
   - Rapport A/V : 2/3
   - Croisements AV
   - Tortuosité
   - Hémorragies
3. **Macula** :
   - 2 diamètres papillaires en temporal
   - Reflet fovéolaire
   - Pigmentation
4. **Rétine périphérique** :
   - 4 quadrants
   - Déchirures, décollements

#### Anomalies du fond d'œil

**Papille**
- **Œdème papillaire** : HTIC, névrite
- **Atrophie** : Pâle
- **Excavation** : Glaucome

**Vaisseaux**
- **Rétrécissement artériel** : HTA
- **Dilatation veineuse** : OVCR
- **Hémorragies** : Superficielles (flammes) ou profondes (rondes)
- **Exsudats** : Durs (lipides) ou cotonneux (ischémie)

**Macula**
- **Drusen** : DMLA
- **Hémorragie** : DMLA exsudative
- **Œdème** : Diabète, OVCR

### 2.7 Champ visuel

#### Confrontation (dépistage)
**Technique**
1. Face au patient à 60 cm
2. Patient cache OG, fixe votre OD
3. Fermez votre OG
4. Doigt à mi-distance
5. Tester 4 quadrants : "Voyez-vous mon doigt bouger ?"

**Variantes**
- Comptage de doigts
- Comparaison rouge (désaturation)

#### Périmétrie
- **Goldmann** : Cinétique manuelle
- **Humphrey** : Statique automatisée
- Indications : Glaucome, neurologique

### 2.8 Tests complémentaires au cabinet

#### Tonométrie (pression intraoculaire)
- **Normale** : 10-21 mmHg
- **Air pulsé** : Dépistage
- **Aplanation** (Goldmann) : Référence
- **Palpation** : Urgence (glaucome aigu)

#### Vision des couleurs
- **Ishihara** : Dépistage
- **Test rouge** : Névrite optique (désaturation)

#### Grille d'Amsler
- Distance : 30 cm
- Un œil à la fois
- Fixer le point central
- Métamorphopsies = maculopathie

#### Test de Schirmer
- Papier buvard 5 min
- < 5 mm = sécheresse oculaire

## 3. SYNDROMES OPHTALMOLOGIQUES

### 3.1 Œil rouge

#### Avec BAV ⚠️ URGENCES
- **Glaucome aigu** : Douleur+++, cercle périkératique, semi-mydriase
- **Uvéite antérieure** : Photophobie, cercle périkératique, myosis
- **Kératite** : Douleur, photophobie, larmoiement

#### Sans BAV
- **Conjonctivite** : Sécrétions, pas de photophobie
- **Hémorragie sous-conjonctivale** : Indolore, secteur rouge vif
- **Épisclérite** : Douleur modérée, secteur rouge

### 3.2 BAV brutale

#### Indolore ⚠️ URGENCES
- **OACR** : Œil blanc, macula rouge cerise
- **OVCR** : Hémorragies rétiniennes diffuses
- **NOIAA** : Déficit altitudinal, œdème papillaire
- **Décollement rétine** : Myodésopsies, phosphènes, voile

#### Douloureuse
- **Glaucome aigu**
- **Uvéite antérieure**
- **Névrite optique** : Douleur aux mouvements

### 3.3 Syndrome maculaire
- BAV centrale
- Métamorphopsies (Amsler+)
- Scotome central
- Micropsie/macropsie

### 3.4 Syndrome cornéen
- Douleur superficielle
- Photophobie
- Larmoiement
- Blépharospasme
- Sensation corps étranger

## 4. URGENCES OPHTALMOLOGIQUES ⚠️

### Urgences absolues (< 6h)
1. **Glaucome aigu par fermeture de l'angle**
2. **OACR** (< 90 min pour fibrinolyse)
3. **Traumatisme perforant**
4. **Brûlure chimique** (base > acide)
5. **Endophtalmie** aiguë

### Urgences relatives (< 48h)
1. **Décollement de rétine** (macula ON)
2. **NOIAA** avec suspicion Horton
3. **Uvéite antérieure** sévère
4. **Kératite** bactérienne
5. **Corps étranger** cornéen

### Semi-urgences (< 1 semaine)
1. **Décollement de rétine** (macula OFF)
2. **OVCR**
3. **Névrite optique** rétrobulbaire
4. **Zona ophtalmique**

## 5. EXAMENS COMPLÉMENTAIRES SPÉCIALISÉS

### Imagerie
- **OCT** : Macula, nerf optique, segment antérieur
- **Angiographie** : Fluorescéine (rétine), ICG (choroïde)
- **Échographie B** : Si milieux opaques
- **IRM** : Orbite, voies optiques
- **Scanner** : Traumatisme, fractures

### Électrophysiologie
- **ERG** : Fonction rétinienne
- **PEV** : Voies optiques
- **EOG** : Épithélium pigmentaire

## 6. CONSEILS PRATIQUES POUR L'EXAMEN

### Ordre systématique
1. Acuité visuelle TOUJOURS
2. Inspection externe
3. Segment antérieur
4. Pupilles et réflexes
5. Oculomotricité
6. Fond d'œil
7. Champ visuel si indiqué

### Pièges à éviter
- Oublier l'acuité visuelle
- Examiner qu'un seul œil
- Ne pas dilater pour le FO
- Oublier le RAPD
- Négliger l'anamnèse systémique

### Red flags à ne pas manquer
- Œil rouge + photophobie + BAV
- BAV brutale indolore
- Céphalées + troubles visuels
- Mydriase unilatérale
- Leucocorie chez l'enfant

## POINTS CLÉS À RETENIR

1. **Triade d'urgence** : Œil rouge + Douleur + BAV
2. **Acuité visuelle** : Toujours en premier
3. **RAPD** : Signe d'atteinte du nerf optique
4. **Fluorescéine** : Si suspicion kératite
5. **BAV brutale indolore** : Urgence vasculaire
6. **Métamorphopsies** : Test d'Amsler pour macula
7. **Fond d'œil** : Systématique en 4 temps
8. **Champ visuel** : Confrontation en dépistage
9. **Pupille semi-mydriase** : Glaucome aigu
10. **Diabète + HTA** : FO annuel systématique
