# Anamnèse générale

## Domaine
Médecine générale

## Description
Guide structuré pour la conduite d'une anamnèse complète, systématique et orientée permettant de recueillir toutes les informations nécessaires au diagnostic et à la prise en charge du patient.

## PRINCIPES GÉNÉRAUX

### Environnement de consultation
- **Cadre** : Calme, confidentiel, confortable
- **Position** : Face à face, même hauteur
- **Contact visuel** : Maintenu sans être intrusif
- **Temps** : Suffisant, sans précipitation
- **Documentation** : Notes discrètes, attention au patient

### Approche relationnelle
- **Accueil** : Chaleureux, professionnel
- **Présentation** : Nom, fonction, rôle
- **Empathie** : Écoute active, validation
- **Respect** : Pudeur, croyances, autonomie
- **Confidentialité** : Assurée et expliquée

## STRUCTURE DE L'ANAMNÈSE

### 1. IDENTIFICATION ET CONTEXTE

#### Données administratives
- **Identité** : Nom, prénom, date de naissance
- **Coordonnées** : Adresse, téléphone
- **Profession** : Actuelle, expositions
- **Statut** : Marital, enfants
- **Assurance** : Couverture sociale

#### Motif de consultation
- **Question ouverte** : "Qu'est-ce qui vous amène?"
- **Propres mots** du patient
- **Attentes** explicites et implicites
- **Agenda** : Priorités du patient
- **ICE** : Ideas, Concerns, Expectations

### 2. HISTOIRE DE LA MALADIE ACTUELLE (HMA)

#### Caractérisation du symptôme principal

**PQRSTU** pour la douleur:
- **P**rovocation/Palliation : Facteurs déclenchants/soulageants
- **Q**ualité : Type, caractère
- **R**égion/Radiation : Localisation, irradiation
- **S**évérité : Intensité (EVA 0-10)
- **T**emps : Début, durée, évolution
- **U**nderstanding : Compréhension du patient

**OPQRST** alternatif:
- **O**nset : Début (brutal/progressif)
- **P**recipitating factors
- **Q**uality
- **R**adiation
- **S**everity
- **T**ime course

#### Chronologie
- **Début** : Date, circonstances précises
- **Évolution** : 
  - Continue/intermittente
  - Amélioration/aggravation
  - Cyclique/épisodique
- **Traitements essayés** : Efficacité, tolérance
- **Consultations antérieures** : Avis, examens

#### Symptômes associés
- **Systématiques** selon organe touché
- **Généraux** : Fièvre, poids, asthénie
- **Red flags** : Signes d'alarme
- **Retentissement** : Fonctionnel, psychologique

### 3. ANTÉCÉDENTS PERSONNELS

#### Médicaux
- **Maladies chroniques** : 
  - Cardiovasculaires : HTA, coronaropathie
  - Métaboliques : Diabète, dyslipidémie
  - Respiratoires : Asthme, BPCO
  - Autres : Cancer, épilepsie
- **Hospitalisations** : Dates, motifs, durée
- **Accidents** : Traumatismes, séquelles
- **Transfusions** : Dates, indications

#### Chirurgicaux
- **Interventions** : Type, date, complications
- **Anesthésies** : Générale/locale, incidents
- **Cicatrisation** : Normale, chéloïdes

#### Gynéco-obstétricaux (femme)
- **Règles** : Ménarche, cycle, ménopause
- **Contraception** : Type, tolérance
- **Grossesses** : G_P_A_ (Gestité, Parité, Avortements)
- **Dépistages** : Frottis, mammographie

#### Psychiatriques
- **Troubles** : Dépression, anxiété
- **Hospitalisations** : Psychiatriques
- **Tentatives** : Suicide
- **Traitements** : Psychotropes

### 4. ANTÉCÉDENTS FAMILIAUX

#### Maladies héréditaires
- **Parents** : Vivants/décédés (âge, cause)
- **Fratrie** : Santé, maladies
- **Enfants** : Santé, développement

#### Pathologies familiales
- **Cardiovasculaires** : IDM < 55 ans (H) / < 65 ans (F)
- **Cancers** : Type, âge survenue
- **Diabète** : Type 1 ou 2
- **Psychiatriques** : Dépression, bipolarité
- **Génétiques** : Mucoviscidose, drépanocytose

### 5. MÉDICAMENTS ET ALLERGIES

#### Traitement actuel
- **Liste complète** : 
  - Nom (DCI préféré)
  - Dosage
  - Posologie
  - Durée
  - Indication
- **Observance** : Oublis, modifications
- **Automédication** : OTC, phytothérapie
- **Compléments** : Vitamines, probiotiques

#### Allergies et intolérances
- **Médicamenteuses** : 
  - Molécule
  - Type réaction
  - Date
  - Gravité
- **Alimentaires** : Aliments, additifs
- **Environnementales** : Pollen, acariens
- **Latex** : Important pour examens

### 6. HABITUDES DE VIE (HABITUS)

#### Toxiques
- **Tabac** :
  - Statut : Actif/sevré/jamais
  - Quantité : Paquets-années
  - Tentatives sevrage
- **Alcool** :
  - Consommation : Unités/semaine
  - CAGE questionnaire
  - Complications
- **Drogues** :
  - Type, fréquence
  - Mode consommation
  - Sevrage

#### Mode de vie
- **Alimentation** : Équilibre, régimes
- **Activité physique** : Type, fréquence
- **Sommeil** : Durée, qualité
- **Stress** : Sources, gestion
- **Sexualité** : Si pertinent, avec tact

#### Environnement
- **Habitat** : Type, salubrité
- **Profession** : Expositions, stress
- **Voyages** : Récents, zones endémiques
- **Animaux** : Contacts, allergies
- **Loisirs** : Sports, activités à risque

### 7. ANAMNÈSE SOCIALE

#### Situation sociale
- **Statut** : Marié, célibataire, veuf
- **Entourage** : Support familial
- **Enfants** : Nombre, âge, garde
- **Aidants** : Présence, disponibilité

#### Situation professionnelle
- **Activité** : Emploi, chômage, retraite
- **Conditions** : Pénibilité, stress
- **Arrêts** : Maladie, accidents travail
- **Expositions** : Chimiques, physiques

#### Autonomie
- **ADL** : Activités vie quotidienne
- **IADL** : Activités instrumentales
- **Aides** : Humaines, techniques
- **Mobilité** : Marche, transferts

### 8. REVUE DES SYSTÈMES (ROS)

#### Symptômes généraux
- Fièvre, frissons
- Perte/prise de poids
- Asthénie
- Sueurs nocturnes
- Anorexie

#### Système cardiovasculaire
- Douleur thoracique
- Dyspnée d'effort
- Orthopnée, DPN
- Palpitations
- Syncope, lipothymie
- Œdèmes MI
- Claudication intermittente

#### Système respiratoire
- Toux (sèche/productive)
- Expectoration (aspect)
- Hémoptysie
- Sibilances
- Douleur pleurale

#### Système digestif
- Dysphagie
- Pyrosis, RGO
- Nausées, vomissements
- Douleurs abdominales
- Transit : Diarrhée/constipation
- Rectorragies, méléna
- Ictère

#### Système génito-urinaire
- Dysurie, pollakiurie
- Urgenturie, incontinence
- Hématurie
- Douleurs lombaires
- Écoulements
- Dysfonction érectile
- Troubles menstruels

#### Système neurologique
- Céphalées
- Vertiges
- Paresthésies
- Faiblesse, parésie
- Troubles visuels
- Troubles du langage
- Convulsions
- Troubles mnésiques

#### Système locomoteur
- Arthralgies
- Gonflements articulaires
- Raideur matinale
- Myalgies
- Limitation mobilité

#### Système endocrinien
- Polyurie, polydipsie
- Intolérance chaud/froid
- Modifications poids
- Modifications pilosité

#### Peau et phanères
- Éruptions
- Prurit
- Modifications ongles/cheveux
- Lésions

#### Système psychiatrique
- Humeur : Tristesse, euphorie
- Anxiété
- Troubles sommeil
- Idées suicidaires
- Hallucinations

## TECHNIQUES DE COMMUNICATION

### Questions types

#### Questions ouvertes
- "Racontez-moi ce qui vous arrive"
- "Comment cela a-t-il commencé?"
- "Qu'est-ce qui vous inquiète le plus?"
- Laissent le patient s'exprimer

#### Questions fermées
- "Avez-vous de la fièvre?"
- "La douleur est-elle constante?"
- Précisent les informations
- À utiliser après questions ouvertes

#### Questions de clarification
- "Que voulez-vous dire par...?"
- "Pouvez-vous décrire plus précisément?"
- "À quoi ressemble cette sensation?"

### Techniques d'écoute active

#### Reformulation
- "Si je comprends bien..."
- "Vous me dites que..."
- Vérifie la compréhension

#### Résumé
- Points clés de l'anamnèse
- Chronologie des événements
- Validation par le patient

#### Silence thérapeutique
- Laisse le temps de réfléchir
- Encourage l'expression
- Ne pas combler systématiquement

#### Empathie
- "Je comprends que cela soit difficile"
- "Cela doit être inquiétant"
- Validation émotionnelle

### Facilitation
- "Mmh", "Je vois"
- Hochements de tête
- "Continuez"
- Encourage sans interrompre

## RED FLAGS PAR SYSTÈME

### Cardiovasculaires
- Douleur thoracique oppressive
- Dyspnée aiguë
- Syncope d'effort
- Palpitations avec malaise
- Œdème aigu

### Neurologiques
- Céphalée brutale "coup de tonnerre"
- Déficit neurologique focal
- Convulsions première fois
- Troubles conscience
- Méningisme

### Abdominaux
- Douleur intense avec défense
- Vomissements bilieux/fécaloïdes
- Hémorragie digestive massive
- Ictère fébrile
- Masse pulsatile

### Généraux
- Perte de poids > 10% en 6 mois
- Sueurs nocturnes profuses
- Fièvre > 3 semaines
- Adénopathies généralisées
- AEG inexpliquée

## PIÈGES À ÉVITER

### Erreurs de communication
- Interrompre trop tôt
- Questions suggestives
- Jargon médical
- Jugements de valeur
- Minimiser les plaintes

### Erreurs de contenu
- Anamnèse incomplète
- Négliger le contexte psychosocial
- Oublier les médicaments
- Ignorer les attentes
- Manquer les red flags

### Biais cognitifs
- Ancrage (première impression)
- Confirmation (chercher ce qu'on attend)
- Disponibilité (dernier cas vu)
- Représentativité (stéréotypes)

## CLÔTURE DE L'ANAMNÈSE

### Vérification
- "Y a-t-il autre chose?"
- "Ai-je oublié quelque chose d'important?"
- Reformulation finale
- Validation par le patient

### Information
- Hypothèses diagnostiques simples
- Plan d'investigation
- Prochaines étapes
- Délais attendus

### Questions du patient
- Temps dédié
- Réponses claires
- Avouer si incertitude
- Ressources additionnelles

## Points clés pour l'ECOS
1. **Structure** systématique de l'anamnèse
2. **Questions ouvertes** puis fermées
3. **Écoute active** sans interrompre
4. **PQRSTU** pour caractériser symptômes
5. **ICE** : Ideas, Concerns, Expectations
6. **Red flags** à ne pas manquer
7. **Empathie** et validation émotionnelle
