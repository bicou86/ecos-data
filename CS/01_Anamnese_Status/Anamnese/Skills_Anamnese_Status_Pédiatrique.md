# SSP - Pédiatrie : Anamnèse et Status général

## 🎯 ANAMNÈSE (25%)

### Motif de consultation et plainte
- **Caractériser la plainte** (PQRSTU adaptée à l'âge)
- **Motif d'amener l'enfant** (qui consulte ? pourquoi maintenant ?)
- **Retentissement** sur alimentation, sommeil, jeu, développement

### État général actuel
- **Tonus** : hypotonie/hypertonie, symétrie
- **Éveil** : contact, regard, réactivité aux stimuli
- **Pleurs** : continus vs habituels, qualité (aigu/grave), consolable ?
- **Nuits** : rythme, réveils, agitation nocturne
- **Température** corporelle (fièvre ?)

### Alimentation
- **Nourrisson** :
  - Type : allaitement maternel/artificiel/mixte
  - Fréquence, quantité, durée des tétées
  - Vomissements, régurgitations
  - Diversification (âge de début, aliments introduits)
- **Enfant** :
  - Nombre de repas, quantités
  - Appétit, sélectivité alimentaire
  - Troubles déglutition

### Croissance et développement
- **Courbes de croissance** :
  - Poids, taille, périmètre crânien
  - Position sur percentiles
  - Évolution dans le temps (cassure de courbe ?)
- **Développement psychomoteur** selon l'âge :
  - **2 mois** : mains ouvertes, sourire social, vocalises
  - **4 mois** : tête dans l'axe, regard des mains, curiosité
  - **6 mois** : transfert, babillage, position assise avec appui
  - **9 mois** : assis seul, peur de l'étranger, pré-locomotion
  - **12 mois** : marche, premier mot, pointage, préférence manuelle
  - **18 mois** : autonomie, opposition, jargon mélodieux
  - **24 mois** : >50 mots, juxtaposition, propreté
  - **3 ans** : >50% compréhensible, identification sexuelle, jeu de groupe
  - **4 ans** : 100% compréhensible, séparation aisée, puzzles

### Fonctions d'élimination
- **Selles** : fréquence, consistance, couleur, présence méconium (NNé)
- **Urines** : fréquence, couleur, quantité, énurésie
- **Vomissements** : fréquence, aspect, relation aux repas

### Symptômes associés
- **Respiratoire** : toux, dyspnée, stridor, sibilances
- **Cutané** : éruption, pâleur, cyanose, ictère
- **ORL** : rhinorrhée, otalgie, se touche l'oreille
- **Digestif** : douleurs abdominales, distension

### Anamnèse périnatale
- **Grossesse** :
  - Terme, surveillance, complications
  - Infections, médications, toxiques
  - Sérologies (TORCH, HBV, HIV, Strepto B)
- **Accouchement** :
  - Voie basse/césarienne, instrumentation
  - Score Apgar, réanimation
  - Adaptation immédiate
- **Période néonatale** :
  - Mensurations naissance
  - Séjour néonatal, complications
  - Première semaine de vie

### Suivi médical
- **Vaccinations** : carnet vaccinal, retards ?
- **Croissance** : courbes, consultations régulières
- **Dépistages** : audition, vision, troubles développement

### Anamnèse psychosociale
- **Environnement familial** :
  - Structure familiale, fratrie
  - Conditions socio-économiques
  - Garde de l'enfant (crèche, famille)
- **Stress familial** : séparation, deuil, déménagement
- **Parentalité** : épuisement parental, shaken baby syndrome

### Antécédents
- **Personnels** : hospitalisations, chirurgies, traumatismes
- **Familiaux** : maladies héréditaires, retard développement, allergies

## 👁️ EXAMEN PHYSIQUE (25%)

### Inspection générale
- **Aspect général** : mouvements spontanés, pleurs, vocalises
- **Nutrition** : signes malnutrition, déshydratation
- **Couleur** : pâleur, cyanose, ictère (zone atteinte)
- **Dysmorphies** : faciès particulier, malformations
- **Symétrie** : membres, mouvements

### Mensurations
- **Poids** : reporter sur courbe (perte <10% acceptable chez NNé)
- **Taille** : percentile, vitesse croissance
- **Périmètre crânien** : macro/microcéphalie

### Examen céphalique
- **Crâne** :
  - Fontanelles : taille, tension (bombée = HTIC)
  - Sutures : chevauchement, fermeture prématurée
  - Déformations : hématomes, plagiocéphalie
- **Yeux** : strabisme, poursuite visuelle, réflexes pupillaires
- **Cavité buccale** :
  - Palais : fente palatine ?
  - Langue : couleur, mobilité
  - Dents : bourgeons, caries
- **Oreilles** : déformation, écoulement

### Examen cardiovasculaire
- **Auscultation** : 4 foyers (mitral parasternal gauche chez enfant)
- **Pouls** : brachiaux, fémoraux (comparaison obligatoire)
- **Signes d'insuffisance cardiaque** :
  - Dyspnée effort (difficultés tétée)
  - Hépatomégalie, œdèmes
  - Sueurs, pâleur

### Examen respiratoire
- **Inspection** :
  - Fréquence (N ~30/min chez NNé)
  - Symétrie thoracique
  - Respiration diaphragmatique possible
- **Signes de détresse** :
  - Battement ailes du nez
  - Tirage intercostal, sus-claviculaire
  - Balancement thoraco-abdominal
  - Cyanose, grunting

### Examen abdominal
- **Inspection** : distension, scaphoïde
- **Palpation** :
  - Foie : normal jusqu'à 2 cm rebord costal
  - Rate : pointe palpable normale
  - Reins : palpables en profondeur
  - Masses, sensibilité
- **Cordon ombilical** : 3 vaisseaux obligatoires (NNé)

### Examen urogénital
- **Filles** :
  - Lèvres proéminentes normales
  - Palpation recherche testicule ectopique
  - Clitoris : >1 cm = clitoromégalie
  - Écoulement non purulent possible
- **Garçons** :
  - Pénis : N >2 cm
  - Prépuce : étroit et adhérent normal
  - Scrotum : grand, testicules descendus

### Examen musculosquelettique
- **Membres** : symétrie, mobilité, déformations
- **Hanches** : tests Barlow et Ortolani (luxation congénitale)
- **Pieds** : position, pieds bots (inversion non réductible)
- **Extrémités** : syndactylie, polydactylie

### Examen neurologique
- **Conscience** : éveil, réactivité stimuli
- **Tonus** :
  - Posture repos : flexion hanches, genoux, coudes
  - Tonus passif : retour en flexion après extension
- **Réflexes archaïques** (disparaissent vers 4-6 mois) :
  - **Moro** : étreinte symétrique + pleurs
  - **Grasping** : préhension plantaire/palmaire  
  - **Marche automatique**
  - **Galant** : flexion latérale
  - **Succion**

## 🔬 EXAMENS COMPLÉMENTAIRES (25%)

### Selon l'âge et contexte
- **Nouveau-né** :
  - Test Guthrie (48h)
  - Test audition
  - Sérologies selon facteurs risque
- **Nourrisson/enfant** :
  - FSC si pâleur, fatigue
  - CRP si fièvre, infection
  - Ionogramme si vomissements, diarrhée

### Examens spécifiques
- **Croissance** : âge osseux si retard
- **Développement** : bilan neuropsychologique
- **Malformations** : échographie, imagerie selon organe

---

## 💊 PRISE EN CHARGE (25%)

### Mesures générales
- **Nutrition** :
  - Allaitement : soutien, conseils techniques
  - Diversification : calendrier adapté
  - Supplémentations : vitamine D, K, fer selon âge
- **Prévention** :
  - Mort subite du nourrisson : position dorsale, température
  - Sécurité : prévention accidents domestiques
  - Vaccinations selon calendrier

### Suivi développement
- **Surveillance courbes croissance**
- **Dépistages** : vision, audition, troubles apprentissage
- **Stimulation** : conseils jeu, lecture, interaction

### Conseils parents
- **Signes d'alarme** : fièvre, détresse respiratoire, troubles conscience
- **Développement normal** : rassurer, expliquer étapes
- **Parentalité** : soutien, prévention épuisement

### Orientations spécialisées
- **Pédiatre** : suivi croissance, développement
- **Neuropédiatre** : retard psychomoteur
- **ORL pédiatrique** : troubles audition, ORL à répétition
- **Urgences pédiatriques** : signes gravité

---

## 🚨 RED FLAGS

### Signes vitaux
- **Fréquence respiratoire >70/min**
- **Apnées, respiration irrégulière**
- **Cyanose persistante**
- **Hyperthermie >38.5°C <3 mois**

### Développement
- **Pas de sourire social à 3 mois**
- **Pas de tenue tête à 4 mois**
- **Pas de position assise à 10 mois**
- **Pas de marche à 18 mois**
- **Pas de mots à 18 mois**

### Comportement
- **Pleurs inconsolables >3h**
- **Léthargie, troubles conscience**
- **Régression développement**
- **Signes maltraitance**

### Croissance
- **Cassure courbe croissance**
- **Microcéphalie progressive**
- **Fontanelle bombée ou déprimée**

---

*💡 Adaptation de l'examen selon l'âge, la coopération de l'enfant et le contexte (urgent vs consultation de routine). Importance de la communication avec les parents et de l'observation comportementale.*

# Anamnèse pédiatrique

## Domaine
Pédiatrie

## Description
Guide structuré pour conduire une anamnèse complète chez l'enfant, adaptée à l'âge et incluant l'histoire périnatale, le développement, les antécédents et le contexte familial.

## PRINCIPES GÉNÉRAUX

### Approche selon l'âge
- **Nouveau-né/Nourrisson** : Parents principaux informateurs
- **Enfant préscolaire** : Parents + observation enfant
- **Enfant scolaire** : Questions simples à l'enfant + parents
- **Adolescent** : Temps seul avec l'ado (HEADSS)

### Triangle de communication
- **Enfant** : Au centre de l'attention
- **Parents** : Sources d'information
- **Médecin** : Facilitateur, observateur

### Environnement adapté
- Salle accueillante, jouets disponibles
- Position adaptée (hauteur enfant)
- Temps suffisant, sans précipitation
- Respect du rythme de l'enfant

## STRUCTURE DE L'ANAMNÈSE PÉDIATRIQUE

### 1. IDENTIFICATION ET MOTIF

#### Données de base
- **Identité** : Nom, prénom, date de naissance
- **Âge** : Années et mois (< 2 ans : mois/semaines)
- **Sexe**
- **Accompagnants** : Parents, tuteur légal
- **Médecin traitant/pédiatre**

#### Motif de consultation
- **Symptômes principaux** : Propres mots des parents
- **Durée** : Depuis quand
- **Inquiétudes parentales** : Explicites et implicites
- **Impact** : Sur enfant, famille, école

### 2. HISTOIRE DE LA MALADIE ACTUELLE

#### Caractérisation des symptômes
- **Début** : Brutal/progressif
- **Évolution** : Amélioration/aggravation
- **Facteurs** : Déclenchants, améliorants
- **Symptômes associés** : Fièvre, comportement
- **Traitements essayés** : Médicaments, remèdes

#### Retentissement
- **Alimentation** : Appétit, refus
- **Sommeil** : Perturbations
- **Jeu** : Intérêt, énergie
- **École** : Absences, performances
- **Comportement** : Irritabilité, apathie

### 3. ANTÉCÉDENTS PERSONNELS

#### Histoire périnatale (toujours pertinente)

**Grossesse**:
- **Suivi** : Régulier, complications
- **Infections** : TORCH, streptocoque B
- **Médicaments/toxiques** : Alcool, tabac, drogues
- **Examens** : Échographies, amniocentèse
- **Pathologies maternelles** : Diabète, HTA

**Accouchement**:
- **Terme** : SA et jours
- **Mode** : Voie basse, césarienne (indication)
- **Présentation** : Céphalique, siège
- **Durée travail** : Complications
- **Liquide amniotique** : Clair, méconial

**Période néonatale**:
- **Mensurations naissance** :
  - Poids (percentile)
  - Taille
  - Périmètre crânien
- **Apgar** : 1, 5, 10 minutes
- **Réanimation** : Nécessaire?
- **Ictère** : Photothérapie
- **Alimentation** : Démarrage
- **Séjour** : Durée, soins intensifs
- **Dépistage néonatal** : Résultats

#### Antécédents médicaux
- **Hospitalisations** : Âge, durée, motif
- **Chirurgies** : Type, âge, complications
- **Maladies chroniques** : Asthme, épilepsie
- **Accidents** : Traumatismes, séquelles
- **Allergies** : Médicaments, aliments, environnement

### 4. DÉVELOPPEMENT

#### Développement moteur
**Motricité globale**:
- Tenir tête : 3 mois
- Position assise : 6-7 mois
- Quatre pattes : 8-10 mois
- Marche : 12-15 mois
- Course : 18-24 mois
- Sauter : 2-3 ans
- Vélo : 4-5 ans

**Motricité fine**:
- Préhension : 4-5 mois
- Pince pouce-index : 9-10 mois
- Cubes empilés : 12-18 mois
- Dessin : Gribouillis → forme → bonhomme

#### Développement du langage
- **Premiers mots** : 12 mois
- **Phrases 2 mots** : 18-24 mois
- **Phrases complètes** : 2-3 ans
- **Compréhension** : Consignes simples/complexes
- **Prononciation** : Défauts articulatoires

#### Développement social
- **Sourire social** : 2-3 mois
- **Angoisse séparation** : 8-10 mois
- **Jeu** : Solitaire → parallèle → coopératif
- **Propreté** : Jour (2-3 ans), nuit (3-4 ans)
- **Autonomie** : Habillage, hygiène

#### Développement cognitif
- **Permanence objet** : 8-10 mois
- **Imitation** : 12-18 mois
- **Jeu symbolique** : 2-3 ans
- **Concepts** : Couleurs, nombres, lettres

#### Scolarité
- **Garderie/crèche** : Âge début, adaptation
- **École** : Niveau, redoublement
- **Performances** : Académiques, difficultés
- **Comportement** : Attention, hyperactivité
- **Aide** : Orthophonie, psychologie, ergothérapie

### 5. ALIMENTATION ET CROISSANCE

#### Alimentation actuelle
- **Type** :
  - Allaitement : Sein/biberon, exclusif/mixte
  - Diversification : Âge début, progression
  - Alimentation solide
- **Quantités** : Volumes, nombre repas
- **Appétit** : Bon, sélectif, refus
- **Comportement alimentaire** : Durée repas, difficultés
- **Régimes** : Restrictions, préférences

#### Histoire nutritionnelle
- **Allaitement maternel** : Durée, sevrage
- **Formules** : Types, changements, tolérance
- **Diversification** : Âge, progression, réactions
- **Intolérances/allergies** : Aliments problématiques

#### Croissance
- **Courbes** : Poids, taille, PC (< 2 ans), IMC
- **Vitesse croissance** : Cassure, rattrapage
- **Comparaison** : Fratrie, parents
- **Inquiétudes** : Trop petit/grand, maigre/gros

### 6. VACCINATIONS

#### Calendrier vaccinal
- **À jour** : Selon programme national
- **Retard** : Raisons, rattrapage prévu
- **Vaccins reçus** :
  - BCG (si indiqué)
  - Hexavalent (DTCaP-VPI-Hib-HepB)
  - Pneumocoque
  - ROR
  - Méningocoque
  - HPV (adolescents)
  - Grippe (si indiqué)

#### Réactions vaccinales
- **Locales** : Rougeur, douleur
- **Systémiques** : Fièvre, irritabilité
- **Graves** : Allergie, autre

### 7. HABITUDES DE VIE

#### Sommeil
- **Durée** : Heures/nuit + siestes
- **Horaires** : Coucher, lever
- **Endormissement** : Facile, difficile, rituels
- **Réveils nocturnes** : Fréquence, raisons
- **Problèmes** : Cauchemars, terreurs, somnambulisme
- **Ronflement** : Apnées observées

#### Activités
- **Jeu** : Types, durée, seul/accompagné
- **Écrans** : TV, tablette, temps/jour
- **Sport** : Activités, fréquence
- **Lecture** : Intérêt, fréquence
- **Socialisation** : Amis, activités groupe

#### Hygiène
- **Brossage dents** : Fréquence, supervision
- **Bain** : Fréquence, autonomie
- **Propreté** : Acquise (jour/nuit), accidents

#### Comportement
- **Tempérament** : Facile, difficile, lent
- **Humeur** : Joyeux, anxieux, triste
- **Oppositions** : Crises, colères
- **Peurs** : Séparation, noir, animaux
- **Habitudes** : Succion pouce, doudou

### 8. ANTÉCÉDENTS FAMILIAUX

#### Parents
- **Âge** et état de santé
- **Consanguinité**
- **Maladies chroniques** : Asthme, diabète, épilepsie
- **Maladies génétiques** : Mucoviscidose, drépanocytose
- **Troubles développement** : Autisme, TDAH, retard
- **Décès** : Âge, cause (mort subite nourrisson)

#### Fratrie
- **Nombre** : Âges
- **Santé** : Maladies, développement
- **Décès** : Causes

#### Famille élargie
- **Maladies héréditaires** : Type, transmission
- **Cancers pédiatriques**
- **Malformations**
- **Retard mental**
- **Surdité/cécité précoce**

### 9. CONTEXTE PSYCHOSOCIAL

#### Structure familiale
- **Parents** : Ensemble, séparés, monoparental
- **Garde** : Arrangements, conflits
- **Fratrie** : Relations
- **Autres membres** : Grands-parents, etc.

#### Conditions de vie
- **Logement** : Type, salubrité, surpeuplement
- **Chambre enfant** : Seul, partagée
- **Animaux** : Types, contacts
- **Tabagisme passif**
- **Sécurité** : Accidents domestiques

#### Situation socio-économique
- **Profession parents**
- **Revenus** : Difficultés financières
- **Assurance** : Couverture santé
- **Support** : Famille, services sociaux

#### Facteurs de stress
- **Changements récents** : Déménagement, deuil
- **Violence** : Témoin, victime
- **Négligence** : Signes
- **Abus** : Suspicion

## APPROCHE SPÉCIFIQUE ADOLESCENT : HEADSS(S)

### H - Home (Maison)
- Avec qui vis-tu?
- Comment ça se passe à la maison?
- Changements récents?
- Te sens-tu en sécurité?

### E - Education/Employment
- Comment ça va à l'école?
- Notes, absences?
- Projets futurs?
- Travail à temps partiel?

### A - Activities (Activités)
- Que fais-tu pour t'amuser?
- Sports, loisirs?
- Amis proches?
- Temps d'écran?

### D - Drugs (Drogues)
- Tes amis consomment-ils?
- As-tu déjà essayé?
- Tabac, alcool, cannabis?
- Fréquence, quantité?

### S - Sexuality (Sexualité)
- As-tu un(e) petit(e) ami(e)?
- Questions sur sexualité?
- Activité sexuelle?
- Contraception, protection?

### S - Suicide/Depression
- Comment est ton humeur?
- Te sens-tu triste?
- Pensées de mort?
- Tentatives antérieures?

### S - Safety (Sécurité)
- Violence à la maison/école?
- Intimidation?
- Accidents, blessures?
- Port ceinture/casque?

### Croissance

# Examen clinique pédiatrique

## Domaine
Pédiatrie

## Description
Guide systématique pour réaliser un examen clinique complet chez l'enfant, adapté à l'âge, incluant les paramètres de croissance, l'examen par système et l'évaluation du développement.

## PRINCIPES GÉNÉRAUX

### Approche selon l'âge
- **Nouveau-né** : Examen sur table, déshabillé
- **Nourrisson** : Sur parent puis table d'examen
- **Bambin (1-3 ans)** : Sur genoux parent, jeu
- **Préscolaire** : Participation active, explications
- **Scolaire** : Coopération, pudeur respectée
- **Adolescent** : Intimité, consentement

### Ordre d'examen adapté
- **Opportuniste** : Commencer par ce qui est accessible
- **Non menaçant d'abord** : Observer avant toucher
- **Douloureux en dernier** : ORL, abdomen sensible
- **Flexibilité** : S'adapter à l'enfant

### Environnement et matériel
- **Température** : Salle chaude (nouveau-né++)
- **Éclairage** : Bon, naturel si possible
- **Jouets** : Distraction, mise en confiance
- **Matériel adapté** : Brassard TA taille appropriée
- **Parents** : Présence rassurante

## EXAMEN GÉNÉRAL

### Première impression (Triangle d'évaluation pédiatrique)
**A - Apparence**:
- Tonus : Normal, hypotonique, hypertonique
- Interactivité : Éveillé, réactif, apathique
- Consolabilité : Facile, difficile, inconsolable
- Regard : Vif, fixe, absent
- Cri/parole : Fort, faible, absent

**B - Breathing (Respiration)**:
- Position : Normale, tripode
- Bruits audibles : Stridor, wheezing, grunting
- Signes de lutte : Tirage, battement ailes nez

**C - Circulation**:
- Couleur : Rose, pâle, cyanosé, marbré
- Perfusion : Temps recoloration capillaire

### État général
- **Bien portant** vs **Malade**
- **État nutritionnel** : Bon, malnutrition, obésité
- **Hydratation** : 
  - Muqueuses : Humides/sèches
  - Larmes présentes
  - Fontanelle (< 18 mois) : Normale/déprimée
  - Pli cutané
- **Niveau d'activité** : Normal, diminué, agité

#### Tension artérielle
- Percentiles selon âge, taille, sexe
- Brassard approprié : 2/3 bras, vessie 80-100% circonférence
- Systolique < 90 + (2 × âge) = hypotension

#### Température
- **Normale** : 36.5-37.5°C

- **Fièvre** : > 38°C rectale, > 37.5°C axillaire

#### Saturation O2
- **Normale** : > 95% air ambiant
- **< 92%** : Hypoxémie significative

### Paramètres de croissance

#### Mesures essentielles
**Poids**:
- Balance appropriée (bébé/debout)
- Déshabillé (< 2 ans) ou sous-vêtements
- Percentile et z-score

**Taille/Longueur**:
- Couché < 2 ans (toise)
- Debout ≥ 2 ans (toise murale)
- Technique : Talons, fesses, épaules, tête contre mur

**Périmètre crânien**:
- Systématique < 2 ans
- Circonférence maximale (front-occiput)
- Courbe spécifique

**IMC**:
- ≥ 2 ans : Poids(kg)/Taille²(m)
- Percentiles selon âge

#### Interprétation courbes
- **Normal** : 3e-97e percentile
- **Surveillance** : < 3e ou > 97e percentile
- **Vitesse croissance** : Plus importante que position
- **Cassure courbe** : Investigation requise
- **Taille cible** : (Taille père + mère ± 13)/2
