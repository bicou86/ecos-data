# Anamnèse psychiatrique

## Domaine
Psychiatrie

## Description
Guide structuré pour conduire une anamnèse psychiatrique complète, incluant l'histoire de la maladie, les antécédents psychiatriques, l'évaluation du risque et le contexte psychosocial.

## PRINCIPES GÉNÉRAUX

### Approche spécifique
- **Alliance thérapeutique** : Établir confiance et empathie
- **Non-jugement** : Attitude neutre et bienveillante
- **Confidentialité** : Expliquer limites (danger pour soi/autrui)
- **Temps suffisant** : Ne pas presser le patient
- **Validation** : Reconnaître la souffrance

### Adaptation selon pathologie
- **Psychose** : Questions simples, concrètes
- **Dépression** : Patience, encouragement
- **Anxiété** : Environnement calme, rassurant
- **Manie** : Structurer, recentrer
- **Trouble personnalité** : Limites claires

## STRUCTURE DE L'ANAMNÈSE PSYCHIATRIQUE

### 1. MOTIF DE CONSULTATION

#### Plainte principale
- **Propres mots** du patient
- **Qui** demande la consultation (patient, famille, médecin)
- **Pourquoi maintenant** : Facteur déclenchant
- **Attentes** du patient
- **Motivation** pour le traitement

#### Symptômes actuels
- **Nature** : Psychiques, somatiques, comportementaux
- **Intensité** : Échelle subjective
- **Fréquence** : Continue, épisodique
- **Durée** : Depuis quand
- **Retentissement** : Fonctionnel, social, professionnel

### 2. HISTOIRE DE LA MALADIE ACTUELLE

#### Mode de début
- **Aigu vs progressif**
- **Âge de début** des premiers symptômes
- **Facteurs déclenchants** :
  - Stress psychosocial
  - Événement de vie
  - Substance
  - Maladie somatique
- **Prodrome** : Signes avant-coureurs

#### Évolution temporelle
- **Évolution** : Amélioration, aggravation, fluctuation
- **Épisodes antérieurs** :
  - Nombre
  - Durée
  - Intervalle libre
  - Symptômes similaires/différents
- **Périodes de rémission** :
  - Complète/partielle
  - Durée
  - Facteurs favorisants

#### Facteurs modulateurs
- **Aggravants** : Stress, fatigue, substances
- **Améliorants** : Repos, activités, support
- **Variations** : Saisonnières, circadiennes
- **Comorbidités** : Anxiété, substances

### 3. ANTÉCÉDENTS PSYCHIATRIQUES

#### Hospitalisations
- **Nombre** et dates
- **Durée** des séjours
- **Motifs** : Décompensation, TS, danger
- **Type** : Volontaire, sous contrainte
- **Traitements** reçus
- **Évolution** durant hospitalisation

#### Suivis ambulatoires
- **Psychiatre** : Durée, fréquence
- **Psychologue/psychothérapie** : Type, durée
- **Autres** : Ergothérapie, art-thérapie
- **Observance** : Régularité des suivis
- **Ruptures** de suivi : Motifs

#### Tentatives de suicide
- **Nombre** et dates
- **Moyens** utilisés
- **Intentionnalité** : Planification, lettres
- **Déclencheurs**
- **Hospitalisations** suite TS
- **Idées suicidaires** actuelles

#### Diagnostics antérieurs
- **Diagnostics** posés
- **Par qui** : Psychiatre, urgences
- **Évolution** diagnostique
- **Accord** du patient avec diagnostic

### 4. TRAITEMENTS

#### Traitements actuels
- **Médicaments** :
  - Nom, dosage, posologie
  - Depuis quand
  - Efficacité perçue
  - Effets secondaires
- **Psychothérapie** :
  - Type (TCC, psychodynamique, etc.)
  - Fréquence
  - Satisfaction

#### Traitements antérieurs
- **Médicaments essayés** :
  - Classes (antidépresseurs, antipsychotiques, etc.)
  - Efficacité
  - Tolérance
  - Raisons d'arrêt
- **Durée** des essais
- **Doses maximales** atteintes
- **ECT** : Nombre séances, efficacité

#### Observance thérapeutique
- **Compliance** actuelle
- **Oublis** : Fréquence
- **Arrêts** : Spontanés, raisons
- **Modifications** : Auto-ajustements
- **Attitudes** vis-à-vis traitement

### 5. FACTEURS DE RISQUE ET ANTÉCÉDENTS

#### Événements de vie
- **Traumatismes** :
  - Enfance : Abus, négligence
  - Adulte : Agression, accident
  - TSPT : Symptômes
- **Pertes** : Deuils, séparations
- **Stress** : Professionnel, financier
- **Changements** majeurs récents

#### Substances
- **Alcool** :
  - Consommation actuelle
  - Pattern : Social, solitaire
  - Quantité
  - Conséquences
  - Sevrage : Symptômes
- **Drogues** :
  - Types
  - Fréquence
  - Voie administration
  - Contexte usage
- **Tabac** : Paquets-années
- **Médicaments** : Benzodiazépines, opioïdes

#### Antécédents familiaux psychiatriques
- **Premier degré** : Parents, fratrie, enfants
  - Troubles psychiatriques
  - Hospitalisations
  - Suicides
  - Addictions
- **Deuxième degré** : Grands-parents, oncles/tantes
- **Traitements** efficaces dans famille
- **Consanguinité**

#### Antécédents médicaux
- **Maladies chroniques** : Impact psychologique
- **Neurologiques** : Épilepsie, TC, AVC
- **Endocriniens** : Thyroïde, diabète
- **Médicaments** : Corticoïdes, interféron
- **Chirurgies** : Stress périopératoire

### 6. CONTEXTE PSYCHOSOCIAL

#### Situation familiale
- **État civil** : Célibataire, marié, divorcé
- **Enfants** : Nombre, âge, garde
- **Relations familiales** :
  - Qualité
  - Conflits
  - Support
- **Violence** : Conjugale, familiale

#### Réseau social
- **Amis** : Nombre, qualité relations
- **Isolement** : Degré, choisi/subi
- **Activités sociales** : Fréquence
- **Appartenance** : Groupes, associations

#### Situation professionnelle
- **Emploi** actuel :
  - Type
  - Satisfaction
  - Stress
  - Relations collègues
- **Arrêts maladie** : Durée, fréquence
- **Changements** récents
- **Projets** professionnels

#### Conditions de vie
- **Logement** : Type, stabilité
- **Autonomie** : AVQ, AIVQ
- **Finances** : Difficultés, dettes
- **Juridique** : Procédures en cours
- **Support** : Services sociaux

### 7. BIOGRAPHIE ET DÉVELOPPEMENT

#### Enfance et adolescence
- **Grossesse/naissance** : Complications
- **Développement** : Retards, particularités
- **Scolarité** : Niveau, difficultés
- **Relations** : Pairs, famille
- **Événements** marquants

#### Personnalité prémorbide
- **Traits** : Anxieux, obsessionnel, etc.
- **Adaptation** : Sociale, professionnelle
- **Coping** : Stratégies habituelles
- **Valeurs** : Importantes pour patient

### 8. ÉVALUATION DU RISQUE

#### Risque suicidaire (RUD)
- **R**isque :
  - Idées suicidaires actuelles
  - Fréquence, intensité
  - Plan spécifique
  - Moyens disponibles
- **U**rgence :
  - Intention passage à l'acte
  - Délai envisagé
  - Préparatifs
- **D**angerosité :
  - Létalité du moyen
  - Accessibilité
  - Croyances sur la mort

#### Facteurs de risque suicidaire
- **Statiques** : Âge, sexe, ATCD TS
- **Dynamiques** :
  - Dépression
  - Désespoir
  - Impulsivité
  - Substances
  - Isolement
- **Précipitants** : Perte, conflit, échec

#### Facteurs protecteurs
- **Support social** disponible
- **Responsabilités** : Enfants, animaux
- **Croyances** : Religieuses, morales
- **Projets** futurs
- **Alliance** thérapeutique

#### Risque hétéro-agressif
- **Idées** : Fréquence, cibles
- **Plan** : Spécificité
- **Antécédents** : Violence
- **Facteurs** : Déclenchants
- **Contrôle** : Capacité

### 9. REVUE DES SYSTÈMES PSYCHIATRIQUES

#### Humeur
- **Dépression** :
  - Tristesse
  - Anhédonie
  - Culpabilité
  - Désespoir
- **Manie/hypomanie** :
  - Euphorie
  - Irritabilité
  - Grandiosité
  - Hyperactivité

#### Anxiété
- **Anxiété généralisée** : Inquiétudes excessives
- **Attaques de panique** : Fréquence, déclencheurs
- **Phobies** : Spécifiques, sociales
- **TOC** : Obsessions, compulsions
- **TSPT** : Reviviscences, évitement

#### Psychose
- **Hallucinations** :
  - Auditives : Voix, contenu
  - Visuelles
  - Autres
- **Idées délirantes** :
  - Persécution
  - Référence
  - Grandeur
  - Contrôle
- **Désorganisation** : Pensée, comportement

#### Cognition
- **Mémoire** : Oublis, confusion
- **Concentration** : Difficultés
- **Orientation** : Temps, lieu
- **Jugement** : Altéré

#### Comportement
- **Alimentation** : Restriction, boulimie
- **Sommeil** : Insomnie, hypersomnie
- **Sexualité** : Changements libido
- **Impulsivité** : Achats, jeu, sexe

## TECHNIQUES SPÉCIFIQUES

### Questions d'exploration

#### Pour la dépression
- "Comment est votre moral ces derniers temps?"
- "Prenez-vous encore plaisir aux choses?"
- "Avez-vous des idées noires?"
- "La vie vaut-elle la peine d'être vécue?"

#### Pour l'anxiété
- "Vous sentez-vous nerveux ou tendu?"
- "Avez-vous des inquiétudes difficiles à contrôler?"
- "Avez-vous des crises d'angoisse?"

#### Pour la psychose
- "Entendez-vous des voix que les autres n'entendent pas?"
- "Avez-vous l'impression qu'on vous veut du mal?"
- "Ressentez-vous des choses étranges dans votre corps?"

#### Pour le risque suicidaire
- "Avez-vous pensé à la mort récemment?"
- "Avez-vous pensé à vous faire du mal?"
- "Comment envisagez-vous de le faire?"
- "Qu'est-ce qui vous retient?"

### Gestion des situations difficiles

#### Patient mutique
- Respecter le silence
- Questions fermées simples
- Proposer de revenir
- Évaluer catatonie

#### Patient agité
- Rester calme
- Voix posée
- Distance sécuritaire
- Aide si nécessaire

#### Patient délirant
- Ne pas confronter
- Explorer vécu
- Chercher souffrance
- Évaluer dangerosité

#### Patient suicidaire
- Prendre au sérieux
- Explorer plan
- Évaluer urgence
- Sécuriser
