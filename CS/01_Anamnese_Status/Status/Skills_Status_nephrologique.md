# Examen néphrologique

## Domaine
Néphrologie

## Description
Examen clinique systématique orienté vers l'évaluation de la fonction rénale, la recherche de néphropathies et l'identification des syndromes néphrologiques.

## PRINCIPES GÉNÉRAUX

### Approche syndromique
- **Syndrome néphrotique** : Œdèmes, protéinurie
- **Syndrome néphritique** : HTA, hématurie, œdèmes
- **Insuffisance rénale** : Aiguë ou chronique
- **Syndrome tubulaire** : Troubles ioniques
- **Syndrome vasculaire** : HTA, hématurie

### Évaluation systématique
- **Fonction rénale** : Créatinine, DFG
- **Pression artérielle** : Debout/couché
- **État d'hydratation** : Œdèmes, pli cutané
- **Complications** : Anémie, troubles phosphocalciques

## ANAMNÈSE NÉPHROLOGIQUE

### Symptômes rénaux

#### Modifications de la diurèse
- **Polyurie** : > 3L/24h
  - Diabète insipide
  - Levée d'obstacle
  - Phase polyurique IRA
- **Oligurie** : < 500mL/24h
  - IRA
  - Syndrome néphrotique sévère
- **Anurie** : < 100mL/24h
  - Obstacle bilatéral
  - NTA sévère
  - Glomérulonéphrite rapidement progressive

#### Anomalies qualitatives des urines
- **Urines mousseuses** : Protéinurie
- **Urines foncées** : Hématurie, myoglobinurie
- **Urines troubles** : Infection, cristallurie
- **Odeur** : Ammoniacale (infection), fruitée (cétonurie)

#### Œdèmes
- **Localisation** :
  - Paupières (matin) : Syndrome néphritique
  - Membres inférieurs : Syndrome néphrotique
  - Généralisés : Anasarque
- **Caractères** :
  - Blancs, mous, indolores
  - Prenant le godet
  - Déclives
- **Évolution** : Progressive, symétrique
- **Prise de poids** associée

### Signes généraux

#### HTA
- **Ancienneté** : Récente vs chronique
- **Sévérité** : Grade, complications
- **Contrôle** : Nombre de traitements
- **Variabilité** : Pics tensionnels

#### Signes d'urémie
- **Digestifs** :
  - Nausées, vomissements
  - Anorexie
  - Goût métallique
  - Haleine urémique
- **Neurologiques** :
  - Asthénie
  - Troubles concentration
  - Somnolence
  - Confusion (stade avancé)
- **Cutanés** :
  - Prurit
  - Givre urémique (rare)
  - Teint cireux

### Antécédents néphrologiques

#### Maladies rénales
- **Glomérulonéphrites** : Type, biopsie
- **Polykystose** : Familiale
- **Néphropathie diabétique** : Ancienneté diabète
- **Reflux vésico-urétéral** : Enfance
- **Pyélonéphrites** : Répétées

#### Facteurs de risque IRC
- **Diabète** : Type, durée, équilibre
- **HTA** : Ancienneté, contrôle
- **Maladies cardiovasculaires**
- **Obésité**
- **Tabagisme**
- **AINS** : Usage chronique
- **Néphrotoxiques** : Aminosides, produits de contraste

#### Facteurs de risque IRA
- **Déshydratation** : Vomissements, diarrhée
- **Médicaments** : IEC, ARA2, AINS, diurétiques
- **Infection** : Sepsis
- **Obstacle** : Lithiase, cancer
- **Chirurgie** récente

### Histoire familiale
- **Polykystose rénale** : Transmission dominante
- **Syndrome d'Alport** : Surdité, atteinte oculaire
- **Néphronophtise** : Consanguinité
- **Diabète, HTA** familiaux

## EXAMEN PHYSIQUE

### Constantes et état général

#### Pression artérielle
- **Mesure** : Repos 5 min, 3 mesures
- **Deux bras** : Asymétrie (sténose)
- **Orthostatisme** : Hypovolémie
- **Membres inférieurs** : Coarctation

#### Poids et hydratation
- **Poids** : Variations récentes
- **Pli cutané** : Déshydratation
- **Turgescence jugulaires** : Hypervolémie
- **Œdèmes** : Localisation, importance

### Examen cardiovasculaire

#### Signes de surcharge
- **Crépitants** : OAP
- **Galop** : B3
- **Reflux hépato-jugulaire**
- **Hépatomégalie** : Congestion

#### Signes d'HTA chronique
- **Souffle carotidien**
- **Pouls périphériques** : Diminués
- **Souffle abdominal** : Sténose artère rénale

### Examen abdominal

#### Reins
- **Palpation** : Contact lombaire
  - Gros reins : Polykystose, hydronéphrose
  - Sensibilité : Pyélonéphrite
- **Percussion** : Giordano
- **Auscultation** : Souffle (sténose artère rénale)

#### Vessie
- **Globe vésical** : Obstacle, vessie neurologique
- **Matité sus-pubienne**

### Examen neurologique

#### Neuropathie urémique
- **Polyneuropathie** : Sensitivomotrice distale
- **Syndrome des jambes sans repos**
- **Crampes**

#### Encéphalopathie urémique
- **Astérixis** : Flapping tremor
- **Confusion**
- **Convulsions** (stade terminal)

### Signes cutanés

#### Urémie
- **Prurit** : Diffus, résistant
- **Pâleur** : Anémie
- **Ecchymoses** : Troubles hémostase
- **Givre urémique** : Cristaux d'urée (exceptionnel)

#### Maladies systémiques
- **Purpura** : Vascularite
- **Livedo** : SAPL, cryoglobulinémie
- **Rash malaire** : Lupus
- **Nodules** : Périartérite noueuse

## SYNDROMES NÉPHROLOGIQUES

### Syndrome néphrotique

#### Critères diagnostiques
- **Protéinurie** > 3g/24h (ou 50mg/kg/j enfant)
- **Hypoalbuminémie** < 30g/L
- **Œdèmes**
- **Hyperlipidémie** (inconstante)

#### Complications
- Thromboses (veine rénale++)
- Infections (pneumocoque)
- IRA fonctionnelle
- Dénutrition

### Syndrome néphritique aigu

#### Tableau clinique
- **Œdèmes** : Visage, paupières
- **HTA** : Récente
- **Hématurie** : Macroscopique "coca-cola"
- **Oligurie**
- **Protéinurie** : < 3g/24h

#### Étiologies principales
- Post-infectieuse (streptocoque)
- IgA (Berger)
- Lupus
- Vascularite

### Syndrome de glomérulonéphrite rapidement progressive

#### Présentation
- **IRC rapidement évolutive** : Semaines
- **Hématurie** : Cylindres hématiques
- **Protéinurie** : Variable
- **HTA** : Fréquente

#### Urgence diagnostique
- Biopsie rénale urgente
- Immunologie complète
- Traitement rapide

### Syndrome tubulo-interstitiel

#### Aigü
- **Fièvre**
- **Rash cutané**
- **Arthralgies**
- **Éosinophilie**
- **Origine médicamenteuse** ++

#### Chronique
- **Polyurie**
- **Nycturie**
- **Acidose métabolique**
- **Hypokaliémie**

## EXAMENS COMPLÉMENTAIRES

### Biologie de base

#### Fonction rénale
- **Créatinine** : Valeur, cinétique
- **DFG estimé** : CKD-EPI, MDRD
- **Urée** : Rapport urée/créatinine
- **Ionogramme** : K+, Na+, Cl-, HCO3-

#### Analyse d'urines
- **Bandelette** :
  - Protéines, sang
  - Leucocytes, nitrites
  - pH, densité, glucose
- **Protéinurie/créatininurie** : Spot
- **Protéinurie 24h** : Si néphropathie
- **Sédiment urinaire** :
  - Hématies : Dysmorphiques = glomérulaire
  - Leucocytes : > 10/mm3 = pathologique
  - Cylindres : Type et signification

### Imagerie rénale

#### Échographie
- **Taille** : 10-12 cm (diminuée si IRC)
- **Différenciation** cortico-médullaire
- **Dilatation** : Obstacle
- **Kystes** : Nombre, taille
- **Doppler** : Flux, résistances

#### Scanner/IRM
- **Angiographie** : Sténose artère rénale
- **Uro-scanner** : Obstacle, tumeur
- **IRM** : Si contre-indication iode

### Biopsie rénale

#### Indications
- Syndrome néphrotique adulte
- IRA inexpliquée
- IRC d'origine indéterminée
- Protéinurie > 1g/j inexpliquée
- Hématurie glomérulaire

#### Contre-indications
- Rein unique
- Troubles hémostase
- HTA non contrôlée
- Pyélonéphrite aiguë

## CLASSIFICATION DE L'IRC

### Stades (KDIGO)
- **G1** : DFG ≥ 90 (atteinte rénale avec DFG normal)
- **G2** : DFG 60-89 (légère)
- **G3a** : DFG 45-59 (modérée)
- **G3b** : DFG 30-44 (modérée)
- **G4** : DFG 15-29 (sévère)
- **G5** : DFG < 15 ou dialyse (terminale)

### Albuminurie
- **A1** : < 30 mg/g (normale)
- **A2** : 30-300 mg/g (modérée)
- **A3** : > 300 mg/g (sévère)

## COMPLICATIONS DE L'IRC

### Anémie
- **Normochrome normocytaire**
- **Déficit EPO**
- **Ferritine, CST** : Carence martiale

### Troubles phosphocalciques
- **Hyperphosphorémie**
- **Hypocalcémie**
- **Hyperparathyroïdie** secondaire
- **Déficit vitamine D**

### Acidose métabolique
- **Trou anionique** normal
- **Bicarbonates** < 22 mmol/L
- **Kaliémie** : Variable

### Hyperkaliémie
- **ECG** : Ondes T pointues
- **Risque** : Troubles rythme
- **Urgence** si > 6 mmol/L

## Points clés pour l'ECOS
1. **DFG** = marqueur clé fonction rénale
2. **Bandelette** systématique si suspicion néphropathie
3. **Œdèmes blancs** mous déclives = rénaux
4. **Protéinurie** > 3g/24h = syndrome néphrotique
5. **Biopsie rénale** = diagnostic étiologique
6. **HTA + œdèmes + hématurie** = syndrome néphritique
7. **Urgences** : Hyperkaliémie, OAP, péricardite

## Mnémotechniques

**"AEIOU"** pour indications dialyse:
- **A**cidose réfractaire
- **E**lectrolytes (hyperkaliémie)
- **I**ntoxication
- **O**verload (surcharge)
- **U**rémie symptomatique

**"PORTH"** pour syndrome néphrotique:
- **P**rotéinurie > 3g/24h
- **O**edèmes
- **R**éduction albumine < 30g/L
- **T**hrombose (complication)
- **H**yperlipidémie
