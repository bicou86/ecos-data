# Examen clinique de la hanche

## Domaine
Musculosquelettique/Membre inférieur

## Description
Examen systématique de la hanche pour évaluer l'articulation coxo-fémorale, les structures périarticulaires et identifier les pathologies articulaires, tendineuses ou osseuses.

## Anatomie fonctionnelle
- **Articulation** : Coxo-fémorale (énarthrose)
- **Stabilisateurs** : Capsule, labrum, ligaments (ilio-fémoral, pubo-fémoral, ischio-fémoral)
- **Muscles** : Fléchisseurs (psoas-iliaque), abducteurs (moyen fessier), rotateurs, extenseurs

## INSPECTION

### Patient debout
- **Posture globale** : Attitude antalgique
- **Bassin** : Horizontalité, asymétrie
- **Signe de Trendelenburg** : 
  - Station unipodale 30 secondes
  - (+) si chute du bassin controlatéral = insuffisance moyen fessier

### Patient en décubitus
- **Position spontanée** : Flexion, rotation externe (attitude vicieuse)
- **Asymétrie de longueur** des membres
- **Amyotrophie** : Quadriceps, fessiers

## PALPATION

### Points de repère
1. **Épine iliaque antéro-supérieure** (EIAS)
2. **Grand trochanter**
3. **Tubercule pubien**
4. **Épine iliaque postéro-supérieure**

### Points douloureux
- **Face antérieure** : Tendon psoas-iliaque
- **Face latérale** : Bourse trochantérienne
- **Face postérieure** : Muscles fessiers
- **Région inguinale** : Ganglions, hernie

## MOBILITÉ

### Amplitudes normales
- **Flexion** : 120-130° (genou fléchi)
- **Extension** : 10-30°
- **Abduction** : 45-50°
- **Adduction** : 20-30°
- **Rotation externe** : 45-60°
- **Rotation interne** : 30-40°

### Méthode d'examen
1. **Mobilité active** : Patient réalise le mouvement
2. **Mobilité passive** : Examinateur mobilise
3. **Toujours comparer** au côté controlatéral

## TESTS SPÉCIFIQUES

### Tests de conflit

**Test FADIR (Flexion-Adduction-Rotation Interne)**
- Flexion 90° + adduction + rotation interne
- (+) si douleur = conflit fémoro-acétabulaire

**Test FABER (Flexion-Abduction-Rotation Externe)**
- Position en 4 (cheville sur genou opposé)
- Pression sur le genou
- (+) si limitation ou douleur = pathologie hanche ou sacro-iliaque

### Tests d'évaluation musculaire

**Test de Thomas**
- Décubitus, flexion maximale hanche opposée
- (+) si flexum hanche testée = rétraction psoas

**Test de Ober**
- Décubitus latéral, abduction + extension
- Relâcher la jambe
- (+) si jambe reste en abduction = rétraction bandelette ilio-tibiale

**Test de Trendelenburg**
- Station unipodale 30 secondes
- (+) si chute bassin controlatéral = faiblesse moyen fessier

### Tests de longueur

**Mesure clinique**
- Distance EIAS - malléole médiale
- Différence >1 cm = significative

**Test de Galeazzi**
- Décubitus, genoux fléchis à 90°
- Comparer hauteur des genoux
- Différence = inégalité de longueur

### Tests spéciaux

**Log roll test**
- Patient allongé, rouler la jambe
- Douleur = pathologie intra-articulaire

**Test de Stinchfield**
- Élévation jambe tendue contre résistance
- (+) si douleur = pathologie intra-articulaire

**Signe de Drehmann**
- Flexion hanche → rotation externe automatique
- (+) = épiphysiolyse chez l'adolescent

## MANŒUVRES PROVOCATRICES

### Bursite trochantérienne
- Palpation directe du grand trochanter
- Douleur en décubitus latéral

### Ressaut de hanche
- Flexion-extension avec palpation
- Sensation/bruit de ressaut = coxa saltans

## EXAMEN NEUROLOGIQUE
- Réflexe rotulien (L4)
- Sensibilité face antérieure cuisse (L2-L3)
- Force psoas (L2-L3), quadriceps (L3-L4)

## DIAGNOSTIC DIFFÉRENTIEL

### Pathologies articulaires
1. **Coxarthrose**
2. **Conflit fémoro-acétabulaire**
3. **Nécrose tête fémorale**
4. **Arthrite septique**
5. **Épiphysiolyse** (adolescent)

### Pathologies périarticulaires
1. **Bursite trochantérienne**
2. **Tendinopathie psoas**
3. **Tendinopathie moyen fessier**
4. **Syndrome du piriforme**

### Pathologies projetées
- Hernie inguinale
- Pathologie lombaire (L2-L3)
- Pathologie sacro-iliaque
- Pathologie gynécologique

## RED FLAGS
- Douleur nocturne intense
- Fièvre + douleur hanche = arthrite septique
- Traumatisme + impotence = fracture
- ATCD corticothérapie = risque nécrose
- Enfant boitant = urgence (arthrite, épiphysiolyse)

## EXAMENS COMPLÉMENTAIRES

### Imagerie
- **Radiographie** : Bassin face + faux profil
- **IRM** : Gold standard pour parties molles
- **Arthro-scanner** : Labrum, cartilage

### Biologie si suspicion inflammatoire
- CRP, VS
- Ponction articulaire si épanchement

## Points clés pour l'ECOS
1. **Test de Trendelenburg** = évalue moyen fessier
2. **FADIR** = test de conflit
3. **Test de Thomas** = rétraction psoas
4. **Mesurer longueur membres** si boiterie
5. **Log roll** = test simple et sensible
6. **Enfant boitant** = toujours éliminer urgence

## Mnémotechnique
**"FABER"** (test et mouvement):
- **F**lexion
- **AB**duction
- **E**xternal
- **R**otation

**"HIP"** pour l'examen:
- **H**istoire et inspection
- **I**nvestigation (palpation, mobilité)
- **P**rovocation (tests spécifiques)
