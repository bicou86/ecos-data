# Examen clinique du coude

## Domaine
Musculosquelettique/Membre supérieur

## Description
Examen systématique du coude, articulation intermédiaire du membre supérieur permettant le positionnement de la main dans l'espace et la transmission des forces.

## Anatomie fonctionnelle
- **3 articulations** : Huméro-ulnaire, huméro-radiale, radio-ulnaire proximale
- **Stabilisateurs** : Ligament collatéral médial (LCM), ligament collatéral latéral (LCL)
- **Muscles** : Fléchisseurs (biceps, brachial), extenseur (triceps), pronateurs/supinateurs
- **Nerfs** : Ulnaire (gouttière épitrochléenne), radial, médian

## INSPECTION

### Face antérieure
- **Pli du coude** : Symétrie
- **Carrying angle** : 5-15° valgus (F>H)
- **Masses musculaires** : Biceps, brachial

### Face postérieure
- **Triangle postérieur** : Olécrane, épicondyles
- **Bourse olécrânienne** : Gonflement
- **Position spontanée** : Flexion antalgique

### Face latérale
- **Profil** : Flexum, recurvatum
- **Relief musculaire**

## PALPATION

### Points de repère osseux
1. **Épicondyle médial** (épitrochlée)
2. **Épicondyle latéral**
3. **Olécrane**
4. **Tête radiale** (pronation/supination pour la sentir)
5. **Processus coronoïde** (palpation profonde)

### Triangle de Hueter
- Épicondyle latéral - Olécrane - Épicondyle médial
- Aligné en extension
- Triangle isocèle à 90° flexion

### Structures spécifiques
- **Gouttière épitrochléenne** : Nerf ulnaire
- **Tendon bicipital** : Pli du coude
- **Tendon tricipital** : Insertion olécrane
- **Épicondyliens latéraux** : ECRB (2e radial)
- **Épitrochléens** : Fléchisseurs/pronateurs

## MOBILITÉ

### Amplitudes normales
- **Flexion** : 140-150°
- **Extension** : 0° (jusqu'à -10° hyperextension)
- **Pronation** : 80-90°
- **Supination** : 80-90°

### Méthode d'examen
- Coude au corps pour prono-supination
- Comparer au côté controlatéral
- Évaluer actif puis passif

## TESTS SPÉCIFIQUES

### Tests ligamentaires

**Test de stress en valgus (LCM)**
- Coude à 30° flexion
- Stress en valgus
- (+) si bâillement médial = lésion LCM

**Test de stress en varus (LCL)**
- Coude à 30° flexion
- Stress en varus
- (+) si bâillement latéral = lésion LCL

**Test du pivot shift**
- Extension → flexion avec valgus + supination
- (+) si appréhension/ressaut = instabilité postéro-latérale

### Tests tendineux

**ÉPICONDYLITE LATÉRALE (tennis elbow)**

**Test de Cozen**
- Extension poignet contre résistance, coude tendu
- (+) si douleur épicondyle latéral

**Test de Mill**
- Pronation + flexion poignet passive
- (+) si douleur épicondyle latéral

**Test de Maudsley**
- Extension majeur contre résistance
- (+) si douleur = épicondylite

**ÉPITROCHLÉITE MÉDIALE (golfer's elbow)**

**Test de flexion poignet**
- Flexion poignet contre résistance
- (+) si douleur épitrochlée

**Test de pronation**
- Pronation contre résistance
- (+) si douleur médiale

### Tests nerveux

**Test de Tinel ulnaire**
- Percussion gouttière épitrochléenne
- (+) si paresthésies territoire ulnaire

**Test de flexion prolongée**
- Flexion maximale 3 minutes
- (+) si paresthésies = compression ulnaire

**Test de compression radiale**
- Compression 5 cm distal épicondyle latéral
- (+) si paresthésies = syndrome tunnel radial

### Tests spéciaux

**Test de Hook (rupture biceps distal)**
- Crochet sous tendon bicipital
- Absence de tendon = rupture

**Test de la chaise**
- Soulever chaise bras tendu
- (+) si douleur = épicondylite

**Moving valgus stress test**
- Flexion/extension avec stress valgus
- (+) si douleur maximale à 70-120° = lésion LCM

## EXAMEN NEUROLOGIQUE

### Nerf ulnaire
- **Moteur** : Interosseux (écartement doigts)
- **Sensitif** : Auriculaire, ½ annulaire
- **Test** : Signe de Froment

### Nerf radial
- **Moteur** : Extension poignet/doigts
- **Sensitif** : Face dorsale 1er espace
- **Test** : Extension MCP

### Nerf médian
- **Moteur** : Pronation, flexion poignet
- **Sensitif** : Face palmaire 3,5 doigts radiaux
- **Test** : Opposition pouce

## PATHOLOGIES FRÉQUENTES

### Tendinopathies
1. **Épicondylite latérale** (tennis elbow)
2. **Épitrochléite médiale** (golfer's elbow)
3. **Tendinite bicipitale/tricipitale**

### Compression nerveuse
1. **Syndrome du tunnel cubital** (nerf ulnaire)
2. **Syndrome du tunnel radial**
3. **Syndrome du nerf interosseux postérieur**

### Instabilité
1. **Lésion LCM** (valgus répétitif)
2. **Instabilité postéro-latérale**

### Autres
1. **Arthrose**
2. **Bursite olécrânienne**
3. **Corps étrangers intra-articulaires**

## RED FLAGS
- Luxation du coude
- Fracture (supracondylienne chez l'enfant++)
- Syndrome de Volkmann (urgence)
- Arthrite septique
- Ostéochondrite disséquante (adolescent)

## EXAMENS COMPLÉMENTAIRES

### Imagerie
- **Radiographie** : Face + Profil + ¾
- **IRM** : Ligaments, tendons
- **Échographie** : Dynamique, tendons

### Autres
- **EMG** : Si compression nerveuse
- **Arthroscopie** : Diagnostic et thérapeutique

## Points clés pour l'ECOS
1. **Triangle de Hueter** = repère anatomique
2. **Test de Cozen** = épicondylite latérale
3. **Tinel ulnaire** = compression nerf ulnaire
4. **Flexion-extension + prono-supination**
5. **Carrying angle** normal 5-15° valgus
6. **Palpation tête radiale** en prono-supination

## Mnémotechnique
**"FEPS"** pour les mouvements:
- **F**lexion
- **E**xtension
- **P**ronation
- **S**upination

**"MUR"** pour les nerfs:
- **M**édian = Milieu (antérieur)
- **U**lnaire = Ulnaire (médial)
- **R**adial = Radial (latéral)
