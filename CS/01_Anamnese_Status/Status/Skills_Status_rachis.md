# Examen clinique du rachis

## Domaine
Musculosquelettique/Rachis

## Description
Examen systématique du rachis cervical, thoracique et lombaire pour identifier les pathologies mécaniques, neurologiques et les red flags nécessitant une prise en charge urgente.

## Anatomie fonctionnelle
- **Segments** : 7 cervicales, 12 thoraciques, 5 lombaires, sacrum, coccyx
- **Courbures** : Lordose cervicale et lombaire, cyphose thoracique
- **Structures** : Corps vertébraux, disques, facettes, ligaments, muscles paravertébraux

## INSPECTION

### Vue postérieure (patient debout)
- **Alignement** : Scoliose (test d'Adams)
- **Symétrie** : Épaules, scapulas, plis de taille, crêtes iliaques
- **Musculature paravertébrale**
- **Déformation** : Gibbosité

### Vue latérale
- **Courbures** : Hyperlordose, cyphose
- **Équilibre sagittal**
- **Projection C7-sacrum**

### Signes cutanés
- Cicatrices
- Angiomes, taches café-au-lait
- Touffe de poils (spina bifida)

## PALPATION

### Points de repère
- **C7** : Processus épineux proéminent
- **T3** : Niveau épine scapula
- **T7** : Pointe scapula
- **L4** : Crêtes iliaques
- **S2** : Épines iliaques postéro-supérieures

### Palpation systématique
1. **Processus épineux** : Un par un
2. **Espaces interépineux**
3. **Muscles paravertébraux** : Contracture
4. **Facettes articulaires** (2-3 cm latéral)
5. **Sacro-iliaques**

## MOBILITÉ

### Rachis cervical
- **Flexion** : 45-60° (menton-sternum)
- **Extension** : 45-75°
- **Rotation** : 60-80° chaque côté
- **Inclinaison latérale** : 45° (oreille-épaule)

### Rachis thoracique
- **Flexion** : Limitée (30°)
- **Extension** : 20-30°
- **Rotation** : 30-40°

### Rachis lombaire
- **Flexion** : 60-90° (distance doigts-sol)
- **Extension** : 20-30°
- **Inclinaison latérale** : 20-30°
- **Rotation** : 5-10° (limitée)

## TESTS SPÉCIFIQUES

### Tests de mobilité

**Test de Schober**
- Marquer L5 et 10 cm au-dessus
- Flexion maximale
- Normal : augmentation ≥5 cm
- (+) si <5 cm = raideur lombaire

**Distance doigts-sol**
- Flexion antérieure maximale
- Mesurer distance doigts-sol
- Évalue mobilité globale

**Distance occiput-mur**
- Dos au mur, talons contre mur
- Normal : occiput touche le mur
- (+) si écart = cyphose/raideur

### Tests neurologiques

**Test de Lasègue**
- Élévation jambe tendue
- (+) si douleur <60° irradiant = radiculopathie L5-S1

**Test de Bragard**
- Lasègue + dorsiflexion pied
- Augmente la tension = confirme radiculopathie

**Test de Léri (femoral stretch)**
- Décubitus ventral, extension hanche
- (+) si douleur face antérieure cuisse = L3-L4

**Test de Spurling (cervical)**
- Extension + rotation + compression
- (+) si reproduction radiculalgie = névralgie cervico-brachiale

### Tests sacro-iliaques

**FABER (Patrick)**
- Flexion-Abduction-Rotation Externe
- (+) si douleur sacro-iliaque

**Test de Gaenslen**
- Hanche en hyperextension
- (+) si douleur sacro-iliaque

**Test de compression/distraction**
- Compression/écartement des ailes iliaques
- (+) si douleur = sacro-iliite

### Tests d'instabilité

**Test de Beighton (hyperlaxité)**
- 5 critères, score /9
- ≥4/9 = hyperlaxité

## EXAMEN NEUROLOGIQUE

### Réflexes
- **C5-C6** : Bicipital
- **C6-C7** : Stylo-radial
- **C7** : Tricipital
- **L4** : Rotulien
- **S1** : Achilléen

### Sensibilité (dermatomes)
- **C5** : Deltoïde
- **C6** : Pouce
- **C7** : Majeur
- **C8** : Auriculaire
- **L3** : Face interne genou
- **L4** : Face interne jambe
- **L5** : Dos du pied
- **S1** : Bord externe pied

### Force musculaire
- **C5** : Abduction épaule
- **C6** : Flexion coude
- **C7** : Extension coude
- **C8** : Flexion doigts
- **L2** : Flexion hanche
- **L3** : Extension genou
- **L4** : Dorsiflexion cheville
- **L5** : Extension gros orteil
- **S1** : Flexion plantaire

## RED FLAGS (drapeaux rouges)

### Urgences absolues
1. **Syndrome de la queue de cheval**
   - Anesthésie en selle
   - Troubles sphinctériens
   - Déficit moteur bilatéral

2. **Compression médullaire**
   - Déficit moteur progressif
   - Troubles de la marche
   - Hyperréflexie, Babinski

### Red flags à rechercher
- Âge <20 ans ou >50 ans (première lombalgie)
- Traumatisme
- Fièvre, frissons
- Perte de poids inexpliquée
- ATCD de cancer
- Douleur nocturne, au repos
- Immunosuppression
- Corticothérapie prolongée
- Déficit neurologique progressif

## YELLOW FLAGS (facteurs psychosociaux)
- Catastrophisme
- Peur-évitement
- Dépression, anxiété
- Insatisfaction au travail
- Litige en cours

## PATHOLOGIES FRÉQUENTES

### Rachis cervical
- Cervicalgie commune
- Névralgie cervico-brachiale
- Myélopathie cervicarthrosique
- Torticolis

### Rachis lombaire
- Lombalgie commune
- Hernie discale
- Canal lombaire étroit
- Spondylolisthésis
- Lombosciatique

## Points clés pour l'ECOS
1. **Toujours rechercher les red flags**
2. **Examen neurologique systématique**
3. **Test de Lasègue** pour lombosciatique
4. **Test de Schober** pour mobilité lombaire
5. **Syndrome queue de cheval** = urgence chirurgicale
6. **Yellow flags** = risque de chronicisation

## Mnémotechnique
**"RED FLAGS"** à rechercher:
- **R**écent trauma
- **E**xtrêmes d'âge
- **D**éficit neurologique

- **F**ièvre
- **L**oss of weight (perte de poids)
- **A**TCD cancer
- **G**rave douleur nocturne
- **S**phincter (troubles)
