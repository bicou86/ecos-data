# Examen clinique de la main et du poignet

## Domaine
Musculosquelettique/Membre supérieur

## Description
Examen systématique de la main et du poignet, structures complexes essentielles pour la fonction et nécessitant une évaluation précise des structures osseuses, tendineuses et nerveuses.

## Anatomie fonctionnelle
- **Os** : 8 os du carpe, 5 métacarpes, 14 phalanges
- **Articulations** : Radio-carpienne, médio-carpienne, carpo-métacarpiennes, MCP, IPP, IPD
- **Nerfs** : Médian, ulnaire, radial
- **Tendons** : Fléchisseurs (FCS, FCP), extenseurs (6 compartiments)

## INSPECTION

### Position de repos
- **Position fonctionnelle** : Légère flexion du poignet, cascade des doigts
- **Déformations** :
  - Swan neck (IPP hyperextension + IPD flexion)
  - Boutonnière (IPP flexion + IPD hyperextension)
  - Maillet (IPD flexion)
  - Déviation ulnaire (PR)

### Signes à rechercher
- **Amyotrophie** : Éminences thénar/hypothénar, 1er espace interosseux
- **Nodules** : Heberden (IPD), Bouchard (IPP), Dupuytren
- **Gonflement** : Synovite, ténosynovite
- **Coloration** : Cyanose, érythème

## PALPATION

### Points de repère osseux
1. **Tabatière anatomique** : Scaphoïde
2. **Processus styloïde radial**
3. **Processus styloïde ulnaire**
4. **Pisiforme**
5. **Hamatum** (crochet)
6. **Base métacarpes**

### Structures spécifiques
- **Canal carpien** : Compression médiane poignet
- **Canal de Guyon** : Face ulnaire poignet
- **Compartiments extenseurs** : 6 loges dorsales
- **Poulies des fléchisseurs** : A1 (trigger finger)

## MOBILITÉ

### Poignet
- **Flexion** : 80-90°
- **Extension** : 70-80°
- **Inclinaison radiale** : 20°
- **Inclinaison ulnaire** : 30-45°

### Doigts
- **MCP flexion** : 90°
- **IPP flexion** : 100-110°
- **IPD flexion** : 60-90°
- **Extension complète** : 0°

### Pouce
- **Opposition** : Pulpe pouce-auriculaire
- **Abduction** : 45-60°
- **Flexion/Extension** MCP et IP

## TESTS SPÉCIFIQUES

### Tests nerveux

**NERF MÉDIAN**

**Test de Phalen**
- Flexion maximale poignets 60 secondes
- (+) si paresthésies territoire médian = canal carpien

**Test de Tinel**
- Percussion canal carpien
- (+) si paresthésies = syndrome canal carpien

**Test de Durkan**
- Compression directe canal carpien 30 secondes
- (+) si paresthésies

**NERF ULNAIRE**

**Test de Froment**
- Tenir papier entre pouce et index
- (+) si flexion IP pouce = paralysie adducteur pouce

**Signe de Wartenberg**
- Écartement permanent auriculaire
- (+) = atteinte ulnaire

**Test de Allen**
- Compression radiale + ulnaire, ouverture main
- Relâcher une artère
- Recoloration >5 sec = anomalie vasculaire

### Tests tendineux

**Test de Finkelstein**
- Poing fermé sur pouce + inclinaison ulnaire
- (+) si douleur = ténosynovite De Quervain

**Test d'Eichhoff**
- Variante du Finkelstein
- Pouce dans poing + déviation ulnaire

### Tests ligamentaires

**Test de Watson (scapho-lunaire)**
- Pression scaphoïde + mouvement poignet
- (+) si ressaut = instabilité scapho-lunaire

**Test de Kleinman (luno-triquétral)**
- Ballottement luno-triquétral
- (+) si douleur/instabilité

**Piano key test**
- Mobilisation tête ulnaire
- (+) si touche de piano = instabilité radio-ulnaire distale

### Tests spéciaux

**Test de la tabatière anatomique**
- Palpation + compression axiale pouce
- (+) si douleur = fracture scaphoïde

**Test de charge axiale**
- Compression dans l'axe du doigt
- (+) si douleur = fracture/arthrose

## EXAMEN NEUROLOGIQUE DÉTAILLÉ

### Territoire sensitif
- **Médian** : Face palmaire pouce, index, majeur, ½ annulaire
- **Ulnaire** : Auriculaire, ½ annulaire
- **Radial** : Face dorsale 1er espace, tabatière

### Fonction motrice
- **Médian** : Opposition pouce, flexion IPP index-majeur
- **Ulnaire** : Écartement doigts, adduction pouce
- **Radial** : Extension poignet et MCP

### Tests de discrimination
- **Weber** : Discrimination 2 points (normal <6mm pulpe)
- **Monofilaments** : Sensibilité fine

## FONCTION GLOBALE

### Préhension
- **Pince terminale** : Pouce-index bout à bout
- **Pince subterminale** : Pouce-index pulpe
- **Pince latérale** : Pouce-côté index
- **Prise palmaire** : Force de serrage
- **Prise sphérique** : Tenir une balle

### Scores fonctionnels
- **DASH** (Disability Arm Shoulder Hand)
- **Quick DASH** : Version courte
- **Force de préhension** : Dynamomètre

## PATHOLOGIES FRÉQUENTES

### Compression nerveuse
1. **Syndrome canal carpien** (médian)
2. **Syndrome canal de Guyon** (ulnaire)
3. **Syndrome du nerf interosseux**

### Tendinopathies
1. **Ténosynovite De Quervain**
2. **Trigger finger** (doigt à ressaut)
3. **Ténosynovite des fléchisseurs**

### Arthropathies
1. **Rhizarthrose** (trapézo-métacarpienne)
2. **Arthrose IPD** (Heberden)
3. **Polyarthrite rhumatoïde**

### Autres
1. **Maladie de Dupuytren**
2. **Kyste synovial**
3. **Fracture scaphoïde**

## RED FLAGS
- Perte de fonction brutale
- Plaie avec section tendineuse/nerveuse
- Infection (panaris, phlegmon)
- Syndrome de loge
- Ischémie digitale

## Points clés pour l'ECOS
1. **Test de Phalen et Tinel** pour canal carpien
2. **Test de Finkelstein** pour De Quervain
3. **Tester les 3 nerfs** (médian, ulnaire, radial)
4. **Palpation tabatière** si trauma
5. **Fonction globale** : Types de préhension
6. **Toujours comparer** au côté controlatéral

## Mnémotechnique
**"MITT"** pour les nerfs:
- **M**édian = **M**ilieu (2,5 doigts radiaux)
- **I**nterosseux = écartement doigts
- **T**hénar = médian (opposition)
- **T**wo = ulnaire (2 doigts ulnaires)
