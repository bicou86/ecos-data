# Examen clinique de l'épaule

## Domaine
Musculosquelettique/Membre supérieur

## Description
Examen systématique de l'épaule incluant inspection, palpation, mobilité et tests spécifiques pour identifier les pathologies de la coiffe des rotateurs, de l'articulation et des structures périarticulaires.

## Anatomie fonctionnelle
- **Articulations** : Gléno-humérale, acromio-claviculaire, sterno-claviculaire, scapulo-thoracique
- **Coiffe des rotateurs** : Supra-épineux, infra-épineux, petit rond, subscapulaire
- **Autres muscles** : Deltoïde, biceps (longue portion), trapèze

## INSPECTION

### Face antérieure
- Asymétrie, déformation
- Amyotrophie deltoïdienne (nerf axillaire)
- Position de la tête humérale
- Sillon delto-pectoral

### Face postérieure
- Amyotrophie fosses supra/infra-épineuses
- Position de la scapula (décollement)
- Asymétrie des reliefs

### Face latérale
- Comblement du sillon sous-acromial
- Relief deltoïdien

## PALPATION

### Points de repère osseux
1. **Clavicule** : Sur toute sa longueur
2. **Articulation acromio-claviculaire**
3. **Acromion**
4. **Grande tubérosité** (trochiter)
5. **Processus coracoïde** (sous clavicule, latéral)
6. **Articulation sterno-claviculaire**

### Structures tendineuses
- **Supra-épineux** : Sous l'acromion antérieur
- **Infra-épineux** : Face postérieure
- **Long biceps** : Gouttière bicipitale
- **Subscapulaire** : Rotation interne pour accès

## MOBILITÉ

### Mobilité active
Observer le patient réaliser les mouvements

### Mobilité passive
Comparer avec le côté controlatéral

### Amplitudes normales
- **Flexion** : 180°
- **Extension** : 45-60°
- **Abduction** : 180°
- **Adduction** : 30-45°
- **Rotation externe** (RE1 coude au corps) : 60°
- **Rotation externe** (RE2 à 90° d'abduction) : 90°
- **Rotation interne** : Main jusqu'à T7-T8

### Rythme scapulo-huméral
- 2:1 après 30° d'abduction
- Observer la synchronisation

## TESTS SPÉCIFIQUES

### Tests de conflit
**Test de Neer**
- Flexion passive maximale, omoplate fixée
- (+) si douleur = conflit sous-acromial

**Test de Hawkins**
- Flexion 90°, rotation interne passive
- (+) si douleur = conflit sous-acromial

**Test de Yocum**
- Main sur épaule opposée, élévation du coude
- (+) si douleur = conflit

### Tests de la coiffe

**Test de Jobe (supra-épineux)**
- Abduction 90°, antépulsion 30°, pouces vers le bas
- Résistance à l'élévation
- (+) si faiblesse ou douleur

**Test de Patte (infra-épineux)**
- Coude à 90°, RE2 contre résistance
- (+) si faiblesse = rupture infra-épineux

**Test de Gerber (subscapulaire)**
- Main dans le dos, décoller contre résistance
- (+) si impossible = rupture subscapulaire

**Belly-Press test (subscapulaire)**
- Main sur ventre, coude en avant
- (+) si coude recule = atteinte subscapulaire

### Tests du biceps

**Test de Speed (palm-up)**
- Flexion contre résistance, coude tendu, supination
- (+) si douleur gouttière = tendinite biceps

**Test de Yergason**
- Coude 90°, supination contre résistance
- (+) si douleur ou ressaut = pathologie biceps

### Tests de stabilité

**Test d'appréhension antérieure**
- RE2 maximale
- (+) si appréhension = instabilité antérieure

**Test de relocation**
- Idem + pression postéro-antérieure
- Soulagement = confirme instabilité

**Sulcus sign**
- Traction caudale du bras
- Sillon sous-acromial = laxité inférieure

### Tests de l'articulation AC

**Cross-arm test**
- Adduction horizontale maximale
- (+) si douleur AC = arthropathie AC

**Test de O'Brien**
- Flexion 90°, adduction 10°, pronation
- Résistance vers le bas
- (+) si douleur AC ou profonde (SLAP)

## EXAMEN NEUROLOGIQUE

### Sensibilité
- C5 : Face latérale bras (deltoïde)
- C6 : Face latérale avant-bras
- C7 : Majeur
- C8 : Face médiale avant-bras

### Motricité
- C5 : Abduction (deltoïde)
- C6 : Flexion coude (biceps)
- C7 : Extension coude (triceps)
- C8 : Flexion doigts

### Réflexes
- Bicipital (C5-C6)
- Tricipital (C7)

## DIAGNOSTIC DIFFÉRENTIEL

### Pathologies fréquentes
1. **Conflit sous-acromial/tendinopathie**
2. **Rupture de coiffe**
3. **Capsulite rétractile**
4. **Arthrose AC ou gléno-humérale**
5. **Instabilité**
6. **Tendinite calcifiante**

### Red flags
- Luxation non réduite
- Fracture
- Infection
- Tumeur
- Douleur d'origine cervicale ou cardiaque

## Points clés pour l'ECOS
1. **Toujours comparer au côté sain**
2. **Inspection des 3 faces**
3. **Tester mobilité active puis passive**
4. **Au minimum 3 tests de coiffe** (Jobe, Patte, Gerber)
5. **Un test de conflit** (Neer ou Hawkins)
6. **Éliminer origine cervicale** (mobilité cervicale, Spurling)
