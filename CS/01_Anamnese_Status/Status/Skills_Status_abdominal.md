# Examen clinique abdominal

## Domaine
Gastroentérologie/Médecine interne

## Description
Examen systématique de l'abdomen suivant la séquence inspection-auscultation-percussion-palpation, permettant l'évaluation des organes abdominaux et la détection des pathologies digestives.

## Anatomie topographique

### 9 régions abdominales
```
Hypochondre D | Épigastre | Hypochondre G
Flanc D       | Ombilical | Flanc G  
Fosse iliaque D | Hypogastre | Fosse iliaque G
```

### 4 quadrants
- Quadrant supérieur droit (QSD)
- Quadrant supérieur gauche (QSG)
- Quadrant inférieur droit (QID)
- Quadrant inférieur gauche (QIG)

## PRÉPARATION
- Patient en décubitus dorsal
- Vessie vide idéalement
- Genoux légèrement fléchis (relâchement paroi)
- Bras le long du corps
- Environnement calme et chaud
- Mains de l'examinateur réchauffées

## 1. INSPECTION

### Observation générale
- **Position** : Antalgique? Genoux fléchis?
- **Faciès** : Douloureux, ictérique
- **Respiration** : Abdominale normale ou thoracique (péritonite)

### Inspection abdominale
- **Forme** :
  - Plat, distendu, excavé
  - Symétrique ou asymétrique
  - Ventre de batracien (ascite)
- **Cicatrices** : Localisation, aspect (chirurgies antérieures)
- **Peau** :
  - Vergetures
  - Circulation collatérale (HTP)
  - Ecchymoses (Cullen, Grey Turner)
  - Éruptions, lésions
- **Ombilic** :
  - Éversé (ascite, masse)
  - Nodule de Sister Mary Joseph (métastase)
- **Mouvements** :
  - Péristaltisme visible (occlusion)
  - Pulsations (anévrisme aortique)
- **Hernies** : Ombilicale, inguinale, incisionnelle

## 2. AUSCULTATION (avant palpation!)

### Bruits hydro-aériques (BHA)
- **Normal** : 5-35/minute, gargouillements
- **Augmentés** : Hyperactifs, métalliques (occlusion haute)
- **Diminués** : < 5/min (iléus débutant)
- **Absents** : Silence > 2 min (iléus paralytique, péritonite)

### Souffles vasculaires
- **Aorte** : Épigastre (sténose, anévrisme)
- **Artères rénales** : Flancs (sténose)
- **Artères iliaques** : Fosses iliaques
- **Artères hépatiques** : HCD (CHC, hémangiome)

### Frottements
- Péri-hépatique (périhépatite)
- Péri-splénique (périsplénite, infarctus)

## 3. PERCUSSION

### Technique
- Percussion médiate systématique
- Commencer par zones non douloureuses
- Comparer les quadrants symétriques

### Sons normaux
- **Tympanisme** : Zones gazeuses (estomac, côlon)
- **Matité** : Organes pleins (foie, rate), masses, globe vésical

### Limites d'organes

#### Foie
- **Bord supérieur** : 5-6e EIC ligne médio-claviculaire
- **Bord inférieur** : Rebord costal droit
- **Flèche hépatique** : 10-12 cm (ligne médio-claviculaire)

#### Rate
- **Espace de Traube** : Tympanique normalement
- **Matité** si splénomégalie > 2x normale

### Recherche d'ascite
- **Matité déclive** : Mobile avec changement de position
- **Matité concave** vers le haut
- **Cercle de Skoda** : Tympanisme péri-ombilical

## 4. PALPATION

### Palpation superficielle
- **Technique** : Main à plat, mouvements circulaires doux
- **Rechercher** :
  - Zones douloureuses (commencer à distance)
  - Défense (contraction volontaire)
  - Contracture (contraction involontaire = péritonite)
  - Hyperesthésie cutanée

### Palpation profonde
- **Technique** : 2 mains superposées, enfoncement progressif
- **Systématique** : 9 régions ou 4 quadrants
- **Rechercher** :
  - Masses (localisation, taille, consistance, mobilité)
  - Organomégalie
  - Douleur profonde

### Palpation des organes

#### Foie
- **Technique de Chauffard** : Main sous rebord costal, inspiration profonde
- **Normal** : Bord inférieur lisse, régulier, indolore
- **Pathologique** : Hépatomégalie, bord dur/irrégulier, nodules

#### Rate
- **Position** : Décubitus dorsal ou latéral droit
- **Technique** : Main depuis FIG vers HCG
- **Normal** : Non palpable
- **Pathologique** : Pole inférieur palpable = splénomégalie

#### Reins
- **Technique** : Ballottement bimanuel (Guyon)
- **Normal** : Non palpables (sauf rein droit chez sujet mince)

#### Vessie
- **Globe vésical** : Matité sus-pubienne, masse rénitente

#### Aorte
- **Palpation** : Épigastre, largeur < 3 cm
- **Pulsatile** ET expansive = anévrisme

## SIGNES SPÉCIFIQUES

### Appendicite
- **Point de McBurney** : 1/3 externe ligne ombilic-EIAS droite
- **Signe de Rovsing** : Douleur FID à la pression FIG
- **Signe du psoas** : Douleur extension hanche droite
- **Signe de l'obturateur** : Douleur rotation interne hanche

### Cholécystite
- **Signe de Murphy** : Arrêt inspiratoire à la palpation HCD
- **Défense HCD**

### Péritonite
- **Contracture abdominale** : Ventre de bois
- **Signe de Blumberg** : Douleur au rebond
- **Disparition matité pré-hépatique** : Pneumopéritoine

### Occlusion
- **Distension** : Symétrique (grêle) ou asymétrique (côlon)
- **Ondulations péristaltiques** visibles
- **BHA métalliques** puis silence

### Ascite
- **Signe du flot** : Onde liquidienne transmise
- **Signe du glaçon** : Rebond hépatique
- **Matité déclive** mobile

### Pancréatite
- **Signe de Cullen** : Ecchymose péri-ombilicale
- **Signe de Grey Turner** : Ecchymoses des flancs
- **Défense épigastrique**

## EXAMENS COMPLÉMENTAIRES

### Toucher rectal (systématique si douleur abdominale)
- Masses rectales
- Sang (méléna, rectorragie)
- Douleur cul-de-sac Douglas
- Prostate chez l'homme

### Toucher vaginal (si indication)
- Douleur mobilisation utérine
- Masses annexielles
- Cul-de-sac de Douglas

### Orifices herniaires
- Région inguinale
- Région crurale
- Ombilic
- Cicatrices

## RED FLAGS ABDOMINAUX

### Urgences chirurgicales
- Contracture généralisée (péritonite)
- Défense + fièvre + douleur intense
- Silence auscultatoire complet
- Choc + douleur abdominale
- Masse pulsatile expansive

### Signes de gravité
- Instabilité hémodynamique
- Fièvre > 39°C
- Ictère + douleur + fièvre (angiocholite)
- Hématémèse massive
- Méléna avec choc

## DIAGNOSTICS DIFFÉRENTIELS PAR QUADRANT

### HCD (Hypochondre droit)
- Cholécystite, colique hépatique
- Hépatite, abcès hépatique
- Ulcère duodénal
- Pyélonéphrite droite
- Pneumonie basale droite

### Épigastre
- Ulcère gastro-duodénal
- Pancréatite
- Reflux gastro-œsophagien
- Infarctus du myocarde (piège!)

### HCG (Hypochondre gauche)
- Pathologie splénique
- Pancréatite (queue)
- Pathologie colique (angle)
- Pyélonéphrite gauche

### FID (Fosse iliaque droite)
- Appendicite
- Iléite terminale (Crohn)
- Annexite, GEU, kyste ovarien
- Colique néphrétique

### FIG (Fosse iliaque gauche)
- Diverticulite sigmoidienne
- Colite
- Annexite, GEU, kyste ovarien
- Colique néphrétique

### Péri-ombilical
- Gastro-entérite
- Occlusion grêle
- Ischémie mésentérique
- Anévrisme aortique

## Points clés pour l'ECOS
1. **Ordre** : Inspection → Auscultation → Percussion → Palpation
2. **Auscultation avant palpation** (ne pas modifier les BHA)
3. **Commencer à distance** de la zone douloureuse
4. **Palpation superficielle puis profonde**
5. **Rechercher signes spécifiques** selon contexte
6. **Toucher rectal** si douleur abdominale
7. **Examiner orifices herniaires**
