# Examen dermatologique

## Domaine
Dermatologie

## Description
Examen systématique de la peau, des phanères et des muqueuses permettant la description précise des lésions cutanées et l'orientation diagnostique.

## PRINCIPES GÉNÉRAUX

### Conditions d'examen
- **Éclairage** : Lumière naturelle idéalement
- **Température** : Pièce chaude (éviter frissons)
- **Patient** : Déshabillé complètement
- **Pudeur** : Respecter, examiner par zones
- **Matériel** : Gants, loupe, dermoscope, lampe de Wood

### Examen complet
- **Peau** : Totalité incluant plis, cuir chevelu
- **Muqueuses** : Buccale, génitale, conjonctive
- **Phanères** : Cheveux, ongles
- **Ganglions** : Aires de drainage

## ANAMNÈSE DERMATOLOGIQUE

### Histoire de la lésion
- **Début** : Date précise, circonstances
- **Mode d'apparition** : Brutal/progressif
- **Évolution** : Extension, régression, récurrence
- **Symptômes** :
  - Prurit (horaire, intensité)
  - Douleur
  - Brûlure
  - Paresthésies

### Facteurs déclenchants/aggravants
- **Exposition solaire** (photosensibilité)
- **Contact** : Produits, métaux, cosmétiques
- **Médicaments** : Nouveaux, modifications
- **Aliments**
- **Stress**
- **Menstruations**
- **Température** : Chaud/froid

### Antécédents
- **Dermatologiques** :
  - Eczéma, psoriasis
  - Mélanome, cancers cutanés
  - Allergies cutanées
- **Généraux** :
  - Atopie (asthme, rhinite)
  - Maladies auto-immunes
  - Immunosuppression
  - Diabète
- **Familiaux** :
  - Psoriasis, eczéma
  - Mélanome
  - Génodermatoses

### Mode de vie
- **Profession** : Expositions professionnelles
- **Loisirs** : Jardinage, bricolage, animaux
- **Voyages** : Zones tropicales
- **Habitudes** : Cosmétiques, hygiène
- **Expositions solaires** : UV, cabines

## INSPECTION - ANALYSE SÉMIOLOGIQUE

### 1. LÉSIONS ÉLÉMENTAIRES

#### Lésions primaires (peau saine)

**Macule** : Tache plane
- Érythémateuse : Inflammatoire
- Pigmentée : Mélanine (café-au-lait)
- Achromique : Vitiligo
- Purpurique : Extravasation (ne s'efface pas à la vitropression)

**Papule** : Élevure < 1 cm
- Épidermique : Verrue
- Dermique : Naevus
- Dermo-épidermique : Lichen plan

**Nodule** : Élevure > 1 cm
- Profond, palpable
- Dermo-hypodermique

**Vésicule** : Collection liquidienne claire < 5 mm
- Intra-épidermique : Eczéma
- Sous-épidermique : Pemphigoïde

**Bulle** : Collection liquidienne > 5 mm
- Tendue ou flasque
- Claire ou hémorragique

**Pustule** : Collection purulente
- Folliculaire : Centrée par un poil
- Non folliculaire

**Wheal** (papule œdémateuse)
- Urticaire : Fugace, prurigineuse

#### Lésions secondaires (transformation)

**Squame** : Desquamation anormale
- Fine : Pityriasis
- Épaisse : Psoriasis
- Grasse : Dermite séborrhéique

**Croûte** : Coagulation d'exsudat
- Jaunâtre : Séreuse
- Brunâtre : Hémorragique
- Mélicérique : Impétigo

**Érosion** : Perte de substance superficielle
- Épidermique
- Post-vésiculeuse

**Ulcération** : Perte de substance profonde
- Atteint le derme
- Cicatrice séquellaire

**Fissure** : Solution de continuité linéaire

**Lichénification** : Épaississement avec accentuation des plis

**Atrophie** : Amincissement cutané

**Cicatrice** : Tissu fibreux de réparation
- Hypertrophique
- Chéloïde
- Atrophique

### 2. CONFIGURATION DES LÉSIONS

#### Disposition
- **Localisée** : Une région
- **Disséminée** : Multiple, dispersée
- **Généralisée** : Tout le corps
- **Universelle** : 100% surface

#### Arrangement
- **Linéaire** : Phénomène de Koebner, dermatose artificielle
- **Annulaire** : Centre plus clair
- **Arciforme** : En arc
- **Serpigineux** : Sinueux
- **Réticulé** : En réseau
- **Groupé** : Herpétiforme
- **Zoostériforme** : Métamérique (zona)
- **En gouttes** : Psoriasis guttata

#### Distribution
- **Symétrique** : Psoriasis, eczéma
- **Asymétrique** : Zona, contact
- **Photo-distribuée** : Zones exposées
- **Photo-protégée** : Zones couvertes
- **Inversée** : Plis (psoriasis inversé)
- **Séborrhéique** : Zones riches en sébum

### 3. LOCALISATION

#### Sites particuliers à examiner
- **Cuir chevelu** : Alopécie, squames
- **Oreilles** : Psoriasis, eczéma
- **Paupières** : Dermite
- **Plis** : Intertrigo, psoriasis inversé
- **Paumes/plantes** : Kératodermie, eczéma
- **Ongles** : Psoriasis, mycose
- **Muqueuses** : Lichen, aphtes
- **Organes génitaux** : IST, lichen

## PALPATION

### Texture
- **Lisse/rugueuse**
- **Molle/dure**
- **Infiltrée** : Épaississement
- **Scléreuse** : Morphée

### Température
- **Chaude** : Inflammation, infection
- **Froide** : Vasculaire

### Sensibilité
- **Douloureuse** : Infection, ischémie
- **Indolore** : Tumeur
- **Anesthésique** : Lèpre

### Mobilité
- **Mobile** : Sur plans profonds
- **Adhérente** : Infiltration

### Consistance
- **Rénitente** : Kyste
- **Fluctuante** : Abcès
- **Pierreuse** : Carcinome

## EXAMENS COMPLÉMENTAIRES

### Lampe de Wood (UV 365 nm)
- **Fluorescence verte** : Teigne (Microsporum)
- **Fluorescence corail** : Érythrasma
- **Accentuation** : Vitiligo, mélasma
- **Porphyrines** : Fluorescence rouge

### Dermoscopie
- **Naevus** : Réseau pigmentaire, globules
- **Mélanome** : Asymétrie, réseau atypique
- **Carcinome basocellulaire** : Télangiectasies arborisées
- **Kératose séborrhéique** : Pseudo-kystes cornés
- **Gale** : Sillon avec sarcopte

### Vitropression
- **Purpura** : Ne s'efface pas
- **Érythème** : S'efface
- **Lupus** : Grain lupoïde (jaunâtre)

### Tests cutanés
- **Patch tests** : Allergie de contact
- **Prick tests** : Allergie immédiate
- **Photopatch** : Photoallergie
- **IDR** : Intradermo-réaction

### Prélèvements
- **Mycologique** : Squames, cheveux, ongles
- **Bactériologique** : Pustule, ulcère
- **Virologique** : Vésicule (HSV, VZV)
- **Parasitologique** : Gale (dermoscope)
- **Cytodiagnostic** : Tzanck

### Biopsie cutanée
- **Indications** :
  - Tumeur suspecte
  - Dermatose inflammatoire atypique
  - Vascularite
  - Panniculite
- **Types** :
  - Punch biopsie (3-6 mm)
  - Biopsie-exérèse
  - Shave biopsie
- **Examens** :
  - Histologie standard
  - Immunofluorescence directe
  - Culture (mycobactéries)

## DESCRIPTION TYPE D'UNE LÉSION

### Formule descriptive
"[Type de lésion] [couleur] de [taille], [forme], [surface], [disposition], localisée au niveau de [site anatomique], [évolution]"

### Exemple
"Plaque érythémato-squameuse de 5 cm, arrondie, bien limitée, à squames argentées, localisée au coude droit, évoluant depuis 3 mois"

## SIGNES DERMATOLOGIQUES SPÉCIFIQUES

### Signes pathognomoniques
- **Signe de Nikolsky** : Décollement bulleux (pemphigus)
- **Signe de la rosée sanglante** : Psoriasis (grattage)
- **Phénomène de Koebner** : Lésions sur traumatisme
- **Signe du chandelier** : Kératose séborrhéique
- **Dermographisme** : Urticaire factice

### Patterns diagnostiques
- **Pityriasis rosé** : Médaillon initial + éruption
- **Érythème migrant** : Lyme
- **Héliotrope** : Dermatomyosite
- **Papules de Gottron** : Dermatomyosite
- **Lupus discoïde** : Cicatrices atrophiques

## URGENCES DERMATOLOGIQUES

### À reconnaître immédiatement
- **Érythrodermie** : > 90% surface
- **Stevens-Johnson/Lyell** : Décollement
- **DRESS** : Éruption + éosinophilie + atteinte viscérale
- **Pustulose exanthématique** : Pustules + fièvre
- **Érysipèle/cellulite** : Urgence infectieuse
- **Purpura fulminans** : Méningococcémie
- **Nécrose cutanée** : Anticoagulants, emboles

## PARASITOSES CUTANÉES

### Gale (Sarcoptes scabiei)
- **Prurit nocturne familial**
- **Sillons** : Espaces interdigitaux
- **Vésicules perlées**
- **Nodules scabieux** : Organes génitaux
- **Respect visage** (sauf nourrisson)

### Pédiculoses
- **Poux de tête** : Prurit, lentes
- **Poux de corps** : SDF, lésions grattage
- **Poux pubiens** : Prurit génital

### Punaises de lit
- **Piqûres groupées/linéaires**
- **Prurit matinal**
- **Diagnostic** : Inspection literie

## Points clés pour l'ECOS
1. **Déshabiller complètement** le patient
2. **Décrire précisément** : Type, couleur, taille, distribution
3. **Utiliser terminologie** dermatologique correcte
4. **Examiner** cuir chevelu, plis, ongles, muqueuses
5. **Penser dermoscopie** si lésion pigmentée
6. **Photos** avec consentement si suivi
7. **Red flags** : Érythrodermie, décollement, purpura

## Mnémotechniques

**"ABCDE" du mélanome**:
- **A**symétrie
- **B**ords irréguliers
- **C**ouleur hétérogène
- **D**iamètre > 6mm
- **E**volution

**"SCALP" pour cuir chevelu**:

- **A**lopécie
- **L**ésions
- **P**rurit
