# Examen clinique général

## Domaine
Médecine générale

## Description
Guide systématique pour la réalisation d'un examen clinique complet, méthodique et orienté permettant d'objectiver les signes cliniques et d'orienter le diagnostic.

## PRINCIPES GÉNÉRAUX

### Préparation
- **Environnement** : Éclairage adéquat, température confortable
- **Matériel** : Stéthoscope, tensiomètre, thermomètre, marteau réflexe, lampe
- **Hygiène** : Lavage mains, matériel propre
- **Patient** : Information, consentement, installation confortable
- **Pudeur** : Respect, découvrir progressivement

### Approche systématique
- **Ordre** : Céphalocaudal ou par systèmes
- **Symétrie** : Toujours comparer côté droit/gauche
- **Séquence** : Inspection → Palpation → Percussion → Auscultation
- **Documentation** : Noter tous les éléments pertinents
- **Normal** : Décrire aussi les éléments normaux

## EXAMEN GÉNÉRAL

### État général
- **Apparence** : Âge apparent vs réel
- **État nutritionnel** : Poids, taille, IMC, périmètre abdominal
- **Hydratation** : Pli cutané, muqueuses
- **Conscience** : Vigile, confus, somnolent (Glasgow si altéré)
- **Coopération** : Bon contact, opposant, agité

### Constantes vitales

#### Signes vitaux de base
- **Température** : 
  - Normale : 36.5-37.5°C
  - Méthode : Auriculaire, axillaire, rectale
- **Fréquence cardiaque** :
  - Normale : 60-100/min
  - Régularité, amplitude
- **Pression artérielle** :
  - Normale : < 140/90 mmHg
  - Deux bras, orthostatisme si indiqué
- **Fréquence respiratoire** :
  - Normale : 12-20/min
  - Régularité, amplitude

#### Signes vitaux additionnels
- **Saturation O2** : Normale > 95% air ambiant
- **Douleur** : EVA 0-10
- **Glycémie capillaire** : Si indiquée
- **Périmètre abdominal** : < 94 cm (H), < 80 cm (F)

### Faciès et aspect général

#### Faciès pathologiques
- **Cushingoïde** : Rond, rouge, acné
- **Myxœdémateux** : Bouffi, infiltré
- **Acromégale** : Prognathe, traits épaissis
- **Parkinsonien** : Figé, amimique
- **Myopathique** : Ptosis, bouche ouverte

#### Coloration
- **Pâleur** : Anémie (conjonctives++)
- **Cyanose** : Centrale (lèvres) vs périphérique
- **Ictère** : Sclérotique, peau
- **Érythrose** : Polyglobulie, alcool
- **Mélanodermie** : Addison, hémochromatose

### Position et mobilité
- **Posture** : Antalgique, orthopnée
- **Démarche** : Symétrique, périmètre marche
- **Équilibre** : Station debout, Romberg
- **Transferts** : Assis-debout, autonomie

## EXAMEN TÊTE ET COU

### Crâne et cuir chevelu
- **Inspection** : Forme, symétrie, cicatrices
- **Palpation** : Masses, points douloureux
- **Cheveux** : Implantation, alopécie, état

### Yeux
- **Paupières** : Œdème, ptosis, xanthélasma
- **Conjonctives** : Couleur (anémie), injection
- **Sclérotiques** : Ictère, hémorragie
- **Pupilles** : Taille, symétrie, réflexes (photomoteur, consensuel)
- **Mouvements oculaires** : 6 directions, nystagmus
- **Acuité visuelle** : Grossière (compter doigts)

### Oreilles
- **Pavillon** : Forme, implantation
- **Conduit auditif** : Écoulement, cérumen
- **Tympan** : Si otoscope disponible
- **Audition** : Test voix chuchotée, Weber, Rinne
- **Mastoïde** : Douleur à la pression

### Nez et sinus
- **Forme** : Déviation, obstruction
- **Narines** : Écoulement, épistaxis
- **Sinus** : Douleur à la pression (frontal, maxillaire)

### Bouche et gorge
- **Lèvres** : Couleur, lésions, chéilite
- **Muqueuse buccale** : Ulcérations, leucoplasie
- **Langue** : Couleur, enduit, mobilité, trophicité
- **Dents** : État, nombre, prothèses
- **Gencives** : Inflammation, saignement
- **Pharynx** : Érythème, exsudat, amygdales
- **Haleine** : Fœtor (hépatique, urémique, acétonique)

### Cou

#### Inspection
- **Forme** : Court, long, goitre
- **Veines jugulaires** : Turgescence, reflux
- **Battements** : Carotidiens visibles
- **Masses** : Asymétrie

#### Palpation
- **Ganglions** : 
  - Chaînes : Sous-mentonnière, sous-maxillaire, pré/rétro-auriculaire
  - Cervicales : Antérieure, postérieure, sus-claviculaire
  - Caractères : Taille, consistance, mobilité, sensibilité
- **Thyroïde** :
  - Technique : Par devant ou derrière
  - Déglutition : Mobilité
  - Caractères : Volume, consistance, nodules
- **Carotides** : Pouls (jamais bilatéral simultané)
- **Trachée** : Position médiane

#### Auscultation
- **Carotides** : Souffle
- **Thyroïde** : Souffle (hyperthyroïdie)

## EXAMEN THORACIQUE

### Inspection thorax
- **Forme** : Symétrique, déformations (tonneau, entonnoir)
- **Ampliation** : Symétrique, amplitude
- **Fréquence respiratoire** : 12-20/min
- **Type** : Thoracique, abdominal
- **Signes de détresse** :
  - Tirage (sus-claviculaire, intercostal)
  - Battement ailes du nez
  - Balancement thoraco-abdominal

### Examen pulmonaire

#### Palpation
- **Vibrations vocales** : "33" - Symétriques
  - Augmentées : Condensation
  - Diminuées : Épanchement
- **Points douloureux** : Côtes, espaces intercostaux

#### Percussion
- **Sonorité normale** : Claire
- **Matité** : Épanchement, condensation
- **Tympanisme** : Pneumothorax
- **Systématique** : Apex → bases, comparatif

#### Auscultation pulmonaire
- **Murmure vésiculaire** :
  - Normal : Présent, symétrique
  - Diminué : Épanchement, obstruction
  - Absent : Pneumothorax
- **Bruits surajoutés** :
  - **Râles crépitants** : Fins (alvéolaire), gros (bronchique)
  - **Râles sibilants** : Obstruction bronchique
  - **Ronchus** : Sécrétions bronchiques
  - **Frottement pleural** : Inspiration et expiration
- **Zones** : 
  - Face antérieure : 6 points
  - Face postérieure : 8 points
  - Latéral : 2 points/côté

### Examen cardiovasculaire

#### Inspection
- **Choc de pointe** : 5e EIC ligne médio-claviculaire
- **Pulsations anormales** : Soulèvement
- **Circulation collatérale** : Veines thoraciques

#### Palpation
- **Choc de pointe** :
  - Localisation : Dévié (cardiomégalie)
  - Caractère : Étalé, soutenu
- **Frémissement** : Thrill (souffle intense)
- **B2 palpable** : HTAP

#### Auscultation cardiaque
- **Foyers** :
  - Aortique : 2e EIC droit
  - Pulmonaire : 2e EIC gauche
  - Tricuspide : 4e EIC gauche (appendice xiphoïde)
  - Mitral : Apex (5e EIC ligne médio-claviculaire)
- **Bruits normaux** :
  - B1 : Fermeture valves AV (lub)
  - B2 : Fermeture valves sigmoïdes (dub)
  - Rythme régulier
- **Bruits surajoutés** :
  - B3 : Protodiastolique (IC, jeune normal)
  - B4 : Télédiastolique (compliance ↓)
  - Souffles : Timing, foyer max, irradiation, intensité (1-6)
  - Frottement péricardique : Superficiel, variable

### Examen vasculaire périphérique
- **Pouls périphériques** :
  - Radiaux : Symétrie, synchronisme
  - Carotidiens : Amplitude (jamais simultané)
  - Fémoraux : Présence, souffle
  - Poplités : Patient en décubitus ventral
  - Pédieux et tibiaux postérieurs
- **Temps de recoloration** capillaire : < 2 secondes
- **Œdèmes** : Localisation, godet, symétrie

## EXAMEN ABDOMINAL

### Inspection
- **Forme** : Plat, distendu, excavé
- **Symétrie** : Masses, hernies
- **Cicatrices** : Localisation, aspect
- **Circulation collatérale** : Porto-cave
- **Mouvements** : Respiratoires, péristaltisme visible

### Auscultation (avant palpation)
- **Bruits hydroaériques** :
  - Normaux : 5-35/min
  - Augmentés : Diarrhée, obstruction haute
  - Diminués : Iléus
  - Absents : Urgence si > 2 min
- **Souffles** : Aorte, artères rénales

### Percussion
- **Tympanisme** : Normal (gaz intestinaux)
- **Matité** : 
  - Foie : Ligne médio-claviculaire
  - Rate : 9e EIC gauche
  - Globe vésical
- **Matité déclive** : Ascite

### Palpation

#### Palpation superficielle
- **Technique** : Main à plat, douce
- **Recherche** :
  - Défense : Contraction involontaire
  - Contracture : Rigidité permanente
  - Hyperesthésie cutanée

#### Palpation profonde
- **Quadrant par quadrant** : 9 régions ou 4 quadrants
- **Foie** :
  - Bord inférieur : Inspiration profonde
  - Taille : Débord sous-costal (cm)
  - Consistance : Souple, ferme, dur
  - Surface : Lisse, nodulaire
  - Sensibilité
- **Rate** :
  - Position : Décubitus dorsal puis latéral droit
  - Main en crochet
  - Inspiration profonde
- **Reins** : Palpation bimanuelle (contact lombaire)
- **Masses** : Localisation, taille, mobilité, pulsatilité

#### Points spécifiques
- **Murphy** : Vésicule (hypochondre droit)
- **McBurney** : Appendice (1/3 externe ligne ombilico-iliaque droite)
- **Uretères** : Points urétéraux supérieurs et moyens

### Toucher rectal (si indiqué)
- **Tonus** sphinctérien
- **Ampoule rectale** : Fécalome, sang
- **Prostate** (homme) : Volume, consistance
- **Douglas** : Douleur, masse

## EXAMEN NEUROLOGIQUE

### État mental
- **Conscience** : Glasgow si altérée
- **Orientation** : Temps, lieu, personne
- **Langage** : Fluence, compréhension, répétition
- **Mémoire** : Immédiate (3 mots), récente, ancienne

### Nerfs crâniens (I-XII)
- **I - Olfactif** : Odeurs (café, savon)
- **II - Optique** : Acuité, champs visuels, fond d'œil
- **III, IV, VI** : Oculomotricité, pupilles
- **V - Trijumeau** : Sensibilité face, masséters
- **VII - Facial** : Mimique, goût 2/3 ant langue
- **VIII - Vestibulocochléaire** : Audition, équilibre
- **IX, X** : Déglutition, voile, réflexe nauséeux
- **XI - Spinal** : Trapèzes, SCM
- **XII - Hypoglosse** : Protraction langue

### Motricité
- **Force musculaire** : Cotation 0-5
  - 0 : Aucune contraction
  - 1 : Contraction sans mouvement
  - 2 : Mouvement sans gravité
  - 3 : Mouvement contre gravité
  - 4 : Mouvement contre résistance
  - 5 : Force normale
- **Tonus** : Spasticité, rigidité, hypotonie
- **Trophicité** : Amyotrophie, fasciculations

### Sensibilité
- **Superficielle** : Tact, douleur, température
- **Profonde** : Position, vibration (diapason)
- **Discrimination** : 2 points, graphesthésie

### Réflexes

#### Ostéotendineux (0 à ++++)
- **Membres supérieurs** :
  - Bicipital (C5-C6)
  - Tricipital (C7)
  - Stylo-radial (C6)
- **Membres inférieurs** :
  - Rotulien (L4)
  - Achilléen (S1)
- **Réponses** :
  - 0 : Absent
  - + : Diminué
  - ++ : Normal
  - +++ : Vif
  - ++++ : Polycinétique, diffusé

#### Réflexes cutanés
- **Cutané plantaire** : Flexion normale (Babinski si extension)
- **Cutané abdominal** : Contraction vers stimulation
- **Crémastérien** : Ascension testicule

### Coordination et équilibre
- **Épreuve doigt-nez** : Dysmétrie
- **Talon-genou** : Ataxie
- **Mouvements alternés** rapides : Dysdiadococinésie
- **Romberg** : Yeux ouverts puis fermés
- **Marche** : Normale, tandem

## EXAMEN LOCOMOTEUR

### Inspection
- **Attitude** : Symétrie, déformations
- **Marche** : Boiterie, périmètre
- **Masses musculaires** : Amyotrophie, hypertrophie

### Examen articulaire
- **Inspection** : Gonflement, déformation, coloration
- **Palpation** :
  - Chaleur locale
  - Épanchement
  - Points douloureux
  - Crépitations
- **Mobilité** :
  - Active : Amplitudes
  - Passive : Limitations
  - Comparaison controlatérale

### GALS screening
- **G**ait : Marche
- **A**rms : Membres supérieurs
- **L**egs : Membres inférieurs
- **S**pine : Rachis

## EXAMEN CUTANÉ

### Inspection systématique
- **Totalité** : Déshabiller complètement
- **Plis** : Inguinaux, interfessier
- **Cuir chevelu** : Alopécie, lésions
- **Ongles** : Dystrophies, hippocratisme
- **Muqueuses** : Buccale, génitale

### Description lésions
- **Type** : Macule, papule, vésicule, pustule, nodule
- **Couleur** : Érythème, pigmentation
- **Taille** : Mesurer (mm/cm)
- **Nombre** : Unique, multiple
- **Distribution** : Localisée, généralisée, symétrique
- **Configuration** : Linéaire, annulaire, groupée

## EXAMENS COMPLÉMENTAIRES AU LIT

### Tests simples
- **Glycémie capillaire** : Diabète, hypoglycémie
- **Bandelette urinaire** : Protéines, sang, leucocytes
- **ECG** : Si symptômes cardiaques
- **Peak flow** : Si dyspnée, asthme

### Tests spécifiques
- **Test diagnostic** : Selon suspicion
- **Mini-Mental State** : Troubles cognitifs
- **Test de marche 6 min** : Capacité fonctionnelle

## SYNTHÈSE ET DOCUMENTATION

### Résumé de l'examen
- **Positif** : Anomalies trouvées
- **Négatif pertinent** : Absence de signes attendus
- **Synthèse syndromique** : Regroupement des signes

### Formulation
- "Examen clinique retrouve..."
- "À l'examen, on note..."
- Éviter : "RAS" (toujours détailler)

### Plan
- Examens complémentaires nécessaires
- Orientation diagnostique
- Surveillance requise

## Points clés pour l'ECOS
1. **Hygiène** : Lavage mains avant/après
2. **Ordre** : Inspection → Palpation → Percussion → Auscultation
3. **Symétrie** : Toujours comparer D/G
4. **Pudeur** : Respecter, couvrir zones non examinées
5. **Communication** : Expliquer, prévenir si désagréable
6. **Documentation** : Noter positif ET négatif pertinent
7. **Synthèse** : Regroupement syndromique
