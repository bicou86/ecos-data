# Examen clinique de la cheville et du pied

## Domaine
Musculosquelettique/Membre inférieur

## Description
Examen systématique de la cheville et du pied pour évaluer les structures osseuses, ligamentaires et tendineuses, essentiel pour le diagnostic des traumatismes et pathologies chroniques.

## Anatomie fonctionnelle
- **Articulations** : Talo-crurale, sous-talienne, médio-tarsienne, tarso-métatarsienne
- **Ligaments** : Collatéral latéral (3 faisceaux), deltoïde (médial)
- **Tendons** : Achille, tibial postérieur, fibulaires, extenseurs
- **Arches** : Médiale longitudinale, latérale, transverse

## INSPECTION

### Patient debout
- **Alignement** : Varus/valgus arrière-pied
- **Arches plantaires** : Pied plat/creux
- **Appui** : Répartition des charges
- **Déformations** : Hallux valgus, orteils en griffe/marteau

### Patient assis/couché
- **Gonflement** : Localisation (malléolaire, médio-pied)
- **Ecchymose** : Signe de fracture
- **Coloration** : Troubles vasculaires
- **Trophicité cutanée**

## PALPATION

### Points de repère osseux
1. **Malléole médiale**
2. **Malléole latérale**
3. **Base 5e métatarse**
4. **Os naviculaire** (tubérosité)
5. **Calcanéum**
6. **Tête du talus**

### Structures ligamentaires
**Ligament collatéral latéral**
- Faisceau antérieur (talo-fibulaire antérieur)
- Faisceau moyen (calcanéo-fibulaire)
- Faisceau postérieur (talo-fibulaire postérieur)

**Ligament deltoïde** (médial)
- 4 faisceaux profonds et superficiels

### Structures tendineuses
- **Tendon d'Achille** : Insertion, corps
- **Tibial postérieur** : Derrière malléole médiale
- **Fibulaires** : Derrière malléole latérale
- **Tibial antérieur** : Face antérieure

## MOBILITÉ

### Talo-crurale
- **Flexion dorsale** : 20-30°
- **Flexion plantaire** : 40-50°

### Sous-talienne
- **Inversion** : 30°
- **Éversion** : 20°

### Avant-pied
- **Pronation** : 15-20°
- **Supination** : 30-35°

## TESTS SPÉCIFIQUES

### Tests ligamentaires

**Tiroir antérieur**
- Pied à 90°, traction antérieure talus
- (+) si translation > 5mm = lésion LTFA

**Test de l'inversion forcée (tilt test)**
- Cheville neutre, stress en varus
- (+) si bâillement = lésion LCL

**Test de compression (squeeze test)**
- Compression tibia-fibula mi-jambe
- (+) si douleur cheville = syndesmose

**Test de rotation externe**
- Genou 90°, rotation externe pied
- (+) si douleur = lésion syndesmose

### Tests tendineux

**Test de Thompson**
- Décubitus ventral, compression mollet
- Absence de flexion plantaire = rupture Achille

**Test de matles**
- Décubitus ventral, genoux 90°
- Asymétrie position pied = rupture partielle Achille

**Test du tibial postérieur**
- Montée sur pointe d'un pied
- Impossible si rupture

**Test des fibulaires**
- Éversion contre résistance
- Subluxation possible derrière malléole

### Tests spéciaux

**Test de Mulder (névrome de Morton)**
- Compression latérale avant-pied + pression plantaire
- (+) si clic + douleur = névrome

**Test de Coleman (pied creux)**
- Bloc sous bord latéral
- Correction varus = pied creux réductible

**Test de Jack (windlass)**
- Extension passive hallux
- Élévation arche médiale normale

## RÈGLES D'OTTAWA

### Radiographie cheville si:
- Douleur malléolaire ET:
  - Sensibilité bord postérieur/pointe malléole médiale (6 cm)
  - OU sensibilité bord postérieur/pointe malléole latérale (6 cm)
  - OU incapacité de faire 4 pas

### Radiographie pied si:
- Douleur médio-pied ET:
  - Sensibilité base 5e métatarse
  - OU sensibilité os naviculaire
  - OU incapacité de faire 4 pas

## EXAMEN VASCULO-NERVEUX

### Pouls
- Tibial postérieur (derrière malléole médiale)
- Pédieux (dorsal pied)

### Sensibilité
- **L4** : Face médiale
- **L5** : Dorsum pied
- **S1** : Face latérale, plante
- **Nerf fibulaire superficiel** : Dorsum pied
- **Nerf tibial** : Plante

### Réflexe
- Achilléen (S1)

## PATHOLOGIES FRÉQUENTES

### Traumatiques
1. **Entorse cheville** (85% latérale)
2. **Fracture malléolaire**
3. **Rupture tendon d'Achille**
4. **Fracture 5e métatarse**

### Dégénératives
1. **Arthrose talo-crurale**
2. **Hallux valgus**
3. **Hallux rigidus**

### Inflammatoires
1. **Fasciite plantaire**
2. **Tendinopathie d'Achille**
3. **Tendinopathie tibial postérieur**

### Neurologiques
1. **Névrome de Morton**
2. **Syndrome du tunnel tarsien**
3. **Neuropathie diabétique**

## BIOMÉCANIQUE DE LA MARCHE
- **Phase d'appui** (60%) : Attaque talon → Pied à plat → Propulsion
- **Phase oscillante** (40%)
- Observer : Boiterie, esquive, steppage

## RED FLAGS
- Fracture ouverte
- Syndrome de loge
- Luxation non réduite
- Signes vasculaires (pied froid, pâle)
- Infection (diabétique++)

## Points clés pour l'ECOS
1. **Règles d'Ottawa** = indications radiographie
2. **Test de Thompson** = rupture Achille
3. **Tiroir antérieur** = entorse cheville
4. **Palpation systématique** des 3 points osseux
5. **Squeeze test** si trauma haute énergie
6. **Examen vasculaire** si diabète

## Mnémotechnique
**"OTTAWA"** pour radiographie:
- **O**s naviculaire
- **T**endre malléoles
- **T**alus (base 5e métatarse)
- **A**mbulation impossible
- **W**alk (4 pas impossibles)
- **A**ge (critères valides 18-55 ans)
