# Examen urologique

## Domaine
Urologie

## Description
Examen clinique systématique de l'appareil urinaire et génital permettant l'évaluation des troubles mictionnels, des pathologies rénales, vésicales, prostatiques et génitales.

## PRINCIPES GÉNÉRAUX

### Installation du patient
- **Position** : Debout, couché, position gynécologique selon examen
- **Déshabillage** : Complet de la taille aux genoux
- **Pudeur** : Respecter, couvrir zones non examinées
- **Matériel** : Gants, gel, lampe, mètre ruban

### Examen systématique
- **Abdomen** : Recherche globe vésical
- **Fosses lombaires** : Palpation rénale
- **Organes génitaux externes** : Systématique
- **Toucher rectal** : Si indiqué (homme > 50 ans)

## ANAMNÈSE UROLOGIQUE

### Symptômes du bas appareil (SBAU)

#### Phase de remplissage
- **Pollakiurie** :
  - Fréquence diurne (normale < 8/jour)
  - Circonstances (effort, froid, stress)
  - Volume par miction
- **Nycturie** :
  - Nombre de levers nocturnes
  - Volume nocturne
  - Polyurie nocturne vs vessie hyperactive
- **Urgenturie** :
  - Besoin impérieux
  - Délai de sécurité
  - Fuites associées
- **Incontinence** :
  - Type (effort, urgence, mixte)
  - Quantification (protections/jour)
  - Circonstances déclenchantes

#### Phase de vidange
- **Dysurie** :
  - Retard au démarrage
  - Poussée abdominale
  - Jet haché, faible
- **Sensation de vidange incomplète**
- **Gouttes retardataires**
- **Miction en deux temps**

#### Symptômes post-mictionnels
- **Gouttes terminales**
- **Résidu post-mictionnel** ressenti

### Score IPSS (International Prostate Symptom Score)
- **7 questions** symptômes (0-5 points chacune)
- **1 question** qualité de vie
- **Interprétation** :
  - 0-7 : Symptômes légers
  - 8-19 : Symptômes modérés
  - 20-35 : Symptômes sévères

### Symptômes du haut appareil

#### Douleur lombaire
- **Type** : Pesanteur, colique, continue
- **Irradiation** : Aine, OGE, cuisse
- **Facteurs** : Position, miction, hydratation
- **Fièvre associée** : Pyélonéphrite

#### Hématurie
- **Macroscopique/microscopique**
- **Totale** : Origine vésicale ou haute
- **Initiale** : Urètre, prostate
- **Terminale** : Col vésical, trigone
- **Caillots** : Forme (vermiculaires = uretère)

### Symptômes généraux
- **Fièvre** : Infection, cancer
- **Amaigrissement** : Cancer
- **Asthénie** : IRC, cancer
- **Œdèmes** : Syndrome néphrotique, IRC
- **HTA** : Néphropathie

### Antécédents urologiques
- **Lithiases** : Type, traitement, récidive
- **Infections urinaires** : Fréquence, germes
- **Chirurgie** : Prostate, rein, vessie
- **Traumatisme** : Rein, vessie, urètre
- **Sondage** : Durée, complications
- **Cancer** : Prostate, vessie, rein

### Facteurs de risque
- **Tabac** : Cancer vessie (principal FR)
- **Exposition professionnelle** : Amines aromatiques
- **Médicaments** : Néphrotoxiques, lithogènes
- **Antécédents familiaux** : Cancer prostate, polykystose

## EXAMEN PHYSIQUE

### Inspection

#### Abdomen
- **Cicatrices** : Lombotomie, laparotomie
- **Voussure** : Globe vésical
- **Circulation collatérale** : Compression cave

#### Organes génitaux externes
- **Méat urétral** :
  - Position (hypospadias, épispadias)
  - Écoulement
  - Sténose
- **Verge** :
  - Phimosis, paraphimosis
  - Plaques de Lapeyronie
  - Lésions cutanées
- **Bourses** :
  - Asymétrie
  - Œdème
  - Varices (varicocèle)

### Palpation abdominale

#### Recherche globe vésical
- **Matité** : Sus-pubienne
- **Voussure** : Convexe vers le haut
- **Palpation** : Masse rénitente médiane
- **Percussion** : Matité convexe
- **Résidu** : > 100-150 mL palpable

#### Fosses lombaires
- **Contact lombaire** bimanuel :
  - Main postérieure soulève
  - Main antérieure palpe
- **Gros rein** : Ballottement
- **Sensibilité** : Pyélonéphrite

### Percussion
- **Ébranlement lombaire** :
  - Points costo-vertébraux
  - Douleur = Giordano +
  - Pyélonéphrite, lithiase

### Examen génital masculin

#### Pénis
- **Palpation** : Corps caverneux
- **Décalottage** : Si non circoncis
- **Méat** : Inspection après miction

#### Testicules
- **Palpation** bilatérale comparative :
  - Taille (12-20 mL normal)
  - Consistance (ferme élastique)
  - Sensibilité
  - Surface (lisse)
- **Épididyme** :
  - Tête, corps, queue
  - Nodule, induration
- **Cordon** :
  - Déférent palpable
  - Varicocèle (Valsalva)

#### Transillumination
- **Hydrocèle** : Transilluminable
- **Tumeur** : Opaque
- **Hématocèle** : Opaque

### Toucher rectal (TR)

#### Indications
- Homme > 50 ans
- SBAU
- Suspicion cancer prostate
- Hématurie
- Prostatite

#### Technique
- **Position** : Décubitus latéral gauche ou debout penché
- **Inspection** : Fissure, hémorroïdes, fistule
- **Introduction** : Douce, lubrifiée
- **Tonus** : Sphincter anal

#### Prostate (normale 15-20g)
- **Volume** : Noix (20g), mandarine (40g), orange (60g)
- **Consistance** : Ferme élastique (normale), dure (cancer)
- **Surface** : Lisse, régulière
- **Sillon médian** : Présent ou effacé
- **Limites** : Nettes
- **Sensibilité** : Indolore (sauf prostatite)
- **Mobilité** : Mobile sur rectum

### Examen neurologique périnéal
- **Sensibilité** : Périnée, OGE
- **Réflexes** :
  - Bulbo-caverneux
  - Crémastérien
  - Anal
- **Tonus** : Sphincter anal

## EXAMENS COMPLÉMENTAIRES DE BASE

### Biologie

#### Sang
- **Créatinine** : Fonction rénale
- **Urée** : Corrélation créatinine
- **PSA** : Homme > 50 ans
- **Ionogramme** : Si IRC suspectée

#### Urines
- **Bandelette** :
  - Sang, leucocytes, nitrites
  - Protéines, glucose
  - pH, densité
- **ECBU** : Si infection suspectée
- **Cytologie** : Si hématurie

### Imagerie

#### Échographie
- **Rénale** :
  - Taille (10-12 cm)
  - Différenciation cortico-médullaire
  - Dilatation pyélocalicielle
  - Calculs, kystes, tumeurs
- **Vésicale** :
  - Paroi (< 3mm à réplétion)
  - Résidu post-mictionnel
  - Calculs, tumeurs
- **Prostatique** (sus-pubienne) :
  - Volume (formule ellipsoïde)
  - Lobe médian
- **Testiculaire** :
  - Structure, vascularisation
  - Épididyme, hydrocèle

#### Débitmétrie
- **Qmax** : > 15 mL/s normal
- **Volume** : > 150 mL pour interprétation
- **Courbe** : En cloche (normale) vs plateau

## SYNDROMES UROLOGIQUES

### Syndrome obstructif (vidange)
- Dysurie d'attente
- Jet faible
- Miction en plusieurs temps
- Gouttes retardataires
- Sensation vidange incomplète

### Syndrome irritatif (remplissage)
- Pollakiurie
- Urgenturie
- Nycturie
- Incontinence par urgenturie

### Syndrome infectieux
- Brûlures mictionnelles
- Pollakiurie
- Urines troubles, malodorantes
- +/- Fièvre

### Syndrome tumoral vésical
- Hématurie macroscopique
- Indolore
- Totale, caillots
- Récidivante

## ORIENTATION DIAGNOSTIQUE

### Homme jeune + dysurie
- Sténose urétrale
- Prostatite
- Vessie neurologique

### Homme > 50 ans + SBAU
- HBP
- Cancer prostate
- Sténose urétrale
- Vessie hyperactive

### Femme + incontinence
- Effort : Insuffisance sphinctérienne
- Urgence : Vessie hyperactive
- Mixte : Association

### Hématurie indolore
- Cancer vessie jusqu'à preuve contraire
- Cancer rein
- Lithiase

### Douleur lombaire + fièvre
- Pyélonéphrite aiguë
- Pyonéphrose
- Abcès rénal

## Points clés pour l'ECOS
1. **Score IPSS** systématique si SBAU
2. **TR** obligatoire homme > 50 ans
3. **Hématurie** = bilan complet obligatoire
4. **Globe** = matité sus-pubienne convexe
5. **Transillumination** pour masse scrotale
6. **PSA** après TR et information patient
7. **ECBU** avant antibiothérapie

## Mnémotechniques

**"FRENCH"** pour symptômes mictionnels:
- **F**réquence augmentée (pollakiurie)
- **R**etard au démarrage
- **E**ffort pour uriner
- **N**ycturie
- **C**ontinence (troubles)
- **H**ématurie

**"POND"** pour causes de globe:
- **P**rostate (HBP, cancer)
- **O**bstruction urétrale
- **N**eurologique (vessie)
- **D**rogues (anticholinergiques)
