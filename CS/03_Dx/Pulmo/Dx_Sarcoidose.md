# 🔎 Sarcoïdose — Résumé OSCE

## 1. Définition
- Maladie inflammatoire **multisystémique**, d’étiologie inconnue.  
- Caractérisée par des **granulomes non caséifiants**.  
- Atteinte typique : **poumons** + **adénopathies hilaires bilatérales**.  
- Évolution variable : résolutive spontanément ou chronique.  

---

## 2. Clinique

### Mnémonique utile : **GRUELING**

| Lettre | Manifestation |
|--------|---------------|
| **G** | Granulomes non caséifiants |
| **R** | Arthrite |
| **U** | Uvéite |
| **E** | Érythème noueux |
| **L** | Lymphadénopathie hilaire bilatérale |
| **I** | Interstitial lung disease (fibrose pulmonaire) |
| **N** | Test tuberculinique négatif |
| **G** | Gammaglobulinémie ↑ (polyclonale) |

---

## 3. Manifestations par appareil

| Appareil | Signes fréquents |
|----------|------------------|
| **Général** | Fièvre, fatigue, anorexie, amaigrissement |
| **Pulmonaire (90%)** | Toux sèche, dyspnée, douleur thoracique, râles secs, fibrose interstitielle |
| **Cutané** | Érythème noueux, **lupus pernio** (pathognomonique), lésions papuleuses/plaques, atteinte cicatrices/tatouages |
| **Oculaire (10–25%)** | Uvéite antérieure, nodules conjonctivaux, sécheresse |
| **Musculosquelettique** | Arthrite chevilles, arthralgies, myopathies |
| **Neurologique (5%)** | Paralysie faciale, méningite aseptique, neuropathies périphériques |
| **Cardiaque** | Troubles du rythme, myocardite, BAV, mort subite |
| **Rénal** | Néphrite interstitielle, néphrocalcinose, lithiase |
| **Hépatique/Splénique** | Hépatomégalie (30%), splénomégalie (30%), granulomes hépatiques |
| **Glandes exocrines** | Hypertrophie parotidienne ou lacrymale |

---

## 4. Diagnostic

### Étapes clés
- **Radio thoracique** = 1er examen (adénopathies hilaires bilatérales).  
- **Scanner thoracique** si doute diagnostique.  
- **Biopsie** : granulomes non caséifiants (poumon, peau, ganglion…).  
- **Exclure autres causes** : tuberculose, mycoses, cancer.  

### Examens complémentaires
- **Biologie :** ACE ↑ (non spécifique), hypercalcémie, hypercalciurie.  
- **IDR tuberculine :** souvent négative.  
- **EFR :** syndrome restrictif si fibrose.  
- **PET-Scan / IRM :** si suspicion atteinte cardiaque/neuro.  

---

## 5. Traitement

| Situation | Recommandation |
|-----------|----------------|
| **Formes asymptomatiques / précoces** | Surveillance (souvent rémission spontanée) |
| **Formes symptomatiques / évolutives** | Corticothérapie orale |
| **Formes sévères / réfractaires** | Immunosuppresseurs (méthotrexate, azathioprine) |
| **Formes cardiaques/neuro graves** | Corticothérapie + immunosuppresseurs d’emblée |

---

## ⚡ Points clés OSCE
- Penser à la **sarcoïdose** devant : adénopathies hilaires bilatérales + symptômes généraux/respiratoires.  
- Rechercher systématiquement atteintes **extrapulmonaires** (cutanée, oculaire, neuro, cardiaque…).  
- Diagnostic repose sur triade : **clinique typique + imagerie + granulomes non caséifiants**.  
- ⚠️ Toujours éliminer **tuberculose** et autres infections granulomateuses avant traitement.  
- Pas toujours besoin de traitement au début → débuter si progression ou atteinte sévère.
