# Rhinite Non Allergique - Fiche de révision Dx

## 📋 Informations générales
- **Discipline**: ORL / Allergologie
- **Fréquence à l'ECOS**: ⭐⭐⭐ Modérée

## 🔍 Définition
- Vasodilatation des plexus veineux nasaux
- Gonflement muqueux d'origine NON allergique
- ≠ Rhinite allergique (IgE-médiée, hypersensibilité type 1)

## 🔍 Types de rhinite non allergique

### 1. Rhinite infectieuse
- Virale des VAS (rhume commun)
- Aiguë, autolimitée

### 2. NARES (Rhinite non allergique avec éosinophilie)
- 1ère cause inflammatoire non allergique
- Clinique similaire à rhinite allergique
- Tests allergiques négatifs
- **Éosinophilie dans sécrétions nasales**

### 3. Rhinite médicamenteuse
**Médicaments causaux**:
- Aspirine, AINS
- Antihypertenseurs (IEC, bêta-bloquants)
- Contraceptifs oraux
- Neuroleptiques, antidépresseurs
- Médicaments érection (sildénafil)

### 4. Rhinitis medicamentosa
- Effet rebond après décongestionnants nasaux
- Cercle vicieux de dépendance

### 5. Rhinite atrophique
- Idiopathique ou secondaire
- Maladies granulomateuses (vascularites)

## 🩺 Présentation Clinique

### Symptômes communs
- Obstruction nasale
- Rhinorrhée (claire ou mucopurulente)
- Éternuements (moins que allergique)
- Prurit nasal (moins marqué)

### Spécificités selon type
- **NARES**: Polypose nasale possible
- **Atrophique**: Croûtes, épistaxis, cacosmie
- **Médicamenteuse**: Congestion rebond

## 🔬 Diagnostic

### Examens de base
- Rhinoscopie antérieure
- Tests cutanés allergiques (négatifs)
- IgE spécifiques (négatifs)

### Examens spécifiques
- **NARES**: Frottis nasal → éosinophilie
- **Atrophique**: Scanner sinus si suspicion granulomatose
- Endoscopie nasale si polypose

### Diagnostic différentiel
- Rhinite allergique
- Sinusite chronique
- Polypose nasale
- Déviation septale

## 💊 Traitement

### NARES
- **Corticoïdes nasaux** (1ère ligne)
- Antihistaminiques (moins efficaces)
- Corticoïdes oraux si sévère

### Rhinite médicamenteuse
- Arrêt du médicament causal si possible
- Substitution thérapeutique
- Corticoïdes nasaux transitoires

### Rhinitis medicamentosa
- **Sevrage progressif** décongestionnants
- Corticoïdes nasaux
- Solution saline
- Éducation patient +++

### Rhinite atrophique
- Lavages nasaux fréquents
- Humidification
- Pommades nasales
- Traitement cause sous-jacente

## ⚠️ Complications
- Sinusite chronique
- Polypose nasale
- Troubles du sommeil
- Otite séreuse

## 🎯 Points Clés pour l'ECOS

### Questions fréquentes
- Différencier allergique vs non allergique
- Connaître les médicaments responsables
- Savoir prescrire les corticoïdes nasaux
- Identifier une rhinitis medicamentosa

### Red Flags 🚩
- Épistaxis récurrentes → Rechercher vascularite
- Obstruction unilatérale → Tumeur?
- Anosmie brutale → COVID-19?
- Rhinorrhée purulente → Sinusite

### Points pratiques
- Tests allergiques négatifs = rhinite non allergique
- Décongestionnants nasaux: Maximum 5-7 jours
- NARES = bon pronostic sous corticoïdes
- Toujours interroger sur médicaments
