# Infections pédiatriques

## Domaine
Pédiatrie / Infectiologie

## Description
Principales infections rencontrées en pédiatrie, incluant les infections respiratoires, les maladies éruptives fébriles, les gastro-entérites et autres infections courantes de l'enfance.

## INFECTIONS RESPIRATOIRES

### Bronchiolite

#### Épidémiologie
- **Âge** : < 2 ans (pic 3-6 mois)
- **Saison** : Hiver (novembre-mars)
- **Agent** : VRS (80%), autres virus

#### Clinique
- **Début** : Rhinite 2-3 jours
- **Phase d'état** :
  - Toux sèche puis grasse
  - Dyspnée expiratoire
  - Wheezing, crépitants
  - Difficultés alimentaires
  - Apnées (< 3 mois)

#### Gravité (score de Wang)
- **Légère** : FR < 40, SaO2 > 95%, alimentation normale
- **Modérée** : FR 40-60, SaO2 92-95%, alimentation difficile
- **Sévère** : FR > 60, SaO2 < 92%, signes de lutte++

#### Prise en charge
- **Ambulatoire** si légère :
  - DRP (désobstruction rhinopharyngée)
  - Fractionnement repas
  - Surveillance
- **Hospitalisation** si :
  - < 6 semaines
  - Prématuré
  - Forme modérée/sévère
  - Apnées
- **Traitement** :
  - O2 si SaO2 < 92%
  - Hydratation
  - Pas d'antibiotiques systématiques
  - Pas de bronchodilatateurs/corticoïdes routine

### Pneumonie

#### Clinique
- **Fièvre** élevée, frissons
- **Toux** productive
- **Douleur** thoracique
- **Dyspnée**, polypnée
- **Auscultation** : Crépitants, souffle tubaire

#### Critères OMS pneumonie
- **< 2 mois** : FR > 60/min
- **2-12 mois** : FR > 50/min
- **1-5 ans** : FR > 40/min
- **> 5 ans** : FR > 30/min
+ Tirage sous-costal

#### Étiologie selon âge
- **< 3 mois** : Streptocoque B, E. coli
- **3 mois-5 ans** : Pneumocoque, virus
- **> 5 ans** : Pneumocoque, Mycoplasme

#### Traitement
- **Ambulatoire** : Amoxicilline 80-100 mg/kg/j
- **Hospitalisation** si :
  - < 3 mois
  - Signes gravité
  - Échec ambulatoire
- **Durée** : 7-10 jours

### Otite moyenne aiguë (OMA)

#### Diagnostic
- **Otalgie** ou irritabilité
- **Fièvre** variable
- **Otoscopie** :
  - Tympan bombé
  - Rougeur
  - Opacité
  - Épanchement
  - ± Perforation

#### Traitement
- **< 2 ans** : Antibiotique systématique
- **≥ 2 ans** : Surveillance 48h si peu symptomatique
- **1ère ligne** : Amoxicilline 80-90 mg/kg/j × 5-10j
- **Allergie** : Céfuroxime ou azithromycine
- **Analgésie** : Paracétamol ± ibuprofène

### Laryngite (Croup)

#### Clinique
- **Toux aboyante**
- **Voix rauque**
- **Stridor inspiratoire**
- **Dyspnée** variable

#### Score de Westley
- 0-2 : Léger
- 3-5 : Modéré
- 6-11 : Sévère
- ≥ 12 : Insuffisance respiratoire

#### Traitement
- **Léger** : Surveillance, humidification
- **Modéré/sévère** :
  - Dexaméthasone 0.15-0.6 mg/kg PO/IM
  - Adrénaline nébulisée si sévère
  - Hospitalisation si non-réponse

### Épiglottite (rare mais urgence)

#### Clinique
- **Début brutal**
- **Fièvre élevée**
- **Dysphagie**, hypersialorrhée
- **Position tripode**
- **Stridor**, détresse respiratoire
- **Pas de toux**

#### Prise en charge
- **Ne pas examiner gorge** (risque obstruction)
- **Maintenir position confort**
- **O2, monitoring**
- **Intubation** au bloc si nécessaire
- **Antibiotiques** : Ceftriaxone IV

## MALADIES ÉRUPTIVES FÉBRILES

### Exanthèmes viraux classiques

#### Rougeole
- **Prodrome** : Fièvre, catarrhe, conjonctivite
- **Signe de Köplik** : J2-3
- **Éruption** : J4, descendante, maculopapuleuse
- **Complications** : Pneumonie, encéphalite
- **Prévention** : Vaccin ROR

#### Rubéole
- **Adénopathies** : Occipitales, rétro-auriculaires
- **Éruption** : Rose, discrète, fugace
- **Risque** : Tératogène si grossesse
- **Prévention** : Vaccin ROR

#### Roséole (Exanthème subit, 6e maladie)
- **Âge** : 6 mois-2 ans
- **Fièvre** : 3-5 jours, défervescence brutale
- **Éruption** : Apparaît à défervescence
- **Agent** : HHV-6
- **Évolution** : Bénigne

#### Varicelle
- **Éruption** : Vésicules "gouttes rosée"
- **Évolution** : Macule → papule → vésicule → croûte
- **Poussées** successives
- **Prurit** intense
- **Contagiosité** : 2j avant - croûtes
- **Traitement** : Symptomatique, aciclovir si compliqué

#### Scarlatine
- **Agent** : Streptocoque A
- **Langue** : Framboisée
- **Éruption** : Granité, plis ++
- **Desquamation** : J7-10
- **Traitement** : Pénicilline V 10 jours

### Maladie de Kawasaki

#### Critères diagnostiques
Fièvre ≥ 5 jours + ≥4 critères :
1. Conjonctivite bilatérale non purulente
2. Modifications buccales (lèvres, langue fraise)
3. Modifications extrémités (œdème, érythème, desquamation)
4. Éruption polymorphe
5. Adénopathie cervicale > 1.5 cm

#### Complications
- **Anévrismes coronaires** (20-25% non traités)

#### Traitement
- **IgIV** : 2 g/kg dans les 10 jours
- **Aspirine** : Dose anti-inflammatoire puis antiagrégante
- **Échocardiographie** : J0, S2, S6-8

## GASTRO-ENTÉRITE AIGUË

### Étiologie
- **Virale** (80%) : Rotavirus, norovirus
- **Bactérienne** : Salmonelle, Shigelle, Campylobacter
- **Parasitaire** : Giardia

### Évaluation déshydratation

#### Score de déshydratation (OMS)
**Légère (< 5%)** :
- Soif
- Pas signes cliniques

**Modérée (5-10%)** :
- Soif intense
- Pli cutané lent
- Yeux cernés
- Fontanelle déprimée

**Sévère (> 10%)** :
- Léthargie
- Pli cutané > 2 sec
- Yeux très enfoncés
- Absence larmes
- Oligurie

### Prise en charge
**Réhydratation orale** (1ère ligne) :
- SRO : 50-100 ml/kg en 4h si modérée
- Petites quantités fréquentes
- Continuer allaitement

**Réhydratation IV** si :
- Déshydratation sévère
- Échec voie orale
- Choc
- Schéma : 20 ml/kg NaCl 0.9% en 20 min, répéter si besoin

**Réalimentation** :
- Précoce (4-6h)
- Régime normal selon âge
- Pas de régime restrictif

**Traitements** :
- Probiotiques peuvent réduire durée
- Antiémétiques : Ondansétron si vomissements
- Pas d'antidiarrhéiques
- Antibiotiques exceptionnels (Shigelle, choléra)

## INFECTIONS URINAIRES

### Classification
- **Cystite** : Bas appareil, pas fièvre
- **Pyélonéphrite** : Fièvre + signes urinaires

### Présentation selon âge
- **Nouveau-né** : Sepsis, ictère
- **Nourrisson** : Fièvre isolée++
- **Enfant** : Dysurie, pollakiurie, douleurs

### Diagnostic
- **Bandelette** : Dépistage (leucocytes + nitrites)
- **ECBU** : Confirmation
  - > 10^5 UFC/ml (mi-jet)
  - > 10^4 UFC/ml (cathétérisme)
- **Prélèvement** : Poche = contamination++

### Traitement
**Cystite** :
- Cotrimoxazole ou nitrofurantoïne
- 3-5 jours

**Pyélonéphrite** :
- < 3 mois : Hospitalisation, IV
- > 3 mois : Ambulatoire possible si bon état
- Ceftriaxone IM/IV ou céfixime PO
- 10 jours total

**Bilan** :
- Échographie rénale si < 2 ans ou pyélonéphrite
- Cystographie si récidive ou anomalie écho

## MÉNINGITE

### Signes cliniques selon âge
**Nouveau-né/nourrisson** :
- Fièvre ou hypothermie
- Léthargie ou irritabilité
- Refus alimentaire
- Fontanelle bombée
- Convulsions

**Enfant** :
- Fièvre + céphalées + vomissements
- Raideur nuque
- Photophobie
- Signes Kernig/Brudzinski
- Purpura (méningocoque++)

### Ponction lombaire
**Indications** : Suspicion méningite
**Contre-indications** :
- Signes HTIC
- Troubles hémostase
- Instabilité hémodynamique
- Infection site ponction

### Analyse LCR

| | Normal | Bactérienne | Virale |
|--|--------|-------------|--------|
| Aspect | Clair | Trouble | Clair |
| Cellules | < 5 | > 1000 | 10-500 |
| PNN | 0 | > 50% | < 50% |
| Protéines | < 0.4 g/L | > 1 g/L | 0.4-1 g/L |
| Glucose | 50-75% glycémie | < 40% | Normal |

### Traitement empirique urgent
**< 3 mois** :
- Amoxicilline + ceftriaxone + gentamicine

**3 mois - 5 ans** :
- Ceftriaxone 100 mg/kg/j

**> 5 ans** :
- Ceftriaxone 100 mg/kg/j

**Si purpura** : Ceftriaxone immédiat avant PL

**Corticoïdes** : Dexaméthasone si pneumocoque/H. influenzae

**Prophylaxie contacts** : Si méningocoque

## AUTRES INFECTIONS COURANTES

### Impétigo
- **Agent** : Staph aureus, Strep A
- **Lésions** : Vésicules → croûtes mélicériques
- **Localisation** : Péri-orificielles
- **Traitement** :
  - Localisé : Mupirocine topique
  - Étendu : Antibiotique PO (pénicilline M)

### Érysipèle
- **Agent** : Streptocoque A
- **Clinique** : Placard rouge, chaud, douloureux, bien limité
- **Fièvre** élevée
- **Traitement** : Pénicilline V ou amoxicilline

### Adénite cervicale
- **Ganglion** : > 1.5 cm, douloureux
- **Fièvre** variable
- **Étiologie** : Virale > bactérienne
- **Traitement** : 
  - Surveillance si viral probable
  - Amoxicilline-clavulanate si bactérien

### Conjonctivite
**Néonatale** (< 1 mois) :
- Gonocoque, Chlamydia : Urgence
- Prélèvement + traitement systémique

**Enfant** :
- Virale : Bilatérale, séreuse
- Bactérienne : Unilatérale, purulente
- Traitement : Collyre antibiotique si bactérienne

## PRÉVENTION

### Vaccinations
- Calendrier vaccinal à jour
- Rattrapage si retard

### Mesures d'hygiène
- Lavage mains
- Éviction collective selon pathologie
- Isolement si contagieux

### Antibioprophylaxie
- Contacts méningite
- Scarlatine dans collectivité
- Coqueluche chez nourrisson

## Points clés pour l'ECOS
1. **Signes gravité** : Détresse respiratoire, déshydratation, sepsis
2. **Critères hospitalisation** selon pathologie
3. **Antibiothérapie** : Indications précises
4. **Réhydratation** : Orale privilégiée
5. **Vaccinations** : Vérifier statut
6. **Éviction** : Connaître durées
7. **Prophylaxie** contacts si indiqué
