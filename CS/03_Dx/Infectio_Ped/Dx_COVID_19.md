# COVID-19 - Fiche de révision ECOS

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient présentant une infection COVID-19 (phase aiguë, Long COVID ≥3 mois, ou troubles anxieux post-COVID)
**Objectifs d'évaluation:** Diagnostic COVID aigu, évaluation gravité, prise en charge phase aiguë, reconnaissance Long COVID, gestion troubles psychologiques post-pandémiques

---

## 📋 COVID-19 PHASE AIGUË

### 1. Anamnèse infection aiguë
- [ ] **Exposition/contact:**
  - Contact COVID+ confirmé?
  - Délai depuis exposition (2-14 jours)
  - Statut vaccinal (doses, dates)
- [ ] **Début symptômes:**
  - Mode installation (brutal/progressif)
  - Durée évolution
  - Symptômes initiaux vs actuels

### 2. Manifestations cliniques COVID aigu

#### Formes cliniques
- [ ] **Asymptomatique** (30-40%)
- [ ] **Forme légère** (80%): Symptômes pseudo-grippaux
- [ ] **Forme modérée** (15%): Pneumonie sans détresse
- [ ] **Forme sévère** (5%): Détresse respiratoire, pneumonie
- [ ] **Forme critique** (<1%): SDRA, choc, défaillance multiviscérale

#### Symptômes fréquents
- [ ] **Généraux:**
  - Fièvre 38-40°C (87%)
  - Fatigue, asthénie (38%)
  - Myalgies (15%)
  - Frissons (11%)
- [ ] **Respiratoires:**
  - Toux sèche (68%)
  - Dyspnée (19%)
  - Mal de gorge (14%)
- [ ] **Digestifs:**
  - Diarrhée (12%)
  - Nausées/vomissements (8%)
  - Douleurs abdominales (6%)
- [ ] **Neurologiques:**
  - Céphalées (13%)
  - Anosmie (30-60%)
  - Agueusie/dysgueusie (30-60%)
  - Confusion (si sévère)

### 3. Facteurs de risque de forme grave
- [ ] **Âge:** >65 ans (risque exponentiel)
- [ ] **Comorbidités:**
  - Obésité (IMC >30)
  - Diabète
  - HTA
  - Insuffisance cardiaque
  - Maladie rénale chronique
  - BPCO
  - Cancer actif
  - Immunodépression

### 4. Examen clinique phase aiguë
- [ ] **État général:** Altération, déshydratation
- [ ] **Constantes:** T°, TA, FC, FR, SaO₂
- [ ] **Respiratoire:**
  - Auscultation: crépitants, râles
  - Signes détresse: tirage, polypnée
  - Test de marche (désaturation?)
- [ ] **Recherche complications:**
  - Thrombose (mollet, EP)
  - Myocardite (douleur thoracique)
  - AVC (déficit focal)

### 5. Examens complémentaires COVID aigu

#### Diagnostic virologique
- [ ] **RT-PCR SARS-CoV-2** (étalon or)
- [ ] **Test antigénique rapide** (moins sensible)
- [ ] **Sérologie** (diagnostic rétrospectif)

#### Bilan de gravité si hospitalisation
- [ ] **Biologie:**
  - NFS (lymphopénie fréquente)
  - CRP (corrélée à la sévérité)
  - D-dimères (risque thrombose)
  - Ferritine (orage cytokinique)
  - Troponine (myocardite)
  - LDH (nécrose tissulaire)
- [ ] **Imagerie:**
  - Rx thorax (pneumonie, SDRA)
  - TDM thoracique (verre dépoli)
- [ ] **ECG:** Si suspicion myocardite

### 6. Prise en charge COVID aigu

#### Mesures générales
- [ ] **Isolement:** 5-10 jours selon symptômes
- [ ] **Hydratation, nutrition**
- [ ] **Surveillance:** SaO₂, constantes
- [ ] **Prévention thrombose:** HBPM si alité

#### Traitements spécifiques
- [ ] **Antiviraux (si <5 jours):**
  - Paxlovid (nirmatrelvir-ritonavir)
  - Remdesivir si hospitalisation
- [ ] **Corticoïdes (si O₂ requis):**
  - Dexaméthasone 6mg/j x 10 jours
- [ ] **Anticorps monoclonaux** (variants sensibles)

#### Critères hospitalisation
- [ ] **SaO₂ <95%** air ambiant
- [ ] **FR >30/min**
- [ ] **Facteurs risque + aggravation**
- [ ] **Décompensation comorbidités**
- [ ] **Isolement impossible**

## 📋 LONG COVID / SYNDROME POST-COVID

### 1. Définition et épidémiologie
**Critères OMS:**
- [ ] Antécédent COVID confirmé/probable
- [ ] Symptômes ≥3 mois après infection
- [ ] Durée symptômes ≥2 mois
- [ ] Non expliqués par autre diagnostic
- [ ] Impact sur fonctionnement quotidien

**Épidémiologie:**
- 10-20% après COVID aigu
- Plus fréquent: femmes 35-50 ans
- Indépendant de la sévérité initiale

### 2. Anamnèse Long COVID

#### Histoire COVID initiale et contexte pandémique
- [ ] **Infection aiguë:** Date, sévérité, traitements, hospitalisation?
- [ ] **Évolution:** Amélioration puis rechute? Persistance?
- [ ] **Vaccinations:** Avant/après infection
- [ ] **Vécu pandémie:** Isolement social, pertes (proches/emploi), télétravail
- [ ] **Peur contamination:** Comportements d'évitement, anxiété sociale

#### Symptômes actuels systématiques

**Fatigue pathologique (90%)**
- [ ] **Caractéristiques:**
  - Épuisement disproportionné
  - Non amélioré par repos
  - **Malaise post-effort (PEM)** ⚠️
  - Aggravation 12-48h après effort
  - Récupération prolongée
- [ ] **Impact fonctionnel:**
  - Réduction activités >50%
  - Arrêt travail/mi-temps thérapeutique
  - Dépendance AVQ

**Troubles neurocognitifs (85%)**
- [ ] **"Brouillard cérébral":**
  - Difficultés concentration
  - Troubles mémoire immédiate
  - Difficultés à trouver mots
  - Ralentissement cognitif
  - Problèmes multitâche
- [ ] **Céphalées:** Nouvelles ou aggravées

**Symptômes cardio-respiratoires (60%)**
- [ ] **Dyspnée:** Repos/effort, orthopnée
- [ ] **Douleurs thoraciques:** Atypiques
- [ ] **Palpitations:** Repos/effort
- [ ] **Tachycardie orthostatique** (POTS)

**Dysautonomie**
- [ ] **Intolérance orthostatique:**
  - Vertiges au lever
  - Lipothymies
  - Tachycardie positionnelle
- [ ] **Thermorégulation:**
  - Sueurs nocturnes
  - Intolérance température
  - Fébricule persistant

**Troubles psychologiques post-COVID**
- [ ] **Anxiété contamination:** Peur excessive virus, évitement foules
- [ ] **Anxiété sociale:** Difficultés vie sociale, agoraphobie secondaire
- [ ] **TSPT:** Flashbacks hospitalisation, hypervigilance sanitaire
- [ ] **Dépression réactionnelle:** Isolement persistant, perte activités

#### Facteurs aggravants
- [ ] **Effort physique** (même minime)
- [ ] **Stress émotionnel** et préoccupations COVID
- [ ] **Infections intercurrentes**
- [ ] **Chaleur et situations anxiogènes**

### 3. Examen clinique Long COVID

#### Évaluation générale
- [ ] **État général:** Fatigue visible, amaigrissement
- [ ] **Constantes:** TA, FC, T°, SpO₂, poids

#### Test orthostatique OBLIGATOIRE
**Protocole NASA Lean Test:**
1. Repos couché 5 minutes
2. FC/TA couchées
3. Debout contre mur
4. FC/TA à 1', 3', 5', 10'
5. **POTS si:** ΔFC >30 bpm sans hypotension

#### Recherche complications
- [ ] **Myocardite:** Auscultation, ECG
- [ ] **Thrombose:** Mollet, signes EP
- [ ] **Déficit neurologique** focal
- [ ] **Organomégalie**

### 4. Examens complémentaires Long COVID

#### Bilan systématique
- [ ] **NFS, plaquettes, CRP, VS**
- [ ] **Ionogramme, créatinine, glycémie**
- [ ] **TSH** (dysthyroïdie post-COVID), **ferritine, B12, folates**
- [ ] **25-OH vitamine D** (carence confinement)
- [ ] **Bilan hépatique**

#### Examens orientés
- [ ] **ECG** si palpitations/douleur thoracique
- [ ] **Rx thorax** si dyspnée persistante
- [ ] **EFR** si dyspnée sans cause cardiaque
- [ ] **Échocardiographie** si suspicion myocardite
- [ ] **Holter ECG** si palpitations
- [ ] **IRM cérébrale** si troubles cognitifs marqués

### 5. Prise en charge Long COVID

#### Principes généraux ⚠️
- [ ] **Validation symptômes:** "Vos symptômes sont réels"
- [ ] **Approche individualisée**
- [ ] **Gestion énergie (Pacing)** pas exercice intensif
- [ ] **Éviter surmenage** (aggrave PEM)
- [ ] **Approche multidisciplinaire**

#### Gestion de la fatigue
**Pacing (gestion énergie):**
- [ ] Identifier "enveloppe énergétique"
- [ ] Planifier activités prioritaires
- [ ] Repos préventif (pas curatif)
- [ ] Fractionnement tâches
- [ ] Journal d'activité

**Réentraînement:** UNIQUEMENT si pas de PEM
- [ ] Progression très lente (10%/semaine)
- [ ] Surveillance malaise post-effort
- [ ] ARRÊT si aggravation

#### Troubles cognitifs
- [ ] **Stratégies compensatoires:**
  - Aides-mémoire, alarmes
  - Environnement calme
  - Tâches séquentielles
  - Pauses cognitives
- [ ] **Rééducation:** Orthophonie, neuropsychologie

#### POTS/Dysautonomie
- [ ] **Non pharmacologique:**
  - Hydratation 2-3L/jour
  - Sel 10-12g/jour (si pas HTA)
  - Bas contention classe II
  - Lever progressif
- [ ] **Pharmacologique si échec:**
  - Fludrocortisone 0.1mg/j
  - Midodrine 2.5-10mg x3/j
  - Propranolol 10-20mg x2/j

#### Traitements symptomatiques
- [ ] **Douleurs:** Paracétamol, gabapentine
- [ ] **Troubles sommeil:** Hygiène sommeil, mélatonine

#### Prise en charge psychologique
- [ ] **TCC spécifique COVID:**
  - Restructuration cognitive (pensées catastrophiques)
  - Exposition graduelle (situations évitées)
  - Psychoéducation COVID/risques réels
  - Gestion incertitude post-pandémique
- [ ] **Pharmacothérapie si besoin:**
  - ISRS: Sertraline 50-200mg/j, Escitalopram 10-20mg/j
  - Anxiolytiques court terme: BZD 2-4 semaines max
- [ ] **Réhabilitation sociale:** Reprise progressive activités, groupes soutien

#### Supplémentations
- [ ] **Vitamine D:** 2000-4000 UI/j
- [ ] **B12:** Si carence
- [ ] **Fer:** Si ferritine <30
- [ ] **Magnésium:** 300mg/j

### 6. Suivi Long COVID
- [ ] **Consultations mensuelles** initialement
- [ ] **Échelles validées:** Chalder Fatigue Scale
- [ ] **Réévaluation fonctionnelle**
- [ ] **Orientation spécialisée** si besoin

## ⚠️ RED FLAGS - Actions immédiates

### COVID aigu
- **SaO₂ <95%** → Hospitalisation immédiate
- **FR >30/min** → Détresse respiratoire
- **Troubles neurologiques** → AVC/encéphalite
- **Douleur thoracique** → Myocardite/EP
- **Choc** → Réanimation

### Long COVID
- **Douleur thoracique aiguë** → ECG, troponine, écho
- **Dyspnée repos nouvelle** → EP/myocardite
- **PEM sévère** → Arrêt activité, pacing strict
- **ΔFC >30 debout** → POTS, traitement dysautonomie
- **Déficit neurologique focal** → AVC
- **Idées suicidaires** → Psychiatrie urgente
- **Attaques panique invalidantes** → Urgence psychiatrique

## 🎯 POINTS CLÉS POUR L'ECOS

### ✅ À faire absolument
1. **Distinguer COVID aigu vs Long COVID** (critère 3 mois)
2. **Test orthostatique** systématique Long COVID
3. **Malaise post-effort (PEM)** = symptôme clé Long COVID
4. **Pacing pas exercice intensif** pour Long COVID
5. **Validation symptômes** ("c'est réel, pas psychologique")
6. **Bilan systématique** éliminer autres causes
7. **Impact fonctionnel** (travail, AVQ, relations)
8. **Évaluer composante anxieuse** post-pandémique

### ❌ Pièges à éviter
1. **Minimiser Long COVID** ("c'est psychologique")
2. **Prescrire sport intensif** (aggrave PEM)
3. **Promettre guérison rapide**
4. **Oublier test orthostatique**
5. **Négliger impact psychosocial** et anxiété post-COVID
6. **Sous-estimer fatigue pathologique**
7. **Négliger recherche troubles anxieux**

## 💡 MNÉMOTECHNIQUES

### Critères Long COVID "3-2-1"
- **3 mois** après infection
- **2 mois** durée symptômes  
- **1 impact** fonctionnel significatif

### Symptômes Long COVID "FACEDA"
- **F**atigue avec PEM
- **A**nosmie persistante
- **C**ognition (brouillard cérébral)
- **E**ssoufflement
- **D**ysautonomie (POTS)
- **A**nxiété post-COVID

### POTS diagnostic "30-40"
- **30 bpm** augmentation FC adulte
- **40 bpm** si < 19 ans

### Pacing "3P"
- **P**lanifier (activités prioritaires)
- **P**ause (repos préventif)
- **P**acing (respecter limites énergétiques)

**B:** "COVID initial: [sévérité]. Vaccinations: [statut]. Comorbidités: [facteurs risque]. Vécu pandémique: [isolement/pertes]."
**A:** "Symptômes: [fièvre/fatigue/dyspnée/anxiété]. PEM: [+/-]. Test orthostatique: [POTS +/-]. Anxiété: [contamination/sociale]. Impact: [travail/AVQ/relations]."
**R:** "[COVID aigu: isolement, surveillance. Long COVID: pacing, suivi spécialisé]. Troubles anxieux: [TCC, ISRS si besoin]. Bilan: [complémentaires]. Suivi: [multidisciplinaire]."
