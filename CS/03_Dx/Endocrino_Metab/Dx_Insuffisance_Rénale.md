# Insuffisance Rénale - Fiche de révision ECOS

## 📋 Description
Altération de la fonction rénale caractérisée par une diminution du débit de filtration glomérulaire (DFG), pouvant être aiguë (IRA) ou chronique (IRC/MRC). L'IRA représente 70% des cas de consultation néphro-urgente.

## 🔬 Épidémiologie
- **IRA hospitalière** : 15-20% patients hospitalisés
- **Causes pré-rénales** : 70% des IRA
- **Mortalité IRA** : 20-50% selon contexte
- **IRC** : 10% population générale >65 ans

## 📋 ANAMNÈSE SYSTÉMATIQUE

### 1. Caractérisation du trouble rénal ⚠️

#### Installation et chronologie
- **IRA** : Détérioration en heures/jours (<3 mois)
  - Installation brutale vs progressive  
  - Dernière créatinine connue normale?
- **IRC** : Évolution >3 mois
  - Découverte fortuite vs symptomatique
  - Antécédents néphrologiques connus

#### Diurèse ⚠️ ESSENTIEL
- **Volume quotidien** : Habituel vs actuel
- **Oligurie** : <500 mL/24h (signe de gravité)
- **Anurie** : <100 mL/24h (urgence absolue)
- **Polyurie** : Phase récupération ou IRC compensée
- **Nycturie** : Perte pouvoir concentration (IRC)

### 2. Recherche étiologique IRA

#### Causes pré-rénales ⚠️ 70% DES CAS
- **Hypovolémie vraie** :
  - Pertes digestives : Vomissements, diarrhée profuse
  - Pertes cutanées : Brûlures, hyperthermie, sudation
  - Hémorragies : Digestive, génitale, traumatisme
  - Pertes rénales : Diurétiques, polyurie osmotique
- **Hypovolémie efficace** :
  - Insuffisance cardiaque décompensée
  - Cirrhose avec ascite
  - Syndrome néphrotique sévère
- **Médicaments** :
  - IEC/ARA2 + déshydratation
  - AINS (particulièrement si âge >65 ans)
  - Diurétiques en surdosage

#### Causes rénales (parenchymateuses)
- **Nécrose tubulaire aiguë** :
  - Ischémique : Choc prolongé, hypotension
  - Toxique : Produits de contraste, aminoglycosides
  - Rhabdomyolyse : Effort extrême, statines, écrasement
- **Néphrite interstitielle aiguë** :
  - Médicamenteuse : AINS, antibiotiques, IPP
  - Infectieuse : Pyélonéphrite, sepsis
  - Auto-immune : Lupus, vascularites
- **Glomérulonéphrite rapidement progressive** :
  - Post-infectieuse (streptocoque)
  - ANCA+ (granulomatose, polyangéite)
  - Anti-MBG (Goodpasture)

#### Causes post-rénales (obstructives)
- **Obstacle bas** :
  - Adénome/cancer prostate
  - Sténoses urétrales
  - Vessie neurologique
- **Obstacle haut** (bilatéral ou rein unique) :
  - Lithiases urétérales
  - Cancers pelviens (utérus, vessie, côlon)
  - Fibrose rétropéritonéale

### 3. Recherche étiologique IRC

#### Principales causes
- **Diabète** : Néphropathie diabétique (1ère cause)
- **HTA** : Néphroangiosclérose hyaline
- **Glomérulonéphrites** chroniques
- **Polykystose** rénale autosomique dominante
- **Néphropathies** interstitielles chroniques
- **Uropathies** malformatives/obstructives

### 4. Symptômes d'insuffisance rénale

#### Signes précoces
- **Asthénie** progressive
- **Nycturie** (perte concentration)
- **HTA** d'apparition récente
- **Œdèmes** des membres inférieurs

#### Signes d'urémie (avancée)
- **Digestifs** : Nausées, vomissements, anorexie, goût métallique
- **Neurologiques** : Confusion, somnolence, astérixis (flapping)
- **Cutanés** : Prurit diffus, peau sèche
- **Cardiovasculaires** : Péricardite, OAP, HTA maligne

### 5. Médicaments et toxiques ⚠️
- **Néphrotoxiques directs** :
  - Aminoglycosides, vancomycine
  - Produits de contraste iodés
  - Cisplatine, méthotrexate
  - Lithium (IRC tubulo-interstitielle)
- **Fonctionnels** : IEC/ARA2, AINS
- **Phytothérapie** : Aristoloche (néphropathie endémique)

## 🩺 EXAMEN CLINIQUE

### Évaluation volémique ⚠️ PRIORITAIRE

#### Signes hypovolémie
- **Hypotension orthostatique** (ΔTA >20 mmHg)
- **Tachycardie** compensatrice
- **Pli cutané** persistant, muqueuses sèches
- **Soif intense**, oligurie

#### Signes hypervolémie/surcharge
- **Œdèmes** déclives bilatéraux, prise de poids
- **Turgescence jugulaires**, reflux hépato-jugulaire
- **Crépitants** pulmonaires (OAP)
- **Hépatomégalie** de stase

### Examen spécialisé

#### Abdominal ⚠️ RECHERCHE OBSTACLE
- **Globe vésical** : Percussion matité sus-pubienne
- **Gros reins** palpables : Polykystose, hydronéphrose
- **Contact lombaire** douloureux
- **Souffle abdominal** : Sténose artère rénale

#### Cardiovasculaire
- **HTA** : Sévérité, retentissement (FO, ECG)
- **Frottement péricardique** (péricardite urémique)
- **Souffle cardiaque** (anémie, surcharge)

#### Neurologique (si urémie)
- **État de conscience** : Obnubilation, coma
- **Astérixis** : Flapping tremor (mains en extension)
- **Myoclonies**, convulsions

## 🔬 EXAMENS COMPLÉMENTAIRES

### Bilan de base ⚠️ SYSTÉMATIQUE

#### Fonction rénale
- **Créatinine** : Valeur actuelle vs antérieure ⚠️
- **DFG estimé** : Formules CKD-EPI/MDRD
- **Urée** : Rapport urée/créatinine >100 si pré-rénal
- **Cystatin C** : Si doute sur créatinine

#### Ionogramme complet
- **Potassium** : Hyperkaliémie >5.5 mmol/L ⚠️
- **Sodium** : Hyponatrémie de dilution
- **Bicarbonates** : Acidose métabolique
- **Phosphore/Calcium** : Troubles phosphocalciques

#### Analyses urinaires ⚠️ DIAGNOSTIQUES
- **Bandelette** : Protéinurie, hématurie, densité
- **ECBU** : Infection, cristaux
- **Sédiment urinaire** :
  - Cylindres granuleux → NTA
  - Cylindres hématiques → Glomérulonéphrite
  - Éosinophilurie → NIA

### Indices rénaux (si oligurie)
- **FeNa** = (NaU/NaP) × (CrP/CrU) × 100
  - <1% → Pré-rénale
  - >2% → Rénale (NTA)
- **Osmolalité urinaire** :
  - >500 mOsm/kg → Pré-rénale
  - <300 mOsm/kg → Rénale

### Imagerie
- **Échographie rénale** ⚠️ SYSTÉMATIQUE :
  - Taille : <9cm → IRC, normale → IRA
  - Dilatation pyélocalicielle → Obstacle
  - Différenciation cortico-médullaire
- **Scanner abdomino-pelvien** : Si obstacle suspecté

## 📊 CLASSIFICATION

### IRA - Critères AKIN
| Stade | Créatinine | Diurèse |
|-------|------------|---------|
| **1** | ×1.5-2 ou +26.5 μmol/L | <0.5 mL/kg/h ×6h |
| **2** | ×2-3 | <0.5 mL/kg/h ×12h |
| **3** | ×3 ou >354 μmol/L | <0.3 mL/kg/h ×24h |

### IRC - Stades KDIGO
| Stade | DFG (mL/min/1.73m²) | Description |
|-------|---------------------|-------------|
| **G1** | ≥90 + marqueurs | Normale avec atteinte |
| **G2** | 60-89 + marqueurs | Légèrement diminuée |
| **G3a** | 45-59 | Modérément diminuée |
| **G3b** | 30-44 | Moyennement diminuée |
| **G4** | 15-29 | Sévèrement diminuée |
| **G5** | <15 ou dialyse | Terminale |

## 💊 PRISE EN CHARGE

### 1. Traitement étiologique IRA

#### IRA pré-rénale
- **Correction hypovolémie** :
  - Arrêt diurétiques/IEC si hypovolémie
  - Remplissage prudent : NaCl 0.9% ou Ringer
  - Objectif diurèse >0.5 mL/kg/h
- **Traitement cause sous-jacente** :
  - Sepsis : Antibiothérapie, source control
  - Choc cardiogénique : Inotropes, revascularisation
  - Arrêt néphrotoxiques (AINS, contraste)

#### IRA rénale
- **NIA** : Arrêt médicament + Corticoïdes 1mg/kg/j si sévère
- **GN** : Immunosuppression selon type + Avis néphrologue
- **NTA** : Traitement supportif, prévention complications

#### IRA post-rénale ⚠️ URGENCE UROLOGIQUE
- **Obstacle bas** : Sondage vésical, désobstruction prostatique
- **Obstacle haut** : Néphrostomie, sonde urétérale (JJ)

### 2. Traitement symptomatique

#### Complications aiguës ⚠️
- **Hyperkaliémie >6.5 mmol/L** :
  - Gluconate calcium 10% IV (antagonisme)
  - Insuline + glucose (transfert intracellulaire)  
  - Résines échangeuses, dialyse
- **OAP** : Diurétiques anse, dialyse si réfractaire
- **Acidose pH <7.20** : Bicarbonates IV

### 3. Traitement IRC - Ralentir progression

#### Néphroprotection
- **IEC/ARA2** si protéinurie >0.3g/j
- **Objectif TA** : <130/80 (<125/75 si protéinurie)
- **Contrôle glycémique** : HbA1c <7% si diabète
- **Arrêt tabac**, contrôle poids, exercice

#### Complications chroniques
- **Anémie** : Fer puis EPO si Hb <10g/dL
- **Troubles phosphocalciques** :
  - Chélateurs phosphore (carbonate calcium)
  - Vitamine D active (calcitriol)
- **Acidose** : Bicarbonates PO si HCO₃⁻ <22 mmol/L

### 4. Épuration extra-rénale

#### Indications urgentes "AEIOU" ⚠️
- **A**cidose sévère pH <7.15 réfractaire
- **E**lectrolytes : K⁺ >6.5 mmol/L réfractaire
- **I**ntoxication (méthanol, éthylène glycol, lithium)
- **O**verload : OAP réfractaire aux diurétiques
- **U**rémie symptomatique (péricardite, encéphalopathie)

#### Modalités
- **Hémodialyse** : 3×4h/semaine si stable
- **Hémofiltration continue** : Si instabilité hémodynamique
- **Dialyse péritonéale** : Rare en aigu

### 5. Surveillance

#### IRA (hospitalisation)
- **Quotidien** : Poids, diurèse horaire, créatinine
- **Récupération** : Habituellement 1-3 semaines
- **Suivi néphro** : Si créatinine reste élevée

#### IRC (ambulatoire)
- **Fréquence** selon stade :
  - G1-2 : Annuelle
  - G3 : 6 mois  
  - G4 : 3 mois
  - G5 : Mensuelle
- **Paramètres** : DFG, protéinurie, ionogramme, NFS, PTH

## ⚠️ RED FLAGS - URGENCES

### Signes de gravité immédiate
- **Oligo-anurie** <12h malgré traitement
- **Hyperkaliémie** >6.5 mmol/L (risque arrêt cardiaque)
- **OAP** réfractaire (surcharge hydrique)
- **Encéphalopathie urémique** (confusion, convulsions)
- **Péricardite** urémique (frottement, tamponnade)

### Critères hospitalisation
- **IRA** stade ≥2 ou complications
- **Cause nécessitant** traitement urgent
- **Impossibilité** surveillance/traitement ambulatoire
- **Contexte** : Âge élevé, comorbidités, isolement

## 🎯 POINTS CLÉS POUR L'ECOS

### ✅ À faire absolument
1. **Créatinine antérieure** = Distinguer IRA/IRC
2. **Évaluer volémie** (hypo/normo/hypervolémie)
3. **Globe vésical** = Cause post-rénale fréquente
4. **Échographie rénale** systématique
5. **Dépister hyperkaliémie** (ECG + ionogramme)
6. **Analyser sédiment urinaire** (cylindres diagnostiques)
7. **Surveiller diurèse** horaire si oligo-anurie

### ❌ Pièges à éviter
1. Confondre IRA et IRC (antécédents, taille rénale)
2. Maintenir IEC/ARA2 en hypovolémie avérée
3. Remplissage excessif si signes surcharge
4. Oublier recherche obstacle (échographie)
5. Retarder dialyse si indication absolue
6. Méconnaître hyperkaliémie maligne

## 💡 MNÉMOTECHNIQUES

### Causes IRA - "DVD"
- **D**éshydratation (pré-rénale)
- **V**asculaire/choc (pré-rénale)  
- **D**rogues/médicaments (IEC, AINS)

### Dialyse urgente - "AEIOU"
- **A**cidose réfractaire
- **E**lectrolytes (hyperkaliémie)
- **I**ntoxication
- **O**verload (surcharge)
- **U**rémie symptomatique

### Indices urinaires - "ON<20"
- **O**smolalité >500 + **N**a <20 → Pré-rénale
