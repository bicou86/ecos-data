# Fiche de Révision ECOS - PROLAPSUS GÉNITAL

## 🎯 Situation à Starting Point (SSP)
**Description:** Femme consultant pour sensation de "boule vaginale" ou pesanteur pelvienne
**Objectifs d'évaluation:** Évaluer le type et le stade du prolapsus, rechercher les symptômes associés, évaluer le retentissement, proposer une prise en charge

---

## 📋 ANAMNÈSE

### 1. Symptôme principal ⚠️ ESSENTIEL

#### 1.1 Description de la gêne
- [ ] **Sensation de "boule" vaginale:**
  - Intravaginale
  - Extériorisée à la vulve
  - Réductible manuellement
- [ ] **Pesanteur pelvienne:**
  - Sensation de "descente d'organes"
  - Lourdeur hypogastrique
  - Aggravation en fin de journée
- [ ] **Gêne à la marche**
- [ ] **Inconfort position assise**

#### 1.2 Évolution dans la journée
- [ ] **Amélioration:** Au repos, position allongée
- [ ] **Aggravation:**
  - Station debout prolongée
  - Effort physique
  - Toux, éternuement
  - Port de charges

#### 1.3 Ancienneté et progression
- [ ] **Début des symptômes**
- [ ] **Évolution:** Progressive habituellement
- [ ] **Retentissement** sur qualité de vie

### 2. Symptômes associés ⚠️ RECHERCHE SYSTÉMATIQUE

#### 2.1 Troubles urinaires (50-80%)
- [ ] **Incontinence urinaire d'effort (IUE):**
  - Fuites à la toux, éternuement
  - Fuites au rire, sport
  - Port de protections
- [ ] **Urgenturie:** Besoins impérieux
- [ ] **Pollakiurie:** >8 mictions/jour
- [ ] **Dysurie:** Difficulté à uriner
- [ ] **Sensation vidange incomplète**
- [ ] **Manœuvres digitales** pour uriner
- [ ] **Infections urinaires** récidivantes

#### 2.2 Troubles ano-rectaux (20-30%)
- [ ] **Constipation terminale**
- [ ] **Sensation évacuation incomplète**
- [ ] **Manœuvres digitales** pour déféquer
- [ ] **Incontinence aux gaz**
- [ ] **Incontinence fécale**

#### 2.3 Troubles sexuels
- [ ] **Dyspareunie:** Douleurs rapports
- [ ] **Diminution sensations**
- [ ] **Gêne mécanique**
- [ ] **Évitement rapports**
- [ ] **Impact relationnel**

#### 2.4 Autres symptômes
- [ ] **Douleurs:**
  - Lombalgies basses
  - Douleurs pelviennes
- [ ] **Saignements:** Ulcération muqueuse
- [ ] **Leucorrhées:** Irritation

### 3. Facteurs de risque ⚠️ MULTIFACTORIELS

#### 3.1 Facteurs obstétricaux (principal)
- [ ] **Nombre de grossesses**
- [ ] **Parité:** Nombre d'accouchements
- [ ] **Voie d'accouchement:**
  - Voie basse (risque++)
  - Césarienne (protection relative)
- [ ] **Poids des enfants:** >4000g
- [ ] **Accouchements difficiles:**
  - Travail prolongé
  - Extraction instrumentale
  - Déchirures périnéales
  - Épisiotomie

#### 3.2 Facteurs constitutionnels
- [ ] **Âge:** Risque augmente
- [ ] **Ménopause:** Carence œstrogénique
- [ ] **Antécédents familiaux** prolapsus
- [ ] **Troubles tissus conjonctifs**
- [ ] **Ethnie:** Caucasiennes > Africaines

#### 3.3 Facteurs aggravants
- [ ] **Obésité:** IMC élevé
- [ ] **Constipation chronique**
- [ ] **Toux chronique:** BPCO, tabac
- [ ] **Port charges lourdes**
- [ ] **Activités sportives** à impact

#### 3.4 Facteurs iatrogènes
- [ ] **Chirurgies pelviennes:**
  - Hystérectomie
  - Cure prolapsus antérieure
- [ ] **Radiothérapie pelvienne**

### 4. Antécédents

#### 4.1 Gynéco-obstétricaux
- [ ] **Détail accouchements:**
  - Durée travail
  - Poids enfants
  - Complications
- [ ] **Rééducation périnéale** post-partum
- [ ] **Statut hormonal:** Ménopause, THS
- [ ] **Chirurgies gynécologiques**

#### 4.2 Médicaux
- [ ] **Pathologies respiratoires** chroniques
- [ ] **Troubles transit**
- [ ] **Pathologies neurologiques**
- [ ] **Diabète** (neuropathie)

### 5. Retentissement ⚠️ QUALITÉ DE VIE

#### 5.1 Activités quotidiennes
- [ ] **Limitation activités** physiques
- [ ] **Arrêt sport**
- [ ] **Difficultés professionnelles**
- [ ] **Gêne sociale**

#### 5.2 Impact psychologique
- [ ] **Image corporelle** altérée
- [ ] **Estime de soi**
- [ ] **Anxiété, dépression**
- [ ] **Isolement social**

#### 5.3 Vie sexuelle
- [ ] **Fréquence rapports**
- [ ] **Satisfaction**
- [ ] **Impact couple**

### 6. Traitements essayés
- [ ] **Rééducation périnéale**
- [ ] **Pessaire**
- [ ] **Œstrogènes locaux**
- [ ] **Chirurgie antérieure**

### 7. Attentes et motivation
- [ ] **Demande traitement** actif
- [ ] **Préférence:** Conservateur vs chirurgical
- [ ] **Désir grossesse** ultérieure

### 8. Question de clôture
"Avez-vous des fuites urinaires ou des difficultés pour aller à la selle?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### État général
- [ ] **IMC** (surpoids = facteur risque)
- [ ] **Mobilité**
- [ ] **État cognitif** (si âgée)

### Examen abdominal
- [ ] **Cicatrices** chirurgicales
- [ ] **Masses pelviennes**
- [ ] **Diastasis recti** (écartement muscles droits)

### Examen gynécologique ⚠️ POSITION GYNÉCOLOGIQUE

#### Inspection vulvaire au repos
- [ ] **Béance vulvaire**
- [ ] **Distance ano-vulvaire** (<3cm = périnée descendu)
- [ ] **Cicatrices** (épisiotomie, déchirures)
- [ ] **Trophicité** (carence œstrogénique)

#### Manœuvres de poussée ⚠️ CLASSIFICATION POP-Q

**Demander effort de poussée (Valsalva):**
- [ ] **Cystocèle:** Bombement paroi vaginale antérieure
- [ ] **Hystérocèle:** Descente col utérin
- [ ] **Rectocèle:** Bombement paroi vaginale postérieure
- [ ] **Élytrocèle:** Bombement cul-de-sac Douglas
- [ ] **Prolapsus rectal:** Extériorisation rectum

**Stadification (Classification de Baden-Walker simplifiée):**
- **Stade 0:** Pas de prolapsus
- **Stade 1:** Descente mi-vagin
- **Stade 2:** Affleure l'orifice vulvaire
- **Stade 3:** Dépasse l'orifice vulvaire
- **Stade 4:** Extériorisation complète

#### Examen au spéculum
- [ ] **Valves séparées** (antérieure/postérieure)
- [ ] **Évaluation compartiments** séparément
- [ ] **Col utérin:** Position, mobilité
- [ ] **Muqueuse vaginale:** Trophicité, ulcérations

#### Toucher vaginal
- [ ] **Tonus musculaire** périnéal (testing)
- [ ] **Contraction volontaire** (0-5)
- [ ] **Inversion commande** (poussée au lieu contraction)
- [ ] **Utérus:** Taille, position
- [ ] **Paramètres:** Souplesse

### Testing périnéal ⚠️ IMPORTANT
- [ ] **Contraction volontaire:**
  - Force (0-5)
  - Endurance
  - Fatigabilité
- [ ] **Réflexe à la toux**
- [ ] **Verrouillage périnéal** (contraction avant toux)

### Recherche incontinence urinaire
- [ ] **Test à la toux:** Vessie pleine, debout
- [ ] **Manœuvre de Bonney:** Soutien urètre (IUE)
- [ ] **Recherche IU masquée** après réduction prolapsus

### Examen neurologique (si indiqué)
- [ ] **Sensibilité périnéale**
- [ ] **Réflexes:** Anal, bulbo-caverneux
- [ ] **Tonus anal** (TR)

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Bilan de base
- [ ] **ECBU:** Si symptômes urinaires
- [ ] **Frottis cervical** à jour
- [ ] **Échographie pelvienne** si doute masses

#### 1.2 Bilan urodynamique (si troubles urinaires)
- [ ] **Débitmétrie**
- [ ] **Cystomanométrie**
- [ ] **Profilométrie urétrale**
- [ ] **Recherche IUE masquée**

#### 1.3 Explorations spécialisées (selon symptômes)
- [ ] **Défécographie/IRM dynamique:** Troubles défécation
- [ ] **Manométrie ano-rectale:** Incontinence fécale
- [ ] **Colpocystographie:** Bilan préopératoire

### 2. Traitement conservateur ⚠️ PREMIÈRE LIGNE

#### 2.1 Rééducation périnéale
- [ ] **Indications:** Stade 1-2, IUE associée
- [ ] **Techniques:**
  - Travail manuel
  - Biofeedback
  - Électrostimulation
- [ ] **Protocole:** 10-20 séances
- [ ] **Auto-exercices** quotidiens (Kegel)
- [ ] **Efficacité:** 40-60% amélioration

#### 2.2 Pessaire ⚠️ ALTERNATIVE CHIRURGIE
**Types:**
- [ ] **Anneau:** Prolapsus modéré
- [ ] **Cube:** Prolapsus sévère
- [ ] **Dish:** Avec incontinence

**Modalités:**
- [ ] **Essai tailles** différentes
- [ ] **Œstrogènes locaux** préalables si atrophie
- [ ] **Apprentissage** auto-gestion
- [ ] **Suivi:** 3-6 mois

**Indications:**
- [ ] **Refus/CI chirurgie**
- [ ] **Attente chirurgie**
- [ ] **Désir grossesse**
- [ ] **Test thérapeutique**

**Complications:**
- [ ] **Érosions vaginales**
- [ ] **Leucorrhées**
- [ ] **Infections**

### 3. Mesures associées

#### 3.1 Œstrogénothérapie locale
- [ ] **Crème/ovules œstrogènes**
- [ ] **Améliore trophicité**
- [ ] **3 fois/semaine** entretien
- [ ] **CI:** Cancer hormono-dépendant

#### 3.2 Modifications hygiéno-diététiques
- [ ] **Perte poids** si surcharge
- [ ] **Traitement constipation**
- [ ] **Arrêt tabac** (toux)
- [ ] **Éviter port charges**
- [ ] **Adaptation activités** physiques

### 4. Traitement chirurgical

#### 4.1 Indications
- [ ] **Échec traitement** conservateur
- [ ] **Prolapsus stade ≥3**
- [ ] **Retentissement** important
- [ ] **Demande patiente**

#### 4.2 Voies d'abord
**Voie vaginale (privilégiée):**
- [ ] **Colpopérinéorraphie** antérieure (cystocèle)
- [ ] **Colpopérinéorraphie** postérieure (rectocèle)
- [ ] **Hystéropexie** (conservation utérus)
- [ ] **Colpectomie** (femme âgée)

**Voie abdominale (laparoscopie/laparotomie):**
- [ ] **Promontofixation:** Gold standard
- [ ] **Hystéropexie** laparoscopique
- [ ] **Fixation prothétique**

**Hystérectomie:**
- [ ] **Non systématique**
- [ ] **Si pathologie utérine** associée
- [ ] **Voie vaginale** privilégiée

#### 4.3 Traitement IUE associée
- [ ] **Bandelette sous-urétrale** (TVT, TOT)
- [ ] **Dans même temps** ou différé
- [ ] **Après test IUE** masquée

### 5. Complications chirurgicales

#### 5.1 Immédiates
- [ ] **Hémorragie**
- [ ] **Plaies vessie/rectum**
- [ ] **Infection**

#### 5.2 Tardives
- [ ] **Récidive:** 20-30%
- [ ] **Dyspareunie** (rétrécissement)
- [ ] **Troubles mictionnels**
- [ ] **Érosion prothèse**
- [ ] **Novo incontinence**

### 6. Surveillance

#### Post-opératoire
- [ ] **Consultation** 1 mois, 3 mois, 1 an
- [ ] **Examen clinique**
- [ ] **Recherche complications**
- [ ] **Satisfaction** patiente

#### Traitement conservateur
- [ ] **Suivi régulier** 3-6 mois
- [ ] **Adaptation pessaire**
- [ ] **Surveillance muqueuse**

### 7. Prévention

#### Primaire
- [ ] **Préparation périnéale** prénatale
- [ ] **Accouchement:** Limiter extractions
- [ ] **Rééducation** post-partum systématique

#### Secondaire
- [ ] **Dépistage précoce**
- [ ] **Traitement facteurs** risque
- [ ] **Rééducation** préventive ménopause

#### Information sur la pathologie
- [ ] **Mécanismes** du prolapsus

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Examen debout + poussée** (stade maximal)
2. **Évaluer 3 compartiments** séparément
3. **Testing périnéal** systématique
4. **Rechercher IUE** associée/masquée
5. **Proposer conservateur** en première ligne
6. **Pessaire = alternative** valable

### ❌ Pièges à éviter
1. **Examen couché** seul (sous-estimation)
2. **Oublier IUE masquée** (novo-incontinence)
3. **Hystérectomie systématique**
4. **Négliger rééducation** périnéale
5. **Promettre 0% récidive** chirurgie

### 💡 Astuces mnémotechniques
- **Types prolapsus:** **C**ystocèle, **H**ystérocèle, **R**ectocèle, **E**lytrocèle (CHRE)
- **Facteurs risque:** **P**arité, **Â**ge, **P**oids, **T**oux (PÂPT)
- **Stades:** 1 = **M**i-vagin, 2 = **A**ffleure, 3 = **D**épasse, 4 = **E**xtériorisé (MADE)
- **POP-Q points:** **A**ntérieur, **P**ostérieur, **C**ervix (APC)
