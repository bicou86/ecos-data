# Fiche de Révision ECOS - GASTRO-ENTÉRITE ENFANT

## 🎯 Situation à Starting Point (SSP)
**Description:** Prise en charge d'un enfant de 6 mois à 15 ans présentant diarrhée et/ou vomissements
**Objectifs d'évaluation:** Évaluation de la déshydratation, critères d'hospitalisation, réhydratation, prévention transmission

---

## 📋 ANAMNÈSE (25% des points)

### 1. Caractérisation des symptômes digestifs ⚠️ PRIORITAIRE

#### 1.1 Diarrhée (symptôme principal)
- [ ] **Début** : brutal ou progressif, durée
- [ ] **Fréquence** : nombre de selles/24h
- [ ] **Volume** : abondant, modéré (selon poids couche)
- [ ] **Consistance** : liquide, molle, présence de glaires
- [ ] **Couleur** : jaune, verte, sanglante ⚠️
- [ ] **Odeur** : fétide, acide, inhabituelle

#### 1.2 Vomissements associés
- [ ] **Fréquence** : nombre d'épisodes/24h
- [ ] **Volume** : abondant, petites quantités
- [ ] **Aspect** : alimentaire, bilieux ⚠️, fécaloïde ⚠️
- [ ] **Rapport aux repas** : immédiat, différé
- [ ] **Facteurs déclenchants** : mouvement, position

#### 1.3 Signes associés
- [ ] **Fièvre** : température, durée, frissons
- [ ] **Douleurs abdominales** : localisation, intensité, type
- [ ] **Nausées** persistantes
- [ ] **Ballonnements** abdominaux

### 2. Évaluation de la déshydratation ⚠️ CRITIQUE

#### 2.1 Signes cliniques rapportés par parents
- [ ] **Soif** : intense, absente (stade avancé)
- [ ] **Urines** : diminution fréquence, couleur foncée
- [ ] **Pleurs** : avec ou sans larmes
- [ ] **Comportement** : apathie, irritabilité
- [ ] **Perte de poids** : si pesée récente disponible

#### 2.2 Tolérance alimentaire ⚠️ CRUCIAL
- [ ] **Boissons** : acceptation, vomissements immédiats
- [ ] **Alimentation solide** : refus total/partiel
- [ ] **Allaitement** : maintien ou arrêt
- [ ] **Volumes ingérés** vs perdus (estimation parents)

### 3. Contexte épidémiologique et contage

#### 3.1 Exposition infectieuse
- [ ] **Cas familiaux** : parents, fratrie, même symptômes
- [ ] **Collectivité** : crèche, école, garderie
- [ ] **Épidémie** : notification cas similaires
- [ ] **Incubation** : délai exposition-symptômes

#### 3.2 Facteurs de risque
- [ ] **Saison** : hiver (rotavirus), été (bactéries)
- [ ] **Alimentation** : repas suspects, eau non potable
- [ ] **Voyages** récents : pays tropicaux
- [ ] **Animaux** : contact récent

### 4. Antécédents et terrain ⚠️ FRAGILITÉ

#### 4.1 Âge et développement
- [ ] **Âge exact** : < 6 mois = haut risque
- [ ] **Poids habituel** : courbe de croissance
- [ ] **Prématurité** : antécédent de fragilité
- [ ] **État nutritionnel** : malnutrition préexistante

#### 4.2 Comorbidités
- [ ] **Immunodéficience** : primitive, acquise, traitements
- [ ] **Maladie inflammatoire** intestinale
- [ ] **Mucoviscidose** : antécédent de malabsorption
- [ ] **Cardiopathie** : risque de décompensation

#### 4.3 Épisodes antérieurs
- [ ] **Gastro-entérites** précédentes : fréquence, gravité
- [ ] **Hospitalisation** pour déshydratation
- [ ] **Intolérance** au lactose post-infectieuse
- [ ] **Retard croissance** post-gastro

### 5. Alimentation et prise en charge initiale

#### 5.1 Alimentation habituelle
- [ ] **Type** : allaitement maternel, artificiel, diversifiée
- [ ] **Appétit habituel** vs actuel
- [ ] **Allergies** ou intolérances alimentaires connues
- [ ] **Suppléments** : vitamines, fer

#### 5.2 Tentatives de réhydratation
- [ ] **Solutés de réhydratation** : type, quantité, tolérance
- [ ] **Autres boissons** : eau pure, sodas (à éviter)
- [ ] **Médicaments** donnés : anti-diarrhéiques (contre-indiqués)
- [ ] **Régime alimentaire** : modifications apportées

### 6. Recherche de complications ⚠️ RED FLAGS

#### 6.1 Signes de gravité digestive
- [ ] **Sang dans selles** : quantité, aspect
- [ ] **Invagination** : pleurs paroxystiques, rectorragies
- [ ] **Appendicite** : douleur fosse iliaque droite
- [ ] **Occlusion** : arrêt selles et gaz, vomissements fécaloïdes

#### 6.2 Signes extra-digestifs
- [ ] **Convulsions** : hyperthermie, déshydratation
- [ ] **Détresse respiratoire** : acidose métabolique
- [ ] **Troubles conscience** : déshydratation sévère
- [ ] **Purpura** : complications thrombotiques

### 7. Question de clôture aux parents
"Y a-t-il autre chose concernant l'alimentation ou l'état de votre enfant que je devrais savoir ?"

## 🩺 EXAMEN CLINIQUE (STATUS) (25% des points)

### Évaluation de la déshydratation ⚠️ QUANTIFICATION PRÉCISE

#### Score de déshydratation clinique (0-8 points)
| Critère | 0 | 1 | 2 |
|---------|---|---|---|
| **État général** | Normal | Soif, agité | Prostré, comateux |
| **Yeux** | Normaux | Légèrement cernés | Très cernés/enfoncés |
| **Larmes** | Présentes | Diminuées | Absentes |
| **Muqueuses** | Humides | Collantes | Sèches |

**Interprétation :** 0-2 = pas de déshydratation, 3-5 = déshydratation modérée (5%), 6-8 = sévère (>10%)

#### Signes vitaux et mensurations ⚠️ SURVEILLANCE
- [ ] **Poids actuel** : comparaison poids antérieur si disponible
- [ ] **Température** : fièvre, hypothermie (choc)
- [ ] **Fréquence cardiaque** : tachycardie (compensation)
- [ ] **Tension artérielle** : hypotension (déshydratation sévère)
- [ ] **Fréquence respiratoire** : tachypnée (acidose)

### Examen physique systématique

#### Évaluation de l'état général
- [ ] **Conscience** : Glasgow pédiatrique, réactivité
- [ ] **Coloration** : pâleur, marbrures, cyanose
- [ ] **Tonus** : hypotonie (déshydratation)
- [ ] **Comportement** : agitation, prostration

#### Signes de déshydratation ⚠️ SYSTÉMATIQUE
- [ ] **Pli cutané** : temps de recoloration (> 2 sec anormal)
- [ ] **Muqueuses** : sècheresse buccale, langue
- [ ] **Yeux** : cernés, enfoncés dans orbites
- [ ] **Fontanelle** : déprimée si < 18 mois
- [ ] **Salive** : épaisse, absente

#### Examen abdominal détaillé
- [ ] **Inspection** : distension, cicatrices
- [ ] **Auscultation** : bruits hydro-aériques
- [ ] **Palpation** : défense, masses, douleur
- [ ] **Recherche sang** : TR si nécessaire (rectorragies)
- [ ] **Hépato-splénomégalie** : complications

#### Examen général et recherche complications
- [ ] **Signes méningés** : raideur nucale, fontanelle
- [ ] **Examen cutané** : purpura, éruption
- [ ] **Auscultation cardio-pulmonaire** : signes de choc
- [ ] **Examen neurologique** : état de conscience, déficits

## 💊 PRISE EN CHARGE (MANAGEMENT) (25% des points)

### 1. Classification et stratification ⚠️ DÉCISION THÉRAPEUTIQUE

#### Classification selon déshydratation
| Degré | Perte de poids | Signes cliniques | Prise en charge |
|-------|----------------|------------------|-----------------|
| **Légère** | < 3% | Soif, muqueuses collantes | Réhydratation orale domicile |
| **Modérée** | 3-9% | Pli cutané, yeux cernés | Réhydratation orale surveillance |
| **Sévère** | > 10% | Choc, coma, anurie | Hospitalisation, réhydratation IV |

### 2. Examens complémentaires ⚠️ SELON GRAVITÉ

#### Généralement INUTILES (gastro-entérite simple)
- [ ] **Coproculture** : seulement si sang/glaires/fièvre élevée
- [ ] **Recherche virale** : rotavirus (épidémiologie)
- [ ] **Parasites** : si voyage tropical récent

#### Si signes de gravité ou déshydratation sévère
- [ ] **Ionogramme complet** : Na, K, Cl, urée, créatinine
- [ ] **Gaz du sang** : pH, bicarbonates (acidose métabolique)
- [ ] **Glycémie** : hypoglycémie chez petit enfant
- [ ] **NFS** : si signes septiques ou rectorragies
- [ ] **CRP** : différenciation virale/bactérienne

### 3. Réhydratation ⚠️ TRAITEMENT PRINCIPAL

#### Réhydratation ORALE (traitement de référence)
**Indications :** déshydratation légère à modérée, vomissements contrôlés

**Solutés de réhydratation orale (SRO) ⚠️ COMPOSITION PRÉCISE**
- [ ] **OMS recommandée** : glucose 75 mmol/L, Na 75 mmol/L, K 20 mmol/L, Cl 65 mmol/L
- [ ] **Osmolarité** : 245 mOsm/L (hypo-osmolaire)
- [ ] **Exemples** : Adiaril, GES 45, Alhydrate

**Modalités d'administration ⚠️ TECHNIQUE CRUCIALE**
- [ ] **Volume** : 50-100 mL/kg sur 4-6h + compensation pertes
- [ ] **Rythme** : 5-10 mL toutes les 5-10 minutes
- [ ] **Température** : fraîche (améliore acceptation)
- [ ] **Persistance** : continuer malgré vomissements occasionnels

#### Réhydratation INTRAVEINEUSE
**Indications STRICTES :**
- [ ] **Vomissements incoercibles** (échec réhydratation orale)
- [ ] **Déshydratation sévère** > 10%
- [ ] **État de choc** ou troubles de conscience
- [ ] **Iléus paralytique**

**Protocole de réhydratation IV ⚠️ CALCULS PRÉCIS**
- [ ] **Phase 1** (6h) : 50% déficit + besoins + pertes
- [ ] **Phase 2** (18h) : 50% déficit restant + besoins + pertes
- [ ] **Solutés** : NaCl 0,9% puis glucosé 5% + NaCl selon ionogramme

### 4. Traitement symptomatique et diététique

#### Alimentation ⚠️ REPRISE PRÉCOCE RECOMMANDÉE
- [ ] **Allaitement maternel** : maintenir systématiquement
- [ ] **Lait artificiel** : reprendre concentration normale après 4-6h
- [ ] **Alimentation solide** : reprise après 4-6h si tolérance
- [ ] **Éviter** : diète prolongée, laits dilués

#### Médicaments ⚠️ LIMITÉS
**INUTILES/CONTRE-INDIQUÉS :**
- [ ] **Anti-diarrhéiques** : lopéramide (contre-indiqué < 2 ans)
- [ ] **Anti-émétiques** : risque effets secondaires
- [ ] **Antibiotiques** : inutiles si viral (95% cas)

**POSSIBLES dans certains cas :**
- [ ] **Probiotiques** : Lactobacillus, Saccharomyces boulardii
- [ ] **Racécadotril** : si > 3 mois et diarrhée profuse
- [ ] **Antiémétique** : ondansétron (si vomissements majeurs)

### 5. Critères d'hospitalisation ⚠️ DÉCISION CRUCIALE

#### Hospitalisation IMMÉDIATE
- [ ] **Déshydratation sévère** > 10% ou signes choc
- [ ] **Âge < 3 mois** avec déshydratation modérée
- [ ] **Vomissements incoercibles** échec réhydratation orale
- [ ] **Troubles conscience** ou convulsions
- [ ] **Rectorragies importantes** ou suspicion invagination
- [ ] **Comorbidités** : immunodéficience, cardiopathie

#### Surveillance ambulatoire renforcée
- [ ] **Déshydratation modérée** bien tolérée
- [ ] **Contexte social** défavorable
- [ ] **Parents anxieux** ou inexpérimentés
- [ ] **Âge 3-6 mois** selon contexte

### 6. Prévention et conseils aux parents ⚠️ ÉDUCATION

#### Mesures d'hygiène ⚠️ TRANSMISSION FÉCO-ORALE
- [ ] **Lavage des mains** : systématique avant/après soins
- [ ] **Désinfection** : eau de Javel diluée surfaces
- [ ] **Éviction** : crèche/école jusqu'à normalisation selles
- [ ] **Linge** : lavage à 60°C minimum

#### Alimentation préventive
- [ ] **Allaitement maternel** : protection relative
- [ ] **Hygiène alimentaire** : conservation, cuisson
- [ ] **Eau** : potable, éviter glaçons pays tropicaux
- [ ] **Probiotiques** : possible en prévention

#### Surveillance à domicile et signes d'alarme
- [ ] **Pesée** : si balance disponible
- [ ] **Diurèse** : surveillance couches
- [ ] **État général** : vivacité, réactivité
- [ ] **Tolérance alimentaire** : acceptation liquides

**Reconsulter IMMÉDIATEMENT si :**
- [ ] **Vomissements** persistants > 6h
- [ ] **Refus total** de boire
- [ ] **Sang** dans selles abondant
- [ ] **Dégradation** état général
- [ ] **Fièvre élevée** persistante
- [ ] **Douleurs abdominales** intenses

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Quantifier déshydratation** : score clinique précis
2. **Privilégier réhydratation orale** : SRO technique correcte
3. **Reprise alimentaire précoce** : après 4-6h réhydratation
4. **Éviter médicaments inutiles** : anti-diarrhéiques contre-indiqués
5. **Critères hospitalisation** clairement évalués
6. **Prévention transmission** : mesures d'hygiène familiales

### ❌ Pièges à éviter
1. **Réhydratation IV systématique** (oral = référence)
2. **Diète prolongée** (reprendre alimentation rapidement)
3. **Laits dilués** ou sans lactose systématiques
4. **Anti-diarrhéiques** chez l'enfant (dangereux)
5. **Antibiotiques** automatiques (viral dans 95% cas)
6. **Sous-estimer déshydratation** chez nourrisson

### 💡 Astuces mnémotechniques
- **SRO = 5-10 mL toutes les 5-10 min** (réhydratation orale)
- **3-6-10%** = légère-modérée-sévère (déshydratation)
- **4-6h** = délai reprise alimentaire normale
- **< 3 mois + déshydratation = hospitalisation**
- **95% viral** = pas d'antibiotiques
- **Pli cutané > 2 sec** = déshydratation

### 🚨 Red Flags gastro-entérite enfant
- **Déshydratation sévère** > 10% (choc)
- **Âge < 3 mois** avec signes déshydratation
- **Vomissements incoercibles** (échec réhydratation orale)
- **Rectorragies importantes** (invagination, colite)
- **Troubles de conscience** (déshydratation/hypoglycémie)
- **Douleurs abdominales intenses** (appendicite, occlusion)
- **Fièvre élevée + altération générale** (sepsis)
