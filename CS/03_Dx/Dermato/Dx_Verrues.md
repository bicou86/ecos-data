# Verrues

## Type
SSP Dermatologie/Infectiologie

## Description
Tumeurs bénignes cutanées d'origine virale (papillomavirus humains - HPV), très fréquentes, contagieuses et généralement autolimitées.

## Présentation clinique typique
- Excroissances cutanées rugueuses
- Localisation mains et pieds principalement
- Enfants et adolescents
- Évolution chronique
- Multiplication possible

## ANAMNÈSE

### Histoire de la lésion
- **Apparition** :
  - Progressive sur plusieurs semaines
  - Incubation 2-6 mois après contamination
  - Une puis multiplication possible
- **Évolution** :
  - Extension lente
  - Auto-inoculation fréquente
  - Résolution spontanée possible (2 ans)
- **Symptômes** :
  - Généralement asymptomatiques
  - Douleur si verrues plantaires
  - Gêne esthétique
  - Saignements si traumatisme

### Facteurs de risque
- **Terrain** :
  - Âge : Pic 12-16 ans
  - Immunodépression
  - Dermatite atopique
  - Hyperhidrose
- **Exposition** :
  - Piscines, douches collectives
  - Sports pieds nus
  - Microtraumatismes répétés
  - Onychophagie (verrues péri-unguéales)
- **Contamination** :
  - Contact direct peau à peau
  - Surfaces contaminées
  - Auto-inoculation

## EXAMEN CLINIQUE

### Types de verrues

#### Verrues vulgaires (70%)
- **Aspect** :
  - Papules kératosiques hémisphériques
  - Surface rugueuse, grisâtre
  - Points noirs (capillaires thrombosés)
  - Taille : 2-10 mm
- **Localisation** :
  - Dos des mains +++
  - Doigts
  - Genoux, coudes
  - Péri-unguéales

#### Verrues plantaires
**Myrmécie** (verrue unique profonde) :
- Inclusion profonde
- Hyperkératose en couronne
- Points noirs centraux
- Douloureuse à la pression
- Interruption dermatoglyphes

**Verrues mosaïques** :
- Multiples verrues superficielles
- Coalescentes en plaques
- Moins douloureuses
- Talons, avant-pied

#### Verrues planes
- **Aspect** :
  - Papules planes, lisses
  - Couleur chair ou brunâtre
  - 2-4 mm diamètre
  - Multiples
- **Localisation** :
  - Visage
  - Dos des mains
  - Jambes (rasage)
- **Phénomène de Koebner** fréquent

#### Verrues filiformes
- **Aspect** : Excroissances pédiculées digitiformes
- **Localisation** :
  - Visage (paupières, lèvres)
  - Cou
  - Barbe (rasage)

#### Condylomes acuminés
- **Localisation** : Muqueuses génitales et anales
- **Aspect** : Papules rosées, "crêtes de coq"
- **IST** : Dépistage autres IST
- **HPV** : Types 6 et 11 principalement

### Diagnostic clinique
- **Inspection** : Aspect caractéristique
- **Dermoscopie** :
  - Papilles avec capillaires centraux
  - Points noirs ou rouges
  - Interruption des crêtes
- **Test diagnostique** :
  - Grattage → Points hémorragiques
  - Différencie du durillon (dermatoglyphes conservés)

## DIAGNOSTIC DIFFÉRENTIEL

### Verrues vulgaires
- Molluscum contagiosum
- Kératose séborrhéique
- Carcinome verruqueux
- Tuberculose verruqueuse

### Verrues plantaires
- Durillon, cor
- Mélanome achromique
- Porokératose plantaire
- Corps étranger

### Verrues planes
- Kératose séborrhéique plane
- Lichen plan
- Naevus verruqueux

## TRAITEMENT

### Principes généraux
- **Abstention** : Option valide (résolution spontanée)
- **Indications traitement** :
  - Douleur
  - Gêne fonctionnelle
  - Préjudice esthétique
  - Multiplication
  - Demande du patient

### Traitements de première ligne

#### Kératolytiques
**Acide salicylique** :
- Concentration : 15-40% selon localisation
- Application quotidienne
- Après décapage mécanique
- Durée : 6-12 semaines
- Efficacité : 60-70%
- Protection peau saine (vaseline)

**Acide lactique** :
- Souvent associé à l'acide salicylique
- Application similaire

#### Cryothérapie
- **Azote liquide** : -196°C
- **Technique** :
  - 2 cycles congélation-décongélation
  - Halo de congélation 1-2 mm
  - Toutes les 2-3 semaines
- **Efficacité** : 60-70%
- **EI** : Douleur, phlyctène, dyschromie
- **CI** : Troubles circulation, enfant < 4 ans

### Traitements de deuxième ligne

#### Immunomodulateurs
**Imiquimod 5%** :
- Verrues génitales principalement
- 3x/semaine, 16 semaines max
- Réaction inflammatoire locale

**Interféron** :
- Injection intralésionnelle
- Verrues récalcitrantes

#### Rétinoïdes
- **Trétinoïne** : Verrues planes
- **Adapalène** : Application locale
- Irritation fréquente

#### Cantharidine
- Application par médecin
- Phlyctène en 24-48h
- Efficace sur verrues péri-unguéales

### Traitements physiques

#### Laser CO2
- Vaporisation contrôlée
- Anesthésie locale
- Cicatrice possible
- Verrues récalcitrantes

#### Laser à colorant pulsé
- Cible vaisseaux
- Moins douloureux
- Plusieurs séances

#### Électrocoagulation
- Anesthésie locale nécessaire
- Risque cicatrice
- Verrues uniques

#### Photothérapie dynamique
- Acide aminolévulinique + lumière rouge
- Verrues récalcitrantes
- Coûteux

### Traitements adjuvants

#### Occlusion
- Sparadrap occlusif
- Changement quotidien
- Mécanisme : Macération, hypoxie
- Efficacité discutée

#### Suggestion/Hypnose
- Particulièrement efficace chez l'enfant
- Effet placebo important

### Stratégie thérapeutique

#### Verrues vulgaires
1. Acide salicylique
2. Cryothérapie
3. Association des deux
4. Laser si échec

#### Verrues plantaires
1. Décapage + acide salicylique
2. Cryothérapie si myrmécie
3. Laser CO2 si récalcitrant

#### Verrues planes
1. Abstention (résolution fréquente)
2. Rétinoïdes locaux
3. Cryothérapie douce
4. Laser

#### Immunodéprimés
- Traitements prolongés
- Associations thérapeutiques
- Surveillance carcinome

## ÉVOLUTION

### Histoire naturelle
- Résolution spontanée : 65% à 2 ans
- Récidives : 30% après traitement
- Persistance possible plusieurs années

### Facteurs de mauvais pronostic
- Immunodépression
- Verrues multiples
- Localisation péri-unguéale
- Durée > 2 ans
- Échecs thérapeutiques multiples

## PRÉVENTION

### Mesures individuelles
- **Hygiène** :
  - Éviter de gratter/mordiller
  - Séchage soigneux pieds
  - Chaussures personnelles
- **Protection** :
  - Sandales piscine/douches
  - Pansements sur verrues
  - Éviter marche pieds nus

### Mesures collectives
- Désinfection surfaces (piscines)
- Information en milieu scolaire
- Pas d'éviction sportive/scolaire

### Vaccination HPV
- Prévention condylomes génitaux
- Gardasil, Cervarix
- Vaccination systématique recommandée

## Points clés pour l'ECOS
1. **Diagnostic clinique** généralement suffisant
2. **Points noirs** = capillaires thrombosés
3. **Abstention** = option thérapeutique valide
4. **Acide salicylique** = 1ère ligne
5. **Cryothérapie** efficace mais douloureuse
6. **Résolution spontanée** fréquente
7. **Auto-inoculation** : Éviter manipulation
