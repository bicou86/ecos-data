# Teigne (Dermatophytose du cuir chevelu)

## Type
SSP Dermatologie/Infectiologie

## Description
Infection fongique du cuir chevelu et des cheveux par des dermatophytes, touchant principalement les enfants. Contagieuse, nécessitant un traitement systémique.

## Présentation clinique typique
- Plaques alopéciques squameuses
- Cheveux cassés courts
- Prurit variable
- Enfant d'âge scolaire
- Contexte épidémique possible

## ANAMNÈSE

### Symptômes principaux
- **Chute de cheveux** :
  - Progressive ou rapide
  - Zones circonscrites
  - Cheveux cassés, non arrachés
- **Prurit** :
  - Intensité variable
  - Parfois absent
- **Squames** :
  - Desquamation localisée
  - Aspect "poudré"
- **Inflammation** :
  - Variable selon le type
  - Parfois suppuration (kérion)

### Facteurs de risque/contamination
- **Contact avec animaux** :
  - Chats, chiens (M. canis)
  - Animaux de ferme
  - Rongeurs
- **Transmission interhumaine** :
  - Contact direct
  - Objets contaminés (peignes, bonnets)
  - Coiffeur
- **Facteurs favorisants** :
  - Promiscuité
  - Immunodépression
  - Microtraumatismes du cuir chevelu
  - Origine africaine/antillaise (T. soudanense)

### Contexte épidémiologique
- Âge : 3-14 ans principalement
- Cas familiaux ou scolaires
- Voyage récent (zones endémiques)
- Profession à risque (éleveur, vétérinaire)

## EXAMEN CLINIQUE

### Formes cliniques

#### Teignes tondantes microsporiques
- **Agent** : Microsporum canis (80% en Europe)
- **Aspect** :
  - Grandes plaques (2-5 cm)
  - Bien limitées
  - Cheveux cassés à 2-3 mm
  - Aspect "tondus"
  - Squames grisâtres
- **Fluorescence** : Verte à la lampe de Wood

#### Teignes tondantes trichophytiques
- **Agents** : T. tonsurans, T. violaceum, T. soudanense
- **Aspect** :
  - Petites plaques multiples
  - Mal limitées
  - Cheveux cassés ras (points noirs)
  - Squames moins importantes
- **Pas de fluorescence** Wood

#### Teignes inflammatoires (Kérion)
- **Agents** : T. mentagrophytes, M. canis
- **Aspect** :
  - Placards inflammatoires surélevés
  - Pustules folliculaires multiples
  - Suppuration ("en pomme d'arrosoir")
  - Cheveux facilement extractibles
  - Adénopathies satellites
- **Évolution** : Alopécie cicatricielle si retard

#### Teignes faviques (Favus)
- **Agent** : T. schoenleinii (rare)
- **Aspect** :
  - Godets faviques jaunes
  - Croûtes jaunâtres (soufre)
  - Odeur de souris
  - Alopécie cicatricielle définitive
- **Zones endémiques** : Afrique, Moyen-Orient

### Examen du cuir chevelu
- **Inspection systématique** :
  - Totalité du cuir chevelu
  - Bonne lumière
  - Écarter les cheveux
- **Rechercher** :
  - Zones alopéciques
  - Squames
  - Cheveux cassés
  - Pustules
  - Croûtes
  - Adénopathies occipitales/cervicales

### Lampe de Wood
- **UV 365 nm**
- **Fluorescence verte** : Microsporum canis, M. audouinii
- **Négatif** : Trichophyton (pas de fluorescence)
- **Limites** : Sensibilité 50%

## DIAGNOSTIC

### Prélèvement mycologique (obligatoire)
- **Avant tout traitement**
- **Technique** :
  - Cheveux cassés + squames
  - Écouvillonnage si kérion
  - Scotch test possible
- **Examens** :
  - Direct : Filaments mycéliens
  - Culture : 3-4 semaines
  - Identification espèce
  - Antifongigramme si échec

### Diagnostic différentiel

#### Alopécies non cicatricielles
- Pelade (zones glabres lisses)
- Trichotillomanie (cheveux de longueurs différentes)
- Alopécie de traction
- Effluvium télogène

#### Dermatoses squameuses
- Dermite séborrhéique
- Psoriasis du cuir chevelu
- Eczéma

#### Alopécies inflammatoires
- Folliculite décalvante
- Cellulite du cuir chevelu
- Abcès

## TRAITEMENT

### Traitement systémique (obligatoire)

#### Griséofulvine (1er choix enfant)
- **Posologie** : 20-25 mg/kg/j
- **Durée** : 6-8 semaines
- **Administration** : Pendant repas gras
- **EI** : Troubles digestifs, photosensibilisation
- **CI** : Porphyrie, lupus

#### Terbinafine
- **Posologie** :
  - < 20 kg : 62.5 mg/j
  - 20-40 kg : 125 mg/j
  - > 40 kg : 250 mg/j
- **Durée** : 4-6 semaines
- **Efficacité** : Supérieure sur Trichophyton
- **EI** : Troubles digestifs, céphalées

#### Itraconazole
- **Posologie** : 5 mg/kg/j
- **Durée** : 4-6 semaines
- **Alternative** si échec
- **Surveillance** : Transaminases si > 1 mois

### Traitement local adjuvant
- **Antifongiques locaux** :
  - Kétoconazole shampooing 2%
  - Ciclopirox olamine
  - 2-3x/semaine
- **Objectifs** :
  - Réduire contagiosité
  - Compléter action systémique
  - Pas suffisant seul

### Kérion : particularités
- **Pas de chirurgie** (aggravation)
- **Antifongique systémique** d'emblée
- **Corticoïdes oraux** discutés :
  - Prednisolone 0.5-1 mg/kg/j
  - 5-10 jours
  - Si très inflammatoire
- **Soins locaux** : Antiseptiques doux

### Mesures associées

#### Éviction scolaire
- **Teigne confirmée** : Jusqu'à certificat de non-contagion
- **Certificat** : Après 2 semaines de traitement
- **Prélèvement négatif** non exigé

#### Décontamination
- **Objets personnels** :
  - Peignes, brosses : Désinfecter ou jeter
  - Bonnets, oreillers : Laver 60°C
  - Tondeuses : Désinfecter
- **Environnement** :
  - Aspiration sols, canapés
  - Pas de désinfection systématique

#### Enquête épidémiologique
- **Dépistage entourage** :
  - Famille
  - Classe si cas multiples
  - Examen clinique +/- prélèvement
- **Recherche source** :
  - Animaux domestiques
  - Coiffeur
  - Objets partagés

## ÉVOLUTION

### Guérison
- Repousse cheveux : 3-6 mois
- Prélèvement contrôle : Non systématique
- Surveillance clinique suffisante

### Complications
- **Alopécie cicatricielle** : Kérion non traité
- **Surinfection bactérienne**
- **Érythème noueux** (rare)
- **Id reaction** : Éruption allergique à distance

### Échec thérapeutique
- **Causes** :
  - Observance insuffisante
  - Résistance antifongique (rare)
  - Réinfestation
  - Immunodépression
- **CAT** :
  - Vérifier observance
  - Nouveau prélèvement
  - Changer molécule
  - Rechercher source persistante

## PRÉVENTION

### Mesures individuelles
- Éviter partage objets de coiffure
- Hygiène régulière du cuir chevelu
- Traitement précoce des lésions suspectes
- Contrôle animaux domestiques

### Mesures collectives
- Information en milieu scolaire
- Dépistage précoce cas contacts
- Mesures d'hygiène renforcées
- Formation personnel (coiffeurs, écoles)

## Points clés pour l'ECOS
1. **Prélèvement mycologique** avant traitement
2. **Traitement systémique** obligatoire
3. **Griséofulvine** 1er choix chez l'enfant
4. **Durée** : 6-8 semaines minimum
5. **Éviction scolaire** jusqu'à certificat
6. **Lampe de Wood** : M. canis fluorescent
7. **Kérion** : Pas de chirurgie

## Mnémotechnique
**"MYCOSE"** pour le traitement:
- **M**ycologique (prélèvement d'abord)
- **Y** a pas que local (systémique obligatoire)
- **C**ontrôle de l'entourage
- **O**bjets à désinfecter
- **S**ix semaines minimum
- **E**viction scolaire
