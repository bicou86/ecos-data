# Punaises de lit

## Type
SSP Dermatologie/Médecine environnementale

## Description
Infestation par Cimex lectularius, ectoparasite hématophage nocturne responsable de piqûres prurigineuses. Problème de santé publique en recrudescence mondiale.

## Présentation clinique typique
- Piqûres multiples au réveil
- Disposition linéaire ou groupée ("petit déjeuner, déjeuner, dîner")
- Prurit intense
- Zones découvertes pendant le sommeil
- Anxiété, troubles du sommeil

## ANAMNÈSE

### Symptômes principaux
- **Piqûres** :
  - Apparition au réveil
  - Indolores sur le moment
  - Prurit retardé (quelques heures)
  - Aggravation sur plusieurs jours
- **Distribution** :
  - Zones découvertes la nuit
  - Bras, jambes, cou, visage
  - Disposition linéaire caractéristique
  - Groupées par 3-4 ("breakfast, lunch, dinner")
- **Évolution** :
  - Récurrence régulière
  - Augmentation progressive du nombre
  - Périodes de rémission (voyages)

### Facteurs favorisants
- **Logement** :
  - Habitat collectif
  - Promiscuité
  - Mobilier d'occasion
  - Fissures dans les murs
- **Voyages** :
  - Hôtels, auberges
  - Transport de bagages
  - Retour de voyage
- **Achats d'occasion** :
  - Meubles
  - Matelas
  - Vêtements

### Impact psychosocial
- **Troubles du sommeil** :
  - Insomnie d'endormissement
  - Réveils nocturnes
  - Anxiété anticipatoire
- **Isolement social** :
  - Honte
  - Peur de contaminer
  - Évitement des visites
- **Impact économique** :
  - Coût de la désinsectisation
  - Remplacement du mobilier
  - Arrêts de travail

## EXAMEN CLINIQUE

### Lésions cutanées

#### Lésions primaires
- **Papules érythémateuses** :
  - 5-15 mm diamètre
  - Centre parfois purpurique
  - Œdémateuses
  - Non douloureuses initialement

#### Distribution caractéristique
- **Pattern linéaire** : "Petit déjeuner-déjeuner-dîner"
- **Zones exposées** :
  - Membres supérieurs +++
  - Membres inférieurs
  - Cou, visage
  - Respect zones couvertes
- **Asymétrique** : Côté du lit infesté

#### Lésions secondaires
- **Excoriations** : Grattage intense
- **Impétiginisation** : Surinfection
- **Lichénification** : Grattage chronique
- **Cicatrices** : Hyperpigmentation post-inflammatoire

### Réactions variables
- **Réaction normale** : Papules prurigineuses 3-10 jours
- **Réaction bulleuse** : Rares cas
- **Réaction urticarienne** : Plaques œdémateuses
- **Absence de réaction** : 30% des personnes

## DIAGNOSTIC

### Diagnostic positif

#### Signes directs (certitude)
- **Visualisation punaises** :
  - Adultes : 4-7 mm, bruns, aplatis
  - Nymphes : 1-4 mm, translucides
  - Œufs : 1 mm, blancs, en grappe
- **Localisation** :
  - Coutures du matelas +++
  - Sommier
  - Têtes de vis
  - Fissures murs
  - Derrière tableaux
  - Prises électriques

#### Signes indirects
- **Taches de sang** : Draps, matelas
- **Déjections** : Points noirs (sang digéré)
- **Mues** : Exuvies translucides
- **Odeur** : Douceâtre caractéristique (infestation massive)

### Techniques de détection
- **Inspection minutieuse** :
  - Lampe torche
  - Loupe
  - Démontage sommier
  - Inspection nocturne
- **Pièges** :
  - Intercepteurs sous pieds de lit
  - Pièges adhésifs
  - Détection canine (chiens dressés)

### Diagnostic différentiel
- Piqûres de moustiques
- Puces
- Gale
- Urticaire
- Prurigo
- Dermite de contact
- Délire de parasitose

## PRISE EN CHARGE

### Traitement symptomatique

#### Traitement du prurit
- **Antihistaminiques oraux** :
  - Cétirizine 10mg/j
  - Desloratadine 5mg/j
- **Corticoïdes locaux** :
  - Classe II-III
  - 1-2 applications/j
  - 5-7 jours
- **Émollients** : Réparation barrière cutanée

#### Prévention surinfection
- Antiseptiques locaux si excoriations
- Antibiotiques si impétigo

### Lutte mécanique (prioritaire)

#### Aspiration minutieuse
- **Zones** : Matelas, sommier, fissures, plinthes
- **Fréquence** : Quotidienne pendant infestation
- **Élimination** : Sac fermé hermétiquement

#### Lavage haute température
- **60°C minimum** : 30 minutes
- **Textiles** : Draps, vêtements, rideaux
- **Alternative** : Congélation -20°C pendant 72h

#### Traitement vapeur
- **120°C** : Matelas, sommier
- **Efficace** sur œufs et adultes
- **Pénétration** fissures

#### Isolation
- **Housses anti-punaises** : Matelas et sommier
- **Éloignement lit** : 15 cm des murs
- **Intercepteurs** : Sous pieds de lit

### Lutte chimique

#### Insecticides
- **Pyréthrinoïdes** : Perméthrine, deltaméthrine
- **Application professionnelle** recommandée
- **2 passages** : J0 et J10-15 (œufs)
- **Résistances** : Fréquentes

#### Terre de diatomée
- **Action mécanique** : Déshydratation
- **Application** : Fissures, passages
- **Non toxique** pour l'homme

### Stratégie intégrée
1. **Préparation** :
   - Désencombrement
   - Aspiration complète
   - Lavage/congélation textiles

2. **Traitement** :
   - Mécanique + chimique
   - Professionnels recommandés
   - 2-3 passages

3. **Suivi** :
   - Surveillance 6 semaines
   - Pièges de détection
   - Nouveau traitement si récidive

## PRÉVENTION

### Prévention primaire
- **Voyages** :
  - Inspection chambre d'hôtel
  - Bagages sur porte-bagages
  - Lavage retour 60°C
- **Achats occasion** :
  - Inspection minutieuse
  - Traitement préventif
  - Éviter matelas/sommiers

### Prévention secondaire
- **Détection précoce** :
  - Housses de détection
  - Pièges sentinelles
  - Inspection régulière
- **Barrières physiques** :
  - Housses anti-punaises
  - Rubans adhésifs double-face
  - Vaseline pieds de lit

## ASPECTS RÉGLEMENTAIRES
- **Pas de déclaration obligatoire**
- **Responsabilité** :
  - Locataire : signalement
  - Propriétaire : traitement
- **Logement décent** : Absence de parasites

## IMPACT PSYCHOLOGIQUE

### Manifestations
- Anxiété, stress post-traumatique
- Troubles du sommeil persistants
- Syndrome d'Ekbom (délire de parasitose)
- Dépression réactionnelle

### Prise en charge
- Écoute, réassurance
- Explication du cycle parasitaire
- Soutien psychologique si nécessaire
- Groupes de parole

## Points clés pour l'ECOS
1. **Disposition linéaire** des piqûres = évocateur
2. **Inspection matelas** : coutures, étiquettes
3. **Taches noires** = déjections
4. **Lavage 60°C** ou congélation -20°C
5. **Traitement simultané** logement entier
6. **2 passages** insecticide (œufs)
7. **Impact psychosocial** important

## Mnémotechnique
**"PUNAISE"** pour l'inspection:
- **P**lis du matelas
- **U**nder (sous) le sommier
- **N**uits (inspection nocturne)
- **A**rrière têtes de lit
- **I**nterstices et fissures
- **S**ommier (lattes, vis)
- **E**lectricité (prises, interrupteurs)
