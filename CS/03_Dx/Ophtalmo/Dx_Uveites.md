# Fiche de Révision ECOS - UVÉITES

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient présentant œil rouge douloureux avec baisse d'acuité visuelle, photophobie et troubles visuels
**Objectifs d'évaluation:** Reconnaître inflammation intraoculaire, identifier type anatomique, rechercher étiologie, traiter urgence, prévenir complications

---

## 📋 ANAMNÈSE

### 1. Symptômes actuels ⚠️ CARDINAL

#### 1.1 Douleur oculaire
- [ ] **Intensité:** Modérée à sévère
- [ ] **Type:** Profonde, sourde
- [ ] **Photophobie intense** ⚠️ CARACTÉRISTIQUE
- [ ] **Aggravation:** Lumière, accommodation
- [ ] **Larmoiement réflexe**

#### 1.2 Troubles visuels
- [ ] **Baisse d'acuité visuelle:**
  - Variable selon localisation
  - Sévère si uvéite postérieure
- [ ] **Vision floue** ("brouillard")
- [ ] **Myodésopsies** (corps flottants)
- [ ] **Photopsies** (éclairs)
- [ ] **Scotomes** (taches aveugles)

#### 1.3 Œil rouge
- [ ] **Injection ciliaire/périkératique** ⚠️
  - Cercle violacé péricornéen
  - ≠ injection conjonctivale superficielle
- [ ] **Unilatéral** ou bilatéral
- [ ] **Récidivant?** Episodes antérieurs

### 2. Caractérisation temporelle

#### 2.1 Installation
- [ ] **Aigu:** < 6 semaines
- [ ] **Chronique:** > 3 mois
- [ ] **Récurrent:** Episodes répétés

#### 2.2 Evolution
- [ ] **Progressif** sur jours
- [ ] **Fluctuant**
- [ ] **Récidives** (fréquence, délai)

### 3. Recherche étiologique ⚠️ SYSTÉMATIQUE

#### 3.1 Maladies inflammatoires systémiques
- [ ] **Spondylarthropathies:** ⚠️ 50% uvéites antérieures
  - Lombalgie inflammatoire?
  - Raideur matinale?
  - Psoriasis cutané/unguéal?
  - MICI (Crohn, RCH)?
- [ ] **Sarcoïdose:**
  - Toux, dyspnée?
  - Adénopathies?
  - Lésions cutanées?
- [ ] **Maladie de Behçet:** ⚠️ CRITÈRES
  - Aphtose buccale récurrente (≥3/an)
  - Aphtose génitale
  - Lésions cutanées (pseudo-folliculite)
  - Test pathergique positif

#### 3.2 Causes infectieuses
- [ ] **Herpès (HSV/VZV):**
  - Vésicules péri-oculaires?
  - Kératite dendritique?
  - Zona ophtalmique?
- [ ] **Toxoplasmose:**
  - Contact chats?
  - Viande mal cuite?
  - Immunodépression?
- [ ] **Tuberculose:**
  - Contage?
  - Toux chronique?
  - Sueurs nocturnes?
- [ ] **Syphilis:** ⚠️ "grande simulatrice"
  - Comportement à risque?
  - Chancre?
  - Éruption cutanée?

#### 3.3 Arthrite juvénile idiopathique
- [ ] **Enfant < 16 ans**
- [ ] **Arthrite oligoarticulaire**
- [ ] **Fille > garçon**
- [ ] **AAN positifs** (risque uvéite)

### 4. Antécédents

#### 4.1 Ophtalmologiques
- [ ] **Episodes antérieurs** uvéite
- [ ] **Chirurgies oculaires**
- [ ] **Traumatisme**
- [ ] **Autres pathologies** (glaucome, cataracte)

#### 4.2 Généraux
- [ ] **HLA-B27** connu?
- [ ] **Maladies auto-immunes**
- [ ] **Infections récentes**
- [ ] **Vaccinations** récentes
- [ ] **Voyages** (zones endémiques)

### 5. Médicaments
- [ ] **Corticoïdes** (complications)
- [ ] **Immunosuppresseurs**
- [ ] **Rifabutine** (uvéite médicamenteuse)
- [ ] **Bisphosphonates**
- [ ] **Anti-TNF** (paradoxal)

### 6. Question de clôture
"Avez-vous des symptômes articulaires, cutanés ou digestifs associés?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Examen ophtalmologique ⚠️ LOCALISATION ANATOMIQUE

#### Classification anatomique
- [ ] **Uvéite antérieure** (60-70%):
  - Iris (iritis)
  - Corps ciliaire (cyclite)
  - Iridocyclite
- [ ] **Uvéite intermédiaire** (15%):
  - Pars planite
  - Hyalite postérieure
- [ ] **Uvéite postérieure** (15-20%):
  - Choroïdite
  - Rétinite
  - Choriorétinite
- [ ] **Panuvéite** (10%):
  - Atteinte globale

### 1. INSPECTION EXTERNE

#### Œil atteint
- [ ] **Injection ciliaire** ⚠️ CARACTÉRISTIQUE
  - Cercle périkératique violacé
  - Vaisseaux profonds radiaires
- [ ] **Photophobie** marquée
- [ ] **Larmoiement**
- [ ] **Blépharospasme**

### 2. LAMPE À FENTE ⚠️ EXAMEN CLÉ

#### Cornée
- [ ] **Précipités rétrocornéens** ⚠️ PATHOGNOMONIQUE
  - **Fins:** Uvéite non granulomateuse
  - **En graisse de mouton:** Granulomateuse (sarcoïdose, Vogt-Koyanagi-Harada)
  - **Stellaires:** Fuchs
  - Distribution: Triangle d'Arlt
- [ ] **Œdème cornéen** (si hypertonie)
- [ ] **Kératite** associée (herpès)

#### Chambre antérieure
- [ ] **Tyndall** ⚠️ INFLAMMATION ACTIVE
  - Cellules (cotation 0 à 4+)
  - Protéines (flare)
  - Quantification précise
- [ ] **Hypopion** (niveau purulent)
- [ ] **Hyphéma** (sang)
- [ ] **Profondeur** normale

#### Iris
- [ ] **Synéchies postérieures** ⚠️ SÉQUELLES
  - Adhérences iris-cristallin
  - Pupille irrégulière
  - "Secousse" iris (festonnée)
- [ ] **Nodules iriens:**
  - Koeppe (bord pupillaire)
  - Busacca (surface iris)
  - Granulomateux
- [ ] **Hétérochromie** (Fuchs)
- [ ] **Atrophie sectorielle**

#### Cristallin
- [ ] **Cataracte secondaire**
- [ ] **Dépôts pigmentaires**
- [ ] **Luxation** (si uvéite sévère)

### 3. TONUS OCULAIRE
- [ ] **Mesure PIO:**
  - **Hypotonie** (< 6 mmHg): Inflammation corps ciliaire
  - **Hypertonie** (> 21 mmHg): ⚠️ URGENCE
    - Uvéite hypertensive
    - Glaucome uvéitique
    - Cortisonique

### 4. FOND D'ŒIL ⚠️ APRÈS DILATATION

#### Vitré
- [ ] **Hyalite:**
  - Cellules vitréennes
  - Condensations ("œufs de fourmis")
  - Voiles
- [ ] **Snowballs** (uvéite intermédiaire)
- [ ] **Snowbank** (pars planite)

#### Rétine/Choroïde
- [ ] **Foyers choriorétiniens:**
  - Actifs: Blancs, flous, œdémateux
  - Cicatriciels: Pigmentés, atrophiques
- [ ] **Vascularite rétinienne:**
  - Engainement vasculaire
  - Occlusions
  - Hémorragies
- [ ] **Œdème maculaire** ⚠️ BAV
- [ ] **Décollement séreux**

#### Papille
- [ ] **Œdème papillaire**
- [ ] **Papillite**
- [ ] **Atrophie** (séquelle)

### 5. EXAMEN GÉNÉRAL

#### Recherche étiologique
- [ ] **Peau:**
  - Psoriasis
  - Érythème noueux
  - Aphtose
  - Vitiligo
- [ ] **Articulations:**
  - Arthrite
  - Enthésite
  - Sacro-iliite
- [ ] **Adénopathies**
- [ ] **Organomégalie**
- [ ] **Auscultation pulmonaire**

### 6. SIGNES DE GRAVITÉ ⚠️
- [ ] **Baisse AV sévère**
- [ ] **Hypertonie > 30 mmHg**
- [ ] **Hypopion**
- [ ] **Atteinte postérieure**
- [ ] **Œdème maculaire**
- [ ] **Vascularite occlusive**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### 1.1 Bilan étiologique initial
- [ ] **NFS, CRP, VS**
- [ ] **BH, fonction rénale**
- [ ] **TPHA-VDRL** (syphilis) ⚠️ SYSTÉMATIQUE
- [ ] **IDR tuberculine/Quantiféron**
- [ ] **Sérologies:** Toxoplasmose, HSV, VZV, CMV
- [ ] **ECA** (sarcoïdose)
- [ ] **HLA-B27** (spondylarthropathies)

#### 1.2 Imagerie
- [ ] **Radio thorax:** Sarcoïdose, tuberculose
- [ ] **Scanner thoracique** si sarcoïdose suspectée
- [ ] **IRM sacro-iliaques** si SpA
- [ ] **OCT maculaire:** Œdème maculaire
- [ ] **Angiographie rétinienne:** Vascularite

#### 1.3 Critères de Behçet ⚠️ SCORE ≥ 4 POINTS
- **Aphtose buccale:** 2 points
- **Aphtose génitale:** 2 points
- **Lésions oculaires:** 2 points
- **Lésions cutanées:** 1 point
- **Manifestations vasculaires:** 1 point
- **Pathergy test positif:** 1 point

### 2. Traitement en urgence ⚠️

#### 2.1 Uvéite antérieure aiguë
- [ ] **Corticoïdes topiques:** ⚠️ PREMIÈRE LIGNE
  - Dexaméthasone 0.1% ou Prednisolone 1%
  - 1 goutte/heure initialement
  - Décroissance progressive sur 6-8 semaines
- [ ] **Mydriatiques-cycloplégiques:**
  - Atropine 1% × 2-3/jour
  - Prévention/levée synéchies
  - Mise au repos corps ciliaire
  - Antalgie
- [ ] **Hypotonisants** si PIO élevée

#### 2.2 Uvéite postérieure/panuvéite
- [ ] **Corticoïdes systémiques:**
  - Prednisone 1mg/kg/j PO
  - Ou méthylprednisolone IV (bolus)
  - Décroissance progressive
- [ ] **± Corticoïdes topiques** associés

#### 2.3 Uvéite hypertensive ⚠️ URGENCE
- [ ] **Collyres hypotonisants:**
  - Bêtabloquants (timolol)
  - Inhibiteurs anhydrase carbonique
  - Alpha-agonistes
  - Éviter prostaglandines (inflammation)
- [ ] **Acétazolamide PO** si PIO > 30
- [ ] **Mannitol IV** si échec

### 3. Traitement étiologique

#### 3.1 Uvéite herpétique
- [ ] **Aciclovir 800mg × 5/j** ou Valaciclovir 1g × 3/j
- [ ] **Durée:** 7-10 jours aigu, prophylaxie si récidivant
- [ ] **Éviter corticoïdes** sans antiviraux

#### 3.2 Toxoplasmose oculaire
- [ ] **Si atteinte menaçante** (macula, papille, vascularite):
  - Pyriméthamine + Sulfadiazine + Acide folinique
  - Ou Bactrim forte × 2/j
  - Durée: 4-6 semaines
- [ ] **Corticoïdes** après 48h antibiotiques

#### 3.3 Sarcoïdose
- [ ] **Corticoïdes systémiques** 0.5-1mg/kg/j
- [ ] **Immunosuppresseurs:** Méthotrexate, azathioprine
- [ ] **Anti-TNF** si réfractaire

#### 3.4 Maladie de Behçet
- [ ] **Poussée:** Corticoïdes haute dose
- [ ] **Fond:** Azathioprine, ciclosporine
- [ ] **Biothérapies:** Anti-TNF, anti-IL6

#### 3.5 Spondylarthropathies
- [ ] **AINS** (indométacine)
- [ ] **Corticoïdes topiques** intensifs
- [ ] **Anti-TNF** si uvéites récidivantes

### 4. Traitement des complications

#### 4.1 Œdème maculaire cystoïde
- [ ] **Acétazolamide** 250-500mg × 2/j
- [ ] **Corticoïdes péri-oculaires**
- [ ] **Anti-VEGF intravitréens**
- [ ] **Implant corticoïdes** (Ozurdex)

#### 4.2 Cataracte uvéitique
- [ ] **Chirurgie** après 3 mois sans inflammation
- [ ] **Corticothérapie** péri-opératoire
- [ ] **Risque synéchies** post-op

#### 4.3 Glaucome uvéitique
- [ ] **Médical** d'abord
- [ ] **Chirurgie filtrante** si échec
- [ ] **Difficile:** Inflammation chronique

### 5. Surveillance

#### Court terme (phase aiguë)
- [ ] **Quotidienne** première semaine:
  - Tyndall
  - PIO
  - Synéchies
- [ ] **Bi-hebdomadaire** ensuite

#### Long terme
- [ ] **Récidives** (30-50%)
- [ ] **Complications:**
  - Cataracte (20%)
  - Glaucome (10%)
  - Œdème maculaire
- [ ] **Fonction visuelle**
- [ ] **Observance traitement**

### 6. Mesures associées

#### Prévention récidives
- [ ] **Traitement fond** si uvéites récidivantes
- [ ] **Éviter facteurs déclenchants:**
  - Stress
  - Fatigue
  - Infections
- [ ] **Vaccination** grippe, pneumocoque

#### Education patient
- [ ] **Signes récidive:**
  - Œil rouge
  - Photophobie
  - Baisse vision
- [ ] **Importance observance**
- [ ] **Décroissance progressive** corticoïdes
- [ ] **Consultation urgente** si récidive

### 7. Pronostic
- [ ] **Uvéite antérieure:** Bon si traité précocement
- [ ] **Uvéite postérieure:** Plus réservé
- [ ] **Complications:** 20-30% des cas
- [ ] **Cécité:** < 5% si bien traité

### 8. Critères d'hospitalisation
- [ ] **Endophtalmie** suspectée
- [ ] **Hypertonie** > 40 mmHg
- [ ] **Panuvéite sévère**
- [ ] **Échec traitement ambulatoire**
- [ ] **Nécessité bolus IV**

## 📢 PRÉSENTATION DU CAS

### Structure pour uvéite

**S - Situation:**
"Patient de [âge] ans présentant œil rouge douloureux avec photophobie intense et baisse d'acuité visuelle depuis [durée]."

**B - Background:**
"Antécédents: [HLA-B27, maladie inflammatoire, épisodes antérieurs]. Facteurs de risque: [voyage, contact animaux, IST]."

**A - Appréciation:**
"Injection ciliaire, Tyndall [grade], synéchies postérieures, PIO: [valeur]. Fond d'œil: [normal/pathologique]."

**R - Recommandation:**
"Uvéite [antérieure/postérieure] [granulomateuse/non-granulomateuse]. Corticoïdes topiques horaires + atropine. Bilan étiologique. Surveillance rapprochée."

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Rechercher injection ciliaire** (≠ conjonctivale)
2. **Examiner Tyndall** à la lampe à fente
3. **Mesurer PIO** (urgence si > 30)
4. **Rechercher synéchies** (mydriase urgente)
5. **Bilan étiologique** systématique
6. **Syphilis + tuberculose** toujours éliminer
7. **Corticoïdes + mydriatiques** sans délai

### ❌ Pièges à éviter
1. Confondre avec conjonctivite (pas de BAV)
2. Oublier atropine (synéchies irréversibles)
3. Arrêt brutal corticoïdes (rebond)
4. Méconnaître uvéite postérieure (FO++)
5. Négliger œdème maculaire (BAV définitive)
6. Oublier syphilis (grande simulatrice)

### 💡 Astuces mnémotechniques

**Types uvéite - "AIPP":**
- **A**ntérieure (iris/corps ciliaire)
- **I**ntermédiaire (pars plana)
- **P**ostérieure (choroïde/rétine)
- **P**anuvéite (toutes structures)

**Causes fréquentes - "BITES":**
- **B**ehçet
- **I**nfections (HSV, toxo, syphilis)
- **T**uberculose
- **E**nthésites (HLA-B27)
- **S**arcoïdose

**Traitement urgent - "CAH":**
- **C**orticoïdes topiques
- **A**tropine (mydriatique)
- **H**ypotonisants si PIO élevée

**Complications - "CGEO":**
- **C**ataracte
- **G**laucome
- **E**dème maculaire (œdème)
- **O**pacités vitréennes
