# Fiche de Révision ECOS - RÉTINOPATHIE DIABÉTIQUE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient diabétique présentant troubles visuels ou venant pour dépistage systématique de complications oculaires
**Objectifs d'évaluation:** Dépister et classifier la rétinopathie, identifier les urgences, planifier surveillance et traitement, éduquer sur l'équilibre glycémique

## 🩺 EXAMEN CLINIQUE (STATUS)

### Signes vitaux
- [ ] **TA:** ⚠️ Objectif <130/80 si diabétique
- [ ] **Glycémie capillaire:** Si disponible
- [ ] **Poids, IMC**

### 1. EXAMEN OPHTALMOLOGIQUE

#### Acuité visuelle ⚠️ SYSTÉMATIQUE
- [ ] **De loin (Snellen/Monoyer):**
  - Chaque œil séparément
  - Avec correction optimale
  - Chiffrer précisément
- [ ] **De près (Parinaud):**
  - Test lecture
  - Distance habituelle
- [ ] **Vision des couleurs:** Si neuropathie optique suspectée

#### Examen segment antérieur
- [ ] **Paupières:** Xanthélasma? (dyslipidémie)
- [ ] **Cornée:** Sensibilité? (neuropathie)
- [ ] **Iris:**
  - **Rubéose irienne** ⚠️ (néovaisseaux iris = RD proliférante sévère)
  - Synéchies?
- [ ] **Cristallin:**
  - Cataracte? (précoce chez diabétique)
  - Pseudophaque?
- [ ] **PIO:** ⚠️ Si rubéose (glaucome néovasculaire)

### 2. FOND D'ŒIL ⚠️ EXAMEN CLÉ

#### Préparation
- [ ] **Dilatation pupillaire:** Obligatoire pour examen complet
- [ ] **Attendre 20-30 minutes**
- [ ] **Prévenir patient:** Vision floue 2-4h

#### Classification rétinopathie diabétique

##### RD NON PROLIFÉRANTE (RDNP)

**RDNP Minime:**
- [ ] **Microanévrismes** seuls (< 20)
- [ ] Pas d'autres lésions
- [ ] **Pronostic:** Bon, risque progression 5%/an

**RDNP Modérée:**
- [ ] **Microanévrismes** nombreux (> 20)
- [ ] **Hémorragies rétiniennes** punctiformes ou en flammèches
- [ ] **Exsudats secs** (lipidiques)
- [ ] **Nodules cotonneux** (occlusions capillaires)
- [ ] Moins sévère que règle 4-2-1

**RDNP Sévère:** ⚠️ HAUT RISQUE PROGRESSION
- [ ] **Règle 4-2-1** (un seul critère suffit):
  - Hémorragies dans **4 quadrants**
  - Veines monilifomes dans **2 quadrants**
  - AMIR (anomalies microvasculaires intrarétiniennes) dans **1 quadrant**
- [ ] **Risque RDP:** 50% à 1 an

##### RD PROLIFÉRANTE (RDP) ⚠️ URGENCE

**RDP sans caractéristiques haut risque:**
- [ ] **Néovaisseaux:**
  - Papillaires (NVD) < 1/4 surface papillaire
  - Ou prérétiniens (NVE) < 1/2 surface papillaire
- [ ] Pas d'hémorragie prérétinienne/vitréenne

**RDP avec caractéristiques haut risque:** ⚠️ LASER URGENT
- [ ] **NVD ≥ 1/4 surface papillaire**
- [ ] **Ou NVD + hémorragie prérétinienne/vitréenne**
- [ ] **Ou NVE ≥ 1/2 surface papillaire + hémorragie**

**Complications RDP:**
- [ ] **Hémorragie intravitréenne** ⚠️
- [ ] **Décollement rétine tractionnel**
- [ ] **Glaucome néovasculaire** (rubéose)
- [ ] **Prolifération fibro-vasculaire**

##### MACULOPATHIE DIABÉTIQUE ⚠️ BAISSE AV

**Œdème maculaire diabétique (OMD):**
- [ ] **Épaississement rétinien** dans les 2 diamètres papillaires du centre
- [ ] **Exsudats secs** en couronne
- [ ] **Classification:**
  - OMD non central
  - **OMD central** ⚠️ (atteinte fovéa)
  - OMD cliniquement significatif (CSME)

**Maculopathie ischémique:**
- [ ] **Élargissement** zone avasculaire centrale
- [ ] **Pronostic** visuel sombre
- [ ] Pas de traitement efficace

### 3. EXAMENS COMPLÉMENTAIRES OPHTALMO

#### OCT maculaire ⚠️ GOLD STANDARD OMD
- [ ] **Épaisseur maculaire centrale** (N < 250 μm)
- [ ] **Œdème maculaire cystoïde**
- [ ] **Décollement séreux rétinien**
- [ ] **Traction vitréo-maculaire**
- [ ] **Suivi quantitatif** sous traitement

#### Angiographie à la fluorescéine
- [ ] **Indications:**
  - Doute diagnostic
  - Bilan pré-laser
  - Ischémie maculaire?
- [ ] **Signes:**
  - Zones non-perfusion
  - Néovaisseaux (hyperfluorescence précoce)
  - Diffusion (œdème)

#### Rétinophotographies
- [ ] **Documentation** évolution
- [ ] **Comparaison** dans le temps
- [ ] **7 champs standard** ou grand champ

#### OCT-Angiographie
- [ ] **Non invasif**
- [ ] **Visualisation** plexus capillaires
- [ ] **Zone avasculaire** centrale

### 4. EXAMEN GÉNÉRAL

#### Recherche complications diabétiques
- [ ] **Pieds:** ⚠️ SYSTÉMATIQUE
  - Inspection (plaies, déformations)
  - Sensibilité (monofilament)
  - Pouls périphériques
  - Réflexes achilléens
- [ ] **Cardiovasculaire:**
  - Auscultation cardiaque
  - Souffles carotidiens
  - TA couché/debout
- [ ] **Neurologique:** Si neuropathie

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. OBJECTIFS THÉRAPEUTIQUES

#### Prévention primaire (pas de RD)
- [ ] **Équilibre glycémique** optimal
- [ ] **Contrôle** facteurs de risque
- [ ] **Surveillance** régulière

#### Prévention progression (RD présente)
- [ ] **Ralentir** évolution
- [ ] **Préserver** fonction visuelle
- [ ] **Éviter** complications

### 2. TRAITEMENT SYSTÉMIQUE ⚠️ FONDAMENTAL

#### 2.1 Équilibre glycémique
- [ ] **HbA1c cible:** ⚠️ INDIVIDUALISER
  - Général: < 7%
  - Strict: < 6.5% si récent, sans complication
  - Souple: < 8% si âgé, comorbidités
- [ ] **Éviter variations brutales** (aggravation transitoire)
- [ ] **Surveillance continue** si DT1
- [ ] **Éducation thérapeutique**

#### 2.2 Contrôle tensionnel
- [ ] **Objectif TA:** < 130/80 mmHg
- [ ] **IEC ou ARA2** en 1ère ligne:
  - Néphroprotection
  - Réduction progression RD 35%
- [ ] **Associations** si besoin
- [ ] **Surveillance** fonction rénale

#### 2.3 Contrôle lipidique
- [ ] **Statine** systématique si DT2
- [ ] **Objectifs:**
  - LDL < 0.7 g/L si haut risque
  - < 0.55 g/L si très haut risque
- [ ] **Fibrates** si hypertriglycéridémie

#### 2.4 Autres mesures
- [ ] **Arrêt tabac** impératif
- [ ] **Activité physique** régulière
- [ ] **Équilibre pondéral**
- [ ] **Antiagrégant** si indication CV

### 3. TRAITEMENT OPHTALMOLOGIQUE SPÉCIFIQUE

#### 3.1 RDNP minime/modérée
- [ ] **Surveillance seule**
- [ ] **Optimisation** facteurs de risque
- [ ] **FO annuel** (semestriel si facteurs risque)
- [ ] **OCT** si doute œdème

#### 3.2 RDNP sévère
- [ ] **Surveillance rapprochée** 3-4 mois
- [ ] **Discussion PPR précoce** si:
  - Mauvaise observance prévisible
  - Œil unique
  - Grossesse prévue
- [ ] **Information** sur risque progression

#### 3.3 RD proliférante ⚠️ TRAITEMENT URGENT

##### Photocoagulation panrétinienne (PPR)
- [ ] **Indications:** ⚠️ URGENTE SI HAUT RISQUE
  - RDP confirmée
  - RDNP sévère à risque
  - Avant chirurgie cataracte si RD sévère
- [ ] **Technique:**
  - **1200-1600 impacts** laser argon
  - **2-4 séances** sur 2-4 semaines
  - Épargne macula et papille
  - Destruction rétine ischémique périphérique
- [ ] **Effets secondaires:**
  - Réduction champ visuel périphérique
  - Baisse vision nocturne
  - Œdème maculaire transitoire
- [ ] **Surveillance:**
  - J7, M1, M3 puis /6 mois
  - Compléments si néovaisseaux persistants

##### Anti-VEGF intravitréens
- [ ] **En complément PPR** si:
  - RDP floride
  - Hémorragie vitréenne
  - OMD associé
- [ ] **Protocole:** 3 injections mensuelles puis PRN
- [ ] **Surveillance** mensuelle

#### 3.4 Œdème maculaire diabétique ⚠️ 1ère CAUSE BAV

##### Anti-VEGF intravitréens (1ère ligne)
- [ ] **Molécules:**
  - **Ranibizumab** (Lucentis) 0.5mg
  - **Aflibercept** (Eylea) 2mg
  - Bevacizumab (Avastin) 1.25mg hors AMM
- [ ] **Protocole:**
  - Phase d'induction: 3-5 injections mensuelles
  - Phase d'entretien: PRN ou Treat & Extend
  - Durée: plusieurs années souvent
- [ ] **Efficacité:**
  - Gain 10-15 lettres ETDRS
  - 40% gain ≥ 15 lettres
- [ ] **Surveillance:**
  - AV + OCT mensuel initialement
  - Espacement progressif si stable

##### Corticoïdes intravitréens (2ème ligne)
- [ ] **Indications:**
  - Échec/contre-indication anti-VEGF
  - OMD chronique
  - Patient pseudophaque
- [ ] **Molécules:**
  - **Implant dexaméthasone** (Ozurdex) 700μg
  - Durée action: 4-6 mois
  - Triamcinolone 4mg (hors AMM)
- [ ] **Effets secondaires:** ⚠️
  - Hypertonie (30%)
  - Cataracte (60% si phaque)
- [ ] **Surveillance:** PIO+++

##### Laser focal/grille maculaire
- [ ] **Indications limitées:**
  - OMD focal avec exsudats circonscrits
  - > 500μm du centre fovéal
  - En complément anti-VEGF
- [ ] **Technique:**
  - Impacts de 50-100μm
  - Photocoagulation douce

#### 3.5 Complications

##### Hémorragie intravitréenne
- [ ] **Traitement conservateur initial:**
  - Repos, tête surélevée 45°
  - Éviter efforts, Valsalva
  - Anti-VEGF si RDP active
- [ ] **Vitrectomie si:**
  - Persistance > 3 mois
  - Décollement rétine associé
  - Œil unique
  - RDP non traitée nécessitant PPR

##### Décollement rétine tractionnel
- [ ] **Surveillance** si macula non menacée
- [ ] **Vitrectomie urgente** si:
  - Atteinte maculaire
  - Progression documentée
  - Décollement mixte (tractionnel + rhegmatogène)

##### Glaucome néovasculaire ⚠️ URGENCE
- [ ] **Traitement immédiat:**
  - Anti-VEGF intravitréen urgent
  - Collyres hypotonisants maximaux
  - PPR dès que possible
  - Corticoïdes topiques
- [ ] **Si échec médical:**
  - Cycloaffaiblissement (laser diode)
  - Valve de drainage
- [ ] **Pronostic** visuel réservé

### 4. SURVEILLANCE

#### 4.1 Fréquence du suivi ⚠️ ADAPTER AU STADE

**Pas de RD:**
- [ ] **DT1:** Annuel après 5 ans d'évolution
- [ ] **DT2:** Dès diagnostic puis annuel
- [ ] **Plus fréquent si:** Mauvais équilibre, HTA

**RDNP minime:** Annuel

**RDNP modérée:** 6-12 mois

**RDNP sévère:** 3-4 mois

**RDP traitée:** 3-6 mois

**OMD sous traitement:** Mensuel puis espacement

**Grossesse diabétique:** ⚠️
- [ ] Avant conception
- [ ] Chaque trimestre minimum
- [ ] Post-partum à 3 mois

#### 4.2 Examens de surveillance
- [ ] **Systématiques:**
  - Acuité visuelle
  - Fond d'œil dilaté
- [ ] **Si indiqué:**
  - OCT maculaire (OMD)
  - Rétinophotographies
  - Angiographie (complications)

### 5. ÉDUCATION THÉRAPEUTIQUE ⚠️ CRUCIALE

#### 5.1 Information sur la maladie
- [ ] **Expliquer:**
  - Lien diabète-rétine
  - Évolution silencieuse longtemps
  - Risque cécité si non traité
  - Efficacité prévention/traitement
- [ ] **Remettre documentation**

#### 5.2 Importance du contrôle glycémique
- [ ] **Objectifs HbA1c** personnalisés
- [ ] **Auto-surveillance** glycémique
- [ ] **Observance** traitement
- [ ] **Règles hygiéno-diététiques**

#### 5.3 Surveillance ophtalmologique
- [ ] **Respecter** calendrier suivi
- [ ] **Ne pas attendre** symptômes
- [ ] **Consulter en urgence si:**
  - Baisse vision brutale
  - Voile noir
  - Éclairs lumineux
  - Pluie de suie

#### 5.4 Facteurs modifiables
- [ ] **Contrôle TA** strict
- [ ] **Arrêt tabac**
- [ ] **Activité physique**
- [ ] **Équilibre lipidique**

### 6. SITUATIONS PARTICULIÈRES

#### 6.1 Grossesse ⚠️ SURVEILLANCE RENFORCÉE
- [ ] **Avant conception:**
  - Équilibre optimal
  - Traitement RD si nécessaire
- [ ] **Pendant grossesse:**
  - FO/trimestre minimum
  - Mensuel si RD préexistante
  - PPR possible si nécessaire
- [ ] **Post-partum:**
  - Risque régression
  - Surveillance 3-6 mois

#### 6.2 Chirurgie de cataracte
- [ ] **Bilan pré-opératoire:**
  - État rétine (FO, OCT)
  - Traiter RD active avant
- [ ] **Risque progression** OMD post-op
- [ ] **Prophylaxie:** AINS topiques

#### 6.3 Amélioration glycémique rapide
- [ ] **Aggravation transitoire** possible
- [ ] **Surveillance rapprochée** 6 mois
- [ ] **Information patient**
- [ ] **Ne pas retarder** équilibration

### 7. PRONOSTIC

#### Facteurs de bon pronostic
- [ ] Dépistage précoce
- [ ] Bon équilibre glycémique
- [ ] TA contrôlée
- [ ] Observance surveillance
- [ ] Traitement précoce

#### Facteurs de mauvais pronostic
- [ ] Diabète ancien mal équilibré
- [ ] Néphropathie sévère
- [ ] Maculopathie ischémique
- [ ] Retard diagnostic/traitement
- [ ] Non-observance

## 📢 PRÉSENTATION DU CAS

### Structure pour rétinopathie diabétique

**S - Situation:**
"Patient diabétique de [type] depuis [années] présentant [symptômes visuels/venu pour dépistage] avec HbA1c à [valeur]."

**B - Background:**
"Facteurs de risque: [HTA, néphropathie, durée diabète]. Dernier FO: [date]. Complications diabétiques: [lesquelles]."

**A - Appréciation:**
"FO: [stade RDNP/RDP], [présence OMD]. OCT: [épaisseur maculaire]. AV: OD [valeur] OG [valeur]."

**R - Recommandation:**
"1) Optimisation équilibre: HbA1c <7%, TA <130/80
2) Traitement ophtalmo: [PPR si RDP, anti-VEGF si OMD]
3) Surveillance: [fréquence selon stade]
4) Éducation importance observance"

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument
1. **Classifier précisément** le stade (RDNP/RDP)
2. **Rechercher œdème maculaire** (1ère cause BAV)
3. **Appliquer règle 4-2-1** pour RDNP sévère
4. **Identifier urgences:** RDP haut risque, glaucome NV
5. **Vérifier autres complications** diabétiques
6. **Insister sur équilibre** glycémique ET tensionnel
7. **Adapter surveillance** au stade

### ❌ Pièges à éviter
1. Oublier dilatation pupillaire (FO incomplet)
2. Méconnaître RDP débutante (NV petits)
3. Négliger œdème maculaire (OCT systématique)
4. Retarder PPR si RDP (risque cécité)
5. Oublier œil controlatéral
6. Sous-estimer grossesse (aggravation rapide)
7. Rassurer si pas de symptômes (évolution silencieuse)

### 💡 Astuces mnémotechniques

**Stades RD - "MMSP":**
- **M**inime: Microanévrismes seuls
- **M**odérée: + Hémorragies, exsudats
- **S**évère: Règle 4-2-1
- **P**roliférante: Néovaisseaux

**Règle 4-2-1 (RDNP sévère):**
- **4** quadrants: Hémorragies
- **2** quadrants: Veines monilifomes  
- **1** quadrant: AMIR

**Traitement OMD - "ALC":**
- **A**nti-VEGF (1ère ligne)
- **L**aser focal (exsudats)
- **C**orticoïdes (2ème ligne)

**Urgences RD - "HEG":**
- **H**émorragie vitréenne massive
- **E**ndophtalmie (post-injection)
- **G**laucome néovasculaire

**Surveillance - "SPOT":**
- **S**ans RD: Annuel
- **P**eu sévère: 6-12 mois
- **O**MD/Sévère: 3-4 mois
- **T**raitée (RDP): 3-6 mois
