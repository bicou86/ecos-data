# Fiche de Révision ECOS - TENDINITES

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient consultant pour douleur tendineuse d'effort nécessitant diagnostic topographique, recherche étiologique et prise en charge adaptée.
**Objectifs d'évaluation:** Diagnostic clinique tendinite, différenciation avec autres causes, traitement conservateur vs spécialisé

---

## 📋 ANAMNÈSE

### 1. Caractérisation de la douleur
**Questions essentielles:**

#### Siège et irradiation
- [ ] **Localisation précise:**
  - Point douloureux sur trajet tendon
  - Uni/bilatérale
  - Irradiation le long du muscle
- [ ] **Topographie par région:**
  - **Épaule:** supra-épineux, biceps, sous-épineux
  - **Coude:** épicondyle (tennis elbow), épitrochléa
  - **Poignet:** De Quervain, fléchisseurs/extenseurs
  - **Hanche:** moyen fessier, psoas-iliaque
  - **Genou:** rotulien, patte d'oie, TFL
  - **Cheville:** Achille, fibulaires, tibial postérieur

#### Caractéristiques temporelles
- [ ] **Début:** brutal vs progressif
- [ ] **Durée évolution:** aiguë (< 6 semaines), chronique (> 3 mois)
- [ ] **Horaire:** mécanique (effort), inflammatoire (repos/nuit)
- [ ] **Évolution:** amélioration, aggravation, plateau

#### Intensité et retentissement
- [ ] **Échelle douleur:** EVA 0-10
- [ ] **Douleur d'effort:** seuil déclenchement
- [ ] **Douleur repos:** présence, intensité
- [ ] **Réveil nocturne:** fréquence
- [ ] **Limitation fonctionnelle:** gestes quotidiens, travail, sport

### 2. Facteurs déclenchants et circonstances

#### Mécanisme traumatique
- [ ] **Traumatisme direct:** choc, contusion
- [ ] **Traumatisme indirect:** étirement brutal, contracture
- [ ] **Microtraumatismes répétés:** surmenage, gestes répétitifs
- [ ] **Changement d'activité:** nouveau sport, intensification

#### Activité professionnelle
- [ ] **Gestes répétitifs:**
  - Informatique: souris, clavier (De Quervain)
  - Manutention: soulèvement (épaule)
  - Vibrations: marteau-piqueur (épicondylite)
- [ ] **Positions prolongées:** bras levés, flexion poignet
- [ ] **Cadence travail:** intensification récente

#### Activité sportive
- [ ] **Type sport:** raquette (épicondylite), course (Achille)
- [ ] **Niveau pratique:** occasionnel, régulier, compétition
- [ ] **Changements récents:**
  - Augmentation volume/intensité
  - Nouveau matériel, terrain
  - Modification technique
- [ ] **Échauffement:** durée, qualité
- [ ] **Hydratation:** apports, pertes

### 3. Antécédents et terrain

#### Antécédents musculo-tendineux
- [ ] **Tendinites antérieures:** localisation, traitement
- [ ] **Lésions muscle-tendon:** ruptures, élongations
- [ ] **Chirurgie orthopédique:** prothèse, arthroscopie
- [ ] **Infiltrations:** nombre, efficacité, complications

#### Terrain favorisant
- [ ] **Âge:** dégénérescence tendineuse (> 40 ans)
- [ ] **Morphologie:** dysharmonie, déséquilibres
- [ ] **Souplesse:** raideur articulaire, rétractions
- [ ] **Force musculaire:** déséquilibres agonistes/antagonistes

#### Pathologies associées
- [ ] **Diabète:** tendinopathie, infection, cicatrisation
- [ ] **Rhumatismes inflammatoires:** PR, SPA
- [ ] **Hypercholestérolémie:** dépôts tendineux
- [ ] **Hypothyroïdie:** raideur, crampes
- [ ] **Insuffisance rénale:** dépôts calciques

### 4. Médicaments
- [ ] **Quinolones:** rupture Achille (ciprofloxacine)
- [ ] **Corticoïdes:** fragilisation tendineuse
- [ ] **Statines:** myalgies, tendinopathies
- [ ] **Anti-inflammatoires:** prise récente, efficacité

### 5. Symptômes d'orientation topographique

#### Épaule (conflit sous-acromial)
- [ ] **Arc douloureux:** 60-120° abduction
- [ ] **Douleur nocturne:** décubitus côté atteint
- [ ] **Limitation active vs passive**
- [ ] **Gêne vêtements:** manches, soutien-gorge

#### Coude
- [ ] **Épicondylite (tennis elbow):**
  - Douleur face externe coude
  - Extension/supination douloureuse
  - Préhension objets, poignée de main
- [ ] **Épitrochléite (golf elbow):**
  - Douleur face interne coude
  - Flexion/pronation douloureuse

#### Poignet-main
- [ ] **Ténosynovite De Quervain:**
  - Douleur radiale poignet
  - Mouvements pouce douloureux
  - Test Finkelstein positif

#### Genou
- [ ] **Tendinite rotulienne (jumper's knee):**
  - Douleur pointe rotule
  - Saut, réception, escaliers
- [ ] **Syndrome essuie-glace (TFL):**
  - Douleur externe genou
  - Course, descente

#### Cheville-pied
- [ ] **Tendinite Achille:**
  - Douleur talon, mollet bas
  - Marche, course, saut
  - Raideur matinale

### 6. Signes d'alarme (complications)
⚠️ **Orientation chirurgicale urgente:**
- [ ] **Rupture tendineuse:** perte fonction, déformation
- [ ] **Infection:** fièvre, rougeur, chaleur
- [ ] **Syndrome compartimental:** tension, douleur intense
- [ ] **Compression nerveuse:** paresthésies, déficit moteur

### 7. Question de clôture
"Cette douleur vous empêche-t-elle de faire certains gestes au quotidien?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Inspection
- [ ] **Déformation:** tuméfaction, nodule tendineux
- [ ] **Attitude spontanée:** position antalgique
- [ ] **Trophicité musculaire:** amyotrophie, asymétrie
- [ ] **Signes inflammatoires:** rougeur, œdème
- [ ] **Signes infection:** lymphangite, adénopathie

### Palpation
- [ ] **Douleur tendineuse:**
  - Point précis sur trajet tendon
  - Concordance plainte fonctionnelle
- [ ] **Consistance:** épaississement, nodule
- [ ] **Mobilité:** adhérences, glissement
- [ ] **Crépitations:** ténosynovite
- [ ] **Chaleur locale:** inflammation

### Tests spécifiques par localisation

#### Épaule
- [ ] **Manœuvres conflit:**
  - Hawkins: flexion 90° + rotation interne
  - Neer: élévation antérieure forcée
  - Jobe: résistance abduction 90°/rotation interne
- [ ] **Tests tendon biceps:**
  - Speed test: flexion épaule résistée
  - Yergason: supination résistée coude fléchi

#### Coude
- [ ] **Test épicondylite:**
  - Douleur épicondyle + extension poignet résistée
  - Mill test: flexion poignet passive coude tendu
- [ ] **Test épitrochléite:**
  - Douleur épitrochléa + flexion poignet résistée

#### Poignet
- [ ] **Test Finkelstein (De Quervain):**
  - Pouce dans paume, déviation ulnaire
  - Douleur styloïde radiale = positif

#### Genou
- [ ] **Test tendon rotulien:**
  - Palpation pointe rotule
  - Extension résistée genou
- [ ] **Test bandelette ilio-tibiale:**
  - Noble test: pression face externe genou
  - Flexion-extension 30°

#### Cheville
- [ ] **Test tendon Achille:**
  - Palpation tendon, insertion calcanéum
  - Flexion plantaire résistée
  - Thompson test si rupture suspectée

### Examen articulaire associé
- [ ] **Amplitudes articulaires:** limitation, compensation
- [ ] **Stabilité articulaire:** laxité, instabilité
- [ ] **Conflits ostéo-articulaires:** butées, accrochages
- [ ] **Morphologie:** déviations, déformations

### Évaluation fonctionnelle
- [ ] **Gestes reproduisant douleur**
- [ ] **Limitation force/endurance**
- [ ] **Compensation:** stratégies évitement
- [ ] **Retentissement activités quotidiennes**

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Examens complémentaires

#### Imagerie de première intention
**Radiographies standard:**
- [ ] **Indications:** suspicion calcification, conflit osseux
- [ ] **Recherche:**
  - Calcifications tendineuses
  - Ostéophytes, becs de perroquet
  - Déformations osseuses

#### Échographie musculo-tendineuse
- [ ] **Examen de choix tendinites:**
  - Non invasif, dynamique, comparatif
  - Excellent pour tendons superficiels
- [ ] **Signes échographiques:**
  - Épaississement tendineux
  - Hypoéchogénie, perte structure fibrillaire
  - Hypervascularisation (Doppler)
  - Épanchement ténosynovial
  - Calcifications, corps étrangers

#### IRM (si échographie non contributive)
- [ ] **Indications:**
  - Tendons profonds (hanche)
  - Diagnostic différentiel (déchirure musculaire)
  - Bilan pré-chirurgical
- [ ] **Avantages:** excellent contraste tissulaire, pas d'irradiation

### 2. Traitement conservateur (première intention)

#### Mesures générales
- [ ] **Repos sportif/professionnel:**
  - Arrêt activité déclenchante
  - Durée: 2-6 semaines selon sévérité
  - Maintien condition physique (sports non douloureux)
- [ ] **Modification gestes:** ergonomie, technique
- [ ] **Éducation patient:** évolution, prévention récidive

#### Traitement médicamenteux
**Anti-inflammatoires (courte durée):**
- [ ] **AINS topiques (première intention):**
  - Diclofénac gel 1% × 3/j × 7-10j
  - Moins d'effets systémiques
  - Efficacité comparable PO pour tendons superficiels
- [ ] **AINS systémiques (si échec topique):**
  - Ibuprofène 400mg × 3/j × 5-7j max
  - **CI:** ulcère, insuffisance rénale, > 65 ans
- [ ] **Paracétamol:** 1g × 4/j, antalgique adjuvant

#### Traitement physique
**Cryothérapie (phase aiguë):**
- [ ] **Glace:** 15-20 min × 3-4/j
- [ ] **Effets:** anti-inflammatoire, antalgique
- [ ] **Précautions:** protection cutanée

**Physiothérapie:**
- [ ] **Ultrasons:** effet thermique profond
- [ ] **Ondes de choc:** tendinopathies chroniques
- [ ] **Électrothérapie:** TENS antalgique

### 3. Kinésithérapie (essentielle)

#### Phase aiguë (0-2 semaines)
- [ ] **Objectifs:** diminuer douleur, inflammation
- [ ] **Moyens:** repos, cryothérapie, mobilisation douce
- [ ] **Éviter:** étirements agressifs, renforcement

#### Phase subaiguë (2-6 semaines)
- [ ] **Étirements progressifs:**
  - Muscle-tendon concerné
  - Chaînes musculaires
  - Maintien 30 sec × 3-5 répétitions
- [ ] **Mobilisation articulaire:** amplitudes complètes
- [ ] **Renforcement excentrique:** progression lente

#### Phase chronique (> 6 semaines)
- [ ] **Renforcement spécifique:**
  - **Travail excentrique:** contraction muscle qui s'allonge
  - Protocole Stanish: augmentation progressive charge
  - Épaule: élastiques, haltères légers
  - Achille: drops excentriques
- [ ] **Rééducation fonctionnelle:**
  - Gestes sport/profession
  - Coordination, proprioception
  - Reprise progressive activité

### 4. Traitements invasifs (seconde intention)

#### Infiltrations corticoïdes
**Indications:**
- [ ] **Échec traitement conservateur 6-8 semaines**
- [ ] **Tendinite avec ténosynovite importante**
- [ ] **Contre-indications:** rupture, infection, diabète déséquilibré

**Modalités:**
- [ ] **Produit:** bétaméthasone, triamcinolone
- [ ] **Voie:** péri-tendineuse (jamais intra-tendineuse)
- [ ] **Nombre:** maximum 3/an, espacées 6 semaines
- [ ] **Repos post-infiltration:** 48-72h

**Complications:**
- [ ] **Rupture tendineuse:** risque majoré
- [ ] **Infection:** rare, stérilité rigoureuse
- [ ] **Dépigmentation cutanée:** transitoire

#### Techniques innovantes
**Injections acide hyaluronique:**
- [ ] **Indications:** tendinopathies chroniques
- [ ] **Mécanisme:** viscoélasticité, anti-inflammatoire
- [ ] **Protocole:** 3 injections espacées 1 semaine

**Plasma riche en plaquettes (PRP):**
- [ ] **Principe:** facteurs croissance autologues
- [ ] **Indications:** échec traitements conventionnels
- [ ] **Efficacité:** études contradictoires

### 5. Traitement chirurgical (dernière intention)

#### Indications chirurgie
- [ ] **Échec traitement conservateur > 6 mois**
- [ ] **Rupture tendineuse complète**
- [ ] **Calcification importante symptomatique**
- [ ] **Conflit mécanique persistant**

#### Techniques selon localisation
**Épaule:**
- [ ] **Acromioplastie:** résection acromion (conflit)
- [ ] **Suture coiffe:** réparation tendineuse

**Coude:**
- [ ] **Débridement épicondyle:** résection tissu pathologique
- [ ] **Ténotomie:** section partielle tendineuse

**Achille:**
- [ ] **Peignage tendineux:** excision zones dégénératives
- [ ] **Plastie:** reconstruction si rupture

### 6. Prévention récidives

#### Correction facteurs favorisants
- [ ] **Ergonomie poste travail:**
  - Hauteur écran, position clavier
  - Pauses régulières, étirements
- [ ] **Matériel sportif adapté:**
  - Chaussures course: amorti, stabilité
  - Raquettes: poids, grip, cordage
  - Progressivité entraînement

#### Programme préventif
- [ ] **Échauffement systématique:** 10-15 min minimum
- [ ] **Étirements post-effort:** maintien souplesse
- [ ] **Renforcement musculaire:** équilibre chaînes
- [ ] **Hydratation:** avant, pendant, après effort

### 7. Surveillance et suivi

#### Critères amélioration
- [ ] **Diminution douleur:** EVA, gestes quotidiens
- [ ] **Récupération force:** testing comparatif
- [ ] **Reprise activité:** progressive, sans douleur
- [ ] **Échographie contrôle:** normalisation structure

#### Suivi chronologique
- [ ] **Consultation J15:** évaluation traitement initial
- [ ] **Consultation 6 semaines:** kinésithérapie, reprise
- [ ] **Consultation 3 mois:** consolidation, prévention
- [ ] **Orientation spécialisée:** si stagnation > 3 mois

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument (25% chaque section)
1. **Test spécifique localisation** (Finkelstein, Hawkins, extension poignet résistée)
2. **Rechercher facteur déclenchant** (gestes répétitifs, sport, travail)
3. **AINS topiques première intention** (moins d'effets secondaires)
4. **Kinésithérapie systématique** (étirements puis renforcement excentrique)
5. **Prévention récidive** (ergonomie, échauffement, progressivité)

### ❌ Pièges à éviter
1. Infiltration intra-tendineuse (risque rupture)
2. Repos absolu prolongé (raideur, déconditionnement)
3. Négliger correction facteurs favorisants (récidive)
4. Étirements agressifs phase aiguë (aggravation)
5. AINS prolongés sans protection gastrique (> 65 ans)

### 💡 Astuces mnémotechniques
- **Tendinites fréquentes = EPACT:** Épaule-Poignet-Achille-Coude-Trochanter
- **Traitement = RICE:** Repos-Ice(glace)-Compression-Élévation
- **Kinésithérapie = EER:** Étirements-Excentrique-Reprise progressive
- **Tests coude = EE:** Extension résistée (épicondylite)-Épitrochléa flexion
- **Infiltration = 3R:** péRi-tendineux (pas intra), Repos 48h, maximum 3/an
