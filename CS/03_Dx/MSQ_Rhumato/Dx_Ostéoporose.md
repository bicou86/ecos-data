# Fiche de Révision ECOS - OSTÉOPOROSE

## 🎯 Situation à Starting Point (SSP)
**Description:** Patient(e) consultant pour évaluation du risque ou prise en charge de l'ostéoporose, maladie osseuse métabolique caractérisée par diminution densité et qualité osseuse.
**Objectifs d'évaluation:** Évaluation risque fracturaire, diagnostic par ostéodensitométrie, recherche étiologique, prévention et traitement

---

## 📋 ANAMNÈSE

### 1. Facteurs de risque majeurs d'ostéoporose
**Questions essentielles:**

#### Facteurs non modifiables
- [ ] **Âge:** > 50 ans (femmes), > 70 ans (hommes)
- [ ] **Sexe:** femme (risque × 4)
- [ ] **Ménopause:** âge, type (naturelle vs chirurgicale)
- [ ] **Antécédents familiaux:**
  - Fracture hanche parents
  - Ostéoporose familiale
- [ ] **Morphologie:**
  - Petite taille/corpulence mince
  - IMC < 19 kg/m²

#### Facteurs modifiables/pathologiques  
- [ ] **Hypogonadisme:**
  - Femme: aménorrhée, ménopause précoce < 45 ans
  - Homme: hypogonadisme, traitement antiandrogène
- [ ] **Corticothérapie:**
  - Dose > 7,5mg/j équivalent prednisolone
  - Durée > 3 mois (cumulative)
- [ ] **Pathologies ostéoporosantes:**
  - Hyperthyroïdie non traitée
  - Hyperparathyroïdie primaire
  - Malabsorption (maladie cœliaque)
  - Polyarthrite rhumatoïde active

### 2. Histoire fracturaire
**Antécédents de fractures:**
- [ ] **Fractures par fragilité osseuse:**
  - Poignet (Colles), vertèbres, hanche
  - Trauma minime: chute de sa hauteur
  - Âge survenue, circonstances
- [ ] **Fractures vertébrales:** souvent asymptomatiques
  - Tassements vertébraux
  - Perte de taille > 4cm depuis âge adulte
- [ ] **Séquelles fonctionnelles:** douleurs, limitation mobilité

### 3. Symptômes actuels
**Douleurs osseuses:**
- [ ] **Rachalgies chroniques:** dorsales, lombaires
- [ ] **Déformation rachidienne:** cyphose dorsale
- [ ] **Perte de taille progressive**
- [ ] **Limitation fonctionnelle:** activités quotidiennes

**Signes de complications:**
- [ ] **Fractures récentes:** circonstances, traitement
- [ ] **Douleurs aiguës:** fracture vertébrale récente
- [ ] **Troubles statiques:** équilibre, marche

### 4. Mode de vie et facteurs modifiables

#### Activité physique
- [ ] **Sédentarité:** facteur de risque majeur
- [ ] **Activité actuelle:** fréquence, type, intensité
- [ ] **Activité passée:** sport, profession physique
- [ ] **Capacité fonctionnelle:** autonomie, mobilité

#### Habitudes alimentaires
- [ ] **Apports calciques:** produits laitiers, eaux calciques
  - Recommandation: 1000-1200mg/j
  - Sources: lait (120mg/100ml), fromage (300-1000mg/100g)
- [ ] **Apports en vitamine D:**
  - Exposition solaire, supplémentation
  - Poissons gras, aliments enrichis
- [ ] **Protéines:** apports suffisants (1g/kg/j)

#### Habitudes toxiques
- [ ] **Tabagisme:** diminue absorption calcium, accélère perte osseuse
- [ ] **Alcool:** > 3 verres/j augmente risque fracture
- [ ] **Caféine excessive:** > 4 tasses café/j

### 5. Médicaments et traitements

#### Traitements ostéoporosants
- [ ] **Corticoïdes systémiques:**
  - Dose, durée, indication
  - Équivalent prednisolone cumulé
- [ ] **Anticonvulsivants:** phénytoïne, phénobarbital
- [ ] **Héparines:** traitement prolongé
- [ ] **Inhibiteurs pompe à protons:** utilisation chronique
- [ ] **Hormones thyroïdiennes:** surdosage chronique

#### Traitements actuels
- [ ] **Supplémentation:** calcium, vitamine D
- [ ] **Traitement ostéoporose:** bisphosphonates, dénosumab
- [ ] **THM (Traitement Hormonal Ménopause):** durée, arrêt
- [ ] **Observance traitement:** prise correcte, effets secondaires

### 6. Comorbidités et pathologies associées

#### Endocriniennes
- [ ] **Hyperthyroïdie:** traitée ou non, TSH supprimée
- [ ] **Hyperparathyroïdie:** lithiase, ostéoporose
- [ ] **Diabète type 1:** risque fracture augmenté
- [ ] **Insuffisance ovarienne:** ménopause précoce
- [ ] **Hypogonadisme masculin:** testostérone basse

#### Digestives
- [ ] **Maladie cœliaque:** malabsorption calcium
- [ ] **Maladie inflammatoire intestinale**
- [ ] **Gastrectomie:** malabsorption
- [ ] **Bypass gastrique:** déficits vitaminiques

#### Autres
- [ ] **Polyarthrite rhumatoïde:** inflammation chronique
- [ ] **Insuffisance rénale chronique:** troubles minéraux
- [ ] **BPCO sévère:** corticoïdes, sédentarité
- [ ] **Cancer:** métastases osseuses, traitements

### 7. Évaluation du risque de chute
**Facteurs de risque de chute:**
- [ ] **Troubles vision:** baisse acuité, cataracte
- [ ] **Troubles équilibre:** vertiges, instabilité
- [ ] **Troubles cognitifs:** démence, confusion
- [ ] **Faiblesse musculaire:** sarcopénie
- [ ] **Médicaments:** benzodiazépines, hypnotiques
- [ ] **Environnement:** éclairage, tapis, obstacles

**Antécédents de chutes:**
- [ ] **Fréquence:** nombre chutes derniers 12 mois
- [ ] **Circonstances:** intérieur/extérieur, moment
- [ ] **Conséquences:** fractures, peur de chuter

### 8. Histoire gynéco-obstétricale (femmes)
- [ ] **Ménarche:** âge premières règles
- [ ] **Ménopause:** âge, type (naturelle/chirurgicale)
- [ ] **Aménorrhées:** durée, causes
- [ ] **Grossesses:** nombre, allaitement
- [ ] **Contraception:** œstro-progestative (protection)
- [ ] **THM:** durée, molécules, arrêt

### 9. Question de clôture
"Avez-vous des douleurs osseuses ou des inquiétudes concernant vos os?"

## 🩺 EXAMEN CLINIQUE (STATUS)

### Morphologie et statique
- [ ] **Taille actuelle vs taille maximale adulte:**
  - Perte > 4cm évocatrice tassements vertébraux
- [ ] **Poids, IMC:** dénutrition (IMC < 19)
- [ ] **Déformation rachidienne:**
  - Cyphose dorsale accentuée
  - Distance mur-occiput > 5cm
- [ ] **Périmètre abdominal:** protrusion (tassements)

### Examen rachidien
- [ ] **Inspection profil:** courbures physiologiques
- [ ] **Palpation épineuses:** douleur, déformation
- [ ] **Mobilité rachidienne:** limitations
- [ ] **Distance doigts-sol:** raideur rachidienne
- [ ] **Recherche gibbosité:** scoliose

### Examen musculo-squelettique
- [ ] **Force musculaire:** testing 4 membres
- [ ] **Équilibre:** 
  - Station unipodale (< 5sec pathologique)
  - Test "Timed Up and Go" (> 14sec = risque chute)
- [ ] **Marche:** vitesse, stabilité, aide technique

### Signes de pathologies associées
- [ ] **Thyroïde:** palpation, signes hyper/hypothyroïdie
- [ ] **Signes malabsorption:** pâleur, dénutrition
- [ ] **Hyperparathyroïdie:** lithiase, troubles cognitifs
- [ ] **Hypogonadisme:** pilosité, morphologie

## 💊 PRISE EN CHARGE (MANAGEMENT)

### 1. Évaluation du risque fracturaire

#### Ostéodensitométrie (DEXA)
**Indications:**
- [ ] **Femme ménopausée** avec facteur de risque
- [ ] **Homme > 70 ans** avec facteur de risque  
- [ ] **Corticothérapie** > 3 mois ≥ 7,5mg/j
- [ ] **Antécédent fracture fragilité** après 40 ans
- [ ] **Pathologie ostéoporosante**

**Interprétation T-score:**
- [ ] **Normal:** T-score > -1
- [ ] **Ostéopénie:** -2,5 < T-score ≤ -1
- [ ] **Ostéoporose:** T-score ≤ -2,5
- [ ] **Ostéoporose sévère:** T-score ≤ -2,5 + fracture

#### Outil FRAX (fracture risk assessment)
- [ ] **Calcul risque fracture 10 ans:**
  - Fracture majeure ostéoporotique
  - Fracture hanche spécifiquement
- [ ] **Facteurs intégrés:** âge, sexe, IMC, FdR
- [ ] **Seuil intervention:** selon pays/guidelines

#### Marqueurs biochimiques (selon contexte)
- [ ] **Bilan phosphocalcique:**
  - Calcémie, phosphorémie
  - 25-OH vitamine D (> 30 ng/ml optimale)
  - PTH si hypercalcémie
- [ ] **Marqueurs osseux:**
  - Ostéocalcine (formation)
  - CTX sérique (résorption)
- [ ] **Bilan étiologique:**
  - TSH, créatinine
  - Électrophorèse protéines (myélome)

### 2. Prévention primaire (avant fracture)

#### Mesures hygiéno-diététiques
- [ ] **Apports calciques:**
  - **1000-1200 mg/j** selon âge
  - Privilégier sources alimentaires
  - Supplémentation si apports insuffisants
- [ ] **Vitamine D:**
  - **800-1000 UI/j** systématique > 65 ans
  - Cholécalciférol (D3) préférable
  - Surveillance 25-OH D (cible > 30 ng/ml)

#### Activité physique adaptée
- [ ] **Exercices en charge:** marche, danse, tennis
- [ ] **Renforcement musculaire:** 2-3 fois/semaine
- [ ] **Équilibre/proprioception:** tai-chi, yoga
- [ ] **Durée:** 30-45 min × 3-5 fois/semaine
- [ ] **Progression graduelle:** éviter surmenage

#### Prévention des chutes
- [ ] **Aménagement domicile:**
  - Éclairage suffisant, rampes
  - Suppression obstacles, tapis
  - Barres d'appui salle de bain
- [ ] **Révision médicaments:** benzodiazépines, hypnotiques
- [ ] **Correction déficits sensoriels:** vision, audition
- [ ] **Kinésithérapie:** équilibre, proprioception

### 3. Traitement médicamenteux ostéoporose

#### Bisphosphonates (première intention)
**Alendronate (Fosamax®):**
- [ ] **Posologie:** 70mg/semaine PO
- [ ] **Modalités prise:** 
  - À jeun, debout, avec grand verre eau
  - Rester debout 30-60 min après prise
- [ ] **Efficacité:** réduction fractures vertébrales 50%
- [ ] **Durée:** réévaluation après 3-5 ans

**Risédronate (Actonel®):**
- [ ] **Posologie:** 35mg/semaine ou 75mg × 2j/mois
- [ ] **Modalités similaires alendronate**
- [ ] **Alternative si intolérance alendronate**

**Zolédronate (Aclasta®):**
- [ ] **Posologie:** 5mg IV annuelle
- [ ] **Indications:** intolérance PO, mauvaise observance
- [ ] **Surveillance:** fonction rénale, calcémie

#### Denosumab (Prolia®)
- [ ] **Posologie:** 60mg SC tous les 6 mois
- [ ] **Mécanisme:** inhibiteur RANK-ligand
- [ ] **Indications:** 
  - Échec/intolérance bisphosphonates
  - Insuffisance rénale modérée
- [ ] **Effets secondaires:** infections, ostéonécrose mâchoire

#### Traitements de seconde intention
**Tériparatide (Forsteo®):**
- [ ] **Posologie:** 20μg/j SC
- [ ] **Durée maximale:** 2 ans
- [ ] **Indications:** ostéoporose sévère, échecs
- [ ] **Anabolisant osseux:** stimule formation

**Romosozumab (Evenity®):**
- [ ] **Posologie:** 210mg SC mensuel
- [ ] **Durée:** 12 mois maximum
- [ ] **Double action:** ↑formation + ↓résorption
- [ ] **CI:** antécédent cardiovasculaire majeur

#### Cas particuliers
**Corticothérapie au long cours:**
- [ ] **Prévention systématique si ≥ 3 mois:**
  - Calcium 1000mg/j + vitamine D 800 UI/j
  - Bisphosphonates si risque élevé
- [ ] **DEXA baseline puis annuelle**

**Ménopause récente (< 60 ans):**
- [ ] **THM:** option si pas de contre-indications
- [ ] **SERM (raloxifène):** si CI aux œstrogènes
- [ ] **Durée limitée:** réévaluation régulière

### 4. Suivi et surveillance

#### Efficacité du traitement
- [ ] **DEXA de contrôle:** tous les 2-3 ans
- [ ] **Marqueurs osseux:** 3-6 mois (optionnel)
- [ ] **Absence nouvelles fractures:** critère principal

#### Tolérance et observance
- [ ] **Effets secondaires digestifs:** bisphosphonates
- [ ] **Observance:** modalités prise, oublis
- [ ] **Complications rares:**
  - Ostéonécrose mâchoire (soins dentaires)
  - Fractures atypiques fémorales (douleur cuisses)

#### Durée de traitement
- [ ] **Bisphosphonates:** "drug holidays" après 3-5 ans
- [ ] **Réévaluation risque:** DEXA, facteurs risque
- [ ] **Arrêt progressif:** si risque faible
- [ ] **Poursuite:** si haut risque persistant

### 5. Éducation thérapeutique

#### Compréhension maladie
- [ ] **Nature ostéoporose:** "maladie silencieuse"
- [ ] **Risque fracturaire:** impact qualité vie
- [ ] **Importance prévention:** chutes, traitement

#### Modalités traitement
- [ ] **Prise médicaments:** horaires, positions
- [ ] **Supplémentation:** calcium, vitamine D quotidiens  
- [ ] **Activité physique:** types recommandés
- [ ] **Signaler:** douleurs osseuses nouvelles

## 📌 POINTS CLÉS POUR L'EXAMEN

### ✅ À faire absolument (25% chaque section)
1. **Évaluer facteurs de risque majeurs** (ménopause, corticoïdes, antécédents fractures)
2. **Mesurer perte de taille** (> 4cm évoque tassements vertébraux)
3. **DEXA si indications** (femme ménopausée + FdR, corticothérapie)
4. **Supplémentation Ca+D** (tous les patients, base traitement)
5. **Bisphosphonates première intention** (modalités prise correctes)

### ❌ Pièges à éviter
1. Oublier supplémentation vitamine D systématique
2. Mal expliquer modalités prise bisphosphonates (échec traitement)
3. Négliger prévention chutes (aussi importante que densité osseuse)
4. Sous-estimer impact fractures vertébrales (souvent asymptomatiques)
5. Prescrire bisphosphonates sans évaluation fonction rénale

### 💡 Astuces mnémotechniques
- **FdR majeurs = CHAFMEC:** Corticoïdes-Hérédité-Âge-Fracture-Ménopause-Éthylisme-Chute
- **T-score = -1/-2,5:** Normal > -1, Ostéopénie -1 à -2,5, Ostéoporose < -2,5
- **Bisphosphonates = JADE:** Jeun-Assis/debout-Demi-heure-Eau
- **Ca+D = 1000+1000:** Calcium 1000mg + vitamine D 1000 UI
- **DEXA indications = CAFT:** Corticoïdes-Âge(>65F/>70H)-Fracture-Thyroïde
