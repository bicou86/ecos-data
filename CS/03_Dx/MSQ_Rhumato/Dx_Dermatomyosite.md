## 1. Définition
- Myopathie inflammatoire idiopathique, caractérisée par :  
  - **Faiblesse musculaire proximale symétrique progressive**  
  - **Atteinte cutanée caractéristique**  
- Forme juvénile possible : **dermatomyosite juvénile**  

---

## 2. Tableau clinique typique

### Musculaire
- Faiblesse proximale (ceintures scapulaire et pelvienne) : difficulté à se lever, monter les escaliers, soulever les bras.  
- Parfois atteinte des **muscles pharyngés** (dysphagie) ou **respiratoires** (dyspnée).  

### Cutané spécifique

| Lésion               | Description |
|----------------------|-------------|
| **Papules de Gottron** | Papules violacées sur les articulations des doigts |
| **Érythème héliotrope** | Érythème violacé autour des paupières |
| **Shawl sign**       | Érythème photosensible en « châle » sur le tronc supérieur |
| **Mains de mécanicien** | Hyperkératose et fissures des paumes/dos des doigts |

### Autres signes
- Fatigue, fièvre, arthralgies fréquentes  
- Risque accru de **cancers sous-jacents** (surtout si > 50 ans)  
- Atteinte pulmonaire interstitielle possible  

---

## 3. Examens diagnostiques

| Domaine  | Tests / résultats attendus |
|----------|-----------------------------|
| **Biologie** | ↑ CPK, aldolase, LDH, transaminases |
| **Séro**     | Anticorps anti-Mi-2, anti-TIF1-γ, anti-MDA5 (selon phénotype) |
| **EMG**      | Myopathie inflammatoire compatible |
| **IRM musculaire** | Inflammation active (œdème) |
| **Biopsie musculaire** | Infiltrat périvasculaire + atrophie périfasciculaire |
| **Biopsie cutanée**    | Aide au diagnostic si lésions typiques |
| **Bilan néoplasique**  | Systématique chez l’adulte (scanner, endoscopie, etc.) |

---

## 4. Prise en charge

| Traitement               | Objectif |
|---------------------------|----------|
| **Corticothérapie systémique** | 1ʳᵉ ligne (dose pleine puis dégressive) |
| **Immunosuppresseurs**   | Méthotrexate, azathioprine (si corticodépendance ou forme sévère) |
| **Traitements topiques** | Crèmes solaires, dermocorticoïdes |
| **Rééducation fonctionnelle** | Prévention amyotrophie/déconditionnement |
| **Surveillance du cancer** | Suivi initial et itératif selon le contexte |

---

## ⚡ Points clés OSCE
- Rechercher **faiblesse musculaire proximale symétrique** + **lésions cutanées spécifiques**.  
- Toujours penser à la **recherche de cancer associé** (surtout > 50 ans).  
- Prescrire rapidement : **CPK + EMG + IRM + biopsie musculaire** si suspicion forte.  
- Débuter **corticothérapie rapide** avec surveillance évolutive.  
- Impliquer **dermatologue, neurologue, et parfois oncologue**.
