REVUE MÉDICALE SUISSE ÉTUDIANTS

Examen du Rachis

Introduction

Les maladies musculo-squelettiques peuvent atteindre les différentes structures osseuses, musculaires, cartilagineuses, tendineuses ou ligamentaires. En Suisse, au moins 80% de la population a souffert au moins une fois du dos. Il s'agit du 1er motif de consultation chez les médecins généralistes.

Anatomie

33 vertèbres réparties en :

  • 7 vertèbres cervicales (rachis cervical)
  • 12 vertèbres thoraciques (rachis thoracique/dorsal)
  • 5 vertèbres lombaires (rachis lombaire)
  • Sacrum (4 vertèbres fusionnées)
  • Coccyx (3-5 vertèbres fusionnées)

Examen clinique

1. Inspection

Station debout - Plan frontal

Déformation latérale → scoliose (idiopathique, congénitale, neuromusculaire, métabolique, tissus mous, trauma, tumeur)

Station debout - Plan sagittal

Hyperlordose → courbure concave exagérée

Hypercyphose → courbure convexe exagérée (Scheuermann, ostéoporose, spondylarthrite ankylosante)

Signes cutanés et musculaires

Zone tuméfiée, rouge, chaude → trauma, ostéomyélite vertébrale, abcès musculaire, spondylodiscite, spondylarthrite, néoplasie, métastase

Amyotrophie → lésion nerveuse, diminution activité physique

Pilosité localisée ou kyste → spina bifida, méningocèle, myéloméningocèle

Cicatrice → anciennes interventions (scoliose, hernie discale)

Plis cutanés (signe du sapin) → ostéoporose, fracture vertébrale

Marche

Boiterie → arthrite septique, ostéomyélite, ostéochondrite disséquante, synovite transitoire, Legg-Calvé-Perthes, épiphysiolyse, spondylarthropathies, polyarthrite rhumatoïde, ostéome ostéoïde, métastases

Boiterie de Trendelenburg → insuffisance moyen fessier

Boiterie de Duchenne → insuffisance chronique moyen fessier

Autres causes → myopathie de Duchenne, spasticité, dystonie, trouble cérébelleux, athétose, raideur articulaire, inégalité membres inférieurs, coxarthrose, conflit fémoro-acétabulaire

2. Palpation

Palpation symétrique et systématique

(FIG 4) (FIG 5) (FIG 6) (FIG 7)

Apophyses épineuses

Douleur à la palpation/percussion → fracture, infection, néoplasie, ostéoporose, fracture-tassement

Loges paravertébrales

Douleur → contraction musculaire paravertébrale, problème mécanique (arthrose)

Colonne sacro-iliaque

Douleur → sacro-ilite (spondylarthrite ankylosante), arthrose, trauma

3. Mobilité et force

Mobilité active uniquement

(FIG 8) (FIG 9)

Rachis cervical

  • Flexion : menton-poitrine
  • Extension : regarder plafond
  • Flexion latérale : oreille-épaule
  • Rotation : regarder par-dessus épaules

Diminution mobilité → trauma, contracture paravertébrale, arthrose, instabilité atlanto-axiale (polyarthrite rhumatoïde), anomalie jonction craniocervicale, hernie discale cervicale, spondylose cervicale

Rachis thoraco-lombaire

  • Rotation assise bras croisés
  • Flexion avant (distance doigts-sol)
  • Test de Schober : mesure L5 + 10cm avant/après flexion
  • Schober inversé : extension
(FIG 10)

Distance doigts-sol >10cm ou extension L5-10cm <5cm → mobilité pathologique

Diminution mobilité ou douleur → fracture vertébrale, spondylolisthésis, spondylarthrite ankylosante, spondylarthrites séronégatives, polyarthrite rhumatoïde, hernie discale lombaire, canal lombaire étroit, syringomyélie, syndrome queue-de-cheval

4. Examen neurologique

Test de Lasègue

Position : décubitus dorsal

Manœuvre : flexion hanche jambe tendue passive

Positif : douleur ipsilatérale 35-70° → sciatalgie (hernie discale L5/S1)

Lasègue croisé : douleur controlatérale

Pseudo-Lasègue : douleur hors angles → contracture, fracture hanche/fémur, sténose canal

(FIG 11)

Test de Bragard

Après Lasègue positif : abaisser membre + dorsiflexion pied

Positif : reproduction douleur → confirme atteinte radiculaire

(FIG 12)

Test de Lasègue inversé (Léri)

Position : décubitus ventral, genou 90°

Manœuvre : extension hanche

Positif : douleur cuisse/inguinale → cruralgie (compression nerf fémoral L2-L4), coxopathie

(FIG 13)

Test de Spurling

Position : assise

Manœuvre : flexion + rotation + pression tête

Positif : reproduction douleur/paresthésie → radiculopathie cervicale

(FIG 14)

Signe de la sonnette

Palpation paravertébrale lombaire

Positif : douleur irradiant selon dermatome → radiculopathie

Radiculopathies

L3 → aréflexie patellaire, diminution flexion hanche, hypoesthésie antérieure cuisse

L4-L5 → aréflexie patellaire, diminution extension genou, hypoesthésie dorsolatérale, difficulté marche talons

S1 → difficulté marche pointe pieds

S2-S3-S4-S5 → hyposensibilité postérieure cuisse/jambe, périnée, région périanale, absence réflexe bublocaverneux

C3/C4 → hypoesthésie nuque/épaule, décollement scapulaire

C5 → hypoesthésie épaule antérieure, diminution flexion bras, aréflexie bicipitale

C6 → hypoesthésie radiale avant-bras, diminution flexion bras/extension avant-bras, aréflexie bicipitale/brachioradiale

C7 → hypoesthésie palmaire doigts II-IV, dorsale avant-bras/doigts II-IV, diminution extension bras/doigts et flexion avant-bras, aréflexie tricipitale

C8 → hypoesthésie dorsale avant-bras, palmaire/dorsale doigts IV-V et éminence hypothénar, diminution flexion doigts

(FIG 15)

Syndromes médullaires

Syndrome queue-de-cheval

→ aréflexie asymétrique, parésie flaccide membres inférieurs, atrophie musculaire, anesthésie en selle, paresthésie asymétrique, douleurs lombaires irradiant, dysfonction vésicale/rectale/érectile

Syndrome cône terminal

→ hyperréflexie symétrique membres inférieurs, parésie distale, fasciculations, hypoesthésie périanale, incontinence, dysfonction érectile

Compression médullaire

→ douleurs radiculaires, rachialgies, déficits sensitivomoteurs sous niveau lésionnel, dysfonction vésicale/intestinale

Syndrome Brown-Séquard

→ perte ipsilatérale proprioception/vibration, perte controlatérale douleur/température, atteinte motoneurone inférieur au site, motoneurone supérieur sous site

Syndrome médullaire antérieur

→ proprioception/vibration préservées, atteinte bilatérale thermo-algique, atteinte motrice bilatérale, rétention urinaire

Syndrome médullaire central

→ atteinte thermo-algique > proprioception, motoneurone supérieur membres inférieurs, motoneurone inférieur membres supérieurs, rétention urinaire → syringomyélie, néoplasie, trauma hyperextension

Syndrome cordon postérieur

→ atteinte bilatérale proprioception/vibration sans atteinte thermo-algique/motrice

Signe de Lhermitte : décharge électrique à la flexion cervicale → sclérose en plaques, compression médullaire, myélopathie cervicale

Carte de synthèse

Inspection

  • Marche : boiterie, symétrie
  • Allure rachis : courbures, déformations
  • Symétrie ceintures scapulaire/pelvienne
  • Aspect musculo-cutané

Palpation

  • Musculature cervicale/dorsale/paravertébrale
  • Apophyses épineuses (C7 visible)
  • Percussion rachis
  • Articulation sacro-iliaque

Mobilité

Cervicale

  • Flexion-extension : 40-0-40°
  • Inclinaison : 45-0-45°
  • Rotation : 90-0-90°

Thoraco-lombaire

  • Flexion-extension
  • Inclinaison latérale
  • Rotation
  • Test de Schober
  • Distance doigts-sol

Tests spécifiques

  • Mennell, FABER (sacro-iliaque)
  • Spurling (racines cervicales)
  • Lhermitte (myélopathie)
  • Lasègue, Bragard (L4-S1)
  • Lasègue inversé (L3-L4)

Examen neurologique

  • Force, réflexes, sensibilité membres
  • Sensibilité périnéale/périanale
  • Toucher rectal si suspicion syndrome queue-de-cheval
