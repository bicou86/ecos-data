REVUE MÉDICALE SUISSE ÉTUDIANTS

Examen du Pied et de la Cheville

Introduction

Les maladies musculo-squelettiques peuvent atteindre les différentes structures osseuses, musculaires, cartilagineuses, tendineuses ou ligamentaires.

Le pied est sujet à de nombreuses pathologies dont l'incidence est élevée chez les personnes âgées. Chez les sujets de plus de 75 ans, un examen clinique du pied peut retrouver un trouble podologique dans 60% des cas. 21 à 40% des patients de cette catégorie d'âge rapportent des troubles du pied.

Anatomie

Os (26 os)

  • Talus : articulation talocrurale avec tibia/fibula, subtalaire avec calcanéus, talonaviculaire avec naviculaire
  • Calcanéus : s'articule avec talus et cuboïde
  • Os naviculaire : s'articule avec talus, cuboïde et 3 cunéiformes
  • 3 os cunéiformes (médial, intermédiaire, latéral)
  • Cuboïde : s'articule avec 4e-5e métatarsiens, calcanéus et cunéiforme latéral
    • 5 métatarsiens
      • 14 phalanges : 3 par orteil sauf hallux (2)
      • (FIG 1)

Articulations principales

  • Articulation talocrurale : talus-tibia-fibula, flexion-extension
  • Ligne de Chopart : calcanéocuboïde et talonaviculaire
  • Ligne de Lisfranc : articulations tarsométatarsiennes
  • Articulation tibiofibulaire distale : syndesmose

Ligaments

  • Ligament deltoïde (médial) : tibiotalaire antérieur, tibionaviculaire, tibiocalcanéen, tibiotalaire postérieur
  • Complexe ligamentaire latéral : talofibulaire antérieur, talofibulaire postérieur, fibulocalcanéen
(FIG 2)

Muscles extrinsèques

Loge antérieure (nerf fibulaire profond)

  • Tibial antérieur : inversion et dorsiflexion
  • Long extenseur de l'hallux : extension hallux et dorsiflexion
  • Long extenseur des orteils : extension orteils II-V et dorsiflexion
  • 3e fibulaire : éversion et dorsiflexion

Loge postérieure (nerf tibial)

Superficielle :

  • Gastrocnémiens : flexion plantaire et genou
  • Soléaire : flexion plantaire
  • Plantaire : flexion plantaire

Profonde :

  • Tibial postérieur : inversion et flexion plantaire
  • Long fléchisseur des orteils : flexion orteils II-V
  • Long fléchisseur de l'hallux : flexion hallux

Loge latérale (nerf fibulaire superficiel)

  • Long fibulaire : flexion plantaire et éversion
  • Court fibulaire : éversion
(FIG 3)

Vascularisation

  • Artère tibiale antérieure → artère pédieuse dorsale
  • Artère tibiale postérieure → artères plantaires médiale et latérale
  • Arc artériel plantaire : anastomose plantaire latérale-pédieuse dorsale
  • Veines : grande veine saphène (médiale), petite veine saphène (latérale)
(FIG 4) (FIG 5)

Retinacula

  • Rétinaculum antérieur (extenseurs) : tendons compartiment antérieur, vaisseaux et nerf fibulaire profond
  • Rétinaculum médial (fléchisseurs) : tendons loge profonde postérieure, vaisseaux et nerf tibial
  • Rétinaculum latéral : tendons loge latérale

Examen clinique

1. Inspection

Marche

Boiterie → arthrite septique, ostéomyélite, goutte, ostéome ostéoïde

Pied et cheville

Rouge, tuméfié, chaud → arthrite septique, arthrite microcristalline, fracture, spondylarthropathie, bursite, polyarthrite rhumatoïde, entorse

Atrophie musculaire → atteinte neuromusculaire, décharge antalgique

Cicatrices → anciennes interventions d'ostéosynthèse

Nodules → polyarthrite rhumatoïde, tophis (goutte)

Plaie → lésion traumatique sur pied diabétique

Déformations

Affaissement voûte + pied valgus → pied plat

Valgisation arrière-pied + "too many toes sign" + affaissement voûte → pied plat valgus

Voûte très arquée + orteils en griffe + médialisation talon → pied creux varus équin (ataxie de Friedreich)

Équin + adduction pied → pied bot varus équin

2. Palpation

Palpation symétrique et systématique de toutes les structures

(FIG 7)

Zones palpables

  • Arrière-pied : malléoles, ligaments, tendon d'Achille
  • Médio-pied : os du tarse, bases métatarsiennes, fascia plantaire, tendons
  • Avant-pied : têtes métatarsiennes, phalanges, os sésamoïdes
  • Cou-de-pied : tendons extenseurs, ligne interarticulaire talocrurale
  • Structures vasculaires
(FIG 8)

Douleurs selon localisation

Arrière-pied → arthrose talocrurale/sous-talienne, tendinopathie d'Achille/fascia plantaire, entorse, fracture, enthésite (spondylarthropathie), arthrite, ténosynovite, syndrome radiculaire L5/S1, syndrome tunnel tarsien, algoneurodystrophie, syndrome épine calcanéenne

Médio-pied → arthrose talo-naviculaire/tarso-métatarsienne, tendinopathie tibial postérieur/antérieur, fracture, arthropathie, spondylarthropathie, polyarthrite rhumatoïde, pied de Charcot

Avant-pied → métatarsalgie, hallux valgus, orteils en griffe/marteau, spondylarthropathie, arthrite septique/microcristalline, polyneuropathie diabétique, névralgie de Morton, maladie de Ledderhose

3. Mobilité - Force - Sensibilité

Mobilité active et passive

  • Flexion-extension cheville
  • Inversion-éversion tarse
  • Flexion-extension orteils
(FIG 9)

Tests de force

Mise sur pointe des pieds :

  • Normal : talon valgus à plat → varisation sur pointe
  • Anormal : talon reste valgus → atteinte tibial postérieur
(FIG 10)

Déficits spécifiques

Déficit flexion active (passive normale) → lésion nerf tibial, lésion tendon d'Achille/fléchisseurs

Déficit extension active (passive normale) → lésion nerf fibulaire profond, lésion tendons extenseurs

Déficit inversion active → lésion tibial antérieur/postérieur

Déficit éversion active → lésion tendons fibulaires

Déficit actif + passif → trauma, inflammation, infection

4. Examens spécifiques

Tiroir antérieur

Position : décubitus dorsal, cheville 20° flexion plantaire

Manœuvre : translation antérieure arrière-pied

Test : ligament talofibulaire antérieur

Positif : translation asymétrique, arrêt mou → entorse, lésion ligamentaire

(FIG 11)

Test de Thompson

Position : décubitus ventral, pieds dépassant table

Manœuvre : compression masse musculaire mollet

Normal : flexion plantaire

Positif : absence/diminution flexion → rupture tendon d'Achille

(FIG 12)

Test de Silfverskiöld

Manœuvre : flexion-extension genou en maintenant dorsiflexion

Positif : dorsiflexion présente genou fléchi, réduite genou tendu → raccourcissement gastrocnémiens

(FIG 13)

Signe de Mulder

Position : décubitus dorsal

Manœuvre : palpation espace intermétatarsien + compression avant-pied

Positif : "clic" ou douleur → névrome de Morton

(FIG 14)

Test de Molloy

Position : décubitus dorsal, genoux fléchis

Manœuvre : pouce sur interligne talo-crurale, flexion plantaire puis dorsale

Positif : douleur au point de pression → conflit antéro-latéral (syndrome d'impingement)

(FIG 15)

Test de Windlass

Position : décubitus dorsal/assis ou debout

Manœuvre : extension passive 1ère métatarsophalangienne

Positif : douleur en fin d'extension → fascéite plantaire

(FIG 16)

Test de Tinel

Nerf tibial : percussion sous malléole interne

Positif : paresthésies face plantaire → syndrome tunnel tarsien postérieur

(FIG 17)

Nerf fibulaire : percussion interligne tibio-talaire

Positif : paresthésies face dorsale → syndrome tunnel tarsien antérieur

(FIG 18)

Test de Hopkinson (Squeeze test)

Manœuvre : compression fibula-tibia ou torsion jambe

Positif : douleur → lésion syndesmose/membrane interosseuse, fracture de Maisonneuve

(FIG 19)

Carte de synthèse

Station debout

Inspection

  • Marche : boiterie, pointe/talons, angle du pas
  • Axe : valgus-varus, appui mono/bipodal
  • Aspect : amyotrophie, rougeur, gonflement

Station assis-couché

Inspection

  • Chaussures et plante : points d'appui, hyperkératose
  • Global : tuméfactions, plaies, amyotrophie
  • Avant-pied : orteils en griffe, hallux valgus
  • Médio-pied : pied plat/creux
  • Arrière-pied : déformation Haglund, tendon d'Achille

Palpation

  • Systématique de toutes les structures
  • Recherche épanchement, synovite
  • Points douloureux spécifiques

Mobilité

  • Amplitudes actives et passives
  • Flexion-extension : 50-0-20°
  • Inversion-éversion : 20-0-5°
  • Rotation : 10-0-10°

Tests spécifiques

  • Tiroir antérieur, talus libre/bloqué
  • Thompson, Heel rise test
  • Silfverskiöld, Windlass
  • Mulder, Molloy, Hopkinson
  • Tinel tarsien et péronier
