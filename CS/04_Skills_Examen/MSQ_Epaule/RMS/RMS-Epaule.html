REVUE MÉDICALE SUISSE ÉTUDIANTS

Examen de l'Épaule

1. Inspection

Observation initiale

  • Capacité à se déshabiller
  • Ballant des bras
  • Position antalgique
  • Poignée de main

Analyse de l'allure de l'épaule

Asymétrie horizontale → Paralysie trapèze, surcharge, scoliose

Asymétrie verticale → Scapula alata, luxation acromio-claviculaire, fracture clavicule, scoliose

Épaule rouge, tuméfiée, chaude → Arthrite septique, arthrite micro-cristalline, tendinite calcifiante, bursite sous-acromiale, tendinite coiffe

Masse biceps asymétrique (signe de Popeye) → Tendinopathie biceps avec rupture complète

Voussure avec bras en abduction/rotation externe → Luxation antérieure tête humérale

Dépression avec bras en adduction/rotation interne → Luxation postérieure

Cicatrices cutanées → Chirurgie (rupture coiffe, conflit sous-acromial, luxation)

2. Palpation

Structures anatomiques (FIG 5)

Palpation systématique bilatérale :

  • Articulation sterno-claviculaire
  • Clavicule
  • Articulation acromio-claviculaire
  • Acromion
  • Processus coracoïde
    • Scapula avec épine scapulaire
    • Tête humérale
    • Gouttière bicipitale

Pathologies associées

Douleur clavicule avec voussure → Fracture clavicule

Voussure acromio-claviculaire réductible ("touche de piano") → Lésion ligamentaire acromio-claviculaire

Voussure sterno-claviculaire → Lésion ligamentaire avec possible luxation

Atrophie fosse sus/sous-épineuse → Amyotrophie sus/sous-épineux

Douleur gouttière bicipitale → Tendinopathie bicipitale

Masse asymétrique insertion distale tendon bicipital (signe de Popeye) → Rupture tendon biceps

3. Mobilité et force

Mobilité active et passive

Abduction (FIG 6)

Déficit → Rupture sus-épineux, lésion nerf axillaire

Douleur en cours de mouvement → Conflit sous-acromial

Flexion (FIG 8)

Test : lever les bras par devant (plan sagittal)

Extension (FIG 9)

Test : lever les bras par derrière

Rotation interne-externe (FIG 7)

Déficit rotation interne → Atteinte rotateurs internes

Déficit rotation externe → Atteinte rotateurs externes

Interprétation clinique

Déficit actif sans déficit passif → Atteinte musculaire ou neurologique

Déficit actif et passif → Atteinte articulaire ou ligamentaire (capsulite rétractile)

Diminution amplitude généralisée → Capsulite rétractile

Diminution amplitude spécifique → Rupture tendon coiffe

4. Tests spécifiques de la coiffe des rotateurs

Test de Jobe (FIG 10)

  • Bras à 90° abduction, 30° antéflexion, pouces vers le bas
  • Résistance contre force vers le bas

Test positif → Rupture sus-épineux, tendinopathie, conflit sous-acromial, bursite

Test du Lift-off (FIG 11)

  • Mains au niveau lombaire, paumes vers l'extérieur
  • Décoller les mains et maintenir

Test positif → Atteinte subscapulaire (partie inférieure)

Test du Belly press (FIG 12)

  • Appuyer sur l'abdomen, maintenir rotation interne
  • Coudes alignés avec le corps

Test positif → Atteinte subscapulaire (partie supérieure)

Test de Patte (FIG 13)

  • Bras à 90° abduction, coudes fléchis à 90°
  • Rotation externe contre résistance

Test positif → Atteinte petit rond

Test du portillon (FIG 14)

  • Rotation externe maximale passive
  • Patient ramène avant-bras en rotation interne

Signe du portillon positif → Atteinte sous-épineux

Signe du Clairon (FIG 15)

  • Porter la main à la bouche

Test positif (coude levé) → Atteinte rotateurs externes (petit rond, sous-épineux)

Test du Palm-up (FIG 16)

  • Bras tendus devant en supination
  • Résistance contre force vers le bas

Test positif → Tendinopathie bicipitale, subluxation biceps, lésion labrum, conflit sous-acromial

Test de Yergason (FIG 17)

  • Bras fléchi à 90°
  • Supination contre résistance

Test positif → Tendinopathie long chef biceps

5. Recherche de conflits

Arc douloureux (FIG 18)

Douleur 60-120° → Conflit sous-acromial

Douleur 120-170° → Atteinte acromio-claviculaire

Douleur tout le mouvement → Atteinte gléno-humérale (épaule gelée, arthrose)

Test de Neer (FIG 19)

  • Flexion passive maximale, bras en pronation
  • Main stabilise la scapula

Douleur 90-120° → Conflit sous-acromial, atteinte sus-épineux

Test de Hawkins-Kennedy (FIG 20)

  • Abduction 90°, coude fléchi 90°
  • Rotation interne passive de l'avant-bras

Test positif → Conflit sous-acromial, pathologie coiffe (sus-épineux)

Test de Yocum (FIG 21)

  • Main sur épaule controlatérale
  • Lever le coude contre résistance

Test positif → Conflit sous-acromial

Body-cross test (test d'adduction forcée) (FIG 22)

  • Adduction horizontale maximale passive

Douleur acromio-claviculaire → Conflit articulation acromio-claviculaire

6. Laxité et instabilité

Tests de laxité

Tiroir antérieur et postérieur (FIG 23)

  • Stabilisation scapula
  • Translation antéro-postérieure tête humérale

Différence entre épaules → Laxité antéro-postérieure gléno-humérale

Tiroir inférieur (FIG 24)

  • Pression vers le bas
  • Recherche sillon humérus-acromion

Sillon présent → Laxité inférieure

Tests d'instabilité

Test d'appréhension antérieur (FIG 25)

  • Bras 90° flexion, 90° abduction
  • Rotation externe + poussée tête humérale en avant

Test positif → Lésion complexe capsulo-ligamentaire

Test d'appréhension postérieur (FIG 26)

  • Bras 90° flexion antérieure, coude fléchi 90°, rotation interne
  • Poussée tête humérale en arrière

Test positif → Lésion complexe capsulo-ligamentaire

Anatomie fonctionnelle

Articulations

  • Gléno-humérale : Non congruente, grande mobilité
  • Sterno-costo-claviculaire : Stabilisée par complexe ligamentaire
  • Acromio-claviculaire : Stabilisée par ligaments coraco-claviculaires

Coiffe des rotateurs (FIG 3)

  • Sus-épineux : Abduction
  • Sous-épineux : Rotation externe
  • Petit rond : Rotation externe (surtout en abduction)
  • Subscapulaire : Rotation interne

Plans de glissement (FIG 4)

  • Plan omo-thoracique : Glissement scapula sur grille thoracique
  • Plan sous-acromial : Passage tendons sus/sous-épineux → Site conflit sous-acromial

Points clés

  • Stabilisation dynamique par la coiffe des rotateurs
  • Coiffe impliquée dans >60% des épaules douloureuses
  • Récidive luxation : 50-80%
  • Conflit sous-acromial : acromion proéminent, ostéophytes, dégénérescence tendineuse
