# 🟠 Glande surrénale (Nebenniere) — vue d'ensemble

## CORTEX (NNR) — hormones stéroïdes

- Précurseur commun : **Cholestérol** (surtout des lipoprotéines plasmatiques)
- Étape limitante : Cholestérol → Pregnénolone (hydrolase/desmolase, cytochrome P450)

### Zona glomerulosa → Minéralocorticoïdes : **ALDOSTÉRONE**

- Stimulus : **Angiotensine II** (& ACTH)
- Système Rénine-Angiotensine-Aldostérone (RAAS)
  - Rénine produite par l'appareil juxta-glomérulaire du rein
  - Angiotensinogène → (rénine) → Angiotensine I → (ECA, surtout poumon) → **Angiotensine II**
- Effet principal : **↑ réabsorption de Na+** dans le rein (et autres organes : glandes salivaires, côlon)
  - → ↓ concentration de Na+ dans urine, sueur, selles
  - → rétention hydro-sodée, perte de K+

### Zona fasciculata → Glucocorticoïdes : **CORTISOL**

- Stimulus : **ACTH**
- Effets physiologiques (p.39) : ↑ néoglucogenèse, ↑ glycogénogenèse, lipolyse, ↓ captation périphérique du glucose (muscle, graisse)
- Cardiovasculaire/rénal : ↑ débit cardiaque, ↑ résistances périphériques, ↑ GFR
- Système immunitaire : anti-inflammatoire / immunosuppresseur
- Pic au petit matin (rythme circadien)

### Zona reticularis → Stéroïdes sexuels : **ANDROGÈNES**

- Stimulus : **ACTH** (& cortisol)
- Produits : DHEA, **DHEA-sulfate (produit de sécrétion principal)**, Androstènedione
- Action androgène faible ; conversion périphérique → testostérone & DHT (plus puissants)

## MÉDULLAIRE (NNM) — cellules chromaffines

- Sécrétion de **catécholamines** : Adrénaline & Noradrénaline
- Stimulus : **sympathique** (sécrétion stimulée par l'acétylcholine des fibres pré-ganglionnaires)
- Synthèse : Phénylalanine → Tyrosine → DOPA → Dopamine → Noradrénaline → Adrénaline
- Récepteurs (p.48)
  - α1 : contraction → vasoconstriction (surtout territoire splanchnique)
  - α2 : présynaptique → inhibition de la libération de transmetteur
  - β1 : myocarde (inotrope/chronotrope/dromotrope +), ↑ glycogénolyse/néoglucogenèse hépatique, libération de rénine
  - β2 : muscle lisse → vasodilatation, bronchodilatation ; lipolyse
  - β3 : tissu adipeux → lipolyse & thermogenèse
