## Complétude — présent dans la source mais omis du diagramme (volontairement, hors scope « vue d'ensemble des 3 zones »)

- **Axe corticotrope HPA détaillé** (CRH → ACTH → cortisol, POMC, feedback négatif) — p.39 : volontairement omis car couvert ailleurs (ancre HPA dédiée, cf. consigne).
- **Transport sanguin du cortisol** (CBG/CBP 75%, albumine 15%, 10% libre ; pool protéique ; CBG↑ hyperthyroïdie/grossesse, CBG↓ hypothyroïdie) — p.38 : omis (détail biochimique).
- **Spécificité minéralocorticoïde via 11β-HSD** (le cortisol se lie au récepteur MC ; 11β-DH inactive les glucocorticoïdes dans les tissus cibles ; déficit 11β-DH → pseudo-hyperaldostéronisme ; réglisse/glycyrrhétine = inhibiteur) — p.38-39 : omis (mécanisme avancé).
- **Puissance relative des corticoïdes** (cortisol 1×, cortisone 0,7×, prednisolone 4×, dexaméthasone 25×) — p.39 : omis.
- **Enzymopathies de la stéroïdogenèse** (21-hydroxylase, 11β-hydroxylase, 17α-hydroxylase, 18-hydroxylase/déshydrogénase) — p.38 : omis (relève du bloc « bloc enzymatique / AGS »).
- **Métabolisme des catécholamines** (uptake neuronal, COMT → métanéphrine/normétanéphrine, MAO → DOPEG/DHMS, VMA urinaire ; HWZ courte) — p.48 : omis (détail biochimique).
- **Proportion NA/A médullaire et origine** : la source (p.48) écrit « 80% NA, 20% NA » (coquille manifeste : la médullosurrénale produit majoritairement de l'adrénaline) ; « seulement ~30% de la NA circulante vient du NNM, le reste des terminaisons sympathiques » — omis du diagramme pour éviter de propager la coquille (voir incertitudes).
- **Pathologies** (insuffisance surrénalienne / Addison p.43-44, syndrome de Cushing, Conn/hyperaldostéronisme p.46-47, phéochromocytome p.49, AGS p.41) — omises : le diagramme cible la physiologie/anatomie de la vue d'ensemble, pas les maladies.
