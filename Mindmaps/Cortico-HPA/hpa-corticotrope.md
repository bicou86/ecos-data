# Axe corticotrope (HPA)

## 1. Hypothalamus → CRH

- **CRH** (corticolibérine) `[socle]`
  - stimulée par le stress, rythme circadien (pic matinal) `[socle]`

## 2. Hypophyse antérieure → ACTH

- **ACTH** (corticotrophine) `[socle]`
  - stimule le cortex surrénalien `[socle]`
  - **rétrocontrôle négatif** par le cortisol `[socle]`

## 3. Surrénale (cortex) → Cortisol

- **Cortisol** (zone fasciculée) `[socle]`
  - **Effets** _(via présentation de Cushing)_ `[CK]`
    - ↑ glycémie / diabète
    - HTA
    - prise de poids facio-tronculaire
    - catabolisme musculaire (faiblesse des jambes)
    - fragilité cutanée (ecchymoses)
    - aménorrhée
    - ostéoporose (corticothérapie chronique)

## 4. Excès → Cushing `[CK]`

- **Étiologies**
  - Hypophysaire (adénome) ≈ 80 % → ACTH normal/élevé _(maladie de Cushing)_
  - Ectopique (K poumon à petites cellules) → ACTH élevé
  - Surrénalien (adénome/carcinome) → ACTH bas
  - **Iatrogène (corticoïdes exogènes) = 1ʳᵉ cause**
- **Dépistage** : cortisol libre urinaire 24 h (= 17-OH corticoïdes) — **pas** le cortisol basal

## 5. Déficit → Insuffisance surrénale `[CK]`

- **Primaire (Addison)**
  - test au **Synacthène** (cortisol après stimulation ACTH)
  - mélanodermie, hypoNa, hyperK, hypoglycémie
- **Iatrogène** : arrêt brutal d'une corticothérapie chronique → insuffisance surrénale aiguë
